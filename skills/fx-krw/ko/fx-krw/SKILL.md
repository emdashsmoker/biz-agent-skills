# fx-krw

글에 나오는 외화 금액 옆에 원화 환산액을 적는다. 환율은 Frankfurter API에서 받아오고 평균과 곱셈은 `scripts/convert.py`가 한다. 언어 모델이 기억에 기대어 환율을 적으면 틀린 숫자가 그럴듯한 모양으로 들어가기 쉽다. 그래서 환율과 환산액은 모두 스크립트 출력에서 가져온다.

## 지켜야 할 원칙

- 환율 값과 원화 환산액은 스크립트 출력만 쓴다. 모델은 환율을 추정하지 않고 외화와 원화 사이의 산술도 직접 하지 않는다.
- 금액의 성격과 시점에 맞는 환율을 쓴다. 과거 실적에 오늘 환율을 적용하지 않는다.
- 환산에 쓴 환율의 기준일 또는 기간, 통화쌍, 값, 조회 URL을 인용 블록으로 남긴다. 독자는 이 URL로 같은 값을 다시 조회할 수 있다.

## 작업 순서

### 1단계. 외화 금액 찾기

본문에서 아래 표기를 모두 찾는다. 원화 기호 ₩와 "원"은 대상이 아니다.

| 표기 방식 | 예 |
|---|---|
| ISO 4217 코드 | USD, EUR, JPY, CNY, GBP, HKD, SGD, AUD, CAD, CHF, TWD, INR |
| 통화 기호 | $, €, ¥, £ |
| 한국어 통화명 | 달러, 유로, 엔, 위안, 파운드, 홍콩달러, 싱가포르달러 |
| 영어 통화명 | dollar, euro, yen, yuan, pound |
| 약칭 단위가 붙은 표기 | $391B, €1.5M, ¥100B |

### 2단계. 적용할 환율 정하기

기본값은 국제회계기준 IAS 21의 외화 환산 방식이다. IAS 21은 자산과 부채를 보고일 환율로, 수익과 비용을 거래일 환율로 환산하도록 정한다. 거래일 환율 대신 기간 평균 환율을 쓰는 방법도 허용한다(IAS 21 문단 39, 40). 이 스킬은 개별 거래일을 알 수 없는 글을 다루므로 기간 금액에 기간 평균 환율을 쓴다.

금액의 성격을 먼저 가르고 아래 표에서 환율을 고른다.

| 금액의 성격 | 예 | 적용 환율 | 스크립트 인자 |
|---|---|---|---|
| 특정 날짜의 거래액 | 2023년 6월 15일 계약 금액 | 그 날짜의 환율 | `--date 2023-06-15` |
| 기간 동안 쌓인 금액 | 연간 매출, 분기 비용, 월간 수출액, 연간 시장 규모, 연간 투자액 | 그 기간의 일별 평균 환율 | `--start 2022-01-01 --end 2022-12-31` |
| 특정 시점의 잔액 | 연말 총자산, 부채, 외환보유액, 특정일 시가총액 | 그 시점의 환율. 연도만 적혀 있으면 그 해의 마지막 날 | `--date 2022-12-31` |
| 현재 값, 시점 표시가 없는 값, 미래 전망 | 현재 시가총액, 2030년 시장 규모 전망 | 가장 최근 값 | 인자 생략 |

- 기간 금액과 잔액을 가르기 어려우면 기간 금액으로 본다.
- 기간의 시작과 끝은 금액이 가리키는 기간을 그대로 쓴다. 달력 연도면 1월 1일부터 12월 31일, 월이면 그 달의 첫날부터 마지막 날이다.
- 회계연도가 12월에 끝나지 않는 기업은 그 회계연도의 첫날과 마지막 날을 쓴다. 9월 결산 기업의 2022 회계연도는 2021-10-01부터 2022-09-30까지다.
- 기간이 오늘을 넘어가면(예: 올해 누적 매출) 스크립트는 조회 가능한 마지막 날까지만 평균한다. 출처 줄에는 실제로 평균에 들어간 첫날과 마지막 날이 찍힌다.
- 시점을 판단하기 어려우면 가장 최근 값을 쓴다.
- 미래 날짜는 API에 값이 없어 오류가 난다. 전망치는 날짜 인자 없이 조회한다.
- 데이터 시작일은 통화마다 다르다. 원화 환율은 1981년 1월 2일부터 조회된다(2026년 9월 확인). 통화별 시작일은 `https://api.frankfurter.dev/v2/currencies`에서 확인한다.

#### 기말 환율 옵션

사용자가 "기말 환율", "연말 환율", "기간 마지막 날 환율로" 등을 요청하면 기간 금액에도 `--start`와 `--end` 대신 `--date`에 기간의 마지막 날을 넣는다. 나머지 세 경우는 기본값과 같다.

| 금액의 성격 | 기본값 | 기말 환율 옵션 |
|---|---|---|
| 2022년 연간 매출 | `--start 2022-01-01 --end 2022-12-31` | `--date 2022-12-31` |
| 2023년 6월 수출액 | `--start 2023-06-01 --end 2023-06-30` | `--date 2023-06-30` |

### 3단계. 금액을 숫자 전체로 바꾸기

스크립트는 B, M, 억 같은 약칭 단위를 읽지 못한다. 모델이 금액을 숫자 전체로 바꿔 `--amount`에 넣는다. 이 단계는 자릿수만 바꾸며 환율 계산은 하지 않는다.

| 원래 표기 | `--amount` 값 |
|---|---|
| $391B | 391000000000 |
| €1.5M | 1500000 |
| ¥100B | 100000000000 |
| £750k | 750000 |
| $1.2T | 1200000000000 |
| 50억 달러 | 5000000000 |
| 3,000만 유로 | 30000000 |

### 4단계. 스크립트 실행

통화명은 ISO 4217 코드로 바꿔 넣는다(아래 "통화명과 코드" 참조).

```bash
# 최근 환율로 한 건 환산
python <스킬 폴더>/scripts/convert.py --amount 391000000000 --currency USD

# 특정 날짜 환율로 한 건 환산
python <스킬 폴더>/scripts/convert.py --amount 100000000 --currency JPY --date 2020-03-15

# 기간 평균 환율로 한 건 환산
python <스킬 폴더>/scripts/convert.py --amount 391000000000 --currency USD --start 2024-01-01 --end 2024-12-31

# 특정 제공기관(예: 유럽중앙은행) 값만 사용
python <스킬 폴더>/scripts/convert.py --amount 1500000 --currency EUR --provider ECB

# 여러 건을 한 번에 환산
python <스킬 폴더>/scripts/convert.py --batch '[{"amount":391000000000,"currency":"USD","start":"2024-01-01","end":"2024-12-31"},{"amount":50000000,"currency":"EUR","date":"2024-06-30"}]'
```

- `--date`와 `--start`/`--end`는 함께 쓰지 않는다. `--start`와 `--end`는 둘 다 넣는다.
- 기간 평균은 API가 돌려준 기간 안의 일별 값을 단순 평균한 값이다. 여러 기관 값을 합친 기본값은 주말을 포함한 매일 값이 있고, 특정 제공기관을 지정하면 그 기관이 공표한 날의 값만 들어간다.
- 한 글에 외화 금액이 3개 이상이면 `--batch`로 한 번에 처리한다. 통화, 날짜 또는 기간, 제공기관이 같은 금액은 환율을 한 번만 조회한다.
- `--batch`에서 한 건이 실패해도 나머지 결과는 정상으로 나온다. 실패한 건은 `error`와 `hint` 필드에 이유가 담긴다.
- `--provider`를 생략하면 여러 기관 값을 합친 Frankfurter 값을 쓴다. 제공기관 코드 목록은 `https://api.frankfurter.dev/v2/providers`에 있다.

### 5단계. 결과 넣기

스크립트 출력(JSON)의 `inline` 값으로 원래 금액 표기를 바꾼다. `footnote` 값은 그 금액이 있는 목록 항목이나 문단 바로 뒤에 넣는다.

### 처리 예시

2단계에서 5단계까지를 원문별로 적용하면 아래와 같다. 회사명과 금액은 설명용이다.

| 원문 | `--amount` | `--currency` | 환율 인자 | 환율을 정한 이유 |
|---|---|---|---|---|
| A사 2023년 매출 $96.8B | 96800000000 | USD | `--start 2023-01-01 --end 2023-12-31` | 기간 동안 쌓인 금액 |
| B사 2023년 말 총자산 $120B | 120000000000 | USD | `--date 2023-12-31` | 특정 시점의 잔액 |
| 2030년 시장 규모 1.5조 달러 전망 | 1500000000000 | USD | 생략 | 미래 전망 |
| C사 시가총액 약 $3.5T | 3500000000000 | USD | 생략 | 시점 표시 없음 |
| D사 2024년 매출 $391B | 391000000000 | USD | `--start 2024-01-01 --end 2024-12-31` | 기간 동안 쌓인 금액 |
| E사 2024년 매출 €175B | 175000000000 | EUR | `--start 2024-01-01 --end 2024-12-31` | 기간 동안 쌓인 금액 |

마지막 두 줄처럼 한 글에 금액이 여럿이면 `--batch`로 묶어 한 번에 실행한다.

## 출력 형식

아래 예시의 `<>` 부분에는 스크립트가 돌려준 값이 들어간다.

```
- A사의 2024년 매출은 3,910억 달러(약 <원화 환산액>)

> Frankfurter(2024), 2024-01-01 - 2024-12-31 USD/KRW 일별 평균 환율 <환율>원(https://api.frankfurter.dev/v2/rates?from=2024-01-01&to=2024-12-31&base=USD&quotes=KRW)

- A사의 2024년 말 총자산은 1,200억 달러(약 <원화 환산액>)

> Frankfurter(2024), 2024-12-31 USD/KRW 환율 <환율>원(https://api.frankfurter.dev/v2/rate/USD/KRW?date=2024-12-31)
```

- 출처 줄은 "기관명(연도), 자료명(링크)" 형식을 따른다. `--provider`를 쓰지 않으면 기관명은 Frankfurter이고, 쓰면 해당 기관명(ECB, FRED 등)이 들어간다.
- 기간 평균의 출처 줄에는 실제로 평균에 들어간 첫날과 마지막 날이 적힌다. 연도는 마지막 날의 연도다.
- 같은 기준일 또는 같은 기간, 같은 통화쌍의 출처 줄은 글에서 처음 나올 때 한 번만 적는다.
- 기준일, 기간, 통화쌍 중 하나라도 다르면 출처 줄을 따로 적고 블록 사이에 빈 줄을 둔다.
- 다른 통계의 출처 블록과 붙어 있으면 빈 줄로 나눈다.

### 숫자 표기

스크립트가 금액을 조, 억, 만 단위로 바꿔 준다. 모델은 `inline` 값을 고치지 않고 그대로 쓴다. 규칙은 다음과 같으며 소수점 끝자리의 0은 지운다.

| 금액 범위 | 표기 | 예 |
|---|---|---|
| 1조 이상 | 1,000조 미만은 소수점 둘째 자리까지, 1,000조 이상은 정수 | 1.5조, 14.73조, 1,514조 |
| 1억 이상 1조 미만 | 100억 미만은 소수점 첫째 자리까지, 100억 이상은 정수 | 1.5억, 14.7억, 3,910억 |
| 1만 이상 1억 미만 | 100만 미만은 소수점 첫째 자리까지, 100만 이상은 정수 | 1.5만, 14.7만, 1,500만 |
| 1만 미만 | 정수 | 9,800 |

출처 줄의 환율은 소수점 둘째 자리까지 적는다. 1보다 작은 환율(예: 베트남 동)은 넷째 자리까지 적는다.

## 통화명과 코드

| 통화명, 기호 | 코드 | 통화명, 기호 | 코드 |
|---|---|---|---|
| 달러, $ | USD | 유로, € | EUR |
| 엔, ¥ | JPY | 위안, 元 | CNY |
| 파운드, £ | GBP | 홍콩달러 | HKD |
| 싱가포르달러 | SGD | 호주달러 | AUD |
| 캐나다달러 | CAD | 스위스프랑 | CHF |
| 대만달러 | TWD | 루피 | INR |
| 바트 | THB | 동(베트남) | VND |

"$" 하나만 적힌 금액은 미국, 캐나다, 호주, 홍콩, 싱가포르 달러일 수 있다. 자료를 낸 나라 등 주변 정보로 통화를 정하고, 정할 수 없으면 USD로 본다. 이때 본문에 가정을 적는다.

```
- (가정) "$" 표기는 미국 자료이므로 USD로 해석
```

지원 통화 전체 목록은 `https://api.frankfurter.dev/v2/currencies`에 있다.

## 예외 처리

| 상황 | 스크립트 신호 | 처리 |
|---|---|---|
| 네트워크 오류나 API 장애 | `URLError` 또는 5xx 오류 | 그 금액은 외화 표기만 남기고 글 끝에 조회 실패를 적는다 |
| 지원하지 않는 통화 (소수 통화, 디지털 자산 등) | 422 오류 | 외화 표기만 남기고 해당 항목에 사유를 적는다 |
| 날짜에 값이 없음 | 404 오류 | 미래 날짜면 날짜 인자 없이 다시 조회한다. 데이터 시작일 이전이면 지원하지 않는 통화와 같이 처리한다 |
| 기간 전체에 값이 없음 | `NoRateData` 오류 | 기간 전체가 미래면 날짜 인자 없이 다시 조회한다. 데이터 시작일 이전이면 지원하지 않는 통화와 같이 처리한다 |
| 통화 단위가 모호함 | 없음 | 가장 가능성이 높은 통화로 환산하고 본문에 가정을 적는다 |

조회 실패와 미지원 통화는 아래처럼 적는다.

```
> (환율 조회 실패) Frankfurter API가 응답하지 않아 일부 외화의 원화 병기를 생략함. 나중에 다시 조회 필요

- (해당 외화) Frankfurter 미지원 통화로 원화 병기 생략
```

## 환산하지 않는 경우

- 통화 기호가 금액 표시 이외의 용도로 쓰인 경우. 변수명, 정규표현식, 코드 리터럴의 "$"가 여기에 해당한다.
- 사용자가 특정 금액의 병기를 빼 달라고 한 경우.
- 외화 단위 그대로 비교해야 뜻이 통하는 경우. 글로벌 매출 순위나 외화 기준 시계열이 여기에 해당하며 사용자가 일부 또는 전체 생략을 정할 수 있다.

## 환율 값과 외부 서비스

- Frankfurter 값은 각국 중앙은행과 공공기관이 공표한 기준 환율을 모은 값이다. 은행 창구나 카드 결제에 쓰는 매매 환율과는 다르다.
- `--provider`를 생략하면 여러 기관 값을 합친 값이 나온다. 새 데이터가 들어오면 소수점 끝자리가 바뀔 수 있으므로 같은 URL을 나중에 조회하면 값이 조금 다를 수 있다. 값을 고정해야 하는 글은 `--provider`로 기관 하나를 지정한다.
- Frankfurter는 제3자가 운영하는 공개 서비스다. API 키 없이 쓸 수 있고 과도한 호출은 제한된다. 환율 데이터의 이용 조건은 각 제공기관의 약관을 따르므로 글을 배포할 때 출처 줄을 지우지 않는다.
- Frankfurter를 자체 서버에 설치해 쓰려면 `scripts/convert.py` 상단의 `API_BASE` 값을 그 서버 주소로 바꾼다.

## 실행 환경

- Python 3.8 이상
- 표준 라이브러리만 사용하므로 추가 설치가 없다
- `api.frankfurter.dev`에 접속할 수 있는 인터넷 연결
