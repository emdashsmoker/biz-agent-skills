# 연평균 성장률 계산

두 시점의 값으로 연평균 성장률(CAGR)을 계산한다. 모델이 머릿속으로 계산한 숫자는 과정이 남지 않아 맞는지 확인할 수 없다. 그래서 결과는 코드를 실행해 얻은 값만 쓴다.

## 입력

계산에는 아래 네 값이 필요하다.

- 기준연도값 (시작 시점의 값)
- 마지막연도값 (끝 시점의 값)
- 기준연도
- 마지막연도

사용자가 "2020년 1,200억 원에서 2025년 1,850억 원" 같은 문장으로 주더라도 네 값을 뽑아서 쓴다. 두 값은 같은 단위여야 한다. 네 값 가운데 하나라도 빠지면 사용자에게 묻는다.

## 계산식

```
CAGR = (마지막연도값 / 기준연도값) ^ (1 / n) - 1
n = 마지막연도 - 기준연도
```

n은 두 연도의 차이다. 2020년부터 2025년까지라면 데이터가 6개 연도에 걸쳐 있어도 n은 5다.

계산식이 성립하려면 아래 조건을 모두 만족해야 한다. 스크립트는 조건에 맞지 않는 입력을 받으면 이유만 출력하고 멈춘다.

- 마지막연도가 기준연도보다 크다
- 기준연도값이 0보다 크다
- 마지막연도값이 0 이상이다

## 계산 방법

Python을 실행할 수 있으면 동봉된 스크립트를 실행한다. 천 단위 쉼표는 그대로 넣어도 된다.

```bash
python scripts/cagr.py <기준연도값> <마지막연도값> <기준연도> <마지막연도>
```

스크립트는 기본적으로 결과를 반올림하지 않는다. 사용자가 소수점 자릿수를 정해 달라고 하면 `--decimals` 옵션을 붙인다. 예를 들어 `--decimals 2`는 소수점 둘째 자리까지 반올림한다.

Python은 없지만 다른 언어를 실행할 수 있으면 같은 식을 그 언어로 작성해 실행한다. JavaScript라면 아래와 같다.

```javascript
const startValue = 기준연도값;
const endValue = 마지막연도값;
const n = 마지막연도 - 기준연도;

console.log('기준연도값:', startValue);
console.log('마지막연도값:', endValue);
console.log('기간(년):', n);

const cagr = Math.pow(endValue / startValue, 1 / n) - 1;
console.log('CAGR(%):', cagr * 100);
```

코드를 실행할 수 있는 환경이 전혀 없으면 위 코드에 값을 채워 출력한다. 결과값은 사용자가 직접 실행해 확인하도록 안내한다.

## 출력 형식

답변은 아래 두 부분으로만 구성한다.

- `# 계산과정` 아래에는 실행한 명령과 출력 결과를 코드 블록에 담는다.
- `# 계산결과` 아래에는 결과값 하나만 % 단위로 코드 블록에 담는다. 사용자가 그대로 복사해 쓰기 위해서다.

예시 입력: 2020년 1,200, 2025년 1,850

````markdown
# 계산과정
```
$ python scripts/cagr.py 1,200 1,850 2020 2025
기준연도값: 1200
마지막연도값: 1850
기간(년): 2025 - 2020 = 5
계산식: (1850 / 1200) ^ (1 / 5) - 1
CAGR(%): 9.043076613444189
```

# 계산결과
```
9.043076613444189%
```
````
