# 사내 초거대AI 도입 검토

## 내년 상반기 사내 서버 설치 방식의 초거대AI 시범 도입 권고
- 품질팀과 설계팀의 과거 문서 검색과 보고서 초안 작성은 초거대AI로 처리 시간 단축을 기대할 수 있는 업무
> (초거대AI) ChatGPT처럼 방대한 글을 학습하여 사람의 질문에 맞춰 답변과 문서를 만들어 내는 인공지능(AI)

- 사내 서버 설치 방식으로 현행 보안 규정 안에서 외부 초거대AI 서비스에 가까운 성능 확보 가능
- 전사 확대 여부는 두 팀의 내년 1-6월 시범 운영에서 측정한 효과로 결정
- AI 비용의 추가 하락을 기다리는 도입 연기보다 소규모 시범 착수가 유리
    + 문서 수집과 현재 소요 시간 측정은 도입 시점과 관계없이 필요한 준비 작업
    + 사내 서버의 AI는 이후 성능이 나은 모델로 교체 가능

## 품질팀과 설계팀의 문서 업무가 첫 적용 대상으로 적합
- 두 팀은 과거 문서 검색과 보고서 초안 작성에 업무 시간이 많이 든다고 호소
- 두 업무는 초거대AI의 문서 이해와 글 작성 기능으로 처리 시간을 줄일 수 있는 유형에 해당
    + (문서 검색) 질문 문장 입력으로 과거 불량 원인 분석 문서와 설계 변경 문서 검색 가능
    + (초안 작성) 과거 보고서의 양식과 내용을 참고하여 새 보고서 초안 작성
- 시범 준비 단계에서 현재 소요 시간과 문서 보관 실태 확인 필요
    + 두 팀의 호소에는 업무별 소요 시간 수치가 없어 시범 효과를 비교할 기준 마련 필요
    + AI 검색 대상이 저장소에 등록한 문서로 한정되어 과거 문서의 보관 위치 파악이 선행 과제

## 사내 서버 설치 방식의 시범 도입은 현행 여건에서 실행 가능
- (보안) 사내 서버에 설치한 초거대AI는 업무 문서를 회사 밖으로 보내지 않아 현행 보안 규정에 부합
    + 현행 규정은 외부 초거대AI 서비스에 업무 문서 입력을 금지
    + 문서 저장, 질문 입력, 답변 생성의 전 과정이 사내 서버 안에서 처리
- (성능) 사내 설치가 가능한 공개형 초거대AI의 성능이 비공개 초거대AI에 근접
    + 스탠퍼드 인간중심AI연구소의 「AI Index Report 2025」에 따르면 일부 성능 평가에서 두 유형의 성능 차이가 1년 사이 8%에서 1.7%로 축소
    + 범용 성능 평가 결과가 한국어로 작성된 당사 품질 문서와 설계 문서에서도 나타나는지는 시범 운영으로 확인 필요
> (공개형 초거대AI) 개발사가 학습을 마친 파일을 배포하여 기업이 내려받아 자체 서버에 설치할 수 있는 초거대AI

- (비용) 같은 성능을 내는 초거대AI의 답변 생성 비용이 빠르게 하락
    + 같은 보고서에 따르면 2022년 11월 ChatGPT 출시 당시 수준의 성능을 내는 초거대AI의 답변 생성 비용은 2024년 10월까지 280분의 1 아래로 하락
    + 당사 시범 비용은 서버 장비 규모와 문서 연결 범위에 따라 달라져 구축 업체 견적으로 확정 필요
> Stanford HAI(2025), AI Index Report 2025(https://hai.stanford.edu/ai-index/2025-ai-index-report)

- (운영 인력) IT팀의 AI 전담 인력 부재는 외부 구축 업체 위탁으로 보완 가능
    + IT팀 5명 가운데 AI 전담 인력이 없어 AI 설치와 문서 연결의 자체 수행 곤란
    + 구축 업체가 설치, 문서 연결, 시범 기간 운영 지원을 담당
    + IT팀 운영 담당자 1명은 구축 업체와 공동 운영으로 시범 종료 전 운영 방법 습득

## 단계별 시범 운영의 측정 결과로 전사 확대 여부 결정
- 시범 도입은 올해 11월 업체 선정부터 내년 6월 평가까지 8개월 일정으로 진행

| 단계 | 기간 | 주요 활동 | 산출물 |
|---|---|---|---|
| 업체 선정 | 올해 11-12월 | 구축 업체 견적 접수, 업체 선정, 시범 예산 확정 | 업체 계약 및 시범 예산 |
| 설치 | 내년 1-2월 | 대상 문서 수집, 사내 서버 설치, 현재 소요 시간 측정 | 문서 저장소 및 기준 소요 시간 |
| 운영 | 내년 3-5월 | 두 팀 실무자의 문서 검색과 보고서 초안 작성에 활용 | 이용 기록 및 오답 사례 |
| 평가 | 내년 6월 | 판단 기준별 결과 정리와 경영진 보고 | 전사 확대 여부 결정안 |

- 시범 예산은 자체 재원으로 편성
    + 2023년 4월 과학기술정보통신부가 발표한 「초거대 AI 경쟁력 강화방안」의 컴퓨팅 자원 지원 대상은 중소기업, 벤처기업, 대학, 연구소로 중견기업인 당사는 미포함
    + 같은 방안의 플래그십 프로젝트 분야는 법률, 의료, 심리상담, 문화예술, 학술연구로 제조 분야 미포함
> 과학기술정보통신부(2023), 초거대 AI 경쟁력 강화에 3901억 투입…"디지털 경제 가속화"(https://www.korea.kr/news/policyNewsView.do?newsId=148913885)

- 시범 기간 중 AI가 만든 검색 결과와 초안은 실무자가 근거 문서와 대조한 뒤 활용
    + 초거대AI는 문서에 없는 내용을 사실처럼 답하는 오류 발생 가능
    + 대조 과정에서 찾은 오답 사례는 답변 정확도 평가 자료로 활용
- 전사 확대 여부는 시간 단축, 답변 정확도, 비용 대비 효과로 판단
    + (시간 단축) 기준 소요 시간 대비 문서 검색과 보고서 초안 작성 시간의 단축 폭 측정
    + (답변 정확도) AI 답변과 AI가 근거로 제시한 사내 문서의 내용 일치 비율 산정
    + (비용 대비 효과) 단축 시간의 인건비 환산액을 연간 운영 비용과 비교
