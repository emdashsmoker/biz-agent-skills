중견 제조기업 경영진 회의에 올릴 「사내 초거대AI 도입 검토」 보고서를 써 줘. 아래 자료 묶음과 사내 현황을 근거로 써 줘.

- 독자는 AI 비전문가인 대표이사와 본부장들이야
- 보고서를 읽고 내년 상반기 시범 도입 여부를 결정할 예정이야
- 분량은 A4 2쪽 안팎으로 맞춰 줘

## 자료 묶음

1. 스탠퍼드 인간중심AI연구소(HAI)의 「AI Index Report 2025」에 따르면 GPT-3.5 수준 성능을 내는 시스템의 추론 비용은 2022년 11월부터 2024년 10월 사이에 280배 넘게 하락했다.
2. 같은 보고서에 따르면 AI를 사용한다고 답한 기업의 비율은 2023년 55%에서 2024년 78%로 늘었다.
3. 같은 보고서에 따르면 일부 벤치마크에서 공개 가중치(open-weight) 모델과 비공개 모델의 성능 차이가 1년 사이에 8%에서 1.7%로 줄었다.
4. 과학기술정보통신부는 2023년 4월 「초거대 AI 경쟁력 강화방안」을 발표했다. 2023년 3,901억 원 투입을 시작으로 2027년까지 학습용 데이터 200종과 한국어 말뭉치 130종을 구축하고, 중소·벤처기업과 대학, 연구소에 제공하는 컴퓨팅 자원을 TF급에서 PF급으로 늘리며, 법률, 의료, 심리상담, 문화·예술, 학술·연구 분야의 5대 플래그십 프로젝트를 추진하는 내용이다. 공무원 대상 공공부문 활용 가이드라인 마련도 포함했다.
