# 정형 표현과 메타 서술

두 가지 모두 같은 질문으로 판별한다. 지워도 독자가 받는 정보에 손실이 없으면 삭제 대상이다. 이 파일의 규칙은 문장 길이, 연결 표현, 종결 형태, 거시 구조, 분량 같은 문체 선택에는 관여하지 않는다.

## 의미 없는 표현

### 접착제 표현

내용이 비어 있으면서 글의 길이를 채우거나 연결을 가장하는 표현이다. 지우고 내용으로 바로 들어간다.

| 유형 | 예 | 처리 |
|---|---|---|
| 맥락 라벨 남발 | "이러한 맥락에서", "해당 맥락을 고려하면", "이러한 관점에서 볼 때" | 삭제 후 내용으로 진입 |
| 시사 결론 회피 | "시사하는 바가 크다", "시사점을 제공한다", "의미가 있다" | 구체적 시사점을 쓰거나 삭제 |
| 중요성 선언 | "중요한 것은", "주목할 점은", "여기서 핵심은", "강조할 부분은" | 삭제 후 내용으로 전달 |
| 도입 예고 | "먼저 A를 살펴보고", "다음으로 B를 분석하면", "마지막으로 정리하면" | 삭제 후 내용으로 진입 |
| 논의 범위 선언 | "이 글에서는 X를 다룬다", "본 분석의 범위는" | 삭제 후 내용으로 진입 |

"맥락"과 "시사"는 뜻을 분명히 전달해야 할 때만 제한적으로 쓴다.

### 과잉 수식어와 평가어

| 유형 | 예 | 처리 |
|---|---|---|
| 뜻 없는 강조 부사 | 매우, 상당히, 굉장히, 정말, 미친 듯이, 특히(남발 시), 진정한, 사실상, 실질적으로 | 삭제하거나 구체적 정도를 밝힘 |
| 감탄형 평가어 | 탁월한, 훌륭한, 획기적인, 혁신적인, 역사적인, 경이로운, 통찰력 있는 | 구체적 근거로 대체 |
| 과장형 한정어 | 엄청난, 폭발적인, 비약적인, 전례 없는, 초유의, 파격적인 | 구체적 수치나 비교 대상으로 대체 |
| 부정 확인형 | "-은 부정할 수 없다", "-은 분명하다", "-은 자명하다" | 삭제 후 사실 자체를 서술 |

### 헷지 누적

한 문장이나 인접 문장에 불확실성 표현이 겹겹이 쌓인 형태다. "상당히 어느 정도 다소 긍정적인 변화가 있었던 것으로 보임"이 여기에 해당한다. 불확실성은 한 번만 밝히고 나머지는 지운다.

### 추상적 재포장

이미 분명한 내용을 "X라는 Y", "X로서의 Y" 구조로 추상 명사에 감싸는 형태다. Y가 정보를 더하지 않으면서 문장만 길어진다. "라는 [추상 명사]", "[추상 명사]로서의"를 지우고 X를 바로 쓰거나 조사를 재구성한다.

| 교정 전 | 교정 후 |
|---|---|
| 토큰 예측이라는 단일 메커니즘 | 토큰 예측 |
| 비용 절감이라는 목표 하에 | 비용 절감을 위해 |
| 디지털 전환이라는 거대한 흐름 속에서 | 디지털 전환이 진행되면서 |
| AI 도입이라는 과제를 안고 | AI 도입 과정에서 |
| 생산성 향상이라는 본질적 가치 | 생산성 향상 |
| 단일 예측 과제로서의 언어 모델 | 언어 모델은 다음 토큰을 예측 |
| 조직 혁신 수단으로서의 AI | AI를 활용한 조직 혁신 |

### 선언형 정의 나열

독자가 이미 아는 사실을 "X는 Y이다" 구조로 늘어놓아 분석과 판단을 대신하는 형태다. 술어 없는 명사구 나열로 우회하기도 한다.

| 교정 전 | 문제 |
|---|---|
| 본질은 다음 토큰 확률 예측 | "본질"로 포장하여 알려진 사실을 새 정보처럼 제시 |
| 구조는 트랜스포머와 어텐션 | 교과서 정의를 반복하며 분석이 없음 |
| 학습은 사전학습과 정렬의 단계 구성 | 같은 "X는 Y" 구조의 기계적 반복 |
| 원리에서 능력과 한계가 동시 발생 | 구체적 설명 없이 선언으로 마무리 |
| 어텐션과 입력 문맥의 활용 | 술어 없는 명사구를 분석처럼 제시 |
| 원리에서 비롯되는 능력과 한계 | "능력과 한계" 같은 대칭 짝을 나열하여 구체성 회피 |

- (판별) 그 문장을 지워도 독자의 이해에 손실이 없으면 해당한다.
- (문단 판별) 문장마다 정보가 있어 보여도 문단 전체가 교과서 수준의 알려진 사실을 다시 쓴 것이면 문단 단위로 해당한다.
- (처리) 독자가 아는 정의는 지우고 독자가 모르는 분석이나 판단으로 채운다.
- (우회 탐지) "X라는 Y"를 막으면 "X로서의 Y"로, 그것도 막으면 "X의 Y" 명사구나 "X는 Y" 선언으로 옮겨 간다. 표면 구조보다 정보를 더하는지로 판별한다.

## LLM 정형 수사

| 패턴 | 예 | 처리 |
|---|---|---|
| 대비 강조 | "단순한 A가 아니라 B", "A가 아닌 진정한 B", "A가 아닌 B", "A를 넘어 B로", "A에 그치지 않고 B" | 부정 후 긍정 구조를 쓰지 않고 B를 바로 서술 |
| 어휘 구조 반복 | "X는 -이다. Y도 -이다. Z 역시 -이다." | 구조를 다양하게 바꿈 |
| 단편 극적 표현 | "혁신. 바로 그것이다." | 완결된 문장으로 재구성 |
| 연속 단문 리듬 | "빠르다. 정확하다. 효율적이다." | 내용 중심 문장으로 통합 |
| 자문자답 | "왜 이런 일이 발생했는가? 그것은" | 질문을 지우고 답을 바로 서술 |
| 시사점 과대 일반화 | "이는 산업 전체의 패러다임 전환을 의미" | 결론을 근거 범위 안으로 줄임 |
| 모호한 부분 평가 | "절반은 맞다", "상당 부분 동의할 수 있다" | 동의 범위와 비동의 범위를 구체적으로 밝힘 |
| 메타 강조 상투어 | "강하게 말해서", "포인트는", "한 가지만 짚고 가자면", "여기서 선을 긋자면" | 삭제 |

### 기호 남용

문장 구조를 정하는 대신 기호에 결정을 떠넘기는 습관이다.

| 기호 | 남용 양상 | 허용 조건 | 처리 |
|---|---|---|---|
| em dash | 삽입구를 끼워 넣으면서 문장 구조를 정하지 않음 | 없음 | 문장 분리, 괄호, 쉼표로 재구성 |
| 콜론 | "결론:", "핵심:"처럼 한 절을 라벨로 대신함 | 실제 나열이나 형식적 인용을 시작할 때. 사용자 표기 지침이 다르면 그 지침 우선 | 한 절을 여는 콜론은 지우고 문장으로 재구성 |
| 세미콜론 | 문장을 나누지 않고 이어 붙여 구조 결정을 회피 | 밀접한 독립절 연결이 자연스러울 때. 사용자 표기 지침이 다르면 그 지침 우선 | 문장을 나누거나 재구성 |
| 말줄임표 | 극적 여운이나 사색적 분위기 연출 | 인용문의 생략 표시 | 삭제 후 문장 완결 |
| 문장 안 굵은 글씨 | 곳곳의 키워드를 굵게 처리하여 강조 남발 | 용어 정의, 기술 식별자처럼 독자가 훑어보는 대상 | 강조용 굵은 글씨 삭제 |
| 장식 요소 | 이모지, 장식용 특수 기호, 장식용 구분선 | 없음 | 삭제 |
| 3개 쉼표 나열 | 내용과 관계없이 항목을 습관적으로 3개로 맞춤 | 실제 항목 수가 3개일 때 | 항목 수를 내용에 맞춤. 2개면 2개, 4개면 4개 |

콜론, 세미콜론, 말줄임표가 150단어당 평균 1회를 넘으면 과밀도로 보고 줄인다. 문장 부호 제한은 `sentence.md`의 공통 표기를 함께 따른다.

## 동어반복과 순환

근거 없이 결론을 자기 참조로 끌어내는 형태다.

| 유형 | 예 | 처리 |
|---|---|---|
| A이므로 A | "개선이 필요하므로 개선이 요구됨" | 구체적 근거를 보충하거나 삭제 |
| 목적의 정의 반복 | "제도는 활용되기 위해 존재", "예산은 집행하기 위해 편성" | 구체적 용도를 쓰거나 삭제 |
| 내용 없는 당위 | "-해야 한다고 판단", "-하는 방향으로 검토가 필요하다고 판단" | 구체적 실행 방안이나 조건을 밝힘 |
| 정의 순환 | 정의 대상 개념을 정의 문장에 다시 씀 | 외부 근거로 정의 재구성 |

## 개수 선언과 계층 수식어

- 내용을 담기 전에 수량부터 선언하지 않는다. "3대 전략", "4개 방안", "5종 핵심 과제", "7대 추진 방향", "세 가지 약속", "두 축"이 여기에 해당한다. 개수를 예고하지 않고 내용을 바로 나열한다.
- 항목을 나열한 결과 수량이 자연스럽게 드러나는 표현은 허용한다("단기, 중기, 장기로 구분").
- "3중 구조", "4단 계층 아키텍처", "6중 모듈 계층" 같은 불필요한 층위 수식어는 구체적 내용으로 풀어 쓴다.

## 구조적 단조성

| 유형 | 설명 | 처리 |
|---|---|---|
| 표제 라벨 반복 | "개요", "배경", "현황", "결론" 같은 일반 라벨의 반복 | 내용을 반영한 키워드로 다시 지음 |
| 소제목 라벨 반복 | "(설명)", "(이유)", "(주장)", "(근거)" 같은 빈 라벨의 반복 | 실제 내용을 담은 키워드로 다시 지음 |
| 통사 구조 고정 | 인접 문장의 주어와 서술어 구조가 같은 패턴으로 3회 이상 반복 | 구조를 다양하게 바꿈 |
| 병렬 나열 강박 | 인접 항목 사이 관계 없이 단순 나열만 반복 | 인과, 부연, 대비 같은 관계를 부여 |
| 굵은 소제목 남발 | 모든 항목에 굵은 소제목을 기계적으로 붙임 | 필요한 항목에만 선택적으로 붙임 |

## 근거 공백

| 유형 | 예 | 처리 |
|---|---|---|
| 근거 없는 결론 | "AI 도입이 생산성을 혁신할 것" | 구체적 근거나 출처 보충 |
| 출처 없는 정량 데이터 | "시장 규모가 30% 성장 전망" | 출처를 밝히거나 삭제 |
| 권위 대체 논증 | 유명 기관 이름만으로 결론 도출 | 권위 인용 외 실질 근거를 함께 제시 |
| 사례 없는 일반화 | "최근 글로벌 기업들은 모두 AI를 도입" | 구체적 사례를 밝히거나 범위를 줄임 |

## 메타 서술

### 정의

메타 서술은 글 자체, 작성 과정, 작성자의 내적 상태, 사용자와의 상호작용, 사용 도구처럼 본문 바깥의 대상을 쓴 문장이다. 작성자가 자기 행위를 보고하거나 정당화하거나 예고하거나 회고하는 문장이다. 사용자가 요청하지 않은 역방향 서술(반례, 역논리, 역규칙, 여집합 설명)도 메타 서술이다. 작성자가 추론 중에 한 반례 검토와 경계 확인을 산출물로 옮겨 내부 검증 과정을 드러내기 때문이다. 응답은 정보 자체로 읽혀야 한다. 글의 존재, 작성자의 존재, 작성 과정이 독자에게 보이지 않게 쓴다.

### 판별 테스트

모든 문장은 산출 전에 아래 테스트를 통과해야 한다. 하나라도 걸리면 삭제하거나 본문 내용으로 바꾼다. 가장 기계적으로 적용할 수 있는 주어 테스트를 먼저 적용하고 이어서 나머지 네 테스트를 적용한다.

- (주어 테스트) 문장의 실제 주어(명시적이든 암묵적이든)가 글 자체("본 보고서는", "이 분석은", "본 절에서는"), 작성자("제가", "저는", "분석한 결과"), 작성 행위("살펴보면", "검토하면", "정리하면"), 사용자의 요청("요청하신", "질문에 대해"), 사용한 도구나 방법론이면 메타 서술이다.
- (삭제 테스트) 지워도 독자가 받는 정보에 손실이 없으면 메타 서술이다.
- (수혜자 테스트) 문장의 수혜자가 작성자(자기 정당화, 자기 보호, 자기 과시)이면 메타 서술이다.
- (응대 테스트) 정보 전달 없이 인사, 칭찬, 확인, 안내, 유도 같은 응대 의례만 하면 메타 서술이다.
- (요청 방향 테스트) 사용자가 요청하지 않은 반대 극성, 여집합, 대체재를 다루면 메타 서술이다. 반대 극성은 A 방향 서술을 요청받고 반대 방향 B를 덧붙이는 경우다. 여집합은 A를 정의하거나 고른 뒤 A에 속하지 않는 나머지를 덧붙이는 경우다. 대체재는 X를 보완하는 기능을 요청받고 X를 대체하거나 금지하는 규칙을 덧붙이는 경우다. 역방향 문장은 정보를 담고 있어 삭제 테스트를 통과하기 쉬우므로 요청 방향과 일치하는지로 판별한다.

### 생기는 이유

LLM은 다음 목적으로 메타 서술을 만든다. 모두 독자의 필요와 무관하다.

- (길이 채우기) 본문 내용이 부족할 때 분량을 보충
- (구조 회피) 내용을 직접 구조화하지 않고 "먼저 A를 살펴보고 다음으로 B를" 식으로 예고만 함
- (책임 분산) "완벽하지 않을 수 있으나"로 품질 책임을 미리 면함

### 우회 형태

직접적인 메타 서술을 막으면 우회 형태가 나온다. 판별 테스트는 표면보다 기능을 보므로 우회에도 적용된다.

- (주어 은폐) 주어를 생략하거나 수동태로 바꾼다. "분석 결과를 정리하면", "검토 내용은 다음과 같다", "조사된 바에 따르면", "도출된 결론은", "파악된 현황은", "확인된 사항은". 주어를 복원했을 때 작성자이면 메타 서술이다.
- (내용 위장) 메타 서술에 본문 내용을 조금 섞는다. "다양한 관점에서 검토한 결과 A가 적합하다"는 "A가 적합하다"만 남긴다. "철저한 분석을 통해 B라는 결론을 도출했다", "종합적 고려 끝에 C 방안을 제안한다"도 같다.
- (겸양 위장) 겸손을 가장한다. "부족하지만 정리해 보면", "미흡하나마", "제한된 정보이지만", "조심스럽게 판단하면". 수혜자가 작성자(면책, 호감)이면 메타 서술이다.
- (질문 위장) 수사 의문으로 감싼다. "그렇다면 어떻게 접근해야 할까?", "왜 이런 결과가 나왔을까?", "무엇이 핵심일까?". 질문을 지우고 답을 바로 쓴다.
- (접속 표현 위장) 메타 서술을 접속 표현으로 줄여 본문 문장에 붙인다. "앞서 살펴본 바와 같이 A는 B이다", "이를 종합하면 C가 적합하다", "이상의 분석에 기초하여 D를 제안한다". 접속 부분만 지운다.

### 첫 문장과 마지막 문장

- 첫 문장은 본문 내용으로 시작한다. 인사, 요청 반복, 과정 예고로 시작하지 않는다.
- 마지막 문장은 본문 내용으로 끝난다. 인사, 추가 질문 권유, 면책으로 끝내지 않는다.

### 허용하는 경우

- 사용자가 메타 서술을 명시적으로 요청한 경우(예: "이 보고서의 목적을 서두에 적어줘")
- 학술 논문의 연구 목적과 연구 방법 섹션처럼 장르 관례상 메타 서술이 필요한 경우
- 사용자가 한계, 유의사항, 방법론 설명을 명시적으로 요청한 경우

## 예시

### 정형 수사와 개수 선언

```markdown
교정 전
## 3대 핵심 전략 방향
- 단순한 기술 도입이 아니라 진정한 의미의 디지털 전환이 필요
    + 왜 이러한 전환이 필요한가? 그것은 기존 방식의 한계가 명백하기 때문
- 이는 곧 산업 전체의 패러다임 전환을 의미하며 그야말로 게임체인저가 될 것으로 전망
    + 혁신. 바로 그것이 핵심
- 3대 핵심 전략은 다음과 같음
    + 첫째, 디지털 역량 강화
    + 둘째, 데이터 기반 의사결정 체계 구축
    + 셋째, 조직문화 혁신

교정 후
## 디지털 전환 추진 방향
- (디지털 역량 확보) 현장 수요를 반영한 기술 교육 운영으로 내부 인력의 기술 활용 능력을 단계적으로 확보
    + 전환 지원 사업의 지원 규모 확대로 초기 도입 비용 절감 검토
    + 교육 이수 후 현업 적용 과제 운영으로 학습 성과를 업무에 연결
- (데이터 활용 의사결정) 업무 절차별 데이터 수집과 분석 환경 도입으로 경험 의존 의사결정을 데이터 활용 의사결정으로 전환
    + 기존 생산관리 시스템과 전사 자원관리 시스템의 데이터 연계 분석 환경을 먼저 마련
    + 의사결정 회의에 데이터 분석 결과를 정기 보고 안건으로 편성
- (조직문화 전환) 전환 과정에서 부서 간 협업 체계를 마련하고 변화 수용성 제고
    + 시범 과제 운영으로 성공 사례를 가시화하여 조직 내 수용성을 단계적으로 확보
    + 부서 간 공동 과제에 성과 평가 가점 부여
```

교정 전 글에서 지운 요소는 개수 선언("3대 핵심 전략"), 대비 강조("단순한 A가 아니라 진정한 B"), 자문자답, 과장형 전환 표현("패러다임 전환", "게임체인저"), 단편 극적 표현("혁신. 바로 그것이 핵심"), 과잉 강조 부사("그야말로")다.

### 결론부의 메타 서술

```markdown
교정 전
## 시사점
- 이상의 분석에 기초하여 다음과 같은 시사점을 도출하였음
- 결론적으로 말하면 국내 스타트업 생태계의 후기 투자 공백은 구조적 문제임
    + 앞서 살펴본 바와 같이 초기 단계 투자 편중이 심화되고 있으며 이처럼 다양한 요인이 복합적으로 작용하고 있음
    + 물론 단정할 수는 없으나 현 추세가 지속될 경우 성장 단계 이탈 기업이 증가할 전망
- 이상과 같이 여러 측면에서 검토하였으며 본 분석의 한계로는 비상장 기업 투자 데이터 접근의 제한이 있음
    + 전문가의 추가 검토가 필요하며 참고하시기 바랍니다
    + 도움이 되셨길 바랍니다

교정 후
## 스타트업 후기 투자 공백의 해소 방향
- 국내 스타트업 생태계의 후기 투자 공백은 구조적 문제
    + 초기 단계에 투자가 편중되면서 후기 단계의 자금 조달 경로가 단절
    + 현 추세가 지속되면 성장 단계에서 이탈하는 기업 증가 전망
- 후기 단계 투자에 참여하는 민간 투자사 대상 세제 유인 신설 검토 필요
    + 초기 투자 이후 성장 전용 투자 경로를 신설하여 단계별 자금 조달 경로를 명확히 할 필요
    + 성장 단계 투자 실적을 공공 모펀드 출자 평가에 반영하는 방안 검토
```

교정 전 글에서 지운 요소는 자기 정당화, 산출물 형태 설명, 과정 회고, 접속 표현 위장, 나열 후 총괄 선언, 조건부 유보 남발, 사전 면책, 독자 행동 지시, 인사다.

## 점검 목록

- 지워도 뜻이 남는 접착제 표현, 뜻 없는 강조 부사, 감탄형 평가어가 없는가
- 불확실성 표현이 한 문장에 겹겹이 쌓이지 않았는가
- "X라는 Y"에서 Y가 정보를 더하지 않는 추상적 재포장이 없는가
- 독자가 아는 사실을 "X는 Y이다" 구조로 늘어놓지 않았는가
- 대비 강조, 자문자답, 단편 극적 표현 같은 정형 수사가 없는가
- em dash, 극적 말줄임표, 강조용 굵은 글씨, 남용된 콜론과 세미콜론이 없는가
- A이므로 A 형태의 동어반복과 내용 없는 당위가 없는가
- 개수를 미리 선언하는 표현이 없는가
- 같은 통사 구조가 3회 이상 이어지지 않았는가
- 표제와 소제목이 빈 라벨의 반복이 아닌가
- 결론과 주장에 근거가 있고 정량 데이터에 출처가 있는가
- 글 자체, 작성자, 작성 과정, 요청, 도구가 주어인 문장이 없는가
- 수혜자가 작성자인 문장, 응대 의례만 하는 문장이 없는가
- 사용자가 요청하지 않은 반대 방향, 여집합, 대체 규칙을 다루는 문장이 없는가
- 주어 은폐, 내용 위장, 겸양 위장, 질문 위장, 접속 표현 위장 같은 우회 형태가 없는가
- 첫 문장과 마지막 문장이 본문 내용인가
- 소리 내어 읽었을 때 리듬이 어색하지 않은가
