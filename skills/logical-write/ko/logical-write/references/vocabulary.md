# 어휘 사전

LLM이 습관적으로 많이 고르는 어휘를 선호, 비선호, 신중 사용으로 나눈 사전이다. 분류 기준은 뜻의 옳고 그름보다 독자 수용성, LLM 산출물 표지 노출 정도, 어감의 자연스러움이다. 뜻이 같아도 어감이 다르면 분류가 다를 수 있다.

## 분류 기준

| 분류 | 기준 |
|---|---|
| 선호 | 독자가 받아들이기 쉽고 LLM 산출물 표지가 드러나지 않으며 격식 있는 보고서 문체에 자연스럽게 맞는 어휘 |
| 비선호 | LLM이 통계적으로 많이 골라 산출물 표지가 되는 어휘, 지워도 문장의 뜻이 남는 의미 공백 어휘, 독자에게 위압감을 주는 공격적 어휘(차단, 배제, 도태, 금지), 반론 여지를 막는 단정적 어휘(절대, 오직, 유일, 무조건), 근거 없이 규모나 정도를 부풀리는 과장 어휘(획기적, 폭발적, 전례 없는), 영어나 일본어 구조를 그대로 옮긴 번역투 어휘, 구어적이거나 비속한 어감이 연상되어 공식 문서에서 피하는 어휘(넣다, 빼다, 박다, 쑤시다) 가운데 하나 이상에 해당하는 어휘 |
| 신중 | 맞는 문맥에서 제한적으로 쓸 수 있으나 남발하면 강조 기능이 옅어지고 글 전체의 어휘 밀도가 떨어지는 어휘 |

## 적용

- 작성할 때는 비선호 어휘 대신 선호 어휘를 고른다. 신중 어휘는 문맥상 꼭 필요할 때만 최소 빈도로 쓴다. 신중 어휘가 한 문단에 두 번 이상 반복되지 않게 한다.
- 교정할 때는 비선호 어휘를 찾아 선호 어휘로 바꿀 수 있는지 본다. 바꾼 뒤에도 문장의 뜻이 그대로인지 확인한다.
- 이 사전은 어휘만 다룬다. 문장 구조, 종결 형태, 거시 구조, 분량에는 관여하지 않는다.

## 명사

### 선호

연계, 협력, 전략, 방향, 비전, 시사점, 변화, 발전, 융합, 전환, 개선, 차별화, 기여, 보완, 단계, 수요, 여건, 현황, 실태, 추이, 동향, 전망, 재원, 인프라, 거점, 실증, 시범, 확산, 이행, 전주기, 동시, 필요, 추가

### 비선호

- (LLM 추상 명사) 맥락, 담론, 지형, 지평, 함의, 층위, 층, 계위, 위계, 흐름. "이러한 맥락에서", "기술 지형", "경쟁 지형", "새로운 지평을 열다", "다양한 층위에서", "거대한 흐름"처럼 구체적 대상 없이 쓰인다. "맥락"은 LLM이 가장 많이 남발하는 어휘다
- (숫자 선언과 결합) 축, 종, 이중, 삼중. "두 축", "세 축", "세 종"처럼 개수 선언과 붙어 남발된다
- (어감이 부자연스러운 명사) 결, 틀. "같은 결", "비슷한 결", "해당 틀", "평가틀"
- (과잉 은유) 뼈대, 촉매, 촉매제, 디딤돌, 초석, 교두보, 청사진, 나침반, 등대, 이정표, 돌파구. "전략의 뼈대", "혁신의 촉매", "발전의 초석", "시장 교두보", "미래 청사진", "정책의 나침반", "혁신의 등대", "새로운 이정표", "돌파구 마련"
- (과장) 패러다임, 게임체인저, 판도, 폭증, 비약, 최강, 최약, 고아, 남발한 전환점, 남발한 최초. "패러다임 전환"은 LLM의 대표적 과장 표현이다. "판도를 바꿀", "비약적 성장"도 같다
- (공격적 어휘) 도태, 선점, 선제. "시장 선점", "선제적 대응"
- (단정적 판단) 직결, 인과, 쟁점, 선결, 준거, "-결"로 끝나는 판단어
- (권위적 표현) 엄수
- (불필요한 외래어) 프레임, 레버리지, 컨틴전시, 게이트("단계별 게이트"), 커버리지, 헷지, MVP, 통합패키지
- (영문 직역) 딥다이브(심층 분석으로 대체), 인사이트(시사점으로 대체), 피보팅, 게이트키핑, 에코시스템(생태계로 대체), 트랜스포메이션(디지털 전환으로 대체), 풀스택("풀스택 솔루션", 전주기로 대체), 매핑(대응, 연결, 배치로 대체)
- (LLM 선호 어휘) 괴리("인식과 현실의 괴리"), 묵음, 차등, 전량, 뽑기와 뽑음 등 "뽑다"의 모든 활용형, 병렬, 한정, 실제 절차 분석이 아닌 곳의 병목, 공학 맥락이 아닌 곳의 값, 분기나 경로의 대체어로 쓴 갈래
- (억지 명사) 온전. "온전한"에서 "한"을 떼어 명사처럼 쓴 형태

### 신중

다음 어휘는 남발하지 않는다.

핵심, 본질, 근본, 원칙, 결과, 영향, 역량, 리스크, 한계, 격차, 문제, 이슈, 과제, 구조, 정합, 검증, 진단, 평가, 판단, 통제, 관리, 책임, 근거, 객관, 주관, 위험, 위협, 규제, 준법, 컴플라이언스, 논리, 우선, 순위, 연결, 결합, 구성, 규칙, 명제, 유보, 확정, 조직, 인사, 보상, 소속, 결정, 단일, 매칭, 탁월, 훌륭

다음 어휘는 조건을 지킬 때 쓴다.

- (핵심) 정말 핵심일 때만
- (본질, 근본, 원칙) 추상적 권위를 붙이는 용도로 쓰지 않음
- (결론) "결론적으로"처럼 메타 서술과 붙으면 비선호
- (영역) 구체적 대상이 있을 때만. 분류할 때 남발하지 않음
- (환경) "환경 변화"처럼 포괄적으로 쓰면 뜻이 흐려짐
- (체계, 구축) "체계 구축", "체계 수립", "시스템 구축"으로 남발하지 않음
- (고도화) "시스템 고도화"처럼 남발하지 않음. 기존 시스템을 실질적으로 개선할 때
- (선도) "선도적" 수식어로 남발하면 비선호
- (거버넌스) 실제 조직 운영 구조를 가리킬 때
- (가드, 가드레일) "가드" 단독 사용은 권장하지 않음. "가드레일"은 보안, 규제, 제도의 뜻이 강하므로 꼭 필요한 문맥인지 판단
- (기반) "기반 조성", "기반 구축" 같은 복합어는 허용. 단독 사용은 피함
- (바우처) 정책 수단을 가리킬 때
- (생태계) 여러 주체가 실제로 상호작용하는 구조를 가리킬 때
- (시너지) 구체적 효과를 밝힐 때
- (로드맵) 실제 일정표를 가리킬 때. 추상적 비전 수사로 쓰지 않음
- (허브) 실제 거점 기능을 가리킬 때
- (플랫폼) 실제 기술 플랫폼을 가리킬 때
- (솔루션) 실제 제품이나 서비스를 가리킬 때
- (아젠다) 실제 의제를 가리킬 때
- (이니셔티브) 실제 추진 과제를 가리킬 때
- (벤치마크) 실제 비교 기준을 가리킬 때
- (마중물) 정책 초기 투자를 비유할 때 제한적으로
- (교차) 방법론을 설명하며 메타적으로 남발하지 않음
- (입력, 출력) 공학적 상황에서만
- (언어) 한국어, 영어, 언어모델처럼 실제 언어를 가리킬 때만. 비유적 의미로 쓰지 않음

## 동사와 서술어

### 선호

수립, 확보, 도입, 증대, 도출, 조성, 전환, 설정, 확장, 부합, 개방, 기여, 연계, 협력, 추진, 마련, 반영, 적용, 운영, 활용, 제고, 경감, 완화, 촉진, 포함, 추가, 제외, 삭제, 차감, 병기

### 비선호

- (과장) 남발한 선도, 아우르다("전 분야를 아우르는"), 망라, 극대화("효과를 극대화"), 군림, 남발한 주도, 석권, 압도, 촉발("변화를 촉발")
- (공격적 어휘) 차단, 배제, 회피, 도태, 금지(규정 원문 인용은 제외)
- (번역투 동사) 야기(cause), 수반(entail), 내포(imply), 탈피("기존 방식을 탈피")
- (중립을 가장한 단정) 좌우
- (실무와 일상에서 쓰지 않는 어휘) 통독. "전체를 읽음"의 뜻으로 남발
- (구어적이거나 비속한 어감) 넣다(포함, 추가로 대체), 빼다(제외, 삭제로 대체), 박다(명시, 고정으로 대체), 쑤시다(점검, 조사로 대체), 동시삽입(병기로 대체). "넣을 것", "뺄 것", "빼고", "코드에 박아 넣다", "박음", "쑤심" 같은 모든 활용형이 대상이다

### 신중

- (혁신) 기존과 근본적으로 다른 변화일 때만
- (견인) "성장을 견인"처럼 쓸 때는 구체적 인과가 분명할 때만
- (포괄) 구체적 범위를 밝힐 때만
- (구축) 실제 신규 개발일 때
- (고도화) 기존 시스템의 실질적 개선일 때
- (판단) "-라고 판단됨"처럼 내용 없는 당위와 붙으면 비선호
- (확인) "확인된 바에 따르면"처럼 메타 서술과 붙으면 비선호
- (강화) 모든 정책 제언에 붙이지 않음. 구체적 방법을 함께 쓸 때
- (검증, 진단, 평가) 남발 주의
- (번역, 통역) 실제 언어 사이의 번역과 통역일 때만. 비유적 의미로 쓰지 않음
- (삽입) "그림 삽입" 같은 문서 편집 기능 이름으로 허용. 서술부에서는 추가나 배치로 대체
- (주입) "SQL 주입" 같은 기술 용어로 허용. 서술부에서는 반영이나 적용으로 대체
- (투입) 인력, 예산 같은 자원 투입일 때

## 형용사, 부사, 수식어

### 선호

단계적, 점진적, 단기, 중장기, 구체적, 명확한

### 비선호

- (과장 수식어) 획기적, 혁신적, 선도적, 압도적, 파격적, 전례 없는, 초유의, 비약적, 폭발적, 경이로운, 전방위적
- (감탄형 평가어) 탁월한, 훌륭한
- (대비 강조의 핵심어) 진정한("진정한 혁신")
- (번역투 수식어) 궁극적(ultimately), 총체적(holistic), 다층적, 역동적(dynamic), 즉각적(immediate)
- (추상적 권위 부여) 남발한 근본적, 남발한 본질적
- (구체성 상실) 남발한 종합적, 남발한 포괄적
- (단정적 어휘) 즉시, 절대, 오직, 유일, 무조건
- (남발 수식어) 맞춤, 맞춤형, 남발한 최우선(모든 항목이 최우선이 되면 뜻이 없음)
- (뜻 없는 강조 부사) 매우, 상당히, 굉장히, 사실상, 그야말로

### 신중

- (특히) 남발하면 모든 항목이 "특히"가 되어 강조 기능을 잃음
- (결정적) "결정적 영향"처럼 남발하면 과장
- (핵심적) "핵심"의 변형이므로 남발 주의
- (전략적) 모든 활동에 붙이지 않음
- (체계적) "체계적 접근"으로 남발하지 않음
- (실질적) 구체적 내용이 뒤따를 때만
- (효과적) 남발 주의
- (적극적, 지속적) 모든 정책 제언에 붙이지 않음
- (다각적) 구체적 관점을 밝힐 때만
- (범정부적) 실제 여러 부처가 협업할 때
- (유기적) "유기적 연계"는 구체적 연계 구조를 밝힐 때
- (확정) 단정적이므로 주의
- (온전한) 정말 온전함이 확인되었을 때만
- (조사 "-으로", "-로") 남발하면 문장이 어색해지므로 빈도 점검

## 연결 표현

다음 연결 표현은 쓰지 않는다. 연결 모드에서 연결 표현을 쓸 때도 이 목록은 피한다.

- (접착제형 빈 표현) 이러한 맥락에서, 해당 맥락을 고려하면, 이러한 관점에서 볼 때, 이러한 측면에서, 이러한 흐름 속에서
- (접속 표현 남발) 그렇기 때문에, 이는
- (번역투) 나아가(furthermore), 더불어, 뿐만 아니라(not only), 궁극적으로(ultimately), 추가적으로(additionally)
- (메타 서술) 결론적으로, 요약하자면, 정리하면, 이와 관련하여
- (동어반복 유발) 다시 말해
- (노이즈) 남발한 "즉"
- (관계 없는 전환) 실질적 대비 없는 한편과 반면, 실질적 연결 없는 "이를 바탕으로", 인과가 불분명한 "이를 통해"

## 번역투

일본어나 영어 문장 구조를 옮긴 표현이다.

| 표현 | 기원 | 대체 |
|---|---|---|
| -에 있어서 | 일본어 において | -에서, -시점에 |
| -인 셈이다 | 일본어 わけだ | 명사형으로 바로 서술 |
| -것은 아닐까 | 일본어 ではないか | 명제로 바로 서술 |
| -라고 하는 | 일본어 という | "X라고 하는 Y"를 "Y인 X"로 어순 정리 |
| -하는듯 | 일본어 ようだ | "-으로 추정" |
| -하지 않으면 안 된다 | 일본어 しなければならない | "-할 필요", "-이 요구됨" |
| -할 수밖에 없다 | 이중 부정 | "-할 필요", "-이 불가피" |

## 영어 LLM 어휘의 한국어 대응

영어권 LLM이 많이 고르는 어휘가 직역이나 차용 형태로 한국어 산출물에 나타난 경우다.

- (비선호) delve(깊이 파고들다, 심층적으로 들여다보다), landscape(지형, 지형도), tapestry(다채로운, 풍부한 직물), realm(-의 세계), leverage(레버리지), navigate(헤쳐나가다), underscore(강조하다, 밑줄 긋다), showcase(보여주다, 선보이다), harness(동력으로 삼다), spearhead(진두지휘), multifaceted(다면적), ever-evolving(끊임없이 진화하는), game-changer(게임체인저), groundbreaking(획기적, 선구적), paradigm shift(패러다임 전환), holistic(총체적, 전인적), not just A but B(단순한 A가 아니라 B)
- (신중) intricate(정교한, 실제 정밀한 구조일 때), pivotal(중추적, 실제 핵심 역할일 때), crucial(필수적, 실제 필수 조건일 때), robust(견고한, 탄탄한, 실제 안정성일 때), foster(육성, 실제 양성 활동일 때), bolster(뒷받침, 구체적 지원 내용이 있을 때), cutting-edge(최첨단, 실제 기술 수준일 때), seamlessly(원활하게, 실제 연동 품질일 때), stakeholder(이해관계자, 구체적 대상을 밝힐 때)

## 어구와 관용 표현

### 비선호

- (결론 회피) 시사하는 바가 크다, 시사점을 제공한다, 의미가 있다
- (독자 환기) 중요한 것은, 주목할 점은, 여기서 핵심은, 강조할 부분은
- (이중 부정 강조와 근거 없는 단정) 간과할 수 없는, 부정할 수 없다, 분명하다, 자명하다, 두말할 나위 없다
- (대비 강조) 단순한 A가 아니라 B, A가 아닌 진정한 B, A를 넘어 B로, A에 그치지 않고 B
- (개수 선언) N대 전략, N가지 방안, N종 핵심 과제, N대 추진 방향
- (자문자답과 극적 표현) 왜 -인가? 그것은, -. 바로 그것이다
- (접착제형) 남발한 "-라는 점에서", 남발한 "-(이)라는 측면에서"
- (추상적 재포장) -라는 단일 메커니즘, -라는 거대한 흐름 속에서, -이라는 과제를 안고, -이라는 본질적 가치, "수단으로서의 AI" 같은 "-로서의"
- (모호한 부분 평가) 절반은 맞다, 상당 부분 동의할 수 있다
- (과대 일반화) 산업 전체의 패러다임 전환을 의미, 전 세계적으로 주목받고 있다, 글로벌 트렌드로 자리잡고 있다, 다양한 분야에서 활발히 활용되고 있다(분야 미명시)
- (상투적 도입부) -의 시대가 도래하였다, -의 중요성이 날로 증가하고 있다, -에 대한 관심이 높아지고 있다, -의 필요성이 대두되고 있다

### 신중

- (-을 위한 기반을 마련) 구체적 내용이 뒤따를 때만
- (시너지 효과를 창출) 구체적 효과를 밝힐 때만
- (선순환 구조를 구축) 순환 경로를 구체적으로 밝힐 때만
- (-와의 연계를 강화) 연계 대상과 방식이 구체적일 때만
- (지속가능한 성장) 구체적 조건이 뒤따를 때만
- (전략적 방향성) "전략적"과 "방향성"이 각각 과다 사용 어휘이므로 함께 쓰지 않도록 주의

## 점검 목록

- 비선호 명사(맥락, 담론, 지형, 함의, 패러다임, 결, 매핑)가 없는가
- 비선호 수식어(획기적, 혁신적, 선도적, 압도적, 진정한)와 비선호 부사(매우, 상당히, 굉장히, 그야말로, 궁극적으로)가 없는가
- 비선호 연결 표현("이러한 맥락에서", "결론적으로")이 없는가
- 번역투 표현과 영어 LLM 어휘의 직역 형태가 없는가
- 구어적이거나 비속한 어감의 동사(넣다, 빼다, 박다, 쑤시다)의 활용형이 없는가
- 대비 강조, 자문자답, 개수 선언이 없는가
- 과장 평가어 대신 구체적 근거로 썼는가
- 신중 어휘가 한 문단 안에서 두 번 이상 반복되지 않았는가

## 적용하지 않는 경우

- 인용문 원문
- AI 기술 자체를 설명하는 글에서 "맥락" 같은 일부 비선호 어휘가 꼭 필요한 경우. 빈도는 최소로 한다
- 고유명사, 법률 용어, 기술 표준 명칭
- 사용자가 특정 어휘를 의도적으로 요청한 경우
- 넣다, 빼다 같은 동사는 원형 기준으로 탐지한다. 빼앗다, 빼어나다, 빼곡하다처럼 원형이 다른 어휘는 대상이 아니다
