# module-off

사용자가 모듈 없이 진행할 대화를 직접 고를 수 있게 하는 스킬이다. 상시 지침은 모든 대화에 적용되므로 특정 대화만 다르게 진행하려면 사용자가 이 스킬을 부른다. 본문에서 괄호로 부르는 이름은 설정 절의 항목을 가리킨다.

## 설정

- (해제 대상) write-standard, code-standard, staged-work, token-lean

## 규칙

- 이 스킬을 부른 응답부터 (해제 대상)의 모듈을 불러오지 않는다. 해제는 사용자가 모듈을 다시 요청할 때까지 그 대화에서 유지한다.
- 같은 대화에서 이미 불러온 (해제 대상)의 모듈이 있으면 그 모듈의 규칙을 이후 응답에 적용하지 않는다.
- (해제 대상)에 없는 모듈은 상시 지침의 로드 규칙대로 불러온다.
- 상시 지침의 공통 작업 규칙과 기타 선호는 계속 적용한다. 이 규칙들은 모듈과 관계없이 모든 대화에 필요하기 때문이다.
- 사용자가 (해제 대상)의 모듈을 이름으로 직접 부르면 그 모듈을 불러온다. 직접 부른 요청이 해제보다 나중에 밝힌 뜻이기 때문이다.
