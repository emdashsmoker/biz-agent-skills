# no-modules

상시 지침이 매 응답에 불러오도록 지정한 모듈을 사용자가 원할 때 끄는 스킬이다. 상시 지침의 로드 규칙은 짧은 질문에도 모듈을 불러오게 하므로 모듈의 기준이 필요 없는 대화에서도 모듈이 적용된다. 이 스킬은 생략 지시를 한 번의 호출로 대신하고 끄는 범위와 기간을 정해 둔다.

## 설정

- (끌 모듈) write-standard, code-standard, staged-work, token-lean

## 끄는 범위

- 사용자가 모듈 이름 없이 호출하면 (끌 모듈)에 적힌 모듈을 모두 불러오지 않는다.
- 사용자가 같은 메시지에 모듈 이름을 적으면 적힌 모듈만 불러오지 않는다. 나머지 모듈은 상시 지침의 로드 규칙대로 불러온다.
- 호출 전에 이미 불러온 모듈이 있으면 호출한 메시지의 응답부터 그 모듈의 규칙을 적용하지 않는다.

## 유지하는 규칙

- 상시 지침의 공통 작업 규칙과 기타 선호는 계속 따른다. 이 규칙들은 모든 작업에 걸리므로 모듈 로드와 관계없이 적용된다.
- 사용자가 직접 요청한 다른 스킬은 평소대로 불러온다. 이 스킬이 멈추는 대상은 상시 지침의 로드 규칙뿐이다.

## 적용 기간

- 호출한 메시지부터 현재 대화가 끝날 때까지 적용한다. 이 스킬의 본문이 대화가 끝날 때까지 컨텍스트에 남으므로 적용 기간도 대화 단위로 맞춘다.
- 새 대화에서는 상시 지침의 로드 규칙을 처음부터 다시 따른다.

## 다시 켜기

- 사용자가 모듈을 다시 쓰라고 요청하거나 모듈 이름을 불러 사용을 요청하면 해당 모듈부터 상시 지침의 로드 규칙을 다시 따른다.
- 사용자가 일부 모듈만 다시 켜면 나머지 모듈은 꺼진 상태로 둔다.
