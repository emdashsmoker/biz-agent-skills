# practical-calc-lite

기획서와 보고서의 숫자는 다른 사람이 같은 입력으로 다시 계산했을 때 같은 값이 나와야 믿을 수 있다. 이 스킬은 자주 쓰는 계산을 `scripts/` 폴더의 파이썬 스크립트로 고정해 두고 산식, 입력 규칙, 판단 기준을 함께 적어 둔다. 계산은 스크립트가 하고, 모델은 입력을 정리하고 결과를 설명한다.

## 작업 원칙

- 보고서에 들어가는 숫자는 모두 스크립트 출력에서 가져온다. 모델이 암산하거나 추정한 숫자는 틀려도 드러나지 않기 때문에 쓰지 않는다.
- 입력값은 사용자 자료나 출처를 확인한 자료에서만 가져온다. 유발계수, 기여율, 시장점유율처럼 결과를 크게 바꾸는 값이 없으면 채워 넣지 말고 사용자에게 묻는다.
- 입력이 충분하면 바로 계산한다. 빠진 항목이 있으면 한 번에 모아서 묻는다.
- 계산 전에 단위(원, 백만원, 억원, 명), 기준연도, 가격 기준(경상가격 또는 불변가격)을 확정한다. 서로 다른 연도의 금액을 더해야 하면 먼저 성장률 도구로 같은 기준연도 가격으로 바꾼다.
- 사용자 자료는 입력 데이터 가공 절차에 따라 코드로 스크립트 입력 형태로 바꾼다. 문서에서 뽑거나 가공한 수치는 계산 전에 표로 보여 주고 사용자 확인을 받는다. 추출과 가공 단계의 오류는 이후 모든 결과로 번지기 때문이다.
- 결과를 보고할 때는 입력 JSON도 함께 준다. 같은 JSON을 같은 스크립트에 넣으면 같은 결과가 나오므로 제3자가 검산할 수 있다.

## 준비

Python 3.9 이상에서 동작한다. 처음 한 번 아래 패키지를 설치한다.

```bash
pip install "markitdown[pdf,docx,pptx,xlsx,xls]" python-hwpx olefile pandas openpyxl matplotlib
```

모든 계산 스크립트는 같은 방식으로 실행한다.

```bash
python scripts/<도구>.py --example > input.json   # 입력 양식 받기
python scripts/<도구>.py input.json               # 계산, 마크다운 보고서 출력
python scripts/<도구>.py input.json --json out.json  # 결과를 JSON으로도 저장
python scripts/<도구>.py input.json --xlsx out.xlsx  # 보고서의 표를 엑셀 시트로도 저장
python scripts/<도구>.py input.json --csv out_csv    # 보고서의 표를 CSV 파일로도 저장
```

입력 JSON의 항목 이름과 구조는 `--example` 출력이 기준이다. 입력에 문제가 있으면 스크립트가 `[INPUT ERROR]`로 원인을 알려 준다.

`--xlsx` 는 보고서의 표마다 시트 하나를 만들고 숫자를 숫자 셀로 저장하며, 마지막 `input` 시트에 사용한 입력 JSON을 붙인다. `--csv` 는 표마다 CSV 파일 하나를 만들고 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM으로 저장한다. 두 옵션은 함께 쓸 수 있다.

| 문서를 마크다운으로 변환 | parse_input.py |

| AHP 가중치 | ahp.py |
| 시장규모 추정 | market_size.py |

## 입력 문서 변환

`python scripts/parse_input.py 입력파일 출력.md` 로 실행한다. 긴 문서는 `--chunk --chunk-size 2000` 을 붙이면 제목 단위로 나눈 파일을 폴더에 만든다.

| 형식 | 처리 방법 |
| --- | --- |
| PDF | markitdown으로 본문을 뽑고 pdfplumber로 표를 찾아 `원본이름_tables.md` 로 따로 저장한다. 표가 없으면 표 파일을 만들지 않는다. |
| HWPX | python-hwpx의 마크다운 변환을 먼저 쓰고, 실패하면 텍스트 추출기, 그다음 문서 XML의 글자를 직접 읽는다. |
| HWP | 스크립트에 들어 있는 HWP 5.0 판독기로 본문 문단을 읽는다. 표 안의 글자는 일반 문단으로 나온다. |
| DOCX, PPTX, XLSX, XLS, CSV, JSON, XML, HTML, TXT, MD, EPUB, ZIP | markitdown으로 변환한다. |

- 로컬 파일만 받는다. 주소(URL)를 넣으면 거절한다.
- 스캔한 이미지 PDF는 글자가 나오지 않는다. 이때는 OCR을 먼저 해야 한다고 알린다.
- 암호가 걸린 HWP와 배포용 HWP는 읽지 못한다. 한글 프로그램에서 HWPX나 PDF로 저장해 달라고 요청한다.
- HWP 표의 행과 열 구조가 필요하면 HWPX로 저장해 달라고 요청한다. HWPX 변환은 표를 마크다운 표로 남긴다.
- DOC와 PPT(구형 형식)는 DOCX와 PPTX로 저장한 뒤 변환한다.
- 이미지와 음성 파일은 지원하지 않는다. 음성 변환은 외부 서비스로 파일을 보내고, 이미지에서는 촬영 위치 같은 메타데이터만 나오기 때문이다.

HWP 판독기 고지: 본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

## 입력 데이터 가공

사용자 자료는 엑셀 표, 통계 사이트 내려받기 파일, 보고서 표, 채팅에 붙여 넣은 숫자처럼 형태가 제각각이다. 계산 전에 이 자료를 각 스크립트가 읽는 형태로 바꾼다. 표 형태 자료는 모델이 손으로 옮겨 적지 않고 pandas 코드로 가공한다. 손으로 옮기면 자릿수와 행을 틀리기 쉽고, 코드로 가공하면 같은 원자료에서 같은 입력을 다시 만들 수 있기 때문이다. 사용자가 채팅에 값 몇 개만 적었다면 JSON을 바로 작성하고 보여 준다.

가공 순서는 다음과 같다.

1. 원자료의 구조를 확인한다. 머리글이 몇째 행인지, 단위가 어디에 적혀 있는지(표 제목, 열 이름, 각주), 연도가 열과 행 가운데 어디에 놓였는지, 합계와 소계 행이 있는지, 시트가 여러 개인지 본다.
2. `--example` 출력으로 목표 형태를 확인하고 원자료의 열과 행을 입력 항목에 대응시킨다.
3. 가공 코드를 작성해 실행하고 `prepare_<도구>.py` 같은 파일로 입력 JSON 옆에 저장한다. parse_input.py가 만든 마크다운 표도 같은 방식으로 읽어 가공한다.
4. 가공 결과를 표로 보여 준다. 원자료에 합계가 있으면 가공한 값의 합과 대조한 결과도 보여 주고 사용자 확인을 받는다.
5. 확인이 끝나면 계산 스크립트를 실행한다.

가공 규칙은 다음과 같다.

- 계산 스크립트는 천 단위 쉼표, 앞뒤 공백, 전각 숫자, 괄호 음수 "(100)", 음수 표시 "△100", 퍼센트 "4.5%"(0.045로 읽음)를 직접 읽는다. "억원"처럼 단위 글자가 붙은 값과 "▲", "▼"는 자료마다 뜻이 달라 받지 않으므로 가공 단계에서 숫자로 바꾼다.
- 모든 금액은 입력 JSON의 `unit` 에 적은 단위 하나로 맞춘다. "1조 2,000억원"은 12,000억원이다. 환산 배수는 코드에 이름 붙은 상수로 적는다.
- 할인율, 점유율, 기여율, 도입률 같은 비율은 소수로 넣는다(4.5%는 0.045). concentration.py의 `basis: "share"` 는 합이 100인 퍼센트와 합이 1인 소수를 모두 받고 어느 쪽으로 읽었는지 출력한다.
- 연도가 열로 놓인 가로형 표는 연도, 항목, 값이 한 행씩인 세로형으로 바꾼 뒤 도구 형태로 옮긴다.
- "2024년", "'24", "2024p", "2024E"는 정수 연도로 바꾸고, 잠정치(p)와 추정치(E) 표시는 보고서의 입력값 표에 남긴다. 회계연도가 1월에 시작하지 않으면 그 사실을 적는다.
- 합계와 소계 행은 계산에 넣지 않고 대조용으로 따로 둔다. 전국 행과 합계 행을 쓰는 regional.py는 `national_label`, `total_label` 로 그 행의 이름을 알려 준다.
- "-", "…", "X", "N/A", 빈칸은 0으로 채우지 않는다. 각주가 "-"를 0이나 해당 없음으로 정의한 경우에만 0으로 바꾸고, 뜻이 적혀 있지 않으면 결측으로 두고 사용자에게 묻는다. 계산 스크립트는 이런 표시를 만나면 멈춘다.
- 같은 대상을 다르게 적은 이름(예: "서울특별시"와 "서울")은 하나로 맞추고 대응표를 코드에 남긴다. 산업은 한국표준산업분류의 같은 수준으로 맞춘다.
- 총사업비만 있고 연차별 금액이 없으면 임의로 나누지 않고 사용자에게 배분 기준을 묻는다.
- 경상가격과 불변가격, 연결과 별도, 잠정치와 확정치가 섞이면 한 기준으로 맞춘 뒤 계산한다.

도구별로 자주 받는 원자료와 가공 방법은 다음과 같다.

| 도구 | 목표 형태 | 흔한 원자료와 가공 |
| --- | --- | --- |
| growth.py | `series` 에 연도별 값 | 연도가 열인 통계표에서 해당 행을 연도와 값의 쌍으로 바꾼다 |
| feasibility.py | `costs`, `benefits` 에 연도, 항목, 금액 | 항목이 행이고 연도가 열인 연차별 투자계획표의 칸마다 한 줄씩 만든다 |
| io_impact.py | `allocations`, `coefficients` | 유발계수표에서 배정한 부문의 행만 뽑는다 |
| regional.py | 지역, 산업, 값 열이 있는 CSV | 사업체 구분 '계' 행만 남기고 세로형으로 바꾼다 |
| concentration.py | `firms` 에 기업별 매출이나 점유율 | 점유율 표의 기타 행은 `other` 로 넣는다 |
| financials.py | `periods` 에 기간별 계정 금액 | 재무제표 분석 절의 계정 대응으로 계정명을 입력 항목 이름으로 바꾼다 |
| bep.py | 제품별 가격과 변동비, 고정비 | 원가 명세를 고정비와 변동비로 나누고 나눈 근거를 적는다 |
| variance.py | 항목별 예산과 실적의 수량, 단가 | 예산 대비 실적표에 금액과 수량만 있으면 가공 코드에서 금액을 수량으로 나눠 단가를 만든다 |
| ahp.py | 평가자별 `upper` 나 `matrix` | 가중치 산정 절의 설문 변환 규칙으로 응답을 쌍대비교 값으로 바꾼다 |
| market_size.py | `top_down`, `bottom_up` | 시장 보고서 수치를 요소별로 옮기고 출처를 붙인다 |

## 성장률

growth.py는 연평균성장률, 전년 대비 증가율, 실질가격 환산, 성장률 기반 전망을 계산한다.

- 연평균성장률(CAGR) = (마지막 값 / 첫 값)^(1/n) - 1 이고 n = 마지막 연도 - 첫 연도다. 해마다 이어진 자료라면 n은 자료 개수에서 1을 뺀 값이다. 2020년부터 2022년까지 자료로 구하면 n = 2 이므로 "3년간 연평균"이라고 쓰지 않는다.
- 첫 값이 0 이하이거나 마지막 값이 음수면 연평균성장률을 정의할 수 없다. 스크립트는 n/a를 내고, 보고서에는 증감액을 쓴다.
- 연도가 건너뛴 구간의 전년 대비 증가율은 해당 구간의 연평균으로 계산된다.
- 실질가격 = 명목가격 × (기준연도 지수 / 해당연도 지수)다. 지수는 GDP 디플레이터나 소비자물가지수를 쓰고 지수 이름과 기준연도를 적는다. 예비타당성조사는 비용에 건설투자 디플레이터, 편익에 소비자물가지수를 원칙으로 쓴다.
- 전망은 마지막 관측값에 연평균성장률을 복리로 적용한다. `projection_rate` 를 주면 그 값을 쓴다. 연평균성장률은 양 끝 값만 반영하므로 전년 대비 증가율 표에서 변동이 큰지 함께 본다.

결과를 보고할 때는 대입한 산식을 한 줄로 보여 주고, 최종 성장률은 복사하기 쉽게 퍼센트 값만 코드 블록에 따로 적는다.

## 경제성 분석

feasibility.py는 연도별 비용과 편익으로 현재가치, 순현재가치(NPV), 편익비용비(B/C), 내부수익률(IRR), 회수기간, 민감도, 전환값을 계산한다.

판단 기준은 B/C 1.0 이상, NPV 0 이상, IRR이 할인율보다 큰 경우다. 비용의 현재가치가 양수면 B/C와 NPV는 항상 같은 결론을 낸다. IRR이 다른 결론을 내면 NPV를 따른다.

할인 방식은 다음과 같다.

- 기준 시점은 `base_year` 연말이다. t년 금액의 현재가치는 금액 / (1 + r)^(t - base_year) 다. 예비타당성조사는 분석을 시작한 해의 전년도 말을 기준 시점으로 삼는다.
- 공공사업의 사회적 할인율은 4.5%다. 분석기간이 30년 이상인 철도와 수자원 사업은 운영 30년까지 4.5%, 이후 3.5%를 쓴다. 이 경우 `rate_schedule` 에 `[{"to_year": 운영30년차, "rate": 0.045}, {"rate": 0.035}]` 를 넣는다.
- 민간사업이나 재무성 분석은 사용자가 정한 자본비용이나 목표수익률을 쓴다. 예비타당성조사의 재무성 분석은 실질 4.5%를 쓴다.
- 할인율과 분석기간 규정은 개정될 수 있으므로 공공사업이면 적용 전에 최신 「예비타당성조사 수행 총괄지침」을 확인한다. 이 문서의 수치는 기획예산처훈령 제63호(2026. 5. 29.) 기준이다.

비용은 다음 규칙으로 정리한 뒤 입력한다.

- 부가가치세는 세금 이전이므로 경제성 분석 비용에서 뺀다. 부가세가 포함된 항목에 `"vat_included": true` 를 붙이면 스크립트가 1.1로 나눈다. 세율이 다르면 `vat_rate` 로 바꾼다.
- 이미 지출해서 사업 여부와 관계없는 매몰비용은 넣지 않는다. 보조금과 세금 같은 이전지출도 넣지 않는다.
- 운영비, 유지관리비, 사업 종료 후 후속 연구비처럼 해마다 드는 비용은 `recurring_costs` 에 기간과 연간 금액으로 넣는다.
- 분석기간이 끝날 때 남는 토지와 장비의 가치는 `residual_values` 에 넣는다. 스크립트는 그 해 비용에서 뺀다. 토지는 매입가 전액, 장비와 건물은 남은 내용연수만큼 계산한다.
- 모든 금액은 같은 기준연도의 불변가격으로 맞춘다.

분석기간은 사업 유형에 따라 다르다. 도로, 공항, 항만, 의료시설 등 건설사업은 사업기간과 운영 30년, 철도는 운영 40년, 수자원은 운영 50년을 더한다. 정보화사업과 기타 재정사업은 사업마다 정한다. 연구개발사업은 사업기간, 편익 회임기간, 편익기간을 더한다.

편익은 연도별 금액(`benefits`)으로 넣거나 편익 흐름(`benefit_streams`)으로 만든다.

- 회임기간은 사업이 끝난 뒤 편익이 아직 생기지 않는 햇수다. 편익 흐름은 `project_end_year + gestation_years + 1` 년에 시작해 `benefit_years` 동안 이어진다. 회임기간 3년이면 사업 종료 후 3년 동안 편익이 없고 4년째부터 생긴다. 스크립트 출력의 입력 항목 표에서 시작 연도와 끝 연도를 확인한다.
- 사업 전체가 하나의 로드맵이면 편익 흐름 하나를 쓴다. 서로 독립된 기술을 여러 개 개발하면 기술마다 회임기간과 편익기간이 다른 흐름을 만들고, 흐름을 합친 편익이 사업 전체 편익을 넘지 않는지 확인한다.
- 회임기간을 사업계획서가 정하지 않았다면 기초연구 5년, 응용과 개발연구 3년을 출발점으로 삼고 사업 종료 시점의 기술성숙도를 고려해 조정한다.
- 편익기간은 사업계획서 근거를 쓰고, 근거가 없으면 관련 특허로 구한 기술수명주기를 쓸 수 있다.
- 연구개발 편익은 시장수요 접근법으로 계산할 수 있다. 연간 편익 = 미래 시장규모 × 사업기여율 × R&D 기여율 × 사업화 성공률 × 부가가치율이다. 흐름에 `market_size` 와 `factors` 를 넣으면 스크립트가 곱한다. 다섯 값 모두 출처를 적는다.
- 산업연관 유발효과는 편익에 넣지 않는다. 생산과 부가가치 유발액을 편익에 더하면 같은 효과를 두 번 세게 된다.

IRR은 순현금흐름의 부호가 두 번 이상 바뀌면 여러 개가 나오거나 없을 수 있다. 스크립트는 찾은 값을 모두 보여 주고, 하나가 아니면 NPV와 B/C로 판단하라고 알린다.

회수기간은 첫 현금흐름 연도부터 누적 순현금흐름이 0 이상이 되는 시점까지의 햇수다. 할인 회수기간은 현재가치 기준이다. 공공 연구개발사업의 경제성 판단에는 보통 쓰지 않지만 민간사업 검토에는 유용하다.

`--xlsx` 로 저장하면 첫 시트 `CF formulas` 에 연도별 비용, 편익, 할인율, 할인계수, 현재가치와 합계, PV 비용, PV 편익, NPV, B/C, IRR이 엑셀 수식으로 들어간다. 할인계수는 기준 시점부터 이어지는 수식(기준연도 다음 해 = 1/(1+r), 이후 = 전년 할인계수/(1+r))이라 할인율 열을 고치면 모든 결과가 다시 계산된다. 엑셀 IRR 함수는 근을 하나만 보여 주므로 부호가 여러 번 바뀌는 흐름은 스크립트 보고서의 IRR 목록을 따른다.

민감도는 기본으로 할인율 ±1%p, 비용 ±10%, 편익 ±10%를 계산한다. `sensitivity` 로 폭을 바꿀 수 있다. 전환값은 B/C가 정확히 1.0이 되는 편익 변화율과 비용 변화율이며, 결과가 얼마나 여유 있는지 보여 준다.

## 경제적 파급효과

io_impact.py는 사업비를 산업연관표 부문에 나눠 배정하고 유발계수를 곱해 생산, 부가가치, 취업, 고용 유발효과를 계산한다.

- 생산유발액 = Σ(부문별 지출액 × 생산유발계수), 부가가치유발액 = Σ(지출액 × 부가가치유발계수)다.
- 취업유발인원과 고용유발인원 = Σ(지출액 × 금액 단위 / 계수 기준 금액 × 계수)다. 한국은행 계수는 최종수요 10억원당 명이므로 지출액이 억원이면 10으로 나눈다. 스크립트는 `amount_unit_krw`(기본 1억원)와 `labor_basis_krw`(기본 10억원)로 이 환산을 한다.
- 취업은 자영업자와 무급가족종사자를 포함한 모든 취업자, 고용은 임금근로자만 센다. 둘은 다른 지표이므로 이름을 섞지 않는다.

진행 순서는 다음과 같다. 사용자가 한 번에 모두 주면 바로 계산한다.

1. 총사업비와 금액 단위를 확인한다.
2. 사업비 항목을 산업연관표 상품 부문에 배정한 안을 만들고 사용자 확인을 받는다.
3. 부문별 유발계수를 사용자에게 받는다. 산업연관표 파일을 받았으면 해당 행을 뽑아 표로 보여 주고 확인을 받는다. 산업연관표는 부문이 많고 표가 복잡해 행을 잘못 읽기 쉽기 때문이다.
4. 계수의 출처(한국은행 산업연관표 연도, 국산 기준 여부, 지역표 여부)를 `coefficient_source` 에 적고 계산한다.

계산 규칙은 다음과 같다.

- 토지 매입비는 기존 자산의 소유권 이전이라 생산을 일으키지 않으므로 뺀다. 부가가치세와 이전지출도 뺀다. 뺀 항목은 `excluded` 에 사유와 함께 적는다. 스크립트가 총사업비와 배정액, 제외액이 맞는지 대조한다.
- 계수는 최종수요에 곱한다. 매출이익이나 영업이익에 곱하지 않는다.
- 생산유발액에는 처음 지출한 금액이 들어 있다. 생산유발액과 부가가치유발액을 더하지 않는다.
- 특정 지역에 미치는 효과는 지역산업연관표나 지역간산업연관표의 계수를 쓴다. 예비타당성조사의 지역경제 파급효과는 지역간산업연관표 기반 모형이 원칙이다.
- 산업연관 계수는 투입 비율이 고정되고 공급 제약이 없다고 가정한다. 다른 곳에서 줄어드는 지출을 빼지 않은 총효과이므로 보고서에 그렇게 적는다.

## 지역 산업 분석

regional.py는 입지계수(LQ), 전국 대비 비중, 변이할당분석을 계산한다. `mode` 로 `lq` 와 `shift_share` 를 고른다.

- 입지계수 = (지역 산업 값 / 지역 전체 값) / (전국 산업 값 / 전국 전체 값)이다. 1보다 크면 그 지역이 전국 평균보다 해당 산업 비중이 높다. 특화 여부를 가를 기준값은 `threshold` 로 정하고 보고서에 적는다. 기본값은 1.0이다.
- 전국 대비 비중 = 지역 산업 값 / 전국 산업 값이다. 보고서에 따라 이 지표를 집적도라고 부르기도 하므로 이름과 함께 산식을 적는다.
- 값은 종사자수, 사업체수, 매출액, 부가가치 중 하나로 정하고 어떤 기준인지 적는다.

데이터는 한 행에 지역, 산업, 값이 하나씩 있는 CSV나 XLSX로 준비한다.

- 통계청 전국사업체조사처럼 사업체 구분이 있는 표는 구분 '계' 행만 남긴다. 같은 지역과 산업이 두 번 나오면 스크립트가 멈춘다.
- 산업은 한 분류 수준(대분류 또는 중분류)만 쓴다. 대분류와 중분류를 섞으면 합계가 두 번 잡힌다.
- 비밀보호로 가려진 칸(X 등)은 지우거나 따로 처리하고 사용자에게 알린다.
- 전국 행이 있으면 `national_label`, 전 산업 합계 행이 있으면 `total_label` 에 그 이름을 적는다. 없으면 스크립트가 지역과 산업을 더해 만들고, 그 전제를 출력에 적는다.

변이할당분석은 두 시점 사이 지역 산업의 증감을 세 부분으로 나눈다. 세 값의 합은 실제 증감과 같고 스크립트가 이를 확인한다.

- 전국 성장효과 = 기준시점 지역 산업 값 × 전국 전 산업 성장률
- 산업구조효과 = 기준시점 값 × (전국 해당 산업 성장률 - 전국 전 산업 성장률)
- 지역경쟁효과 = 기준시점 값 × (지역 해당 산업 성장률 - 전국 해당 산업 성장률)

지역경쟁효과가 양수면 그 지역의 해당 산업이 전국의 같은 산업보다 빠르게 성장했다는 뜻이다.

`target` 에 산업을 지정하면 지역끼리, 지역을 지정하면 산업끼리 비교한다. 표는 입지계수 내림차순이다. 표를 보여 준 뒤 차트가 필요한지 묻고, 필요하면 `chart` 에 파일 경로를 넣어 다시 실행한다. 차트는 입지계수가 큰 순서로 위에서부터 그린 가로 막대와 기준선, 값 표시만 담는다. 한글 글꼴(나눔고딕, 맑은 고딕 등)이 없으면 경고가 나온다.

## 시장 집중도

concentration.py는 허핀달-허쉬만 지수(HHI), 상위 기업 점유율 합계(CR1, CR3, CR4), 기업결합 전후 변화를 계산한다.

- HHI = Σ(점유율%)² 이고 범위는 0에서 10,000이다. 10,000 / HHI는 같은 크기 기업이 몇 개 있는 시장과 같은지 보여 준다.
- 시장 범위(상품, 지역, 기간)를 먼저 정한다. 범위를 넓게 잡으면 HHI가 낮아지므로 범위를 보고서에 적는다.
- 매출액을 넣으면 점유율로 바꾸고, 점유율을 넣으면 합이 100%인지 확인한다.
- 목록에 없는 기업을 '기타' 한 덩어리로 넣으면 HHI를 범위로 보여 준다. 하한은 기타를 아주 작은 기업들로, 상한은 기타를 한 기업으로 본 값이다.
- 두 기업의 결합을 보려면 `merger` 에 두 이름을 넣는다. HHI 증가분 = 2 × 두 기업 점유율의 곱이다.

참고 기준으로 공정거래위원회 기업결합 심사기준의 수평결합 안전지대(HHI 1,200 미만, HHI 1,200 이상 2,500 미만이면서 증가분 250 미만, HHI 2,500 이상이면서 증가분 150 미만)와 미국 2023 기업결합 가이드라인(결합 후 HHI 1,800 초과 또는 결합 기업 점유율 30% 초과이면서 증가분 100 초과)을 함께 출력한다. 이 결과는 1차 선별용이며 법적 판단은 해당 기관의 심사로 정해진다.

## 재무제표 분석

financials.py는 여러 기간의 재무제표 금액으로 파생 지표, 재무비율, 기간 간 변동, 재무제표 사이 정합성을 계산한다. 입력 항목 이름은 `--example` 을 따른다.

파생 지표의 정의는 다음과 같다.

| 지표 | 정의 |
| --- | --- |
| EBITDA | 영업이익 + 감가상각비 + 무형자산상각비 |
| CAPEX | 유형자산 취득 + 무형자산 취득 (현금흐름표 투자활동) |
| 순 CAPEX | CAPEX - 자산 처분으로 받은 현금 |
| OPEX | 판매비와관리비 |
| 영업비용 | 매출원가 + 판매비와관리비 |
| FCF | 영업활동현금흐름 - CAPEX |

- EBITDA는 회계기준이 정한 이익이 아니다. 회사마다 계산이 다를 수 있으므로 위 정의를 보고서에 적는다. 당기순이익에서 거꾸로 계산한 값과는 영업외손익만큼 차이가 난다.
- OPEX는 쓰는 곳에 따라 뜻이 다르다. 재무제표 분석에서는 판매비와관리비로 보고, 사업계획에서는 운영 기간에 해마다 드는 현금 비용(인건비, 유지보수비, 임차료 등, 감가상각비 제외)을 뜻한다. 사업계획의 CAPEX는 초기 투자비다. 사업계획 수치는 경제성 분석의 `costs` 와 `recurring_costs`, 손익분기점의 감가상각비 입력으로 쓴다.
- 안정성 비율은 한국은행 기업경영분석의 정의를 따른다. 부채비율 = 부채 / 자기자본 × 100, 이자보상비율 = 영업이익 / 이자비용 × 100, 차입금의존도 = 차입금 / 총자산 × 100이다. 차입금에는 회사채를 포함한다.
- ROA와 ROE는 당기순이익으로 계산한다. 세전순이익으로 계산한 통계와 비교할 때는 분자를 맞춘다.
- ROA, ROE, 회전율은 앞 기간이 있으면 기초와 기말 평균 잔액을, 없으면 기말 잔액을 쓴다. 표의 괄호가 어느 쪽인지 알려 준다.
- 재고자산회전율은 매출원가가 있으면 매출원가, 없으면 매출액으로 계산하고 표에 적는다.
- 정합성 점검은 자산 = 부채 + 자본, 기말현금 = 기초현금 + 영업, 투자, 재무활동 현금흐름 + 환율변동효과, 영업이익과 (매출액 - 매출원가 - 판매비와관리비)의 차이를 본다. 영업이익 차이는 기타 영업손익이 있다는 뜻일 수 있다.
- 변동 표시는 증감률과 금액 기준을 모두 넘는 항목에 붙는다. 사용자가 기준을 주지 않으면 증감률 10%를 선별용 기본값으로 쓰고 출력에 그렇게 적는다. 중요성 판단은 사용자가 정한 기준으로 한다.
- 2027년 1월 1일 이후 시작하는 회계연도부터 한국채택국제회계기준 제1118호가 적용되어 영업이익의 범위가 바뀐다. 2026년 이전과 2027년 이후 수치를 비교하면 같은 기준으로 다시 작성된 수치인지 확인한다.
- 연결재무제표와 별도재무제표를 섞지 않고, `statement_basis` 에 어느 쪽인지 적는다.

계정 대응은 한국채택국제회계기준 재무제표의 계정명을 기준으로 한다.

## 손익분기점

bep.py는 공헌이익으로 손익분기점, 목표이익 판매량, 안전한계율, 영업레버리지도를 계산한다.

- 단위 공헌이익 = 판매가격 - 단위 변동비다. 제품이 여러 개면 판매수량 구성비(`mix`, 합계 1)로 가중평균한다.
- 회계상 손익분기 판매량 = (현금 고정비 + 감가상각비) / 가중평균 단위 공헌이익이다. 현금 손익분기 판매량은 감가상각비를 뺀 고정비로 계산하며, 현금 유출이 멈추는 판매량을 뜻한다.
- 감가상각비는 금액으로 넣거나 CAPEX, 내용연수, 잔존가치를 넣어 정액법으로 계산한다.
- 목표이익은 세전 금액(`pre_tax`)이나 세후 금액과 세율(`after_tax`, `tax_rate`)로 넣는다. 세전 목표 = 세후 목표 / (1 - 세율)이다.
- 예상 판매량을 넣으면 안전한계율(예상 판매량 대비 손익분기 초과분)과 영업레버리지도(공헌이익 / 영업이익)를 계산한다.
- 이 계산은 가격, 단위 변동비, 제품 구성비가 판매량과 관계없이 일정하다고 가정한다. 비용을 고정비와 변동비로 나눈 근거를 보고서에 적는다.

## 차이 분석

variance.py는 예산(또는 전기)과 실적의 차이를 항목별로 나누고 가격, 구성비, 물량 효과로 분해한다.

- 수익 항목은 실적이 예산보다 크면 유리, 비용 항목은 실적이 예산보다 작으면 유리다. `kind` 에 `revenue` 나 `cost` 를 넣는다.
- 가격효과 = Σ(실적 단가 - 예산 단가) × 실적 수량
- 구성비효과 = Σ(실적 수량 - 실적 총수량 × 예산 구성비) × 예산 단가
- 물량효과 = (실적 총수량 - 예산 총수량) × 예산 평균 단가
- 세 효과의 합은 총차이와 같고 스크립트가 이를 확인한다.
- 구성비효과는 항목들이 같은 수량 단위를 쓸 때만 의미가 있다. 단위가 다르면 `"separate_mix": false` 로 두어 항목별 물량효과만 계산한다.
- 수량이 없으면 `budget` 과 `actual` 금액만 넣는다. 이때는 항목별 차이와 브리지 표만 나온다.
- 표시 기준은 재무제표 분석과 같다. 사용자가 정한 증감률과 금액 기준을 모두 넘는 항목에 표시한다.
- 인건비 차이는 수량에 인원, 단가에 1인당 평균 인건비를 넣어 같은 방식으로 나눈다. 가격효과가 단가 차이, 물량효과가 인원 차이다.
- 예산, 전망, 실적을 함께 비교하려면 실적 대 예산, 실적 대 전망으로 두 번 실행한다.

표시된 항목마다 차이 금액과 비율, 유리 또는 불리, 어느 효과가 컸는지, 일회성인지 계속될지, 필요한 후속 조치를 두세 문장으로 적는다. "매출이 늘어서 매출 차이가 생겼다"처럼 결과를 원인으로 되풀이하는 설명은 쓰지 않는다. 브리지 표는 예산에서 출발해 각 효과를 더해 실적에 도착하며, 도착 값이 실적과 맞는지 스크립트가 확인한다.

## 가중치 산정

ahp.py는 AHP 쌍대비교 행렬로 평가 항목의 가중치와 일관성 비율(CR)을 구하고 여러 평가자를 합친다.

- 가중치는 쌍대비교 행렬의 주고유벡터이고 합이 1이다. CI = (λmax - n) / (n - 1), CR = CI / RI이다. RI는 Saaty(2000)의 값(n=3부터 9까지 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45)을 쓴다.
- 한 행렬의 비교 항목은 2개 이상 9개 이하로 둔다. 항목이 많으면 상위와 하위 계층으로 나눠 계층마다 실행한다. 하위 계층의 전체 가중치는 `parent_weight`(상위 항목 가중치)를 넣어 구한다.
- 행렬은 전체 행렬(`matrix`)이나 대각선 위쪽 값(`upper`)으로 넣는다. `upper` 는 행 순서대로 읽는다. 항목이 3개면 1행 2열, 1행 3열, 2행 3열 순서다. 값은 1/9에서 9 사이이고 "1/3" 같은 분수 문자열도 받는다.
- 9점 척도 설문은 왼쪽 항목을 i, 오른쪽 항목을 j로 두고 바꾼다. 응답자가 왼쪽 쪽에 k를 표시하면 a_ij = k, 오른쪽 쪽에 k를 표시하면 a_ij = 1/k, 가운데(같음)면 1이다. 설문지의 항목 순서가 `criteria` 순서와 다르면 행렬을 만들 때 순서를 맞춘다.
- CR 기준은 일반적으로 0.1 이하다. 예비타당성조사는 CR이 0.15를 넘으면 재설문을 할 수 있다. `cr_threshold` 로 정하고 기준을 넘은 평가자는 재설문을 제안한다.
- 여러 평가자의 가중치는 행렬 원소별 기하평균 행렬로 구한다. `aggregate_consistent_only` 를 true로 두면 CR 기준을 통과한 평가자만 합친다.
- `ratings` 에 평가자별 항목 평점(0에서 1)을 넣으면 평가자별 종합점수 = Σ(본인 가중치 × 평점)를 계산한다. `trim` 에 개수를 넣으면 가장 높은 점수와 가장 낮은 점수를 그 개수만큼 빼고 평균을 낸다. 예비타당성조사 종합평가는 양쪽 2명씩을 빼며, 사업 시행에 대한 점수가 0.5 이상이면 시행이 타당하다고 본다.

## 시장규모 추정

market_size.py는 TAM, SAM, SOM을 하향식으로 계산하고 상향식 추정과 비교한다.

- TAM은 정의한 시장 전체의 연간 수요 금액이다. 수치를 그대로 넣거나 사용자 수 × 도입률 × 사용자당 연간 지출로 만든다.
- SAM은 TAM 가운데 제품 범위, 지역, 판매 경로로 실제 공략할 수 있는 부분이다. 거르는 조건마다 비율과 출처를 `sam_filters` 에 넣는다.
- SOM은 SAM 가운데 경쟁과 공급 능력을 고려해 정해진 기간 안에 확보할 수 있는 부분이다. 목표 점유율의 근거(유사 기업의 진입 초기 점유율 등)를 적는다.
- 상향식 추정 = Σ(고객 수 × 도입률 × 고객당 구매 수량 × 단가 × 연간 구매 횟수)다. 하향식 SOM과 비율을 비교하고, 차이가 크면 어느 가정이 다른지 설명한 뒤 한쪽을 고른다.
- 전망은 `projection` 의 연평균성장률로 계산한다. 성장률도 출처가 필요하다.
- 출처가 빠진 입력은 스크립트가 목록으로 알려 준다. 해외 시장 자료를 원화로 바꾸면 적용 환율과 기준일을 적는다.

## 결과 보고
