# Statement of work (excerpt)

## Project name
In-house hyperscale AI pilot consulting

## Purpose
- Prepare a plan to pilot an in-house hyperscale AI on the quality and design teams' past document search and report drafting work
- Give executives the basis to decide whether to run a pilot in the first half of 2027

## Scope
1. Current-state diagnosis: survey the two teams' document work processes and time spent (10+ staff interviews, 2 weeks of work time measurement)
2. Target task selection: select 2 tasks for the pilot and define impact indicators
3. Model comparison test: compare 3 or more open-weight models on samples of company documents
4. Pilot operation design: in-house server design, security check criteria, operations staffing and cost estimate
5. Reporting: pilot recommendation and executive briefing materials

## Reports and meetings
- 1 kickoff report, 1 interim report, 1 final report
- 1 advisory meeting with the company security team (before the model comparison test)

## Deliverables
- Kickoff report, interim report, final report (including the pilot recommendation), model comparison test report
