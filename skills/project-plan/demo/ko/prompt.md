# 과업지시서 (발췌)

## 과업명
사내 초거대AI 시범 도입 컨설팅

## 과업 목적
- 품질팀과 설계팀의 과거 문서 검색 업무와 보고서 초안 작성 업무에 사내 설치형 초거대AI를 시범 적용하는 방안 마련
- 2027년 상반기 시범 운영 여부를 경영진이 결정할 수 있는 근거 제공

## 과업 범위
1. 현황 진단: 두 팀의 문서 업무 절차와 소요 시간 조사 (실무자 인터뷰 10명 이상, 업무 시간 측정 2주)
2. 대상 업무 선정: 시범 적용 업무 2개 선정과 효과 지표 정의
3. 모델 비교 시험: 공개 가중치 모델 3종 이상을 사내 문서 샘플로 비교 시험
4. 시범 운영 설계: 사내 서버 구성안, 보안 점검 기준, 운영 인력과 비용 추정
5. 결과 보고: 시범 도입 권고안과 경영진 보고 자료 작성

## 보고와 회의
- 착수보고 1회, 중간보고 1회, 최종보고 1회
- 사내 보안팀 자문회의 1회 (모델 비교 시험 전)

## 납품 산출물
- 착수보고서, 중간보고서, 최종보고서(시범 도입 권고안 포함), 모델 비교 시험 결과서
