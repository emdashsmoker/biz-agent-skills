## [2] 문서 찾는 데 시간 많이 쓰는 부서만 추려 줘

**확인이 필요합니다**

"시간 많이 쓰는"에 기준값이 없어 아직 추리지 않았습니다. 검색 시간과 관련된 열도 두 개(C열 1인 월평균 문서 검색 시간, D열 검색 시간 구간)라서 어떤 기준으로 고를지 정해 주세요.

| 번호 | 기준 | 실행할 코드 |
|:---:|:---:|:---:|
| 1 | D열(검색 시간 구간)이 '15시간 이상'인 부서 | `result = df[df['검색 시간 구간'] == '15시간 이상']` |
| 2 | C열(1인 월평균 문서 검색 시간)이 N시간 이상인 부서 | `result = df[df['1인 월평균 문서 검색 시간'] >= N]` |
| 3 | C열 기준 상위 N개 부서 | `result = df.nlargest(N, '1인 월평균 문서 검색 시간')` |
| 4 | 부서 전체 검색 시간(B열 인원 × C열) 기준 상위 N개 부서 | `result = df.assign(부서_검색시간=df['인원'] * df['1인 월평균 문서 검색 시간']).nlargest(N, '부서_검색시간')` |

번호와 필요한 값을 알려 주세요. 예: "1번", "2번, 10시간", "3번, 3개". 1번은 파일에 이미 있는 구간을 그대로 쓰므로 기준값을 따로 정하지 않아도 됩니다.

## [3] 설계팀 인원이 잘못 들어갔어. 14명으로 고쳐 줘

**현재 상태**
- 환경: Python 3.13 | pandas 3.0.5
- 데이터: df (10행 × 6열)
- 열 매핑: A=부서, B=인원, C=1인 월평균 문서 검색 시간, D=검색 시간 구간, E=1인 월평균 보고서 작성 시간, F=문서 보관 방식

**실행 코드**
```python

# 해석: A열(부서)이 '설계팀'인 행(2행)의 B열(인원)을 14로 변경, 즉 B2 = 14

result = df[df['부서'] == '설계팀']
```
