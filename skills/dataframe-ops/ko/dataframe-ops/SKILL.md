# dataframe-ops

자연어나 엑셀식 좌표로 받은 표 데이터 요청을 pandas 코드로 바꿔 실행하는 스킬이다. 실행한 코드와 결과 표를 함께 보여주며, 보여준 코드만으로 같은 결과를 다시 만들 수 있다.

## 기본 원칙

- 실행한 pandas 코드를 매 응답에 보여준다. 사용자가 결과가 어디서 나왔는지 직접 확인할 수 있어야 한다.
- 자연어 요청, pandas 코드, 엑셀식 좌표를 모두 받는다. 세 방식을 한 요청에 섞어 써도 같은 명령으로 처리한다.
- 같은 요청에는 같은 형식으로 답한다. 형식은 아래 "응답 형식"을 따른다.
- 숫자 계산은 pandas와 무관한 질문이라도 Python 코드로 한다. 합계, 평균, 비율, 행 수를 모델이 직접 계산해 적지 않는다.
- 사용자가 요청한 내용만 보여준다. 기초 통계처럼 요청하지 않은 정보는 덧붙이지 않는다.

## 보조 스크립트

`scripts/dataframe_ops.py`에는 좌표 변환, 표 출력, 행 범위 계산, 민감 정보 탐지, 체크포인트, 환경 점검 함수가 들어 있다. 코드를 실행할 수 있으면 세션 시작 때 불러온다.

```python
import sys
sys.path.insert(0, "<이 스킬 폴더>/scripts")
import dataframe_ops as dfo
session = dfo.Session()
```

- 기본 출력 행 수, 페이지 크기 같은 설정값은 파일 위쪽 상수에 모여 있고 이 문서의 숫자와 같다.
- 사용자에게 보여주는 실행 코드에는 `dfo` 함수를 쓰지 않는다. 사용자가 자기 컴퓨터에서 pandas만으로 결과를 재현해야 하기 때문이다. 좌표 요청은 `dfo.ref_to_code()`가 만든 `df.iloc[...]` 코드를 보여준다.
- 스크립트를 불러올 수 없는 환경에서는 파일 내용을 읽고 같은 규칙으로 처리한다.

## 작업 순서

요청 하나를 네 단계로 처리한다.

| 단계 | 하는 일 |
|---|---|
| 인식 | 입력이 자연어 명령인지, pandas 코드인지, 파일 업로드인지 구분한다 |
| 기억 | 주 데이터 `df`, 최근 결과 `result`, 실행 기록, 출력 설정을 세션 내내 유지한다 |
| 계획 | 단일 명령은 바로 실행한다. 여러 동작이 이어진 명령은 단계로 나눠 연달아 실행한다. 모호한 명령은 먼저 묻는다 |
| 실행 | 코드를 실행하고 결과 표를 보여준 뒤 기록에 남긴다 |

- 조회, 필터, 정렬, 집계 결과는 `result`에 담는다. 이때 `df`는 그대로 둔다.
- 추가, 삭제, 이름 변경, 값 변경처럼 수정 의도가 분명한 명령만 `df`에 반영한다. 사용자가 결과를 보고 "이걸로 바꿔줘"라고 하면 `df = result.copy()`로 반영한다.
- 실행한 코드 블록 하나를 명령 1회로 센다. 실행 후 `session.record(code, modifies=...)`를 부른다. `df`를 바꾼 코드면 `modifies=True`로 넘긴다. 반환값이 True면 자동 체크포인트를 저장한다.
- `df`를 바꿀 때는 `df = df.drop(...)`처럼 결과를 다시 대입한다. pandas가 여러 메서드에서 `inplace=True` 폐지를 예고했기 때문에 이 인자는 쓰지 않는다.

## 세션 시작

첫 응답 전에 아래 순서로 준비한다. 세부 절차와 안내 문구는 `references/environment.md`에 있다.

1. 실행 환경을 찾는다. 내장 코드 실행기, 연결된 Python 실행 도구(MCP 서버 등), 외부 코드 실행 API 순서로 확인한다. 모두 없으면 시뮬레이션 모드로 전환한다.
2. 사용자 컴퓨터에서 실행 중이면 가상환경을 확인한다. 채팅 서비스의 일회용 실행기에서는 이 단계를 건너뛴다.
3. 설치된 pandas 버전을 확인한다. 웹 검색 도구가 있으면 그 버전과 최신 안정 버전의 공식 릴리스 노트를 확인한다.
4. 초기화 안내를 보여준다.

`/env`, "환경 확인", "환경 재탐지"를 받으면 1번부터 다시 확인한다.

## 명령 해석

자연어 요청은 의도를 먼저 정하고 pandas 코드로 옮긴다. 의도는 불러오기, 저장, 보기, 필터, 정렬, 그룹 집계, 수정, 통계, 시각화, 도움말로 나눈다. 의도별 키워드와 전체 명령어 표는 `references/commands.md`에 있다.

아래 경우에는 실행하지 않고 먼저 묻는다.

- 이름이 정확히 같은 열이 없고, 이름 일부가 겹치는 열이 두 개 이상이다. 예를 들어 "나이대"와 "나이 구간"만 있는 데이터에서 "나이"를 요청하면 어느 열인지 묻는다.
- 조건에 기준값이 없다. "높은 것"이 "상위 10개"인지 "100 이상"인지 묻는다.
- 열 이름이 좌표처럼 생겼다. 열 이름이 `A`나 `B3`이면 좌표인지 열 이름인지 묻는다.

요청한 열이 하나도 없으면 오류 형식으로 답하고 `dfo.similar_columns()`로 비슷한 열 이름을 제안한다.

## 좌표 규칙

엑셀처럼 열은 알파벳으로, 행은 숫자로 부른다.

- 열 문자는 `df`의 열 순서를 따라 A, B, ..., Z, AA, AB 순으로 붙는다.
- 첫 데이터 행이 1행이다. 열 이름 줄은 행 번호에 들어가지 않으므로 A1은 첫 열의 첫 데이터 값이다.
- 좌표는 항상 현재 `df`의 위치를 가리킨다. 행을 삭제하면 아래 행들의 번호가 하나씩 당겨진다.
- 필터나 정렬 결과 표는 `df` 기준의 행 번호와 열 문자를 그대로 쓴다. 결과 표에서 본 번호로 `df`의 셀을 바로 가리킬 수 있게 하기 위해서다. `dfo.render(result, base=df)`가 이 방식으로 번호를 붙인다.
- 그룹 집계처럼 새로 만들어진 표에는 열 문자를 붙이지 않고 행 번호는 1부터 센다(`dfo.render(result)`). 좌표는 `df`의 셀만 가리키기 때문이다.
- "B열 평균", "나이 평균", "나이 열 평균"은 모두 같은 명령이다.
- 좌표를 코드로 옮길 때는 위치 기반 `iloc`을 쓴다. 행 삭제도 `df.drop(df.index[2])`처럼 위치로 지정한다. 앞선 삭제로 행 이름표와 위치가 달라져도 좌표가 맞게 유지된다.

`/map`, "열 매핑", "좌표 확인"을 받으면 좌표, 열 이름, 데이터 타입, 샘플 값(비어 있지 않은 첫 값)을 표로 보여준다(`dfo.column_map_rows(df)`). 표 아래에 "B3은 나이 열의 3번째 값" 같은 사용 예를 한 줄 붙인다.

## 응답 형식

### 출력 모드

- `markdown` 모드는 채팅 화면처럼 마크다운 표가 표로 보이는 곳에서 쓴다. 기본값이다.
- `ascii` 모드는 터미널이나 API 원문처럼 마크다운 기호가 글자 그대로 보이는 곳에서 쓴다.
- `/render auto`는 응답이 표시되는 화면을 기준으로 모드를 고른다. 코드가 도는 곳과 화면이 다른 경우가 많으므로 Python 쪽 환경 변수로는 판단하지 않는다.
- `/render`는 현재 모드를 보여준다. `/render markdown`, `/render ascii`로 직접 바꾼다.

### 코드를 실행한 응답

markdown 모드에서는 다섯 부분을 이 순서로 쓴다.

| 순서 | 부분 | 내용 |
|---|---|---|
| 1 | 현재 상태 | 환경, 데이터 크기, 열 매핑을 불릿 세 줄로 |
| 2 | 실행 코드 | python 코드 블록. 자연어 요청이면 맨 위에 `# 입력:`과 `# 해석:` 주석 |
| 3 | 실행 결과 | 결과 표와 완료 한 줄. 완료 줄에는 한 일과 표시한 행 수(전체 몇 행 중 몇 행)를 적는다 |
| 4 | 주요 명령어 | 아래 표와 단축 명령 한 줄 |
| 5 | 상태 줄 | 환경과 데이터 요약 한 줄 |

코드 블록은 실행 코드에만 쓴다. 현재 상태, 결과 표, 완료 줄, 명령어 표, 상태 줄을 코드 블록 안에 두면 표가 깨지므로 모두 일반 텍스트로 쓴다.

예시는 아래와 같다.

**현재 상태**
- 환경: Python 3.11 | pandas 3.0.6
- 데이터: df (100행 × 3열)
- 열 매핑: A=이름, B=나이, C=부서

**실행 코드**
```python
# 입력: 나이 30 이상, 영업부만
# 해석: (B열 >= 30) 그리고 (C열 == '영업')
result = df[(df['나이'] >= 30) & (df['부서'] == '영업')]
```

**실행 결과**

|     | A(이름) | B(나이) | C(부서) |
|:---:|:---:|:---:|:---:|
| 1 | 김철수 | 32 | 영업 |
| 4 | 홍길동 | 35 | 영업 |

완료: 100행 중 2행 추출

**주요 명령어**

| 자연어 | pandas | 설명 |
|:---:|:---:|:---:|
| 상위 N개 | `df.head(N)` | 처음 N행 |
| A1:C5 선택 | `df.iloc[0:5, 0:3]` | 셀 범위 |
| B열 평균 | `df['열이름'].mean()` | 열 계산 |
| 3행 삭제 | `df.drop(df.index[2])` | 행 제거 |
| 열 매핑 | `/map` | 좌표와 열 이름 |
| 저장 | `df.to_csv('파일.csv', index=False)` | CSV 저장 |

`/?` 전체 명령어 | `/map` 좌표 | `/env` 환경 | `/venv` 가상환경

venv:.dataframe_ops_env | Py 3.11 | pd 3.0.6 | df: 100×3 | 변경: 0 | 실행 가능

상태 줄은 아래 규칙으로 만든다.

- 맨 앞 환경 표시는 `venv:이름`, `conda:이름`, `기본 Python(격리 권장)`, `내장 실행기` 가운데 하나다.
- `변경`은 이 세션에서 `df`를 바꾼 명령의 수(`session.change_count`)다.
- 시뮬레이션 모드의 상태 줄은 `시뮬레이션 | 참조: pandas 버전 | 코드만 생성`이다.
- 숫자는 천 단위 쉼표를 붙인다(`1,234×8`).

### ascii 모드

다섯 부분을 코드 블록 하나에 담고 각 부분의 제목은 `[현재 상태]`처럼 대괄호로 쓴다. 표는 `dfo.render(..., mode="ascii")`로 만든다. 한글처럼 폭이 넓은 글자가 있어도 열이 맞는다.

### 시뮬레이션 모드

실행 환경이 없으면 코드를 만들어 주고 결과는 예시로만 보여준다.

- 실행 코드는 `import pandas as pd`와 파일 불러오기 줄(경로를 바꾸라는 주석 포함)까지 포함한 전체 코드로 쓴다.
- 필터, 정렬, 상위 N개처럼 행을 고르는 요청은 예상 결과 표를 보여주고 "예상 결과(시뮬레이션)"라고 표시한다. 사용자가 데이터를 주지 않았으면 작은 예시 데이터를 쓰고 그 사실을 적는다.
- 합계, 평균, 개수처럼 계산이 필요한 값은 보여주지 않는다. 코드를 실행하지 않고 만든 숫자는 쓰지 않는다는 원칙 때문이다.
- 결과 아래에 "실제 결과는 데이터에 따라 다르며 위 코드를 Python 환경에서 실행해야 함"을 적는다.

### 그 밖의 응답

- (일부 성공) 첫 줄에 "일부 완료"를 쓰고 성공한 항목, 실패한 항목과 원인, 해결 제안을 적는다.
- (오류) 오류 종류, 원인 한 줄, 발생 위치, 해결 방법, 현재 데이터 상태를 적는다. 열 이름 오류면 비슷한 열 이름과 현재 열 목록을 보여주고 "나이를 뜻했는지(y/n)" 묻는다.
- (사용법 질문) "groupby 어떻게 써?" 같은 질문에는 기본 문법, 자연어 예시 두세 개, 여러 집계를 함께 쓰는 예시 하나를 보여준다. 끝에 "부서별 급여 평균 구해줘"처럼 바로 시도할 문장을 제안한다.
- 어떤 응답이든 끝에 주요 명령어와 상태 줄을 붙인다.

## 표 출력 분량

| 설정 | 기본값 |
|---|---|
| 기본 출력 행 수 | 10행 |
| 한 표의 최대 행 수 | 100행 |
| 페이지 크기 | 20행 |
| 셀당 글자 수 | 30자, 넘으면 `...`으로 줄임 |
| 행 번호 표시 | 켬 |

- 결과가 10행 이하면 모두 보여준다. 10행을 넘으면 페이지 방식으로 바꾸어 20행씩 보여주고 "페이지 1/62, 행 1-20 표시"처럼 위치를 적는다.
- 사용자가 행 수를 말하면("50개만", `/h 50`) 그만큼 보여주되 100행을 넘기지 않는다.
- 100행이 넘는 전체 출력을 요청하면 먼저 묻는다. 선택지는 상위 100행만, 그래도 전체(100행씩 나누어 모두 출력), 페이지 방식, CSV로 저장 후 확인이며 페이지 방식이나 CSV 저장을 권한다.
- 빈 값은 `NaN`으로 표시한다.
- 행 범위, 페이지 이동, 출력 설정 명령은 `references/commands.md`에 있다.

## 데이터 보호

### 백업과 실행취소

- `df`를 바꾸는 명령 직전에 `session.keep_backup(df)`로 복사본을 남긴다.
- "되돌리기", "실행취소", "undo", `/u`를 받으면 `df = session.undo()`로 직전 상태로 돌린다.
- 되돌리기는 한 단계까지만 된다. 더 이전 상태는 체크포인트로 복원한다.

### 확인이 필요한 작업

몇 행이 사라질지 사용자가 미리 알 수 없는 삭제는 실행 전에 변경 전후 크기를 보여주고 "취소"와 "백업 후 실행" 가운데 고르게 한다. 결측 행 제거, 중복 행 제거, 조건에 맞는 행 삭제, 두 개 이상의 열을 한꺼번에 지우는 작업이 여기에 해당한다. "백업 후 실행"을 고르면 `before_작업명.pkl` 체크포인트를 저장한 뒤 실행한다.

"3행 삭제", "B열 삭제"처럼 사용자가 대상 하나를 직접 지정한 삭제는 요청 자체를 확인으로 보고 바로 실행한다.

같은 이름의 파일 덮어쓰기, 패키지 설치, 가상환경 생성과 삭제는 실행 여부를 묻는다.

### 민감 정보

데이터를 불러오면 `dfo.find_sensitive_columns(df)`로 개인정보로 보이는 열을 찾는다. 열 이름(주민, 여권, 계좌, 전화, 이메일, 주소 등)과 값 형태(주민등록번호, 미국 사회보장번호, 이메일 주소)를 함께 본다.

- 찾은 열이 있으면 열 이름과 판단 근거를 알린다. 경고 문구에 실제 값은 적지 않는다.
- 마스킹 코드(`df['주민등록번호'] = df['주민등록번호'].astype(str).str[:6] + '******'`)와 삭제 코드(`df = df.drop(columns=['주민등록번호'])`)를 제안하고 계속할지 묻는다.
- 마스킹이나 삭제를 하지 않은 상태에서 체크포인트를 저장하면 원래 값이 파일에 그대로 남는다. 첫 저장 전에 이 사실을 알리고 저장 여부를 묻는다.

### 실행 한도

- 500MB가 넘는 파일은 불러오기 전에 묻는다. 선택지는 일부 행만(`nrows`), 필요한 열만(`usecols`), 나누어 처리(`chunksize`), 그대로 진행이다. 불러온 뒤 `df` 메모리 사용량이 500MB를 넘을 때도 알린다(`dfo.frame_memory_mb(df)`).
- 행마다 Python 함수를 도는 코드(`apply(axis=1)`, `iterrows`, `for` 반복문)는 1,000행이 넘는 데이터에서 먼저 `dfo.estimate_seconds()`로 시간을 추정한다. 추정 시간이 5초를 넘으면 그 시간을 알리고 열 단위로 한 번에 계산하는 대안 코드를 제시한다. 실행은 사용자가 고른 방식으로 한다.
- 파일은 사용자가 올렸거나 경로를 직접 알려준 것만 읽는다. pandas로 인터넷 주소의 데이터를 내려받지 않는다.

## 파일 불러오기

- 파일이 올라오면 `dfo.read_any(path)`로 확장자에 맞게 읽는다. CSV, TSV, TXT는 utf-8-sig, cp949 순서로 인코딩을 시도하고 성공한 인코딩을 실행 코드에 적는다.
- 불러온 뒤 파일 이름, 시트 이름(엑셀), 행과 열 수, 파일 크기, 상위 5행 표를 보여준다. 시트가 여러 개면 다른 시트를 불러오는 문장과 코드를 한 줄로 알린다.
- 이미지 속 표는 모델이 읽은 값을 표로 옮겨 보여주고, 원본과 맞는지 사용자 확인을 받은 뒤 `df`로 만든다.
- PDF 표는 `dfo.pdf_tables()`, Word 표는 `dfo.docx_tables()`로 추출한다. 표가 여러 개면 목록을 보여주고 고르게 한다.
- 불러온 직후 원본 스냅샷 체크포인트를 저장한다. 체크포인트, 재현 코드, 세션 복원은 `references/session-files.md`를 따른다.

## 추가 기능

- (연결 실행) "영업부만 골라 급여 높은 순으로 정렬해서 상위 10개"처럼 이어진 요청은 괄호로 묶은 메서드 연결 하나로 쓴다.
- (매크로) "이 작업 저장해줘"를 받으면 직전 요청에서 실행한 코드 블록들을 `session.macros["macro_1"]`처럼 번호를 붙여 저장하고 내용을 한 줄로 요약해 알린다. "macro_1 실행" 또는 `/run macro_1`로 다시 실행한다.
- (프로파일) "데이터 프로파일", "상세 분석"을 받으면 `dfo.profile(df)` 값으로 네 부분을 보여준다. 기본 정보(행, 열, 메모리), 열별 표(타입, 결측 수, 고유값 수, 최빈값), 숫자 열 분포(평균, 중앙값, 표준편차), 데이터 품질(전체 결측률, 중복 행 수)이다.
- (기록) `/history`, "작업 기록"을 받으면 최근 10개 명령을 번호, 시간, 코드, 결과 요약 표로 보여준다. "3번 다시 실행" 또는 `!3`은 3번 명령의 코드를 다시 실행한다.

## 참조 파일

- `references/commands.md`에는 `/?` 전체 명령어 표, 의도 키워드, 좌표 명령, 행 범위와 페이지 명령, 출력 설정, 파일 형식과 저장 형식, 시각화 명령이 있다.
- `references/environment.md`에는 실행 환경 감지, 가상환경 정책, 패키지 설치 확인, 버전 확인과 호환성 표, 초기화 안내 문구가 있다.
- `references/session-files.md`에는 체크포인트 저장 시점과 파일 이름, 저장과 복원 명령, 컨텍스트 압축 뒤 복원, 세션 종료 처리, 재현 코드 형식이 있다.
- `scripts/dataframe_ops.py`는 이 문서의 규칙을 구현한 함수 모음이다.
