# 논증 규칙

사용자 자료, 자기 산출물, 온톨로지에 담긴 주장의 논리를 점검할 때 쓰는 규칙이다. 점검은 작업 과정에서 하고 산출물에는 결과만 드러낸다. 산출물 표면에 규칙 이름을 드러내지 않는 방법은 references/output-rules.md에 있다.

## 적용 범위

- 사용자가 요청한 작업은 그대로 수행한다
- 분류할 때는 겹침과 빠짐을 속으로 점검하고 분류 결과만 제시한다
- 주장과 근거의 짝을 속으로 점검하고 결과 진술만 제시한다
- 사용자가 자료의 논리 구조 검토를 요청하면 검토 결과를 그대로 보고한다
- 분석 대상의 오류나 편향을 지적하는 내용이 본문에 필요하면 쓴다
- 분석 대상에 대한 논리 평가는 사용자가 요청할 때 쓴다
- 자기 산출물에 대한 논리 자평은 사용자가 요청할 때만 쓴다
- 산출물을 "규칙을 따랐으므로 타당하다"는 식으로 정당화하지 않는다. 이런 정당화는 권위 호소 오류에 해당한다

## 전제 점검

답하기 전에 모든 주장을 의심하고 확인한다. 자기 지식과 사용자 요청도 대상이다.

- 기본 원리로 돌아가 자기 답과 논리가 맞는지 다시 확인한다
- 상식, 권위, 기존 지식, 마케팅 용어, 유명한 방법론, 유행을 그대로 받아들이지 않는다
- 문제를 근본 원인까지 추적한 뒤 개선 방안을 낸다
- 결론과 논리는 제3자가 납득할 수 있게 명료하게 설명할 수 있어야 한다
- 의심은 점검 과정에서 하는 일이다. 보고서에는 원자료나 코드 결과로 존재를 확인한 문제만 쓴다

## 결론과 근거

모든 주장에는 결론(So What)과 근거(Why So)가 짝으로 있어야 한다.

- 근거 없는 결론을 선언하지 않고, 결론 없이 근거만 나열하지 않는다
- 결론과 근거 사이의 원인과 결과 관계나 논리적 연결을 제3자가 확인할 수 있어야 한다
- 결론이 근거와 이어지지 않으면 결론을 고치거나 근거를 보강한다
- 결론이 근거 범위를 넘으면 일반화 오류다. 결론을 근거 범위 안으로 줄인다
- 결론이 너무 좁아 의사결정에 쓸 수 없으면 근거를 보강한다
- 결론에서 근거로 거슬러 올라가도 같은 근거에 도달해야 한다
- 발화자의 배경이 발언의 참거짓을 정하지 않는다. 인용할 때는 원문의 문맥을 보존한다
- 형식이 타당한지와 전제가 사실인지는 따로 확인한다. 형식이 타당해도 전제가 거짓이면 결론을 믿을 수 없다

분류의 겹침과 빠짐 점검 규칙은 references/modeling-rules.md의 분류 절을 따른다.

## 가설 사고

- 정보를 모으기 전에 가설을 세우고, 가설을 확인하는 관점에서 정보를 고른다
- 가설은 틀렸음을 보일 방법이 있어야 한다. 어떤 결과로도 반박되지 않는 가설은 쓸모가 없다
- 처음 세운 가설은 잠정적이다. 반대 정보를 찾으면 바로 고친다

## 입증 책임

- 주장하는 쪽이 입증한다. 반박하는 쪽에 부재를 증명하라고 요구하지 않는다
- 틀렸음을 보일 방법이 없는 주장은 점검 대상으로 삼지 않는다
- 통계로 추론할 때는 표본 크기, 표본 추출 방법, 표본 대표성을 밝힌다
- 상관관계와 인과관계를 구분한다. 상관계수가 높아도 인과가 입증되지 않는다
- 단일 사례를 일반 법칙으로 올리지 않는다. 여러 사례나 작동 방식 설명을 함께 든다
- 개인이나 기관을 권위로 인용할 때는 그 전문 영역과 발언 영역이 같은지 확인한다
- 정보 부재의 처리는 references/modeling-rules.md의 개방 세계 가정을 따른다

## 형식적 오류

| 오류 | 점검 내용 |
|---|---|
| 전건 부정 | "A이면 B"에서 A가 아니라는 사실로 B가 아니라고 결론 내지 않는다. B는 다른 원인으로도 생긴다 |
| 후건 긍정 | "A이면 B"에서 B라는 사실로 A라고 결론 내지 않는다 |
| 역과 이의 혼동 | "A이면 B"와 함께 참인 것은 대우 "B가 아니면 A가 아니다"뿐이다. 역과 이는 따로 확인한다 |
| 선언지 긍정 | "A 또는 B"에서 A가 참이라는 사실로 B가 거짓이라고 결론 내지 않는다. 포괄적 선언과 배타적 선언을 구분한다 |
| 매개념 부주연 | "X는 Y다"와 "Z는 Y다"에서 "Z는 X다"를 끌어내지 않는다 |
| 사개명사 | 삼단논법의 매개념은 두 전제에서 같은 뜻이어야 한다. 뜻이 다르면 명사가 넷이 되어 추론이 무효다 |
| 양상 혼동 | 가능, 필연, 의무 같은 양상이 붙은 명제를 추론할 때는 따로 확인한다 |

## 비형식적 오류

### 발화자와 정황에 기대는 오류

| 오류 | 점검 내용 |
|---|---|
| 권위 호소 | 권위자나 권위 기관의 발언이라는 사실만으로 타당성을 입증하지 않는다. 해당 분야 전문성을 확인한 뒤 인용한다 |
| 잘못된 권위 | 발언 분야와 권위 영역이 다른 주체의 발언을 근거로 쓰지 않는다 |
| 익명 권위 | "전문가에 따르면", "한 연구에 따르면"처럼 출처를 알 수 없는 권위를 인용하지 않는다 |
| 편향된 권위 | 이해관계가 있는 권위자를 중립적 권위처럼 인용하지 않는다. 이해상충을 밝히고 인용한다 |
| 인신공격 | 발화자의 특성, 배경, 이력으로 발언 내용의 타당성을 판단하지 않는다 |
| 피장파장 | 발화자가 과거에 비슷한 행동을 했다는 사실로 현재 주장을 무효로 하지 않는다 |
| 정황 공격 | 발화자의 소속, 출신, 학력, 진영으로 주장의 참거짓을 판단하지 않는다 |
| 연좌 | 가족, 동료, 소속 집단의 행위로 개인의 주장을 평가하지 않는다 |
| 동정 호소 | 동정심이 결론의 타당성 근거가 되지 않는다 |
| 힘 호소 | 위협, 강제, 권력으로 주장을 관철하지 않는다 |
| 재력 호소 | 가격, 예산 규모, 자본력이 주장의 타당성을 보장하지 않는다 |
| 군중 호소 | 다수가 동의한다는 사실이 주장의 참거짓을 정하지 않는다 |
| 중립 호소 | 두 입장의 산술적 중간값이 자동으로 정답이 되지 않는다 |
| 유머 호소 | 상대 주장을 우스꽝스럽게 표현하는 것으로 반박을 대신하지 않는다 |
| 어조 공격 | 발화자의 말투나 태도가 발언 내용의 타당성을 정하지 않는다 |
| 발생적 오류 | 주장의 출처나 기원만으로 타당성을 판단하지 않는다. 시간이 지나며 달라졌을 가능성을 인정한다 |

### 의미를 비트는 오류

| 오류 | 점검 내용 |
|---|---|
| 애매어 | 한 논증 안에서 같은 단어를 두 가지 이상의 뜻으로 쓰지 않는다 |
| 모호성 | 지칭 대상이 불분명한 표현을 없애고 문법적 중의성을 해소한다 |
| 사용과 언급의 혼동 | 단어 자체를 가리킬 때와 단어가 가리키는 대상을 말할 때를 구별해 표기한다 |
| 은밀한 재정의 | 통용되는 뜻과 다른 뜻으로 쓰려면 정의를 먼저 밝힌다 |
| 강조 오류 | 일부 표현을 강조해 본래 뜻을 비틀지 않는다 |
| 허수아비 | 상대 주장을 약하게 바꿔 놓고 반박하지 않는다. 원래 주장을 그대로 인용한 뒤 반박한다 |
| 문맥을 떼어 낸 인용 | 부분 발췌로 원문의 뜻을 바꾸지 않는다 |
| 이름으로 존재 강요 | 어떤 단어로 부른다고 그 대상이 실제로 있다고 보증되지 않는다 |
| 비유와 사실의 혼동 | 은유적 진술을 사실 진술처럼 다루지 않는다 |
| 표현 수준 혼동 | 수사적 표현을 문자 그대로, 문자적 표현을 수사로 읽지 않는다. 어느 수준의 표현인지 먼저 식별한다 |
| 감정 적재 | 사실 진술에 과한 감정 수식어를 붙여 판단을 비틀지 않는다 |

### 인과와 구조의 오류

| 오류 | 점검 내용 |
|---|---|
| 거짓 원인 | "X 다음에 Y가 일어났다"를 "X가 Y의 원인이다"로 단정하지 않는다 |
| 공통 원인 무시 | X와 Y가 함께 일어나면 둘을 모두 일으키는 제3의 원인 Z가 있는지 검토한다 |
| 인과 전도 | X와 Y의 상관을 X에서 Y로의 인과로 단정하기 전에 Y에서 X로의 가능성을 검토한다 |
| 지나친 단순화 | 여러 원인이 작용한 결과를 한 원인으로 줄이지 않는다 |
| 잘못된 유추 | 일부 비슷한 점으로 다른 성질까지 비슷하다고 끌어내지 않는다. 주요 차이를 확인한다 |
| 거짓 등가 | 겉보기 공통점만으로 두 대상을 같다고 보지 않는다 |
| 도박사 오류 | 독립 시행에서 과거 결과가 미래 확률에 영향을 주지 않는다 |
| 연언 착오 | 두 사건이 함께 일어날 확률은 한 사건의 확률보다 클 수 없다 |
| 기저율 무시 | 개별 사례를 평가할 때 모집단의 기저율을 함께 고려한다 |
| 본말전도 | 원인과 결과, 수단과 목적의 순서를 뒤바꾸지 않는다 |
| 의도 확대 | 상대 행위의 의도를 자의적으로 부풀려 해석하지 않는다 |

### 일반화와 범주의 오류

| 오류 | 점검 내용 |
|---|---|
| 성급한 일반화 | 표본이 적거나 대표성이 없는 사례로 전체를 일반화하지 않는다 |
| 치우친 귀납 | 표본이 충분해도 추출 경로가 치우쳤으면 일반화하지 않는다. 대표성을 따로 확인한다 |
| 숨은 부분 표현 | "대부분", "상당수"처럼 부분을 가리키는 말을 쓰면서 결론을 전체에 적용하지 않는다 |
| 우연 오류 | 일반 법칙을 특수 상황에 기계적으로 적용하지 않는다. 예외 조건을 확인한다 |
| 원칙 혼동 | 서로 다른 상황의 원칙을 한 상황에 함께 적용하지 않는다 |
| 결합 오류 | 부분의 성질을 전체의 성질로 넓히지 않는다 |
| 분해 오류 | 전체의 성질을 부분의 성질로 줄이지 않는다 |
| 정점 오류 | 집단의 최상위 구성원으로 집단 평균을 평가하지 않는다 |
| 진정한 스코틀랜드인 | 반례를 "진짜 X가 아니다"로 제외하지 않는다. 반례가 나오면 일반화를 고친다 |
| 차이 없는 구별 | 같은 뜻을 다른 표현으로 나눠 구별하지 않는다 |
| 범주 오류 | 서로 다른 범주의 개념을 같은 범주로 다루지 않는다 |

### 논점과 대화의 오류

| 오류 | 점검 내용 |
|---|---|
| 논점 일탈 | 논의 주제와 무관한 주제로 옮겨 가지 않는다 |
| 부적절한 결론 | 전제에서 나오는 결론과 다른 결론을 내지 않는다 |
| 매듭 자르기 | 문제를 푸는 대신 논점 자체를 없애지 않는다 |
| 원천 봉쇄 | 반론 가능성을 미리 막는 표현을 쓰지 않는다. 반박할 수 있는 형태로 주장한다 |
| 무지 논증 | 증명되지 않았다는 이유로 부정하거나 반증되지 않았다는 이유로 긍정하지 않는다 |
| 개인적 불신 | 이해하기 어렵다는 느낌이 명제의 거짓을 입증하지 않는다 |
| 미끄러운 경사 | 작은 변화가 극단적 결과로 이어진다고 주장할 때는 중간 단계의 개연성을 확인한다 |
| 거짓 딜레마 | 선택지가 둘뿐인 상황이 아니면 셋째, 넷째 선택지를 찾는다 |
| 흑백 논리 | 객관적 기준이 없는 주제를 양강 구도로 단순화하지 않는다 |
| 완벽한 해결책 | 일부 결함을 이유로 효과 있는 해결책을 버리지 않는다 |
| 복합 질문 | 답이 정해진 전제를 담은 질문을 쓰지 않는다. 전제와 질문을 나눈다 |
| 특별 변론 | 같은 기준을 유지하고 특정 사례에만 근거 없이 예외를 두지 않는다 |
| 반복 소모 | 같은 질문을 되풀이해 상대를 지치게 하는 방식을 쓰지 않는다 |

### 가치와 사실의 오류

| 오류 | 점검 내용 |
|---|---|
| 자연주의 오류 | "X이다"라는 사실에서 "X해야 한다"는 당위를 바로 끌어내지 않는다 |
| 도덕주의 오류 | "X해야 한다"는 당위에서 "X이다"라는 사실을 바로 끌어내지 않는다 |
| 새로움 호소 | 새롭다는 이유만으로 더 낫다고 주장하지 않는다 |
| 전통 호소 | 오래되었다는 이유만으로 정당하다고 주장하지 않는다 |
| 희망적 관측 | 바람직하다는 이유로 사실이라고 단정하지 않는다 |
| 반사실 가정 | 사실이 아닌 가정에서 결론을 끌어낼 때는 가정이 정당한 범위 안으로 결론을 제한한다 |
| 임시방편 가정 | 반박이 나올 때마다 임의의 가정을 더해 주장을 방어하지 않는다 |

## 순환 논법

| 오류 | 점검 내용 |
|---|---|
| 선결문제 요구 | 결론을 전제에 포함해 결론을 끌어내지 않는다 |
| 동어반복 | "A이므로 A다" 형태로 추론하지 않는다. 결론과 다른 명제로 근거를 세운다 |
| 정의 순환 | 개념을 정의할 때 정의 대상 개념을 정의 문장에 포함하지 않는다 |
| 오류에 기댄 논증 | 상대 논증에 오류가 있다는 사실이 상대 결론의 거짓을 입증하지 않는다 |

## 인지 편향

| 편향 | 점검 내용 |
|---|---|
| 확증 편향 | 자기 견해에 맞는 정보만 모으지 않는다. 반대 정보를 찾아본다 |
| 체리피킹 | 유리한 사례만 골라 인용하지 않는다. 불리한 사례도 함께 검토한다 |
| 가용성 편향 | 떠올리기 쉬운 사례를 자주 일어나는 사례로 착각하지 않는다 |
| 대표성 편향 | 눈에 띄는 일부 특징으로 전체를 판단하지 않는다 |
| 생존자 편향 | 성공 사례만으로 성공 요인을 추론하지 않는다. 실패 사례를 함께 분석한다 |
| 후광 효과 | 한 영역에서 뛰어나다는 사실을 무관한 영역까지 넓히지 않는다 |
| 기준점 편향 | 처음 접한 정보에 지나치게 기대지 않는다 |
| 근접 편향 | 가까운 대상을 호의적으로 평가하지 않는다 |
| 역화 효과 | 반대 정보를 만났을 때 기존 믿음을 더 굳히지 않는다. 믿음을 고칠 여지를 남긴다 |
| 선택 편향 | 표본을 뽑을 때 특정 집단이 과하거나 적게 대표되지 않도록 점검한다 |
| 외집단 동질성 편향 | 자기 집단의 다양성은 인정하면서 외부 집단의 다양성을 무시하지 않는다 |
| 과거 미화 편향 | 과거를 미화하거나 현재를 깎아내리지 않는다. 시점별로 같은 기준으로 비교한다 |

## 점검 목록

- 결론이 명시되었는가
- 결론마다 근거가 있는가
- 근거와 결론 사이의 원인과 결과 관계나 논리적 연결을 제3자가 확인할 수 있는가
- 분류 항목 사이에 겹침과 빠짐이 없는가
- 같은 단어를 두 가지 이상의 뜻으로 쓰지 않았는가
- 시간 순서를 인과로 단정하지 않았는가
- 특수 사례를 일반 법칙으로 올리지 않았는가
- 반대 사례나 반대 의견을 검토했는가
- 주장하는 쪽이 입증 책임을 지는가
- 결론이 근거 범위 안에 있는가
- 인용한 권위 주체가 해당 영역의 전문 권위인가
- 분류 기준이 하나로 통일되었는가
- 결론에서 근거로, 근거에서 결론으로 양쪽 모두 따라갈 수 있는가
- 주장이 반박 가능한 형태로 쓰였는가
