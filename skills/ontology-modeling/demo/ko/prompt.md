우리 회사 초거대AI 활용 현황이야. 보안 규정에 걸리는 업무나 관리 공백이 있는지 점검해 줘. 업무, 부서, 모델, 문서가 어떻게 이어져 있는지 한눈에 보이는 그림도 그려 줘. 확인 질문 없이 끝까지 해 줘.

## 현황
- 우리 회사는 모델 A, 모델 B, 모델 C, 모델 D 네 가지 초거대AI 모델을 쓰고 있음
- 모델 A와 모델 B는 사내 서버에 설치해서 쓰고, 모델 C와 모델 D는 외부 업체의 API로 씀
- 그런데 IT팀 자료를 보면 모델 B도 외부 API로 쓴다고 적혀 있음
- 사내 보안 규정상 사내 문서를 다루는 업무에는 사내 서버에 설치한 모델만 쓸 수 있음
- 품질팀은 과거 품질 문서 검색에 모델 A를, 불량 원인 분석 보고서 초안 작성에 모델 B를 씀
- 설계팀은 설계 변경 보고서 초안 작성에 모델 C를, 공개 규격 문서 요약에 모델 D를 씀
- 기획팀은 업계 동향 브리핑에 모델 C를 씀
- 회의록 정리에는 모델 A를 쓰는데 담당 부서는 아직 정하지 않았음
- 과거 품질 문서, 불량 원인 분석 보고서, 설계 변경 보고서, 회의록은 사내 문서이고 공개 규격 문서와 업계 동향 자료는 외부 공개 자료임
