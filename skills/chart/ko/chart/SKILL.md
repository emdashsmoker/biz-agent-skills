# 차트 제작

보고서와 발표자료에 들어갈 정적 차트를 matplotlib으로 만든다. 사용자는 엑셀처럼 셀 범위로 데이터를 고르고 렌더링 전에 ASCII 기획안으로 결과를 확인한다. 완성한 차트는 요소 ID로 부분 수정하고 설정 파일로 다시 불러온다.

## 작업 원칙

- (재현성) 같은 입력은 같은 차트를 만든다. 색상은 HEX 코드로 명시하고 모든 설정을 JSON 파일로 저장하고 불러온다.
- (투명성) 차트를 만든 코드와 차트 형태를 고른 근거를 함께 보여준다.
- (일관성) 세션이 달라도 같은 질의 순서와 같은 응답 형식을 쓴다.
- (편의성) 데이터는 셀 범위(A1:B10)로 지정하고 차트는 요소 ID로 수정한다.

## 수치와 데이터 처리

합계, 비율, 평균, 정렬, 순위를 포함한 모든 수치 연산은 Python 코드를 실행해 구한다. 언어 모델이 직접 계산한 값은 틀릴 수 있으므로 기획안, 레이블, 차트 어디에도 쓰지 않는다.

- 사용자가 준 데이터만 쓰며 임의의 데이터를 만들지 않는다.
- 차트는 기획안 승인 후 렌더링한다. 사용자가 원스톱 모드를 요청한 경우에만 승인 단계를 건너뛴다.
- 코드를 실행할 수 없는 환경에서는 사용자가 직접 실행할 수 있는 전체 코드를 제공한다.

## 실행 환경 준비

세션을 시작하면 아래 순서로 환경을 준비한다. 의존성 설치는 다른 작업보다 먼저 끝낸다.

1. 코드 실행 가능 여부, matplotlib 버전, 설치된 폰트를 확인한다. matplotlib은 bar_label 함수가 추가된 3.4 이상이 필요하다.
2. 웹 검색을 쓸 수 있으면 "matplotlib {버전} changelog"를 검색해 새 기능, 폐기 예정 기능, 유의 사항을 사용자에게 짧게 안내한다. 웹 검색을 쓸 수 없으면 설치 버전만 안내하고 렌더링 중 나오는 MatplotlibDeprecationWarning을 확인한다.
3. adjustText가 없으면 설치한다. CSV와 엑셀 입력을 읽는 pandas와 openpyxl도 없으면 설치한다.
4. NanumGothic이 없으면 폰트 파일을 받아 matplotlib에 등록한다. 등록은 실행 중인 프로세스에만 적용되므로 렌더링 코드마다 등록 코드를 앞에 둔다.

```bash
pip install adjustText pandas openpyxl
curl -L -O https://raw.githubusercontent.com/google/fonts/main/ofl/nanumgothic/NanumGothic-Regular.ttf
curl -L -O https://raw.githubusercontent.com/google/fonts/main/ofl/nanumgothic/NanumGothic-Bold.ttf
```

```python
from matplotlib import font_manager, rcParams

for path in ["NanumGothic-Regular.ttf", "NanumGothic-Bold.ttf"]:
    font_manager.fontManager.addfont(path)
rcParams.update({
    "font.family": "NanumGothic",
    "font.size": 16,
    "font.weight": "bold",
    "axes.labelweight": "bold",
    "axes.titleweight": "bold",
    "axes.unicode_minus": False,  # NanumGothic에는 유니코드 마이너스 기호가 없어 음수 부호가 깨짐
})
```

## 작업 흐름

실행 모드는 두 가지다.

- (순차 모드) 기본값이다. 데이터 입력, 차트 형태 결정, 데이터 정리, 기획안 승인, 렌더링, 설정 저장 순서로 진행한다. 차트를 세밀하게 조정할 때 쓴다.
- (원스톱 모드) 요청에 "기획안 생략" 또는 "바로 생성"이 있으면 쓴다. 차트 형태를 자동으로 고르고 데이터 정리 제안을 적용한 뒤 기획안 확인 없이 렌더링한다. 생성 코드, 형태 선택 근거, 적용한 데이터 정리 내용은 차트와 함께 보여준다.

### 1. 데이터 입력

텍스트, CSV, 엑셀, JSON 입력을 읽어 열 문자와 행 번호가 붙은 표로 보여준 뒤 사용할 범위를 묻는다.

```
|   | A      | B    |
|---|--------|------|
| 1 | 회사명 | 매출 |
| 2 | A사    | 150  |
| 3 | B사    | 120  |

범위 지정: A2:B3 또는 all
```

범위가 정해지면 각 열을 시계열, 범주형, 수치형 중 하나로 판별한다. 요청 문장에서는 차트 유형 지정 여부, 강조할 항목, 선호 색상을 파악한다.

### 2. 차트 형태 결정

차트 형태는 전달할 메시지 1개를 먼저 정하고 그 메시지가 요구하는 비교 유형을 판단한 뒤 고른다. 사용자가 차트 유형을 지정하지 않았으면 "차트 유형을 직접 선택하시겠습니까, 자동 추천해 드릴까요?"라고 묻는다. 자동 추천을 고르면 Python으로 데이터를 계산하고 아래 표로 비교 유형을 판단해 근거와 함께 제안한다.

| 비교 유형 | 요청에 나오는 표현 | 권장 차트 |
|---|---|---|
| 구성비 | 비율, 점유율, % | 원형, 누적 막대 |
| 항목 비교 | 크다, 순위 | 수평 막대 |
| 시계열 | 변화, 추이 | 세로 막대, 선 |
| 상관 | 상관, 관계 | 산점도 |
| 매트릭스 | 맵, 행렬, 상관행렬 | 버블, 히트맵 |

### 3. 데이터 정리

- 시계열 외의 데이터는 값의 내림차순으로 정렬한다.
- 범주가 5개를 넘으면 상위 5개를 남기고 나머지를 "기타"로 묶는 안을 제안한다. 범주가 6개이면 상위 4개를 남겨 기타에 2개 이상의 항목이 들어가게 한다. 기타는 값과 관계없이 맨 뒤에 둔다.
- 시계열 구간이 12개를 넘으면 최근 12개 구간만 쓰는 안을 제안한다.
- 순차 모드에서는 제안을 기획안에 담아 승인을 받는다.

### 4. 기획안

승인 전 미리보기는 ASCII 문자로만 그린다. 렌더링 전에 고치면 수정 비용이 적기 때문이다. 사용자가 "y"로 승인하면 matplotlib을 실행한다.

````
## 차트 기획안
유형: 수평 막대 | 근거: 항목 비교 | n=2,220 (값의 합계, Python 계산)

[미리보기]
(A) ████████████████████ 영업1팀 850
(B) █████████████████░░░ 영업2팀 720
(C) ███████████████░░░░░ 영업3팀 650

[생성 코드]
```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(10, 6))
bars = ax.barh(["영업1팀", "영업2팀", "영업3팀"], [850, 720, 650], color="#6B8EC2")
ax.invert_yaxis()
ax.bar_label(bars, padding=3)
# 수치 축 숨김, 스파인 설정 등
```

[설정] 범주: 축 | 수치: 레이블 | 스파인: 좌 | 제목: OFF | n수: OFF | 소수점: 0자리
수정: "A 강조", "제목 OOO", "n수 표시" 등 | 진행: "y"
````

- 미리보기 막대 길이는 최대값을 20칸으로 두고 Python으로 비례 계산한다.
- (A), (B), (C)는 요소 ID다. 수정 명령에서 요소를 가리킬 때 쓴다.
- 막대 외의 차트는 요소 ID, 항목, 값을 ASCII 표로 보여준다.

> (n수) 차트 값의 근거가 되는 응답자나 표본의 수

> (스파인) 그래프 영역을 둘러싼 상하좌우 테두리 선

### 5. 렌더링

승인을 받으면 시각화 규격에 따라 렌더링한다. 렌더링한 이미지를 열어 레이블 겹침과 잘림을 확인한다. 레이블이 겹치면 아래 순서로 해결 방법을 적용한다.

1. adjustText로 레이블 위치를 자동 조정한다. 산점도와 선 차트는 점 좌표를 함께 넘겨(adjust_text(texts, x=xs, y=ys, ax=ax)) 레이블이 점을 가리지 않게 한다.
2. bar_label의 padding 값으로 막대와 레이블 사이 간격을 조정한다.
3. tight_layout으로 여백을 다시 계산한다.
4. 레이블을 회전한다.
5. 레이블 좌표를 직접 지정한다.

### 6. 설정 저장

렌더링 후 "현재 설정을 저장하면 나중에 같은 차트를 다시 만들 수 있습니다. 저장하시겠습니까? (y/n)"라고 묻는다. 사용자가 승인하면 chart_config_YYYYMMDD_HHMMSS.json 파일로 저장한다. 파일 구조는 설정 파일 절을 따른다.

## 수정 명령

사용자가 `/?`를 입력하면 아래 표를 보여준다.

| 명령 | 동작 |
|---|---|
| /? | 도움말 표시 |
| /new | 새 차트 시작 |
| /save | 현재 설정 저장 |
| /load | 저장한 설정 불러오기 |
| y | 기획안 승인 |
| A 강조 | 요소 A를 강조색으로 표시 |
| B 색상 빨간색 | 요소 B의 색상 변경 |
| A,B 기타로 | 요소 A와 B를 기타로 묶음 |
| 제목 OOO | 제목을 OOO로 설정 |
| n수 표시 | n수 표시 켜기 |

"n수 표시"를 받으면 n수와 함께 쓸 설명문(예: 전체 응답자 기준)을 묻는다. 차트 전체에 걸친 설정을 바꾸면 바뀐 기획안으로 확인을 받고 설정 저장을 안내한다.

모든 요소는 요소 ID로 개별 조정한다. 조정 가능한 항목은 아래와 같다.

- (켜기와 끄기) 제목, 데이터 레이블, 축, 그리드, 범례, 스파인, n수, 컬러바
- (값 지정) 색상, 폰트, 그림 크기, 축 범위, 제목 문구, n수 설명문, 버블 크기 비율, 소수점 자릿수
- (레이블 형식) 수치, 비율, 수치+비율, 수치+순위
- (방향 전환) 수평 막대와 세로 막대

> (컬러바) 히트맵의 색 농도와 값의 대응을 보여주는 막대 모양 범례

## 시각화 규격

### 색상과 폰트

```python
COLORS = {
    "primary": "#6B8EC2",    # 기본색
    "highlight": "#F5A962",  # 강조색
    "pastel": ["#A8C5E2", "#B8D4A8", "#F5D5A8", "#E8B8C2", "#C4C4C4", "#D4C4E8"],
}
DARK_TEXT = "#1A1A1A"
FONT = {"family": "NanumGothic", "size": 16, "weight": "bold"}
```

- 모든 텍스트는 굵게 쓴다.
- 요소는 기본색으로 칠하고 사용자가 강조를 요청한 요소만 강조색으로 칠한다.
- 원형, 누적 막대, 버블처럼 항목마다 색을 달리할 때는 파스텔 팔레트를 순서대로 쓴다. 파스텔 위의 글씨는 검은 글씨가 잘 읽히도록 DARK_TEXT로 쓴다.

### 기본 레이아웃

- (표시) 범주는 축에, 수치는 데이터 레이블에 굵게 표시한다. 제목은 기본으로 끈다.
- (기본으로 끄는 요소) 그리드, 범례, 차트별 규격에 없는 스파인, 원형 차트 지시선, 컬러바
- (그림 크기) 기본값은 figsize=(10, 6)이다.
- (n수) 기본으로 끈다. 켜면 그림 오른쪽 위에 12pt로 "(n=2,220)"을 쓰고 설명문이 있으면 "(n=2,220, 전체 응답자 기준)"처럼 뒤에 붙인다. 다른 요소와 겹치면 위치를 옮긴다. n 값은 선택 범위 값의 합계를 기본으로 하고 사용자가 값을 주면 그 값을 쓴다.

> (지시선) 원형 차트 조각과 바깥 레이블을 잇는 선

### 차트별 규격

- (수평 막대) 좌측 스파인만 남긴다. 범주는 Y축, 수치는 막대 끝 레이블로 쓰고 수치 축은 숨긴다. 값이 가장 큰 막대를 맨 위에 둔다(ax.invert_yaxis). 항목 비교에 쓴다.
- (세로 막대) 하단 스파인만 남긴다. 범주는 X축, 수치는 막대 위 레이블로 쓰고 수치 축은 숨긴다. 시계열에 권장한다.
- (선) 좌측과 하단 스파인을 남긴다. 범주는 X축에 두고 Y축은 눈금 수치와 축 제목을 표시한다. 점마다 데이터 레이블을 붙인다.
- (산점도) 좌측과 하단 스파인을 남긴다. 점마다 "항목명\n(x, y)" 형식의 레이블을 붙인다. n수는 표시하지 않는다.
- (버블) 4면 스파인을 모두 남긴다. X 분류와 Y 항목이 만나는 칸의 값을 버블 크기로 나타내고 버블 안에 수치를 쓴다. Y 항목마다 파스텔 팔레트 색을 순서대로 쓴다. X축 레이블은 "분류명\n(열합계)" 형식으로 쓴다. 값이 0인 칸은 버블 대신 ▽를 그린다.
- (히트맵) 4면 스파인을 모두 남긴다. 칸 색은 흰색(#FFFFFF)에서 기본색까지 이어지는 단일 색 농도로 칠하고 칸 안에 수치를 쓴다. 컬러바는 기본으로 끈다.
- (원형) 조각은 6개 이하로 한다. 12시 방향에서 시작해 시계 방향으로 그리고(startangle=90, counterclock=False) 파스텔 팔레트를 쓴다. 레이블은 "항목명\n(00%)" 형식으로 조각 안쪽(labeldistance=0.6)에 쓴다. 지시선은 기본으로 끈다.
- (누적 막대) 막대 방향에 맞춰 세로 막대나 수평 막대의 스파인과 축 규칙을 따른다. 구간 색은 파스텔 팔레트를 순서대로 쓰고 구간 가운데에 "항목명\n(값)" 레이블을 쓴다.

버블 크기와 히트맵 글씨색은 아래 계산으로 정한다.

- (버블 크기) 0보다 큰 값 중 최소값의 버블 면적은 300pt²이고 최대값의 버블 면적은 최소 면적에 크기 비율(기본 10)을 곱한 값이다. 그 사이 값의 면적은 두 면적 사이에서 값에 비례해 선형으로 정한다.
- (히트맵 글씨색) 칸 색과 DARK_TEXT, 칸 색과 흰색의 대비비를 각각 구해 대비비가 큰 쪽 색을 쓴다. 대비비는 WCAG 2의 상대 휘도 공식으로 계산한 (L1 + 0.05) / (L2 + 0.05)를 쓴다.

```python
size = s_min + (v - v_min) / (v_max - v_min) * (s_min * ratio - s_min)
```

### 레이블 형식

| 형식 | 예시 |
|---|---|
| 수치 | 850 |
| 비율 | 38% |
| 수치+비율 | 850(38%) |
| 수치+순위 | 850(1위) |

- 비율의 분모는 선택 범위 값의 합계다.
- 소수점은 기본 0자리이며 기획안 설정에서 1자리나 2자리로 바꿀 수 있다.

## 설정 파일

세션 안에서는 현재 데이터셋, 사용자가 정한 설정, 지금까지 만든 차트 이력을 유지한다. 세션이 끝난 뒤에도 쓸 설정은 설정 파일에 저장하며 설정 파일에는 조정 가능한 모든 항목을 담는다.

```json
{
  "metadata": {"created": "2026-01-15T09:30:00+09:00", "matplotlib_version": "3.10.0"},
  "input": {"file_path": "data.xlsx", "sheet": "Sheet1", "range": "A1:B4"},
  "data": {
    "labels": ["영업1팀", "영업2팀", "영업3팀"],
    "values": [850, 720, 650],
    "element_ids": {"A": "영업1팀", "B": "영업2팀", "C": "영업3팀"}
  },
  "style": {
    "chart_type": "barh",
    "colors": {"A": "#F5A962", "B": "#6B8EC2", "C": "#6B8EC2"},
    "font": {"family": "NanumGothic", "size": 16, "weight": "bold"},
    "label_format": "value",
    "decimals": 0,
    "bubble": {"min_size": 300, "ratio": 10}
  },
  "visibility": {
    "title": false,
    "data_label": true,
    "axis": true,
    "grid": false,
    "legend": false,
    "spines": ["left"],
    "n_display": false,
    "colorbar": false
  },
  "n_display": {"value": 2220, "text": "전체 응답자 기준", "fontsize": 12},
  "layout": {
    "figsize": [10, 6],
    "title_text": "",
    "axis_range": {"x": null, "y": null},
    "margin": {"left": null, "right": null, "top": null, "bottom": null}
  }
}
```

- (chart_type) barh, bar, line, scatter, bubble, heatmap, pie, stacked_bar, stacked_barh 중 하나
- (label_format) value, percent, value+percent, value+rank 중 하나이며 레이블 형식 표의 순서와 같다
- (data) 여러 계열이나 행렬 데이터는 values를 2차원 목록으로 저장하고 labels에 행 이름과 열 이름을 함께 저장한다
- (visibility.axis) true이면 차트별 규격대로 축을 표시하고 false이면 모든 축을 숨긴다
- (visibility.spines) 남길 스파인을 left, right, top, bottom 중에서 고른 목록
- (layout.axis_range) null이면 자동 범위, [최솟값, 최댓값]이면 고정 범위
- (layout.margin) null이면 tight_layout을 쓰고 0에서 1 사이 값이면 subplots_adjust에 그대로 넘긴다

사용자가 `/load`로 설정 파일을 불러오면 아래 순서로 처리한다.

1. 생성 시각, matplotlib 버전, 주요 설정을 보여준다.
2. input.file_path의 원본 파일이 있는지 확인한다. 파일이 없으면 경고한 뒤 설정 파일의 data 값을 쓴다.
3. 설치된 matplotlib 버전이 metadata와 다르면 경고하고 "다시 생성하시겠습니까? (y/n)"라고 묻는다.
