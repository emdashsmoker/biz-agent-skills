# 회의 내용
- **(문서 검색 부담) 과거 문서 검색이 현업의 주요 시간 소요 업무**
    + (불량 보고서 검색) 품질팀의 유사 불량 이력 확인 시 공유 폴더 개별 열람 필요
    + (체감 소요 시간) 품질팀 1인당 월 20시간 가까이 소요 체감
    + (변경 이력 첨부) 설계팀의 설계 변경 보고서 초안 작성 시 과거 변경 이력 검색과 첨부 필요
    + (종이 도면) 2015년 이전 도면은 종이로만 보관되어 검색 불가
- **(보안 요건) 보안 규정이 도입의 최대 제약 요인**
    + (외부 서비스 제한) 현행 규정상 외부 생성형 AI 서비스에 업무 문서 입력 불가
    + (설치 방식) 사내 서버 직접 설치 방식 필요
    + (접근 권한 기준) 사내 설치형도 접근 권한 기준은 보안팀 확인 필요
- **(사내 설치형 성능) 사내 설치형으로 문서 업무 지원 가능 전망**
    + (모델 성능 향상) 최근 공개 가중치 모델 성능 향상
    + (지원 가능 업무) 문서 검색과 초안 작성 수준 처리 가능이라는 IT팀장 판단
- **(구축 인력) 구축과 운영에 외부 업체 지원 필요**
    + (IT팀 규모) IT팀 인력 5명
    + (전담 인력 부재) AI 전담 인력 없음
- **(업체 비용) 외부 업체 활용 비용 미정**
    + (견적 필요) 견적 수령 전 비용 산정 불가
    + (견적 범위) 업체 3곳 정도 견적 수령 제안
- **(시범 범위) 품질팀 불량 보고서 검색과 설계팀 변경 보고서 초안 작성으로 범위 한정**
    + (종이 도면 제외) 종이 도면은 이번 시범 범위에서 제외
    + (전사 확대 판단) 전사 확대는 시범 결과 확인 후 별도 판단
- **(업무 시간 측정) 시범 전 실제 업무 시간 측정 필요**
    + (실측 부재) 월 20시간은 실측 없이 팀원 의견으로 추정한 수치
    + (품질팀 측정) 품질팀 2주간 업무 시간 기록 제안
    + (설계팀 참여) 설계팀도 같은 측정에 참여
