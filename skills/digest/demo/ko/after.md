# 개요
- (제목) 생성형 AI 업무 활용 실태 조사 결과 보고
- (발행 주체) 기획실
- (발행일) 2026년 9월 30일
- (출처) 첨부 파일(내부 검토용)

# 요약
- (수요) 사용 경험률 54.7%와 사내 전용 서비스 요구 61.3%로 활용 수요 확인
- (격차) 생산팀 22.1%와 50대 이상 29.3%의 사용 경험률 저조
- (보안) 외부 서비스 문서 입력자 36명 중 22명이 금지 규정 인지 상태
- (효과) 업무 시간 절감 효과의 실측 근거 부재
- (도입 방향) 보안 계약형 클라우드 방식의 시범 도입 우선 검토

# 내용
## 조사 개요
- (설문) 2026년 9월 8일-19일 전 직원 412명 대상 설문에 287명 응답(응답률 69.7%)
- (응답 구성) 생산팀 응답률 56.6%로 부서 중 최저

## 사용 현황
- (사용 경험률) 전체 54.7%. 생산팀 22.1%, 50대 이상 29.3%, 부장 이상 32.0%로 저조
- (사용 행태) 주 2회 이상 사용 51.6%. 무료 범용 챗봇 사용 77.1%
- (활용 업무) 문서 초안 작성 62.4%와 자료 검색 및 요약 55.4%가 상위

## 보안 규정 준수
- (규정 인지) 문서 입력 금지 규정 인지율 70.0%. 생산팀은 50.0%
- (문서 입력) 사용 경험자 36명(22.9%)이 외부 서비스에 입력. 이 중 22명은 규정 인지 상태
- (민감 문서) 기밀 등급 문서 4명, 고객 및 거래처 자료 9명, 개인정보 포함 문서 3명 입력
- (규정 오해) 미사용자의 44.6%가 보안 규정 때문에 미사용. 금지 대상은 문서 입력에 한정

## 사용 효과
- (시간 절감) 사용 경험자의 68.8%가 주 1시간 이상 절감 체감. 실측값 없음
- (품질 변화) 결과물 품질 개선 응답 40.8%

## 답변 오류
- (오류 경험) 사용 경험자의 71.3%가 사실과 다른 답변 경험. 17명은 업무 문서에 그대로 사용

## 직원 의견
- (우려) 답변 정확성 58.5%와 정보 유출 49.5%가 상위
- (지원 요구) 사내 전용 서비스 61.3%, 활용 교육 51.9%, 사용 지침 마련 46.3%
- (희망 업무) 주관식 응답 중 과거 문서 검색 30.6%가 최다

## 타사 사례
- (A사) 보안 계약형 클라우드 시범 전 기준값 실측. 검색 시간 59.5% 단축 입증 후 전사 확대
- (B사) 지침 없는 전면 허용. 고객사 도면 입력 적발로 6개월 만에 사용 중단
- (C사) 사내 설치형에 약 4억 원 투입. 답변 품질 불만으로 월간 활성 사용자 18%에 머묾

## 도입 방식 비교
- (기획실 판단) 보안 계약형 클라우드 우선 검토. 사내 설치형은 중장기 대안으로 유지

| 구분 | 외부 범용 서비스 | 보안 계약형 클라우드 | 사내 설치형 |
|---|---|---|---|
| 보안 규정 | 현행 규정 위반 | 일부 개정 시 허용 가능 | 현행 규정 내 허용 |
| 초기 비용 | 없음 | 3,000만 원 내외 | 3억-5억 원 |
| 월 운영 비용 | 1인당 3만 원 내외 | 800만-1,200만 원 | 유지보수 300만 원 내외 |
| 구축 기간 | 즉시 | 2-3개월 | 6-9개월 |

## 향후 계획
- (10월) 사용 지침 공지, 기밀 등급 문서 입력 후속 확인, 클라우드 2개사 계약 조건 확인
- (11월) 사내 초거대AI 시범 도입 계획(안) 경영진 보고
- (12월) 부서별 활용 교육 일정 수립

# 시사점
- (보안 통제) 입력 경험자의 61.1%가 규정 인지 상태. 안내만으로 위반 차단 곤란
- (효과 검증) 효과 근거가 체감치뿐. 시범 전 기준값 실측 필요
- (오류 관리) 사용 지침에 답변 근거 확인 절차 반영 필요
- (운영 여력) 보안 계약형 클라우드도 IT팀 인력 투입 필요. IT팀은 운영 인력 부족을 지적한 상태
