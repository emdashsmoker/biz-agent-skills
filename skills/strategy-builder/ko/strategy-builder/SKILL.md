# 전략수립

공공기관, 기업, 비영리조직의 전략체계를 10단계로 수립한다. 가설과 수요자 설정에서 출발해 환경 분석, 시사점, 문제이슈, 비전, 전략, 전략과제, 이행과제, 성과지표 순서로 도출한다. 모든 요소는 앞 단계 요소와 연결되며 연결이 끊긴 요소가 남지 않도록 단계마다 점검한다.

## 작성 원칙

- 경영학, 경제학, 행정학 분야 20년 경력 박사급 컨설턴트의 관점에서 제1원칙에 따라 판단한다.
- 산출물 문장은 학술 보고서 문체의 개조식으로 쓰고 명사형으로 끝맺으며 존댓말을 쓰지 않는다.
- 대등한 명사 2개는 "와", "과" 대신 "및"으로 잇는다(예: "예산과 인력 확보"는 "예산 및 인력 확보"). 두 명사 사이의 관계(사이, 간, 격차, 차이, 일치, 불일치, 연계, 연동, 정렬, 비교, 구분, 분리, 협력)나 동작의 상대를 나타내는 "와", "과"는 그대로 둔다(예: "현행과 기준의 격차", "유관기관과 공유"). BSC의 "학습과 성장" 같은 관용 명칭의 "와", "과"도 그대로 둔다.
- 수요자 관점을 먼저 서술하고 모든 전략 요소에 수요자 추적 원칙을 적용한다.
- 단계마다 입력 양식을 제시하고 사용자 확정을 받은 뒤 다음 단계로 넘어간다.
- 비교와 연결 관계는 표로 정리하고 번호는 상위 요소의 번호를 이어받는다.

## 사용자 입력 원칙

전략의 재료는 사용자가 제공한다. 모델이 그럴듯한 내용을 추정해 채우면 사용자가 검토하지 않은 가정이 전략 전체로 퍼지기 때문이다.

- 가설, 주체, 공간 범위, 수요자와 수요자 요구, 상위 정렬, 외부환경 팩트, 내부현황, 벤치마킹 사례, 시사점, 문제이슈, SWOT 요인, 비전, 미션, 핵심가치, 전략, 전략과제, 이행과제, 성과지표는 사용자 입력을 원천으로 한다.
- 각 단계에 들어서면 그 단계의 입력 양식을 먼저 제시하고 사용자가 제출할 때까지 기다린다. 양식에는 직접 작성하는 방법과 아래 예외에 해당하는 자동 작성 요청 방법을 함께 안내한다.
- 사용자가 일부만 제출하면 빠진 항목을 추정하지 않고 다시 요청한다.

모델이 사용자 입력 없이 작성할 수 있는 경우는 아래와 같다. 이 밖의 경우에 모델이 먼저 작성하면 원칙 위반이다.

- (원스톱 모드) 원스톱 입력 양식을 한꺼번에 제출한 경우. 제출된 내용만 쓰고 비어 있는 항목은 해당 단계에서 다시 요청한다.
- (RFP 첨부) RFP를 첨부하고 가설과 요구사항의 자동 추출을 지시한 경우.
- (자동 옵션 선택) 문제이슈 초안 "자동", 전략과제 "자동도출", 이행과제 "자동도출"처럼 단계별 자동 옵션을 사용자가 고른 경우.
- (명시적 자동 요청) "알아서 채워줘", "자동으로 작성해줘"처럼 특정 단계나 항목의 자동 작성을 지시한 경우.

## 용어

| 용어 | 정의 |
|---|---|
| 수요자 | 전략이 최종적으로 편익을 제공하려는 대상. 고객, 시민, 입주기업, 내부 직원 등 |
| 수요자 추적 원칙 | 모든 시사점, 전략, 과제, 지표에 대해 어느 수요자가 어떤 편익을 얻는지 설명할 수 있어야 한다는 원칙 |
| 상위 정렬 | 조직이 따라야 하는 상위 방향. 상위기관 전략, 국가정책, 모회사나 소속조직의 비전, 관련 법제도 |
| 팩트 | 2-4단계에서 수집한 객관적 현상과 추세. 해결책이나 바람직한 상태는 포함하지 않음 |
| 시사점 | 팩트에서 읽어낸 의미. 시사점 하나는 출처 하나(거시환경, 미시환경, 내부현황, 벤치마킹)에 속함 |
| 귀납 | 여러 시사점이 가리키는 공통 문제를 묶어 문제이슈 하나로 정리하는 과정 |
| 문제이슈 | 전략이 해결할 문제. 1단계 초안을 6단계에서 시사점 근거로 확정 |
| As-is, To-be, 갭 | 현재 상태, 목표 상태, 두 상태의 차이 |
| CSF | Critical Success Factor. 벤치마킹 사례가 성공한 결정적 요인 |
| 전략 후보 | SWOT 요인을 결합한 전략 초안. SO, ST, WO, WT 구분 중 하나에 속함 |
| 미연결 요소 | 있어야 할 상위 연결이나 하위 연결이 없는 요소 |
| 후보군 | 선별 전에 충분히 도출해 두는 과제나 지표 후보의 목록 |

## 정렬 규칙

비전에서 성과지표까지는 하나의 전략체계를 이룬다. 상위 요소는 하위 요소의 방향을 정하고 하위 요소는 상위 요소를 달성하는 수단이 된다.

| 요소 | 역할 |
|---|---|
| 비전 | 조직이 장기적으로 지향하는 미래 모습. 존재 이유를 압축한 문장 |
| 미션 | 어떤 수요자에게 어떤 가치를 어떤 방식으로 제공할지 서술한 문장 |
| 핵심가치 | 미션을 수행하는 과정의 행동 기준. 전략마다 1개씩 대응 |
| 전략 | 비전과 미션을 달성하는 방향 |
| 전략목표 | 전략이 달성된 상태. 전략 번호를 그대로 사용 |
| 전략과제 | 전략을 달성하는 구체 방안. 상위 전략 번호를 이어받음 |
| 이행과제 | 전략과제를 실행하는 세부 활동 단위. 상위 전략과제 번호를 이어받음 |
| 성과지표 | 각 계층의 달성 정도를 측정하는 지표. 측정 대상 요소의 번호를 이어받음 |

아래 연결은 빠짐없이 성립해야 한다. 요소를 도출할 때마다 위아래 연결을 함께 확인해 미연결 요소를 남기지 않는다.

- 모든 팩트는 시사점 1개 이상에 반영된다.
- 모든 시사점은 문제이슈 1개 이상으로 귀납된다.
- 모든 문제이슈는 전략 1개 이상에 대응하고 모든 전략은 문제이슈 1개 이상을 해결한다.
- 모든 SWOT 요인은 해당 구분의 전략 후보에 사용된다.
- 모든 전략은 핵심가치 1개와 전략과제 1개 이상을 가진다.
- 이행과제 단계를 수행하면 모든 전략과제가 이행과제를 가진다.
- 하위 성과지표는 바로 위 요소의 지표와 연결되어 상위 지표 달성에 기여한다.

## 실행 모드

- (순차 모드) 기본값이다. 단계별 입력 양식을 제시하고 입력을 받아 산출물을 작성한 뒤 사용자 확정을 받는다. 뒤 단계를 미리 작성하지 않는다.
- (원스톱 모드) 사용자가 아래 양식을 한꺼번에 제출한 경우이다. 중간 확정을 생략하고 제출된 내용의 범위에서 전체 결과를 출력한 뒤 수정 요청을 받는다. 비어 있는 항목은 해당 단계에 들어설 때 다시 요청한다. 단계별 점검은 원스톱 모드에서도 각 단계 직후에 수행한다.

### 원스톱 입력 양식

```
[가설] 주체, 공간 범위, 시간 범위 또는 RFP 첨부
[수요자] 핵심 수요자와 수요자 요구
[상위 정렬] 상위기관 전략, 국가정책, 소속조직 비전 또는 "없음"
[문제이슈 초안] 직접 서술 또는 자동
[외부환경] 거시환경(자유입력, PEST, STEEP, PESTEL 중 택1)과 미시환경(자유입력 또는 5-Forces) 서술
[내부현황] 자유입력 또는 VRIO, 수요조사 자료 첨부 가능
[벤치마킹] 사례 서술 또는 생략
[분석도구] SWOT 또는 갭분석
[갭분석 모드] 분리 또는 통합 (갭분석 선택 시, 기본값 분리)
[문제이슈 확정] 고도화, 유지, 재도출 중 택1 (기본값 고도화)
[SWOT 모드] 고정형, 유연형, 문제이슈연결형 중 택1 (SWOT 선택 시, 기본값 고정형)
[SWOT 후속] 고정형은 Y 또는 N, 유연형은 후보 그대로, 구분별 대표, 구분 교차 결합 중 택1
[전략유형] 표준형 또는 R&BD형 (SWOT 선택 시, 기본값 표준형)
[전략목표] 통합형, 이중형, 정성형, 정량형 중 택1 (기본값 통합형)
[전략과제] 수요제출, n개 지정, 자동도출 중 택1 (기본값 수요제출)
[이행과제] 생략, 수요제출, n개 지정, 자동도출 중 택1, 우선순위 평가 Y 또는 N
[성과지표] 생략, 전계층형, 하위형, 전략형 중 택1 (기본값 전계층형)
[성과지표 트랙] BSC, 정부업무평가, R&D(Impact 포함 여부), 모델 자율, 질적 지표 중 택1
[시간 형식] 단중장기, 날짜, 단중장기와 날짜 병행 중 택1
[점검 방식] 스크립트 또는 수동 (기본값 스크립트)
```

## 단계별 점검

각 단계의 "점검" 항목은 연결 누락과 규칙 위반을 찾는 조건이다. 점검은 1, 5, 6, 7, 8, 9, 10단계 직후에 수행하며 2-4단계의 팩트는 5단계 점검에서 함께 다룬다. 코드를 실행할 수 있으면 스크립트로 점검하고 실행할 수 없거나 사용자가 수동을 고르면 같은 항목을 직접 대조한다. 위반이 나오면 위반 내용을 사용자에게 보여주고 수정한 뒤 다시 점검하며 통과 전에는 다음 단계로 넘어가지 않는다.

스크립트는 이 스킬 폴더의 `scripts/check_strategy.py`이며 파이썬 3.8 이상의 표준 라이브러리만 사용한다. 환경에 `python` 명령이 없으면 `python3`로 실행한다. 작업 내용은 상태 파일(JSON) 하나에 누적하며 이 파일로 중단한 작업을 이어갈 수 있다.

```bash
python scripts/check_strategy.py --template > strategy_state.json         # 빈 상태 파일 생성
python scripts/check_strategy.py strategy_state.json --step 6 --lang ko   # 1-6단계 점검
python scripts/check_strategy.py strategy_state.json --step all --lang ko --chart   # 전체 점검과 연결도
```

- 상태 파일의 키, 필드, 옵션 값은 `python scripts/check_strategy.py --schema --lang ko`로 확인하고 그대로 따른다. 원스톱 입력 양식과 단계별 선택 중 `--schema`에 나온 옵션은 settings에 기록한다.
- 전략과제, 이행과제, 성과지표의 상위 요소는 id 번호로 정해지므로 번호 형식을 정확히 지킨다.
- `--step N`은 1단계부터 N단계까지의 점검을 모두 수행하므로 뒤 단계에서 고친 내용이 앞 단계 규칙을 깨도 함께 드러난다.
- 종료 코드는 통과 0, 위반 1, 입력 파일 오류 2이다. "(권고)"로 시작하는 줄은 참고 사항이며 통과 여부에 영향을 주지 않는다.
- `--chart`는 시사점에서 성과지표까지의 추적 연결도와 비전하우스 연결도를 Mermaid 형식으로 출력한다.

## 전체 흐름

| 단계 | 내용 | 수행 조건 |
|---|---|---|
| 1 | 과제 설정(가설, 수요자, 상위 정렬, 문제이슈 초안) | 필수 |
| 2, 3 | 외부환경 분석, 내부현황 분석 | SWOT 경로와 갭분석 분리 모드에서 필수, 갭분석 통합 모드에서 생략 |
| 4 | 벤치마킹 | 모든 경로에서 선택 |
| 5 | 시사점 도출 | 필수 |
| 6 | 문제이슈 확정과 전략 도출 | 필수 |
| 7 | 비전, 미션, 핵심가치 도출 | 필수 |
| 8 | 전략목표와 전략과제 도출 | 필수 |
| 9 | 이행과제 도출과 우선순위 평가 | 선택 |
| 10 | 성과지표 설정 | 선택 |

## 1단계 과제 설정

- (가설) 전략의 주체, 공간 범위, 시간 범위를 받는다. RFP가 첨부되면 RFP에서 추출한 뒤 사용자 확인을 받는다.
- (수요자) 핵심 수요자와 수요자 요구를 받는다.
- (상위 정렬) 상위기관 전략, 국가정책, 소속조직 비전, 법제도를 받는다. 해당 사항이 없으면 사용자가 "없음"으로 답하게 하고 그대로 기록한다. 상위 정렬은 7단계 비전의 탑다운 입력이 된다.
- (문제이슈 초안) 사용자가 직접 서술하거나 "자동"을 고른다. 자동이면 가설, 수요자 요구, 상위 정렬을 근거로 초안을 만든다. 초안은 6단계에서 시사점으로 다시 따진다.
- 산출물은 가설과 목적, 주체, 공간 범위, 시간 범위 정리와 수요자 요구 정리, 상위 정렬 서술, 문제이슈 초안 목록이다.
- 점검: 가설의 주체, 공간 범위, 시간 범위가 모두 있다. 수요자가 1개 이상 있다. 상위 정렬이 1건 이상 있거나 "없음"이 기록되어 있고 둘이 동시에 있지 않다. 문제이슈 초안이 1건 이상 있다.

1단계 점검을 통과하면 분석도구(SWOT 또는 갭분석)를 묻는다. 갭분석을 고르면 갭분석 모드를 이어서 묻는다. 분리 모드(기본값)는 2-5단계를 차례로 거치며 환경 요인 누락을 막아야 하는 중장기 전략과 정보화전략계획(ISP)에 적합하다. 통합 모드는 2-3단계를 생략하고 벤치마킹 여부를 확인한 뒤 5단계로 가며 비교적 작은 의사결정과 단기 운영 개선에 적합하다.

## 2단계 외부환경 분석

거시환경과 미시환경을 나누어 팩트를 수집한다. 거시환경 프레임은 미시환경을 다루지 않으므로 둘을 함께 진행한다. 기본값은 자유입력이며 사용자가 프레임을 고를 수 있다.

| 구분 | 프레임 | 구성 |
|---|---|---|
| 거시환경 | PEST | 정치, 경제, 사회, 기술 |
| 거시환경 | STEEP | 사회, 기술, 경제, 환경, 정치 |
| 거시환경 | PESTEL | 정치, 경제, 사회, 기술, 환경, 법규 |
| 미시환경 | 5-Forces | 기존 경쟁자 간 경쟁, 공급자 교섭력, 구매자 교섭력, 신규 진입자 위협, 대체재 위협 |

- 프레임을 고르지 않으면 거시환경과 미시환경을 자유 서술로 정리한다. 팩트는 객관적 현상과 추세만 적고 To-be, 전략, 해결 방법은 이 단계에 적지 않는다.

## 3단계 내부현황 분석

- 기본값은 자유입력이며 VRIO를 고를 수 있다. VRIO는 자원과 역량을 가치(Value), 희소성(Rarity), 모방 난이도(Imitability), 조직의 활용 체계(Organization) 네 질문으로 진단한다.
- 설문, 인터뷰, RFP 요구사항 같은 수요조사 자료를 받으면 요구사항 목록을 만든다.
- 구분별 내부역량 현황과 진단을 팩트로 적는다. To-be나 필요 사항은 적지 않는다.

## 4단계 벤치마킹

모든 경로에서 선택 단계이며 필요 없으면 생략한다. 선진사례의 객관적 사실을 팩트로 적고 사례별 CSF를 추출한다. 벤치마킹 결과는 6단계 To-be 방안의 근거로 쓸 수 있다.

## 5단계 시사점 도출

시사점은 문제이슈를 도출하는 입력이므로 어떤 경로에서도 생략하지 않는다.

- (SWOT, 갭분석 분리 모드) 2-4단계 팩트에서 시사점을 도출하고 거시환경, 미시환경, 내부현황, 벤치마킹 네 소제목 아래 불렛 1줄씩 쓴다.
- (갭분석 통합 모드) 사용자가 As-is 시사점을 자유 서술하고 벤치마킹을 했으면 벤치마킹 시사점을 더한다. 소제목은 As-is 시사점과 벤치마킹 시사점이며 벤치마킹을 하지 않았으면 As-is 시사점만 쓴다.
- 시사점 하나는 출처 하나에 속한다. 서로 다른 출처의 팩트를 함께 쓰는 시사점은 출처별로 나눈다. 이 구분은 6단계 SWOT 요인의 출처 규칙을 적용하는 기준이 된다.
- 표를 쓰지 않고 불렛으로 쓰며 사용자 확정을 받는다.
- 점검: 모든 팩트가 시사점 1개 이상에 쓰였다. SWOT과 분리 모드에서는 모든 시사점이 같은 출처의 팩트 1개 이상에 근거하고 asis 출처가 없다. 통합 모드에서는 팩트 출처가 벤치마킹뿐이고 시사점 출처는 As-is 또는 벤치마킹이다.

## 6단계 문제이슈 확정

문제이슈 확정 방식을 먼저 정한다.

- (고도화, 기본값) 1단계 초안을 시사점에 근거해 재구성하고 보강한다.
- (유지) 1단계 초안을 그대로 확정하고 시사점만 연결한다.
- (재도출) 1단계 초안을 버리고 시사점을 귀납해 새로 도출한다.

여러 시사점이 같은 문제를 가리키면 하나의 문제이슈로 묶는다. 시사점과 문제이슈의 연결표를 만들고 고도화나 재도출을 했으면 초안과 근거 시사점을 함께 적는다. 이어서 앞에서 고른 경로로 전략을 도출한다.

- 점검: 모든 문제이슈가 시사점 1개 이상에서 귀납되었다. 모든 시사점이 문제이슈 1개 이상으로 귀납되었다. 전략이 1개 이상 있고 전략 번호는 1 이상의 정수이다.

### 갭분석 경로

- 전체 As-is와 To-be를 서술하고 둘의 차이인 갭을 도출한다. 문제이슈마다 핵심 갭을 정하고 갭을 해소하는 전략으로 연결한다.
- 문제이슈는 3개 이상을 권장한다.

| 해결 대상 문제이슈 | As-is 시사점 | 갭 | To-be 방안 | 전략 |
|---|---|---|---|---|
| 문제이슈 번호와 이름 | As-is 상태 요약 | As-is와 To-be의 차이 | To-be 달성 방안 | 전략명 |

- 점검: 모든 갭이 실제 문제이슈 1개에 속하고 As-is와 To-be가 적혀 있다. 모든 문제이슈가 갭을 가진다. 모든 전략이 갭 1개 이상을 해소하고 모든 갭이 전략 1개 이상과 연결된다.

### SWOT 경로

요인마다 번호를 붙인다. 강점 S, 약점 W, 기회 O, 위협 T는 각 4개가 기본이며 사용자가 요청하면 개수를 바꾸되 네 구분 모두 1개 이상 둔다. 요인표에는 구분 열(강점, 약점, 기회, 위협)을 두고 요인명과 전략명은 정량 수치 없이 정성 개념으로 쓴다.

요인은 5단계 시사점에서 도출하며 아래 출처 규칙을 따른다. 내부현황은 조직 자신을, 거시환경과 미시환경은 조직 바깥을 설명하기 때문이다.

| 요인 | 사용 가능한 시사점 출처 | 사용할 수 없는 출처 |
|---|---|---|
| 강점(S), 약점(W) | 내부현황, 벤치마킹 | 거시환경, 미시환경 |
| 기회(O), 위협(T) | 거시환경, 미시환경, 벤치마킹 | 내부현황 |

전략 후보는 해당 구분의 두 요인 유형만 결합하고 두 유형을 모두 1개 이상 쓴다. SO는 강점과 기회, ST는 강점과 위협, WO는 약점과 기회, WT는 약점과 위협을 결합한다. 한 구분의 후보 전체는 그 구분에 해당하는 요인을 모두 사용한다.

| 모드 | 후보 도출 | 후속 처리 | 최종 전략 수 |
|---|---|---|---|
| 고정형(기본값) | 구분마다 1개. 후보 하나가 두 유형의 요인을 모두 사용 | Y는 그대로 확정, N은 문제이슈 해결 관점으로 재구성 | 4개 |
| 유연형 | 구분마다 여러 개. 후보마다 사용 요인 번호 표기 | 아래 세 방식 중 택1 | 방식에 따름 |
| 문제이슈연결형 | 구분마다 여러 개 | 문제이슈 해결 관점으로 1대1 재구성 | 문제이슈 수와 같음 |

- (고정형 후속 질의) 네 전략을 그대로 쓸지 묻는다. Y는 전략 방향을 바꾸지 않고 확정한 뒤 문제이슈를 각 전략에 연결한다. N은 전략 4개를 유지하면서 해결 대상 문제이슈(4개를 넘어도 됨)를 네 전략에 나누어 연결하고 전략명과 내용을 다시 조정한다.
- (유연형 후보 그대로) 모든 후보를 각각 하나의 전략으로 확정한다.
- (유연형 구분별 대표) 각 구분의 후보를 전략과제로 배치하고 구분마다 대표 전략을 1개씩 귀납해 모두 4개를 만든다.
- (유연형 구분 교차 결합) 서로 다른 구분의 후보를 단독 또는 여러 개 결합해 통합 전략을 만든다. 결합 수에는 제한이 없다(예: SO1 단독, ST1과 WO2 결합, SO3과 ST2와 WT1 결합). 최종 전략 전체가 모든 요인을 포함해야 한다.
- (문제이슈연결형) 후보가 어떤 문제이슈를 해결하는지 행렬로 정리하고 해결 기여도에 따라 후보를 고르거나 통합한다. 최종 전략과 문제이슈는 1대1로 대응하며 후보 수와 최종 전략 수는 달라도 된다.

전략유형은 전략명의 성격을 정하는 표기 기준이며 기본값은 표준형이다. 표준형은 SO는 강점으로 기회를 살리고, ST는 강점으로 위협을 줄이고, WO는 기회로 약점을 보완하고, WT는 약점과 위협을 함께 줄인다는 네 구분의 뜻을 전략 방향으로 부른 이름이다. R&BD형은 전략을 실행할 사업 수단으로 부른 이름이며 R&BD와 공공 연구개발 사업 기획에서 쓴다.

| 유형 | SO | ST | WO | WT |
|---|---|---|---|---|
| 표준형 | 성장 | 경쟁우위 유지 | 혁신 | 리스크 관리 |
| R&BD형 | 인프라 | 비R&D | R&D | 거버넌스 |

전략 도출 결과는 아래 양식으로 정리한다.

| 구분 | 요인 | As-is 시사점 | To-be 방안 | 전략 |
|---|---|---|---|---|
| SO1, ST2, WO1 등 | 요인 번호와 이름 | 5단계 시사점 요약 | 구체적 To-be | 전략명 |

- 구분 열은 SO, ST, WO, WT 뒤에 순번을 붙인다. 고정형은 구분당 1개이므로 순번 없이 쓸 수 있다.
- 요인 열에는 번호와 이름을 함께 쓴다(예: `S2. 숙련 인력 기반 품질 관리 역량`). 번호만 나열하지 않는다.
- As-is 시사점은 5단계 시사점을 키워드 수준으로 요약해 나열한다. To-be 방안은 실행 방향이 드러나도록 구체적으로 쓴다.
- 셀 안의 여러 항목은 줄을 바꿔 쓴다. 문제이슈연결형과 고정형 N은 구분 열 다음에 해결 대상 문제이슈 열을 추가한다.
- 구분 교차 결합은 아래 표를 추가로 쓴다.

| 전략 번호 | 결합 후보 | 결합 논리 | 전략명 | 사용 요인 |
|---|---|---|---|---|

- 점검: 요인의 출처 규칙, 후보의 요인 결합 규칙, 구분별 요인 전수 사용을 지킨다. 고정형은 구분마다 후보가 1개이고 전략 4개가 SO, ST, WO, WT를 하나씩 맡는다. 후보 그대로 방식은 후보와 전략이 1대1이다. 구분별 대표 방식은 전략 4개가 각 구분의 후보 전체를 하나씩 맡는다. 교차 결합은 최종 전략 전체가 모든 요인을 포함한다. 문제이슈연결형은 전략과 문제이슈가 1대1이다.

## 7단계 비전 도출

비전, 미션, 핵심가치를 탑다운 입력과 바텀업 입력을 합쳐 도출한다. 상위 정렬이 "없음"이면 바텀업 입력만으로 도출한다.

| 방향 | 입력 |
|---|---|
| 탑다운 | 상위기관 전략, 국가정책, 소속조직 비전, 법제도 |
| 바텀업 | 6단계 전략들의 공통 지향점, 수요자가 중시하는 가치 |

핵심가치는 전략마다 1개씩 대응시키고 한 핵심가치를 여러 전략에 쓰지 않는다. 최종 비전하우스가 전략별로 핵심가치 1개를 표시하기 때문이다.

| 항목 | 탑다운 | 바텀업 | 최종 도출 |
|---|---|---|---|
| 비전 | | | |
| 미션 | | | |
| 핵심가치 | | | |

전략과 핵심가치의 대응은 아래 표로 정리한다.

| 전략 번호 | 전략명 | 대응 핵심가치 |
|---|---|---|

- 점검: 비전과 미션 문장이 있다. 상위 정렬이 있으면 비전이 상위 정렬 1건 이상과 연결된다. 미션이 수요자 1개 이상과 연결된다. 모든 전략이 핵심가치를 정확히 1개 가진다.

## 8단계 전략과제 도출

| 계층 | 번호 형식 | 예시 |
|---|---|---|
| 전략 | `N. 전략명` | `1. 저탄소 생산 전환` |
| 전략과제 | `N-M. 전략과제명` | `1-1. 공정 에너지 관리 고도화` |
| 이행과제 | `N-M-L. 이행과제명` | `1-1-1. 주요 설비 전력 계측 도입` |

전략목표 패턴을 고른다. 전략목표는 전략 번호를 그대로 쓰고 별도 번호를 붙이지 않는다.

| 패턴 | 구성 | 쓰이는 경우 |
|---|---|---|
| 통합형(기본값) | 전략명이 전략목표를 겸함 | 전략명 자체가 목표 역할 |
| 이중형 | 정성 전략목표 1개와 정량 전략목표 1개 | 공공 중장기계획, R&D 사업목표 |
| 정성형 | 정성 전략목표 1개 | 방향성 중심의 비전하우스 |
| 정량형 | 정량 전략목표 1개 | 지표 달성 중심의 성과관리 |

전략목표는 아래 양식으로 적는다.

| 전략 번호 | 전략명 | 정성 전략목표 | 정량 전략목표 |
|---|---|---|---|

- 이중형은 두 열을 모두 채운다. 정성형은 정량 열을, 정량형은 정성 열을 비운다. 통합형은 이 표를 생략한다.
- 정량 전략목표는 전략당 1개이며 여러 목표치를 한 칸에 묶지 않는다.

전략과제 도출 방식을 고른다. 사용자 지시 없이 모델이 전략과제를 만들지 않는다.

- (수요제출, 기본값) 사용자가 전략과제 목록을 제출한다. 제출 목록 확인, 사업목표 관점의 공통 지향점 추출, 지향점을 전략으로 귀납, 상위 정렬과의 정합성 확인, 정합성이 부족한 과제 별도 표시의 순서로 처리한다.
- (n개 지정) 사용자가 정한 개수만큼 후보를 제시하고 확정을 받는다.
- (자동도출) 사용자가 고른 경우에만 전략별 후보군을 개수 제한 없이 제시하고 승인을 받는다.
- 전략과제는 문제이슈를 To-be로 바꾸는 구체 방안이며 전략과 전략과제의 연결 논리를 함께 적는다.
- 구분별 대표 방식이면 각 전략 후보가 해당 전략의 전략과제 하나가 된다.

| 전략 번호 | 전략과제 번호 | 전략과제명 |
|---|---|---|

- 점검: 모든 문제이슈가 전략 1개 이상에 대응하고 모든 전략이 문제이슈 1개 이상을 해결한다. 갭분석 경로에서는 전략이 해소하는 갭의 문제이슈가 그 전략의 해결 목록에 있다. 전략목표가 고른 패턴과 맞다. 모든 전략이 전략과제를 가지고 전략과제 번호는 `N-M` 형식이며 상위 전략이 존재한다. 구분별 대표 방식은 후보마다 전략과제가 정확히 1개이다.

## 9단계 이행과제 도출

선택 단계이다. 도출 방식은 8단계와 같이 수요제출(기본값), n개 지정, 자동도출 중에서 고른다.

- 수요제출이면 제출 목록을 유사성에 따라 묶고 묶음을 전략과제로, 전략과제 묶음을 전략으로 귀납한 뒤 상위 정렬과의 정합성을 확인한다.
- 이행과제는 실행 가능한 세부 활동 수준으로 쓰고 SMART 기준으로 확인한다.

| 기준 | 이행과제 | 성과지표(10단계) |
|---|---|---|
| Specific(명확성) | 활동이 명확히 정의됨 | 지표 개념과 측정 방법이 명확함 |
| Measurable(측정가능성) | 산출물을 측정할 수 있음 | 측정 데이터가 존재함 |
| Achievable(실현가능성) | 가용 자원으로 실행 가능 | 목표치 달성이 가능함 |
| Relevant(관련성) | 상위 전략과제와 정렬됨 | 상위 계층 지표와 연결됨 |
| Time-bound(기한성) | 기한이 명시됨 | 측정 시기가 적합함 |

- (우선순위 평가, 선택) 필요성(전략 달성 기여도), 시급성(시점별 추진 필요도), 중복성(기존 사업이나 다른 과제와 겹치는 정도), 실현가능성(자원과 역량 확보 수준)으로 평가하고 추진 일정과 선후관계 로드맵을 만든다. 선후관계는 상태 파일의 precedes에 기록한다.

| 전략과제 번호 | 이행과제 번호 | 이행과제명 |
|---|---|---|

- 점검: 모든 전략과제가 이행과제를 가진다. 이행과제 번호는 `N-M-L` 형식이며 상위 전략과제가 존재한다. 선후관계에 자기 참조와 순환이 없다. 이 단계를 생략했으면 이행과제가 없다.

## 10단계 성과지표 설정

선택 단계이다. 적용 계층과 트랙을 차례로 묻는다.

- (적용 계층) 전계층형(기본값)은 전략, 전략과제, 이행과제 모두에 지표를 둔다. 하위형은 이행과제에만, 전략형은 전략에만 둔다. 이행과제 단계를 생략했으면 전략형만 고를 수 있다.
- (트랙) 사용자가 고르지 않으면 주체에 따라 권고한다. 공공기관 정책은 트랙 2, 연구개발 사업은 트랙 3, 그 밖은 트랙 1이다.

| 트랙 | 이름 | 적용 대상 |
|---|---|---|
| 1 | BSC | 민간, 비영리, 공공 일반 |
| 2 | 정부업무평가 | 중앙행정기관, 공공기관 정책 |
| 3 | R&D | 연구개발 사업, 기술개발 과제 |
| 4 | 모델 자율 | 표준 트랙이 맞지 않는 신생 분야, 실험적 사업 |
| 5 | 질적 지표 | 정량화가 어려운 분야 |

모든 트랙에 아래 공통 원칙을 적용한다.

- 9단계 SMART 기준을 충족한다. 트랙 3은 자체 SMART 기준을 추가로 쓴다.
- 모든 지표는 비전, 미션, 전략과 정렬되며 하위 지표의 합계나 기여가 상위 지표 달성으로 이어진다.
- 성과목표별 또는 계층별로 지표를 2개 이상 둔다.
- 지표 후보군을 충분히 도출한 뒤 선별한다.
- 트랙은 하나를 기본으로 한다. 섞어 써야 하면 주 트랙 1개를 정하고 보조 트랙의 원칙을 일부 빌려 쓰며 혼합 사유와 적용 범위를 적는다.

지표 번호는 전략 `1-KPI-1`, 전략과제 `1-1-KPI-1`, 이행과제 `1-1-1-KPI-1` 형식이다. 전계층형에서 하위 지표는 contributes_to로 바로 위 요소의 지표 하나에 연결하고 전략 지표는 상위 지표를 두지 않는다.

| 번호 | 상위 요소 | 지표명 | 지표 유형 | 측정 방식 | 목표치 | 달성 시한 |
|---|---|---|---|---|---|---|

- 상위 요소는 지표가 측정하는 요소의 한 단계 위이다. 전략 지표는 비전 또는 미션, 전략과제 지표는 해당 전략, 이행과제 지표는 해당 전략과제를 적는다.
- 지표 유형은 Input(투입), Activity(과정), Output(산출), Outcome(결과), Impact(파급) 중 하나이다.
- 측정 방식은 괄호 제목과 산식이나 방법을 함께 쓴다(예: `(집계) 연간 이용 기업 단순 합산`, `(산식) 집행액 / 총예산 × 100`, `(척도) 리커트 5점 척도 분기별 평균`).
- 달성 시한은 고른 시간 형식(단기, 중기, 장기 또는 날짜 또는 병행)으로 적는다.
- 점검: 지표 번호 형식이 맞고 측정 대상 요소가 존재하며 적용 계층 밖의 지표가 없다. 적용 계층의 모든 요소가 지표를 가진다. 전계층형은 전략과제와 이행과제 지표가 바로 위 요소의 지표에 연결된다. 정부업무평가 트랙은 전략목표가 이중형이다. R&D 트랙은 사용자가 포함을 고르지 않았으면 Impact 지표가 없다. 전계층형과 하위형은 이행과제 단계를 수행했다. 성과지표 단계를 생략했으면 지표가 없다.

### 트랙 1 BSC

| 계층 | 지표 유형 |
|---|---|
| 전략 | Outcome, Impact |
| 전략과제 | Output, 단기 Outcome |
| 이행과제 | Input, Activity, Output |

- 아래 계층으로 갈수록 지표가 구체적이고 운영 수준으로 바뀐다.
- 상위 계층은 결과를 보여주는 후행 지표(Outcome), 하위 계층은 결과를 이끄는 선행 지표(Output, Activity)를 중심으로 둔다.
- Input, Activity, Output, Outcome, Impact로 이어지는 연결을 명시한다.
- 재무, 고객, 내부 프로세스, 학습과 성장 네 관점을 고르게 배치한다.
- 하위 지표를 모으는 방식은 가중평균(만족도, 달성률), 합산(건수, 인원, 예산), 대표지표(핵심 지표 1개 선정) 중에서 고른다.
- Impact 지표를 쓰면 전략목표는 정량형이나 이중형을 권고한다. 통합형이나 정성형이면 Impact 지표를 산출물에 따로 표시한다.

### 트랙 2 정부업무평가

한국 중앙행정기관의 성과관리 체계(5년 단위 성과관리전략계획과 1년 단위 시행계획)에 맞춘 트랙이다.

| 정부업무평가 | 이 스킬 | 성격 |
|---|---|---|
| 임무 | 미션 | 조직의 존재 이유 |
| 비전 | 비전 | 장기 지향점 |
| 전략목표 | 전략과 정성 전략목표 | 정책 방향 |
| 성과목표 | 정량 전략목표 | 측정 가능한 구체 목표 |
| 관리과제 | 전략과제 또는 이행과제 | 실행 단위 |
| 성과지표 | 성과지표 | 달성도 측정 |

- 정부업무평가의 "전략목표"는 이 스킬의 전략과 정성 전략목표에 해당하고 이 스킬의 정량 전략목표는 "성과목표"에 해당한다. 같은 단어가 다른 뜻으로 쓰이므로 산출물에서 구분해 적는다.
- 관리과제는 기본적으로 이행과제에 대응시키고 실행 단위가 넓으면 전략과제에 대응시킨다.
- 전략목표는 이중형이어야 한다. 8단계에서 다른 패턴을 골랐으면 트랙에 들어가기 전에 사용자 확인을 받아 이중형으로 바꾼다.
- 계층별 지표 유형을 강제하지 않고 계층의 추상도에 따라 정한다. 지표는 정량, 정성, 투입, 과정, 산출, 결과로 구분하며 정성 지표는 평가자 주관이 들어가므로 측정 도구를 표준화한다.
- 5년 단위 중장기 지표와 1년 단위 시행 지표를 함께 운영하고 관리과제 단위로 자체평가한다.

### 트랙 3 R&D

한국 국가연구개발사업의 성과목표와 성과지표 설정 방식을 따른 트랙이다. 아래 분류와 기간 기준은 한국과학기술기획평가원의 국가연구개발사업 표준 성과지표 6차(2024)를 따르며 개정판이 나오면 개정판을 따른다.

| 유형 | 정의 | 예시 |
|---|---|---|
| 투입(Input) | 연구에 쓰인 재원, 인력, 장비 | 연간 연구비 총액, 석박사급 인력 수, 장비 수 |
| 과정(Activity) | 투입을 산출로 바꾸는 활동 | 공정률, 진척도, 로드맵 이행률 |
| 산출(Output) | 사업 수행으로 직접 나온 양적, 질적 성과 | 논문 수, 등록 특허 수, 논문 피인용 |
| 결과(Outcome) | 사업이 목표한 효과의 달성 수준 | 기술수준 향상, 취업률, 기업 성장률 |

- 성과지표는 투입, 과정, 산출, 결과 순으로 후보군을 도출하고 질적 산출 지표와 결과 지표 중심으로 선별한다. 예산만 투입하면 달성되는 투입과 과정 지표, 논문 수나 특허 수 같은 단순 건수 지표는 지양한다.
- Impact 지표는 사업 종료 후 효과성 분석에서 다루므로 사업 성과지표에서는 기본적으로 제외한다. 사용자가 장기 파급효과 관리를 원하면 포함하고 효과성 분석용으로 따로 표시한다.
- 산출 지표 중 질을 측정하는 지표와 결과 지표는 질적 성과지표로 따로 분류한다. 예시는 논문의 mrnIF(학술지의 분야 내 순위를 0-100으로 표준화한 지수), 특허 평가 시스템 K-PEG와 SMART의 등급, 등급화한 전문가 정성평가이며 측정 방법을 객관화한다.
- 이행과제 단계를 수행했으면 이행과제를, 생략했으면 전략과제를 R&D 사업 단위로 보고 지표 유형과 시간 단계를 적용한다.

| 시간 단계 | 기간 | 중심 지표 |
|---|---|---|
| 초기 | 사업 시작 후 3년 이내 | 산출 |
| 중기 | 3년에서 5년 | 단기 결과 |
| 장기 | 6년 이상 | 장기 결과 |

사업 유형별로 단계마다 중심이 되는 성과 분야의 예시는 아래와 같으며 사업 특성에 따라 조정할 수 있다. 기초연구처럼 장기간이 필요한 사업은 단계별 기간도 달라질 수 있다.

| 사업 유형 | 초기 | 중기 | 장기 |
|---|---|---|---|
| 기초연구 | 과학적, 기술적 | 과학적, 기술적 | 과학적, 기술적, 경제적, 사회적 |
| 단기산업 기술개발 | 기술적, 경제적 | 기술적, 경제적 | 기술적, 경제적 |
| 중장기산업 기술개발 | 과학적, 기술적 | 과학적, 기술적, 경제적 | 경제적 |
| 공공기술개발 | 과학적, 기술적 | 과학적, 기술적, 사회적 | 경제적, 사회적 |
| 지역연구개발 | 과학적, 기술적, 경제적 | 기술적, 경제적, 사회적 | 경제적, 사회적 |
| 국방기술개발 | 기술적, 경제적, 인프라 | 기술적, 경제적, 인프라 | 기술적, 경제적, 인프라 |
| 인력양성 | 과학적, 기술적 | 과학적, 기술적 | 경제적, 사회적 |
| 시설장비구축 | 인프라 | 인프라 | 경제적, 사회적, 인프라 |
| 성과확산 | 기술적, 경제적, 인프라 | 기술적, 경제적, 인프라 | 기술적, 경제적, 인프라 |
| 국제협력 | 과학적, 기술적 | 과학적, 기술적 | 경제적, 사회적 |

- 성과 분야는 과학적(논문, 생명자원, 화합물), 기술적(특허, 콘텐츠, 소프트웨어, 기술노하우), 경제적(기술계약, 매출액, 산업 부문 일자리와 창업, 중소기업 지원, 수입대체 효과), 사회적(인력양성, 공공 부문 일자리와 창업, 과학 대중화, 국제교류, 정책 효과), 인프라(시설장비, 정보시스템, 무기체계 확보)로 나눈다.
- 지표는 성과 분야(대분류), 분야 안에서 사업 성과를 대표하는 유무형 산출물인 성과 유형(중분류), 산출물의 우수성을 재는 성과지표(소분류)의 3단계로 구성한다.
- 사업 유형, 기간, 이력을 함께 고려한다. 계속 사업은 산출 지표 비중을 낮추고 결과 지표 중심으로 둔다. 기한이 있는 사업은 초기에 산출, 중후반에 결과 중심으로 단계적으로 바꾼다. 기초연구 외의 사업에서는 논문 지표의 비중을 과하게 두지 않는다.
- 성과목표마다 지표를 2개 이상 두고 아래 R&D용 SMART로 선별한다. 9단계 일반 SMART와 약자가 같지만 뜻이 다르므로 구분해 쓴다.

| 기준 | 내용 |
|---|---|
| Specific(구체성) | 지표 개념과 측정 방법이 명확하고 데이터가 일관됨 |
| Measurable(측정가능성) | 측정 데이터가 있고 사용 제약이 없음 |
| Attributable(원인성) | 사업 범위 안의 성과이며 외부 요인에 왜곡되지 않음 |
| Reliable(신뢰성) | 제3자가 검토해도 같은 결과가 나옴 |
| Timely(적시성) | 측정 시기가 적합함 |

### 트랙 4 모델 자율

- 표준 트랙이 맞지 않는 신생 분야, 정의되지 않은 분야에서 지표를 새로 찾아야 하는 경우, 사전에 정한 대응 규칙 없이 사업 특성에 맞춰 도출하기를 원하는 경우에 쓴다.
- 공통 원칙(SMART, 수직 정렬, 정량 지표와 질적 지표의 균형)만 적용하고 계층별 지표 유형, 시간 단계, 사업 유형별 기준은 강제하지 않는다.
- 가설, 수요자 요구, 전략체계를 종합해 지표 후보를 도출하고 SMART와 수직 정렬 원칙으로 선별한 뒤 사용자 확정을 받는다.

### 트랙 5 질적 지표

- 조직문화, 거버넌스, 리더십, 협력 관계, 신뢰도, 예술, 교육, 사회 통합, 지역 공동체, 정량 데이터가 쌓이지 않은 초기 사업처럼 정량화가 어려운 분야에 쓴다.
- 모든 계층에서 질적 지표를 먼저 도출하고 정량 지표는 보조로 쓴다.
- 측정 도구는 리커트 척도(만족도, 인식, 동의 수준을 5점이나 7점으로 측정), 루브릭(단계별 성취 기준), 표준화 지수(비교 가능한 정성 점수), 사례연구(변화 과정 기록), 내러티브 평가(변화 이야기 평가), 전문가 정성평가(외부 전문가 의견 수렴과 합의), 심층 인터뷰(수요자와 관계자 의견 수집), 포커스 그룹(집단 토론 평가) 중에서 고른다.
- 측정 도구를 미리 표준화하고 측정자를 훈련하며 측정자 간 일관성을 확인한다. 여러 측정자의 교차 확인과 정량 지표 보조로 객관성을 보완한다.

## 최종 비전하우스

모든 단계를 마치면 전체를 통합해 출력한다. 점검 방식이 스크립트이면 `--chart` 연결도를 함께 제시한다. 먼저 비전, 미션, 핵심가치를 구분과 내용 두 열의 표로 제시한 뒤 전략마다 `전략 N 전략명` 제목 아래 두 표를 반복한다.

| 항목 | 내용 |
|---|---|
| 핵심가치 | |
| 정성 전략목표 | 해당 패턴일 때 기재 |
| 정량 전략목표 | 해당 패턴일 때 기재 |

전략과제, 이행과제, 지표는 아래 표로 정리한다.

| 전략과제 | 이행과제 | 핵심 지표 |
|---|---|---|
| N-M. 전략과제명 | N-M-L. 이행과제명 줄바꿈 나열 | 지표 번호와 지표명 줄바꿈 나열 |

- 통합형 전략목표이면 정성과 정량 전략목표 행을 생략한다.
- 이행과제 단계를 생략했으면 이행과제 열을, 성과지표 단계를 생략했으면 핵심 지표 열을 생략한다.
