# 경쟁 구도 분석

02_제안전략서.md의 4절(경쟁 구도)을 작성하는 절차와 양식이다. 경쟁 후보 탐색은 웹검색 허용 환경에서 수행한다. 대한민국 공공 조달의 제도를 기준으로 쓰였다.

## 참가자격 판정

경쟁 후보를 찾기 전에 이번 공고에 입찰할 수 있는 기업 규모부터 판정한다. 판정 없이 찾으면 입찰할 수 없는 대형 기관이 후보에 들어와 경쟁 구도가 틀어진다.

- 판정 근거의 1순위는 입찰공고문과 RFP의 참가자격 문구다. 문구가 아래 금액 기준과 달라도 문구를 따른다.
- 문구가 없거나 모호하면 아래 제도로 추정하고 판정 결과에 [확인]을 붙인다.
- 제도 수치는 개정될 수 있으므로 공고일 기준 현행 값을 웹검색으로 확인한다.

### 용역 금액 기준

「중소기업제품 구매촉진 및 판로지원에 관한 법률」 제4조와 같은 법 시행령 제2조의2가 공공기관 용역의 기업 규모 제한을 정한다.

| 추정가격 | 입찰할 수 있는 기업 |
|---|---|
| 1억원 미만 | 소기업 또는 소상공인. 입찰 가능한 소기업과 소상공인이 3인 이하이거나 유찰되면 중소기업자 간 제한경쟁으로 완화되어 중기업도 입찰할 수 있다 |
| 1억원 이상, 고시금액 미만 | 중소기업자. 중견기업과 대기업은 입찰할 수 없다 |
| 고시금액 이상 | 금액에 따른 기업 규모 제한 없음 |

- 중소기업자간 경쟁제품으로 지정된 용역은 금액과 관계없이 중소기업자 간 경쟁이다. 공고문에서 경쟁제품 여부를 확인한다.
- 추정가격은 부가가치세를 뺀 금액이다. 공고의 기초금액이나 사업 예산이 부가가치세 포함 금액이면 1.1로 나눠 추정가격으로 바꾼다. 계산은 코드로 한다.
- 고시금액은 「국가를 당사자로 하는 계약에 관한 법률」 제4조에 따라 2년마다 고시되는 국제입찰 대상금액이다. 2025-2026년 중앙행정기관의 물품과 용역 기준은 2억 3천만원이다. 공고일이 이 기간 밖이면 새 고시금액을 확인한다.

### 학술연구 예외

같은 시행령 제2조의3은 비영리법인의 경쟁입찰 참여가 필요한 학술, 연구, 교육, 검사 등 용역에 우선조달계약을 적용하지 않을 수 있게 한다. 이 예외를 쓴 공고는 사유를 공고문에 적는다. 예외 공고에서는 대형 컨설팅사도 입찰할 수 있다. 그래서 학술연구용역은 금액과 함께 공고문의 참가자격 문구와 예외 사유 기재 여부를 보고 판정한다.

### 소프트웨어사업 기준

- 「소프트웨어 진흥법」 제48조와 과학기술정보통신부 고시 「중소 소프트웨어사업자의 사업 참여 지원에 관한 지침」이 대기업인 소프트웨어사업자의 참여 하한을 정한다. 여기서 대기업은 중소기업을 제외한 모든 소프트웨어사업자이며 중견기업을 포함한다.
- 하한은 지침 별표 1이 매출액 구간별로 정한다. 2026년 기준으로 매출액 8천억원 이상 기업은 사업금액 80억원 이상, 8천억원 미만 기업은 40억원 이상 사업에 참여할 수 있다.
- 중소기업에서 중견기업이 된 지 5년이 지나지 않은 기업은 매출액과 관계없이 20억원 이상 사업에 참여할 수 있다. 따라서 사업금액 20억원 미만 사업은 중소기업만 입찰할 수 있다.
- 상호출자제한기업집단 소속 회사는 예외로 인정된 사업을 제외하고 금액과 관계없이 참여할 수 없다.
- 소프트웨어사업의 사업금액은 부가가치세를 포함한 금액이다. 용역 금액 기준의 추정가격과 산정 방식이 다르다.
- 발주기관은 대기업 참여 제한 여부를 공고문이나 RFP에 적어야 한다. 그 문구를 먼저 확인한다. ISP, ISMP 같은 정보화 기획 용역은 소프트웨어사업 해당 여부를 공고문 문구로 확인한다.
- 정부가 발표한 제도 개선안이나 개정 예고는 지침에 반영되었는지 확인한 뒤 적용한다.

### 판정 적용

- 판정 결과가 중소기업자 이하로 제한되면 대형 컨설팅사 유형을 경쟁 구도에서 삭제하고 대형 컨설팅사 기본 후보 규칙도 적용하지 않는다. 대학 산학협력단 유형은 기업 규모 판정과 관계없이 유지한다.
- 자사 유사 기관 경로와 업종 탐색 경로의 검색 질의에 기업 규모 조건과 지역 조건을 포함한다(예: "[지역] 소재 [업종] 소기업", "[과업 유형] 연구용역 중소기업 제한 낙찰").
- 판정 결과와 근거(공고문 문구, 또는 추정가격과 적용 조문)를 경쟁 구도 절 첫 줄에 적는다.
- 사용자가 참가자격 필터링 없이 탐색을 요청하면 참가자격 판정과 판정 적용을 건너뛴다. 제도는 개정 시점과 적용 방식이 자주 바뀌어 판정이 틀릴 수 있으므로 사용자 판단을 따른다. 이때는 대형 컨설팅사 기본 후보 규칙을 공고 금액과 관계없이 적용하고 업종 탐색 경로의 참가자격 제외도 적용하지 않는다. 판정 결과 칸에는 "필터링 해제(사용자 요청)"로 적는다.

## 경쟁 후보 탐색

공공 용역은 수행 사실을 공개하지 않는 기관이 많다. 수행 공개 경로만 쓰면 후보 표가 비어 경쟁 구도를 판단할 수 없다. 그래서 확인 경로 2개와 추정 경로 2개를 함께 쓴다.

| 경로 | 구분 | 찾는 대상 |
|---|---|---|
| 낙찰 기록 | 확인 기관 | 동일 발주처의 과거 동명 사업과 다른 발주처의 동일 유형 사업의 낙찰자, 우선협상대상자 |
| 수행 공개 | 확인 기관 | 수행 기관이 직접 알린 수주와 수행 사실 |
| 자사 유사 기관 | 추정 후보 | 제안사와 사업 분야, 인력 규모, 실적 분야가 비슷한 기관 |
| 업종 탐색 | 추정 후보 | 과업 특성상 이 과업을 수행할 수 있는 업종의 기관 |

### 낙찰 기록

- 조달 시스템의 개찰 결과와 낙찰 결과를 확인한다. 공공데이터포털의 조달청 나라장터 낙찰정보서비스와 계약정보서비스(개방 API), 민간 입찰정보 사이트의 공고 상세 페이지, 발주처 홈페이지의 입찰공고와 우선협상대상자 선정 결과, 계약정보 공개 게시판을 쓴다.
- 검색 엔진은 개찰 결과보다 공고명을 주로 색인한다. 그래서 2단계로 확인한다. 1단계는 과거 사업의 공고 페이지를 공고명으로 찾는다. 2단계는 그 페이지에서 개찰결과, 낙찰자, 우선협상대상자 항목을 확인한다. 항목이 없으면 공고번호로 다시 검색한다.
- 질의 예: "[과거 사업명] 개찰결과", "[과거 사업명] 우선협상대상자", "[공고번호] 낙찰자", "[발주처명] 계약정보 공개 [과업 키워드]"
- 사용자가 제공한 낙찰 결과도 이 경로로 기록한다.

### 수행 공개

- 수행 기관이 보도자료, 홈페이지 실적 목록, 기관 블로그, 기관 SNS로 알린 수주와 수행 사실을 찾는다. 동일 발주처 사업과 다른 발주처의 동일 유형 사업을 모두 찾는다.
- 질의 예: "[발주처명] 연구용역 수주", "[발주처명] 착수보고회 수행기관", "[과업 유형] 수립 연구용역 최종보고회 수행기관"

### 자사 유사 기관

- 제안사 정보의 사업 분야, 인력 규모, 수행실적 분야로 제안사 프로필을 정리한다. 같은 프로필의 기관을 찾는다. 같은 발주처 시장에서 제안사와 자주 경쟁하는 기관을 찾는 경로다.
- 질의 예: "[자사 사업 분야] 전문 컨설팅 기업", "[자사 대표 과업 유형] 연구용역 수행기관"
- 제안사 정보가 없으면 이 경로를 건너뛴다.

### 업종 탐색

- 과업 특성에서 이 과업을 수행할 수 있는 업종을 도출하고 그 업종의 기관을 찾는다. 예를 들어 ISP는 IT 컨설팅사와 시스템 통합 계열사, R&D 성과분석은 과학기술 컨설팅사와 전문 연구기관, 지역 발전계획은 지역 연구원과 도시계획 엔지니어링사다.
- 협회 회원사 목록, 업계 기사의 주요 기업 언급, 과업 분야와 과업 유형과 발주처 유형을 조합한 질의(예: "OO 기본계획 수립 연구용역", "OO 분야 산학협력단 정책연구")를 쓴다.
- RFP 참가자격(업종 등록, 대기업 참여 제한, 지역 제한)으로 입찰할 수 없는 기관은 후보에서 제외하고 제외 기관 메모에 적는다.

### 대형 컨설팅사 기본 후보

- 참가자격 판정에서 중견기업과 대기업이 입찰할 수 있는 공고에만 적용한다. 필터링 해제 요청이 있으면 모든 공고에 적용한다.
- 대형 컨설팅사는 홈페이지에 공공 분야를 내걸지 않아도 공공 용역을 많이 수주한다. 공공 분야 표방 여부로 후보를 거르지 않는다.
- 대형 회계법인 계열 컨설팅사, 대형 경영컨설팅사, 대형 교육협회형 기관을 기본 후보 유형으로 둔다. 대형 교육협회형 기관은 경영교육과 인증 사업을 앞세우는 협회 형태의 기관이다. 컨설팅사로 표방하지 않아도 공공 컨설팅 용역을 수주하므로 따로 검색한다.
- 기관명은 업계 기사와 공공 용역 수행 보도에서 검색으로 확보한다. 과업 분야의 수행 근거를 찾아 선정 근거 열에 적는다. 근거를 찾지 못하면 "공공 용역 다수 수주 기관군"으로 적고 출처는 기관 홈페이지 URL과 확인일로 적는다.

### 탐색 순서

- 낙찰 기록과 수행 공개 경로를 먼저 수행한다. 두 경로의 확인 기관이 추정 후보보다 근거가 강하다.
- 낙찰 기록과 수행 공개 경로는 결과 유무와 관계없이 수행한다.
- 한 경로에서 연속 3회 질의가 기관을 내지 못하면 다음 경로로 넘어간다.
- 자사 유사 기관과 업종 탐색 경로는 경쟁사 유형마다 기관이 1곳 이상 채워질 때까지 수행한다. 남은 검색은 기관이 비어 있는 유형을 채우는 데 쓴다.
- 과업에 해당하지 않는 경쟁사 유형은 행을 지운다. 업종 탐색으로 새 유형을 찾으면 행을 추가한다.
- 웹검색을 허용하지 않았으면 사용자가 제공한 낙찰 결과만 적고 나머지는 [확인]으로 남긴다. 네 경로를 모두 수행해도 기관을 찾지 못한 유형도 [확인]으로 남긴다.

## 기록 규칙

- 확인 경로 열에는 네 경로 이름 중 하나를 적는다.
- 추정 후보를 강점과 약점 서술에서 확인 기관처럼 쓰지 않는다.
- 기관마다 출처 URL을 적는다. 게시일을 확인하면 게시일을, 확인하지 못하면 검색한 날을 "확인일"로 적는다. URL이 없는 기관은 표에 적지 않는다. 사용자 제공 자료의 출처는 "사용자 제공"으로 적는다.
- 참가자격으로 제외한 기관이 전임 수행사이거나 확인 기관이면 경쟁 강도가 달라진다. 이 사실을 유형별 강점과 약점 서술에 반영한다.
- 유형별 예상 강점과 약점은 경쟁 후보 기관 표를 근거로 적는다.
- 경쟁사 유형의 강점마다 그 강점을 상쇄할 제안사 근거를 찾아 02_제안전략서.md 6절의 차별화 포인트로 넘긴다.

## 양식

아래 양식을 그대로 복사해 채운다. 열의 이름, 순서, 개수는 바꾸지 않는다. 셀 안에서 줄을 바꾸지 않고 `|` 문자를 쓰지 않는다. 한 셀에 여러 값을 적을 때는 쉼표로 구분한다.

```markdown
- (참가자격 판정) 입찰 가능 기업 규모와 판정 근거

| 경쟁사 유형 | 예상 강점 | 예상 약점 |
|---|---|---|
| 대학 산학협력단 | | |
| 대형 컨설팅사 | | |
| 전문 연구기관 | | |
| 유사 규모 컨설팅사 | | |

| 기관명 | 경쟁사 유형 | 확인 경로 | 유사 과업 또는 선정 근거 | 확인 출처 |
|---|---|---|---|---|

- (동일 발주처 전임 수행사) 기관명과 확인 경로. 확인하지 못하면 "미확인"
- (제외 기관) 기관명, 제외 사유, 확인 경로. 해당 없으면 "없음"
```
