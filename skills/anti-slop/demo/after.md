# 초거대AI는 사용 기준을 정한 뒤 검토 가능한 문서 업무부터 활용 필요

## 초거대AI는 대규모 문서를 학습하여 질문에 문장으로 답하는 인공지능
- 초거대AI(초거대 인공지능)의 '초거대'는 수천억 개에 이르는 매개변수와 방대한 학습 자료의 규모를 지칭

> (매개변수) 학습 과정에서 값이 조정되어 답변 내용을 결정하는 인공지능 내부의 수치

- 답변은 학습 자료에서 익힌 단어 연결 경향에 따라 다음에 올 단어를 차례로 골라 생성

## 초거대AI가 첫 작업을 맡아 문서 업무 시간 단축 기대
- 담당자 업무는 직접 작성에서 검토와 수정 중심으로 전환
    + (문서 작성) 보고서 초안, 회의록 요약, 외국어 문서 번역에 활용
    + (기획안 구상) 구상 단계에서 방향이 서로 다른 안 여러 건을 짧은 시간에 확보
    + (고객 응대) 문의와 의견을 유형별로 분류하여 자주 나오는 요구 파악

## 활용 위험은 보호 대상 정보의 입력과 검토 없는 결과물 사용에서 발생
- (정보 유출) 외부 초거대AI 서비스에 입력한 사내 자료와 고객 개인정보는 서비스 제공사 서버로 전송
    + 일부 서비스는 약관에 따라 입력 내용을 서비스 개선 학습에 활용
    + 전송된 정보의 보관과 삭제는 회사가 직접 통제하기 어려움
- (사실 오류) 답변이 단어 연결 경향에 따라 생성되어 틀린 정보가 자연스러운 문장에 섞일 가능성 존재
    + 매끄러운 문장 탓에 수치, 날짜, 인명, 출처의 오류 발견 지연
    + 검토 없이 보고서나 고객 답변에 옮긴 오류는 회사 공식 정보의 신뢰 저하 초래
- (저작권과 편향) 외부에 공개한 문서의 저작권 침해와 차별적 표현은 작성 도구와 관계없이 회사가 책임 부담
    + 기존 저작물과 유사한 문장이 생성될 수 있음
    + 학습 자료에 담긴 편향이 답변 표현에 반영될 우려

## 업무 선정부터 확대까지 사용 기준 마련 필요
- (시작 업무) 담당자가 내용을 알고 있어 오류를 바로 고칠 수 있는 초안 작성, 요약, 번역부터 활용
- (입력 정보) 고객 개인정보와 공개 전 사내 자료는 외부 초거대AI 서비스의 입력 대상에서 제외
- (결과물 확인) 생성된 내용은 담당자 검토를 거쳐 업무에 사용
    + 수치, 날짜, 인명, 출처는 원자료와 대조
    + 외부 공개 문서는 기존 저작물과의 유사성과 차별적 표현 여부를 추가 점검
- (단계적 확대) 업무별 시간 단축 정도와 오류 빈도를 살핀 후 활용 업무 추가
    + 유료 서비스 이용료는 사용자 수와 사용량에 비례하여 증가
    + 시간 단축이 확인된 업무에 이용료를 집중하여 지출 낭비 방지
