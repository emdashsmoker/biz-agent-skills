# 초거대AI는 문서 업무부터 담당자 검토를 거쳐 활용하는 방향이 적합

## 초거대AI는 글을 다루는 업무에 활용 가능한 인공지능
- 파라미터가 수천억 개에 이르는 모델이 대량의 글을 학습
- 학습 결과를 바탕으로 사람이 쓴 글과 비슷한 문장 생성
- 주요 활용 업무는 문서 작성, 번역, 프로그램 코드 작성

> (파라미터) 인공지능 모델이 학습 과정에서 데이터에 맞춰 조정하는 내부 수치

## 당사의 적용 대상은 품질 관리, 설계, 고객 응대 분야의 문서 업무
- (품질 관리) 검사 결과와 불량 원인을 정리한 품질 보고서 초안 작성
- (설계) 해외 규격 문서 및 기술 문헌 번역
- (고객 응대) 고객 문의에 대한 답변 초안 작성

## 정확성, 보안, 비용 우려는 사용 기준과 시범 운영으로 관리 가능
- (정확성) 초거대AI가 작성한 초안은 담당자 검토 후 사용
    + 초거대AI는 사실과 다른 내용도 자연스러운 문장으로 생성 가능
    + 사실 확인과 최종 판단은 담당자 책임으로 유지
- (보안) 사내 자료의 입력 기준 마련 필요
    + 외부 초거대AI 서비스에 입력한 내용은 회사 밖 서버로 전송
    + 설계 자료 및 고객 정보처럼 유출 피해가 큰 자료는 입력 대상에서 제외
- (비용) 시범 운영으로 효과와 비용을 확인한 후 대상 부서 확대
    + 시범 부서에서 문서 한 건당 작성 시간 변화 측정
    + 절감 시간과 서비스 이용료를 비교하여 확대 순서 결정
