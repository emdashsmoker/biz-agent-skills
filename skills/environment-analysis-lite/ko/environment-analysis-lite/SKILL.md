# 전략 환경분석

전략이나 사업을 기획하기 전에 대외 환경과 대내 역량을 조사하여 출처가 추적되는 팩트와 시사점으로 정리한다. 결과물은 시사점에서 끝난다. SWOT 요인 분류, 비전, 전략, 과제, 지원 방안은 이 스킬의 범위 밖이며 요청이 함께 오면 환경분석 결과까지 작성하고 나머지는 후속 작업으로 안내한다. 용어는 용어 정의 표의 뜻으로만 쓴다.

## 적용 범위

환경분석은 전체보다 일부만 필요한 경우가 많다. 사용자가 요청한 범위만 수행하고 요청하지 않은 모듈은 만들지 않는다.

| 호출 방식 | 요청 예시 | 수행 범위 |
|---|---|---|
| 전체 분석 | "OO 지역 OO 산업 대내외 환경분석" | 대상 개요, 네 모듈, 시사점 |
| 모듈 분석 | "OO 산업 5-Forces 분석", "우리 기관 내부역량 진단" | 해당 모듈과 해당 모듈의 시사점 |
| 항목 분석 | "최근 5년 해외 OO 정책 동향 표", "해외 사례 3건 벤치마킹" | 해당 항목의 표와 서술, 시사점은 요청 시 작성 |

## 용어 정의

| 용어 | 정의 |
|---|---|
| 분석 주체 | 분석 결과를 활용하는 조직이나 지역. 모듈을 나누는 기준점이며 산업 동향 보고서처럼 주체가 없는 분석도 가능 |
| 분석 대상 | 조사하는 산업, 기술, 시장, 정책 분야 |
| 모듈 | 거시환경, 미시환경, 내부역량, 벤치마킹의 네 가지 분석 단위 |
| 팩트 | 출처로 확인되는 현상, 수치, 사건의 서술. 해석과 처방을 담지 않음 |
| 시사점 | 여러 팩트를 묶어 분석 주체에게 주는 의미를 압축한 서술. 행동 제안을 담지 않음 |
| 전망 | 출처가 제시한 미래 예측. 스킬이 자체 예측을 만들지 않음 |
| 근거 대장 | 사용한 자료의 번호, 확보 경로, 발행 주체, 자료명, 기준일, 위치, 품질 등급을 적은 목록 |
| 확인 수준 | 출처를 확인하는 강도. 1, 2, 3의 세 단계 |
| 산업 가치사슬 | 원료와 부품에서 최종 수요까지 이어지는 산업 단계를 후방에서 전방 순서로 나열한 구조. 미시환경에서 시장 단위를 나눌 때 사용 |
| 조직 가치사슬 | 한 조직 안에서 가치를 만드는 활동을 본원적 활동(입고 물류, 운영, 출하 물류, 마케팅과 판매, 서비스)과 지원 활동(기업 기반 관리, 인적자원 관리, 기술 개발, 조달)으로 나눈 구조(Porter, 1985). 내부역량에서 분석 주체의 활동을 나눌 때만 사용하며 공공기관처럼 활동 구성이 다르면 실제 업무 단위로 바꿔 씀 |

## 모듈 구분 기준

같은 자료라도 분석 주체와의 관계에 따라 들어갈 모듈이 달라진다. 구분 기준은 분석 주체가 해당 요인을 통제하거나 영향을 줄 수 있는 정도 하나로 통일한다. 경계가 모호한 자료는 표 아래 기준으로 배치한다.

| 모듈 | 구분 기준 | 대표 항목 |
|---|---|---|
| 거시환경 | 분석 주체가 영향을 줄 수 없는 외부 요인 | 정책과 제도(규제 포함), 경제, 사회, 기술, 자연환경, 법 |
| 미시환경 | 분석 주체가 거래, 경쟁, 협력으로 상호작용하는 산업과 시장 | 산업 가치사슬, 시장 규모, 경쟁 기업, 고객, 공급자, 투자 흐름 |
| 내부역량 | 분석 주체가 보유하거나 운영하는 자원과 역량 | 인력, 재원, 시설, 수행 사업, 조직 가치사슬 활동, 조직, 문화, 지역 소재 기업과 기관 |
| 벤치마킹 | 비교 기준으로 삼는 다른 주체의 성과와 추진 방식 | 해외 사례, 국내 타 지역 사례, 동종 기관 사례 |

- 지역 소재 기업, 대학, 연구기관, 산업 통계는 분석 주체가 그 지역이면 내부역량, 분석 주체가 기업이면 미시환경
- 정책 문서가 밝힌 방향과 제도는 거시환경, 예산 집행과 투자 유치 같은 자금 흐름은 미시환경의 투자 동향, 분석 주체가 직접 수립한 정책과 수행 중인 사업은 내부역량
- 경쟁 기업의 점유율과 규모는 미시환경, 경쟁 기업의 추진 방식을 배우기 위해 조사한 내용은 벤치마킹
- 분석 주체가 없으면 내부역량 모듈은 수행하지 않고 미시환경은 산업 전체 관점으로 작성

## 작업 절차

다섯 단계로 진행한다. 각 단계는 확인 가능한 결과물을 남기며 통과 조건을 만족해야 다음 단계로 넘어간다. 통과 조건은 표, 번호, 링크처럼 다른 사람이 직접 대조할 수 있는 상태로 정의한다.

| 단계 | 결과물 | 통과 조건 |
|---|---|---|
| 1. 범위 설정 | 범위 정의 | 목적, 주체, 대상, 지리 범위, 조사 기간, 전망 시계, 수행 범위, 확인 수준이 모두 기재됨 |
| 2. 자료 확보 | 근거 대장 | 수행 범위의 조사 항목마다 자료가 연결되거나 미확보 사유가 기재됨 |
| 3. 모듈 분석 | 모듈별 팩트와 표 | 모든 팩트에 팩트 번호와 근거 대장 번호가 붙음 |
| 4. 시사점 도출 | 시사점 목록 | 모든 시사점에 근거 팩트 번호가 붙고 모든 팩트가 1개 이상 시사점에 쓰임(항목 분석에서 시사점을 요청하지 않았으면 생략) |
| 5. 점검과 정리 | 최종 결과물 | 산출 전 점검 항목을 모두 통과 |

- 파일 저장이 가능한 환경이면 단계별 결과물을 파일로 남겨 작업이 끊겨도 이어서 진행
- 뒤 단계에서 앞 단계 결과물을 고치면 앞 단계 통과 조건을 다시 확인
- 경미한 문제(출처 날짜 불명, 출처 간 수치 불일치, 범위 모호 등)가 3건 쌓이면 진행을 멈추고 사용자에게 한 번에 알림
- 문제를 알리기 전에 원문, 수치, 링크로 실제 존재 여부를 먼저 확인하고 확인되지 않은 의심은 알리지 않음
- 통과 조건을 확인할 수단이 없는 단계는 그 사실을 알리고 해당 결과물을 미확인으로 표시

### 1단계 범위 설정

범위 정의는 이후 모든 판단의 기준이다. 한 번 정한 정의, 기준, 범위는 작업 끝까지 유지하고 바꿔야 하면 사용자에게 알린 뒤 영향받는 단계를 다시 수행한다.

| 항목 | 정할 내용 | 기본값 |
|---|---|---|
| 목적 | 결과물의 용도(동향 파악, 현황 진단, 전략 수립 준비 등)와 독자 | 요청문에서 판단, 불명확하면 현황 진단 |
| 분석 주체 | 기업, 공공기관, 지역 중 하나 또는 없음 | 요청문에서 판단, 불명확하면 없음 |
| 분석 대상 | 대상 명칭, 포함 범위, 제외 범위(인접 분야를 포함할지 대체재로 볼지) | 필수 입력 |
| 지리 범위 | 국내 한정, 해외 한정, 국내외 통합, 국내외 분리 | 국내외 통합 |
| 조사 기간 | 동향을 조사할 과거 기간 | 최근 5년 |
| 전망 시계 | 현재(전망 없음), 중기(3년 이내), 중장기(5년 이내), 산업 생애주기(10년 이내), 초장기(30년 이내), 사용자 지정, 제한 없음 | 중장기 |
| 수행 범위 | 전체 분석, 모듈 분석, 항목 분석 | 요청문 기준 |
| 확인 수준 | 1, 2, 3 | 확인 수준 표 기준 |

- 필수 입력이 빠졌으면 빠진 항목을 한 번에 묶어 질의하고 나머지는 기본값을 적용
- 사용자가 응답할 수 없는 상황이면 합리적 기본값으로 진행하고 적용한 범위를 결과물의 대상 개요에 기재
- 부분 분석은 해당 모듈에 필요한 항목만 정함. 예를 들어 정책 동향 표는 대상, 지리 범위, 조사 기간만 있으면 됨
- 전체 분석이면 대상 개요를 작성. 대상 개요는 대상의 중요성(출처로 확인되는 사실), 정의와 범위, 작동 원리나 사업 방식, 산업 가치사슬로 구성
- 정의 문장은 상위 개념, 구성 요소, 목적으로 서술하고 정의 대상 단어를 정의 문장 안에서 다시 쓰지 않음
- 독자가 이미 아는 일반 정의는 쓰지 않고 분석 범위를 가르는 데 필요한 정의만 씀

### 2단계 자료 확보

자료는 아래 순서로 찾는다. 앞 경로에서 조사 기간에 맞는 자료를 확보한 항목은 뒤 경로에서 다시 찾지 않는다.

1. 사용자 제출 자료
2. 연결 도구: 작업 환경에 연결된 MCP 서버, API, 데이터베이스 조회 도구, 문서 저장소, 협업 도구
3. 웹 검색과 페이지 열람: 한국어와 영어 자료를 모두 검색
4. 사용자 요청: 위 경로로 확보하지 못한 항목의 자료명과 보유처 후보를 목록으로 제시하고 제출이나 도구 연결을 요청

일반 웹 검색으로 찾기 어려운 자료는 처음부터 연결 도구와 사용자 요청 경로를 함께 준비한다.

| 자료 유형 | 예시 | 보유처 유형 |
|---|---|---|
| 투자 동향 | 벤처투자 건수와 금액, 인수합병, 정부 연구개발 예산과 과제 | 벤처투자 데이터베이스, 국가 연구개발 정보 서비스(한국의 NTIS 등), 예산 공개 시스템 |
| 내부역량 | 인력, 예산, 사업 실적, 업무 절차, 조직 문화 | 인사, 재무, 사업관리 시스템, 협업 문서 도구, 스프레드시트, 메일, 메신저, 사내 데이터베이스, 온톨로지 |
| 상세 통계 | 지역별 업종별 사업체 수, 종사자 수, 생산액 | 국가 통계 포털, 통계 공개 API |
| 시설과 장비 | 연구 장비 규격, 개방 여부 | 국가 연구장비 정보 서비스, 기관 공개 자료 |

- 확보하지 못한 항목은 "미확보"로 표기하고 추정값으로 채우지 않음. 미확보는 존재하지 않는다는 뜻으로 쓰지 않음
- 근거 대장에는 번호(S-01 형식), 확보 경로, 발행 주체, 자료명, 발행일이나 기준일, 위치(전체 URL이나 시스템 경로), 품질 등급을 기록
- 검색어는 핵심 단어 1-2개로 짧게 시작하고 결과를 보며 좁힘

구조가 복잡한 데이터베이스(국가 연구개발 정보 서비스, 벤처투자 데이터베이스, 통계 데이터베이스, 사내 데이터베이스 등)는 필드 의미, 코드 체계, 집계 기준이 데이터베이스마다 달라서 이 스킬의 규칙만으로 조회 방법을 정할 수 없다. 이런 자료는 아래 순서로 단계마다 사용자와 확인하며 탐색한다.

- (탐색 계획) 필요한 항목, 후보 데이터베이스, 접근 방식(연결 도구, API, 사용자 직접 조회 후 내보내기)을 제시하고 확인받음
- (구조 확인) 필드 정의, 분류 코드표, 조회 조건, 갱신 주기를 공식 설명 자료나 사용자 설명으로 확인. 의미를 모르는 필드는 추측하지 않고 질의
- (조건 합의) 검색어, 분류 코드, 기간, 금액 단위, 중복 집계 기준(다년도 과제의 연도별 중복, 상위 과제와 세부 과제의 중복 등)을 추출 전에 사용자와 합의
- (시범 추출) 소량을 먼저 추출하여 누락과 오분류를 사용자와 함께 확인하고 조건을 고친 뒤 전체를 추출
- (기록) 최종 조건, 추출일, 건수를 근거 대장에 적어 같은 조건으로 다시 추출할 수 있게 함
- (접근 불가) 도구로 접근할 수 없으면 합의한 조건으로 사용자에게 조회와 내보내기를 요청. 사용자 확인 없이 조건을 바꾸거나 전체 추출을 진행하지 않음

### 3단계 모듈 분석

수행 범위에 해당하는 모듈 섹션의 규칙을 따른다. 모든 모듈에 아래 공통 규칙을 적용한다.

- 팩트에는 모듈 약호와 순번으로 팩트 번호를 붙임. 거시환경 MA, 미시환경 MI, 내부역량 IN, 벤치마킹 BM (예: MA-03)
- 팩트 서술에 해석, 처방, 목표 상태를 섞지 않음. 전망은 출처가 제시한 경우에만 출처와 함께 기재
- 분석 틀의 항목 중 대상과 관련 없는 항목은 형식적으로 채우지 않음
- 모든 수치 계산(증감률, 연평균 성장률, 비중, 입지계수, 격차)은 코드로 수행하고 출처에 있는 수치도 코드로 다시 계산하여 대조
- 시간 선후나 동시 발생만으로 인과를 단정하지 않고 소수 사례나 일부 세그먼트를 전체로 일반화하지 않음

## 출처 규칙

### 공통 원칙

- 지식의 출처는 사용자 제출 자료, 연결 도구 조회 결과, 웹 검색 결과로 한정. 모델이 기억하는 사실은 출처로 쓰지 않음
- 출처로 확인되지 않는 정보는 쓰지 않고 "미확인"으로 표기
- 정보가 없다는 사실을 부정의 근거로 쓰지 않음. 전수 조사를 마친 범위에서만 "없음"으로 적고 조사 범위를 함께 적음
- 기관의 명성만으로 주장을 정당화하지 않고 자료의 내용과 산출 방법을 근거로 서술
- 정량 데이터는 조사 주체, 조사 시점, 산출 방법을 함께 적어 제3자가 근거를 물을 때 답할 수 있게 함. 예: "OO연구원의 2024년 조사에 따르면 국내 OO 시장은 2023년 A원에서 2028년 B원으로 연평균 N% 성장 전망(업계 매출 합산 방식)"
- 공개 자료 출처 형식: 기관명이나 저자명(연도), 자료명(URL). URL은 도메인만 적지 않고 해당 정보가 있는 페이지의 전체 경로로 기재
- 내부 자료 출처 형식: 시스템이나 도구명(기준일), 문서명이나 테이블명(도구 내 위치)
- 제출 자료 출처 형식: 제출 자료명(작성 기관, 기준일), 쪽이나 시트 위치

### 공개 자료 품질

공개 자료는 아래 여섯 기준으로 품질을 판단한다.

| 기준 | 높은 품질 신호 | 낮은 품질 신호 |
|---|---|---|
| 편집과 사실 확인 | 편집 책임과 검수 절차가 드러남 | 편집 책임자 없이 자가 발행 |
| 발행 주체 독립성 | 분석 대상과 이해관계가 없는 제3자 | 홍보나 광고 목적의 당사자 |
| 자료 유형 | 원자료를 직접 생산한 1차 자료 | 원출처를 밝히지 않은 재가공 |
| 추적 가능성 | 원문, 방법론, 표본, 산출 근거 확인 가능 | 근거 없이 단정 |
| 전문성 | 동료평가나 전문기관 공식 발간 | 익명이거나 전문성 확인 불가 |
| 작성 주체 | 사람 저자와 편집 책임 확인 | 자동 생성으로 보이는 검증 불가 콘텐츠 |

추적 가능성이 없거나 자동 생성으로 판단되는 자료는 다른 기준을 충족해도 제외 등급으로 분류한다.

| 등급 | 처리 | 해당 유형 예시 |
|---|---|---|
| 우선 인용 | 바로 인용 | 중앙정부와 지방정부의 공식 발간물과 보도자료, 공식 통계, 법령, 의회와 감사기관 보고서, 국책연구기관 보고서, 국제기구 보고서와 통계, 동료평가 논문, 특허 공보, 표준 문서, 중앙은행과 거래소 공식 자료, 방법론을 공개한 전문 조사기관과 컨설팅사 보고서, 대형 오픈소스 프로젝트 공식 문서(기술 주제) |
| 조건부 인용 | 원출처 추적이나 독립 출처 교차 확인 후 인용 | 일반 언론 보도(보도가 인용한 원출처를 우선 인용), 기업 자체 발표(해당 기업의 주장 범위로 한정), 사전 공개 논문(미검증 자료로 표시), 단일 출처 주장, 사설과 칼럼(필자 견해로 한정), 협회와 이익단체 발간물(이해관계 표시), 통계 집계 사이트와 시장 보고서 요약(원출처 확인) |
| 제외 | 인용하지 않고 없는 자료로 취급 | 자동 생성 리포트와 콘텐츠 팜, 누구나 편집하는 위키 본문(표기된 원출처는 추적하여 사용 가능), 질의응답 사이트, 개인 블로그와 개인 SNS, 익명 커뮤니티, 선정성 위주로 사실 확인이 없는 매체, 출처 없는 뉴스 모음과 카드뉴스, 기업 보도자료를 그대로 옮긴 광고성 기사, 편집 독립성이 없는 국가 선전 매체, 발행 주체를 알 수 없는 사이트 |

- 예시 목록에 없는 출처는 여섯 기준으로 개별 판단
- 매체의 인지도와 정치 성향은 판단 기준에 포함하지 않음. 진영이 다른 두 매체도 같은 기준으로 평가
- 수집한 출처가 모두 제외 등급이면 해당 주장은 쓰지 않고 정보 부재로 남긴 뒤 우선 인용 유형으로 검색 범위를 바꿔 다시 찾음
- 사용자가 특정 출처 사용을 지시한 경우와 분석 대상 자체가 해당 출처인 경우(예: 허위정보 확산 사례 분석)는 예외
- 품질 등급과 제외 사실은 사용자가 요청할 때만 결과물에 씀

### 내부 자료 품질

사내 시스템, 협업 문서 도구, 스프레드시트, 메일, 메신저, 데이터베이스, 온톨로지에서 가져온 자료는 발행 매체가 없어서 공개 자료 기준을 그대로 적용할 수 없다. 내부 자료의 등급은 그 기록이 조직 안에서 맡는 역할로 정하고 도구 종류(전사 업무 시스템, 협업 문서 도구, 스프레드시트 등)는 등급 판단에 쓰지 않는다. 같은 도구의 문서라도 조직 전체가 기준으로 쓰는 프로젝트 데이터베이스이면 기준 기록이고 개인 메모이면 비공식 기록이다.

| 기준 | 확인할 내용 |
|---|---|
| 기준 기록 여부 | 조직이 해당 항목을 확인하고 갱신할 때 기준으로 쓰는 기록인지(예: 매출은 회계 프로그램, 과제 현황은 협업 문서 도구의 프로젝트 데이터베이스) |
| 기준 시점 | 데이터 기준일과 최종 수정일. 조사 기간 밖의 자료는 기준일을 명시 |
| 작성과 확정 주체 | 작성자나 담당 부서, 확정 여부(결재, 상태 값, 확정 표시), 초안과 확정본의 구분 |
| 기록 간 일치 | 같은 항목이 여러 기록에 있을 때 값의 일치 여부 |
| 누락 여부 | 조회 조건이나 권한 때문에 일부 기간, 부서, 페이지가 빠졌는지 여부 |

| 등급 | 처리 | 해당 유형 예시 |
|---|---|---|
| 기준 기록 | 기준일을 적고 바로 인용 | 회계와 인사 프로그램 데이터, 결재나 상태 값으로 확정된 문서, 조직 전체가 기준으로 쓰는 협업 문서 도구나 스프레드시트의 데이터베이스, 공시 자료 |
| 업무 문서 | 작성 주체와 기준일을 적고 인용. 같은 항목의 기준 기록이 있으면 수치를 대조 | 회의록, 보고서 초안, 사내 위키와 협업 문서 도구의 문서 페이지, 공유 스프레드시트 |
| 비공식 기록 | 수치의 단독 근거로 쓰지 않음. 업무 방식과 문화 같은 정성 진단에는 여러 기록에서 반복 확인된 양상만 집계하여 사용 | 메신저 대화, 개인 메모, 메일 본문의 의견 |

- 항목별 기준 기록이 불분명하면 사용자에게 한 번에 묶어 질의(예: 매출 기준 기록이 회계 프로그램인지 협업 문서 도구의 매출 표인지). 응답을 받을 수 없으면 작성자와 수정일이 가장 분명한 최신 기록을 쓰고 그 선택을 결과물에 주석으로 기재
- 기록 간 값이 다르면 기준 기록의 값을 쓰고 차이를 주석으로 기재. 기준 기록이 없으면 두 값과 각 기준일을 함께 기재
- 사용자의 접근 권한 안에서만 조회하고 권한 밖의 자료를 우회하여 조회하지 않음
- 개인을 식별할 수 있는 정보는 집계 단위로만 쓰고 개인의 대화나 메일 문장을 결과물에 옮기지 않음
- 기밀 표시 자료를 외부 공유용 결과물에 포함할 때는 사용자 확인을 먼저 받음

### 사용자 제출 자료

- 제출 자료를 1차 근거로 쓰고 작성 기관과 기준일을 근거 대장에 기록
- 제출 자료가 언론 보도나 재가공 자료이면 해당 유형의 공개 자료 기준을 적용
- 사용자가 대화 중 직접 제시한 수치는 확인 절차 없이 쓰고 출처를 "사용자 제시"로 표기

### 확인 수준

결과물이 잘못되었을 때 고칠 기회가 있는지와 정량 데이터가 있는지에 따라 확인 강도를 정한다.

| 수정 가능성 | 정량 데이터 없음 | 정량 데이터 있음 |
|---|---|---|
| 수정 가능(본인이나 내부 팀만 보는 메모, 초안, 정기 브리핑) | 1 | 2 |
| 수정 제한(외부 발송 보고서, 제안서, 감사 증빙, 게재 논문, 최종 보고서) | 3 | 3 |

외부로 나간 결과물은 수치 오류, 사실 서술 오류, 존재하지 않는 출처 인용을 모두 바로잡기 어렵다. 그래서 수정 제한 행은 정량 데이터 유무와 관계없이 수준 3을 적용한다.

- 적용 수준을 작업 시작 시 한 줄로 알림. 예: "확인 수준 2: 내부 검토용 초안에 시장 규모 수치가 들어가므로 정량 데이터 확인 적용"
- 사용자가 올리거나 내리라고 하면 한 단계씩 조정하고 특정 수준을 지정하면 그대로 적용. 이 표에 없는 보정 규칙은 만들지 않음. 사용자가 "확인 생략"을 지시하면 해당 턴에만 확인 절차를 생략하고 다음 턴부터 원래 수준으로 돌아감
- (수준 1) 출처 규칙만 적용
- (수준 2) 본문에 정량 데이터를 쓰기 전에 정량 데이터 확인 요청을 보내고 승인된 수치만 사용. 수정 요청은 사용자가 제시한 수치로 바꾸고 거부된 수치는 제외하고 작성
- (수준 3) 정성 인용과 정량 데이터를 모두 포함한 전체 인용 항목의 증거를 모아 인용 항목 확인 요청을 보내고 승인된 항목만 사용. 교체 요청을 받으면 대체 출처를 같은 절차로 다시 확인
- 수준 3의 웹 출처 증거는 실재(기관명과 자료명 검색 결과 원문), 날짜(확인된 발행일 원문), 접근(URL 열람 성공 여부와 페이지 제목), 내용(인용할 내용이 있는 문단 원문)
- 수준 3의 제출 자료 증거는 날짜(문서에 표기된 기준일 원문), 내용(해당 문단 원문), 일치(문서 제목, 작성 기관, 기준 연도가 인용 목적과 맞는지)
- 수준 3의 내부 자료 증거는 시스템명과 위치, 기준일, 조회 조건, 해당 레코드나 문단 원문
- 확인 요청에는 인용 예정 항목을 중요도와 관계없이 빠짐없이 기재
- 증거는 요약하거나 가공하지 않고 원문 그대로 제시하며 검색 결과가 없거나 접근에 실패하면 그 사실을 그대로 적음. URL과 발행 연도를 추정하여 쓰지 않음
- 확인을 기다리는 동안 해당 내용을 사실로 쓰지 않고 "약", "추정" 같은 표현으로 미승인 수치를 우회하여 쓰지 않음

```
정량 데이터 확인 요청
| 번호 | 항목 | 수치 | 출처 |
|---|---|---|---|
| 1 | 국내 OO 시장 규모(2024년) | 0,000억원 | OO연구원(2025), OO 시장 보고서 |
응답 방법: 승인(전체 또는 번호 지정), 수정(번호와 올바른 수치), 거부(번호)
```

### 적법한 자료 수집

- 사이트 이용약관, 로그인이나 유료 구독 같은 접근 제한, 수집 금지 표시를 우회하지 않음
- 데이터베이스나 목록의 상당 부분을 반복하여 복제하지 않고 공식 API, 내려받기 기능, 연결 도구, 사용자 제출 경로를 이용
- 보고서와 기사는 요약하여 서술하고 원문 인용은 필요한 짧은 구절로 제한한 뒤 출처를 밝힘
- 연구자와 담당자의 정보는 본인이 직무상 공개한 정보(소속, 직위, 연구 분야, 공개 논문과 과제)로 한정하고 공개 목적과 관련된 범위에서만 사용. 개인 연락처와 사생활 정보는 수집하지 않음

## 거시환경 모듈

분석 주체가 바꿀 수 없는 외부 변화를 사실 위주로 정리한다.

- (항목 선택) 사용자가 틀을 지정하면 그 틀을 쓰고 지정이 없으면 대상에 실제로 영향을 주는 항목만 고름
- (틀의 구성) PEST는 정치, 경제, 사회, 기술을 다룸. PESTEL은 PEST에 자연환경과 법을 더함. STEEP은 사회, 기술, 경제, 자연환경, 정치 순서로 다룸
- (항목 순서) 목적과 강조점에 따라 정함. 연구개발과 산업 분야 분석은 정책과 제도, 기술 항목이 중심이 되는 경우가 많으므로 두 항목을 먼저 검토
- (해외와 국내) 한 항목 안에서 해외 동향을 먼저 쓰고 국내 동향으로 넘어가며 둘 사이의 영향, 대응, 격차가 드러나게 씀. 지역이 분석 주체가 아니어도 지역 정책이 대상에 영향을 주면 국가 다음에 지역 순서로 씀
- (조사 기간) 1단계에서 정한 조사 기간의 자료를 우선 사용
- (정책과 제도) 규제 변화를 포함하여 아래 표로 정리. 산업 정책과 과학기술 정책이 모두 해당하면 분야 열로 구분. 기대 효과는 정책 문서가 밝힌 내용만 기재

| 연도 | 국가 | 기관 | 분야 | 정책이나 제도명 | 추진 배경 | 주요 내용 | 추진 수단 | 기대 효과 |
|---|---|---|---|---|---|---|---|---|

- (기술) 연구개발 동향은 아래 표로 정리. TRL(기술 성숙도 9단계 척도)은 출처가 밝힌 값만 쓰고 출처에 없으면 판단 근거와 적용 기준(사용한 TRL 정의표)을 적은 추정값으로 표시하며 근거가 부족하면 "미상"으로 적음. TRL은 분야와 기관마다 정의표가 달라서 기준 없이 비교하면 오해가 생김
- (논문과 특허) 자료를 확보할 수 있으면 논문 발표와 특허 출원의 연도별 추이, 주요 출원인을 시계열 표로 추가

| 연도 | 국가 | 수행 기관 | 연구개발 내용 | TRL | TRL 근거와 적용 기준 |
|---|---|---|---|---|---|

- (경제, 사회, 자연환경, 법) 대상과 직접 관련된 지표와 사건만 쓰고 지표는 3-5년 이상 시계열과 연평균 성장률을 함께 제시

## 미시환경 모듈

분석 주체가 참여하거나 경쟁하는 산업과 시장을 정리한다. 거시환경에서 정리한 변화가 이 시장의 어느 부분에 반영되는지 연결하여 쓴다.

### 산업 가치사슬

- 산업 가치사슬은 용어 정의를 따름. 조직 가치사슬의 활동 구분(입고 물류, 운영, 마케팅과 판매 등)을 산업 단계 이름으로 쓰지 않음
- 단계 명칭은 해당 산업에서 실제로 쓰는 이름을 쓰고 "소재", "부품", "장비" 같은 범용 명칭은 그 산업에서 널리 쓰일 때만 사용
- 단계끼리 겹치지 않고 모든 단계를 합하면 대상 산업 전체가 되도록 나눔

### 시장과 기업

- 시장 규모(금액 기준), 성장 전망(전망 기간과 출처 필수), 주요 지표(매출액, 종사자 수, 기업체 수 등)를 정리. 지리 범위가 국내외 분리이면 국내와 글로벌을 각각 조사
- 주요 기업은 아래 표로 정리. 기업명, 국가나 소재지, 규모는 필수이며 나머지 열은 확보된 자료에 맞춰 가감. 표와 함께 기업 간 경쟁 구도를 서술

| 기업명 | 국가나 소재지 | 규모(매출이나 인원, 기준연도) | 점유율 | 사업 영역과 주력 제품 | 주요 고객 | 경쟁 분야 | 최신 동향 |
|---|---|---|---|---|---|---|---|

### 산업 통계

- 사업체 수, 종사자 수, 생산액이나 매출액, 부가가치액을 최근 3년 이상 시계열 표로 정리하고 연평균 성장률과 전체 대비 비중을 코드로 계산
- 지역의 산업 집중도는 입지계수로 나타냄. 입지계수는 지역 전체 종사자 중 해당 산업 종사자 비중을 전국 전체 종사자 중 해당 산업 종사자 비중으로 나눈 값이며 1보다 크면 전국 평균보다 집중
- 통계의 산업분류 기준과 개정 차수를 출처와 함께 적음. 분류 기준이 다른 연도를 한 시계열로 잇지 않음

### 투자 동향

- 공공 연구개발 예산 집행, 벤처투자(투자 단계별 건수와 금액), 인수합병을 조사
- 정책 문서가 밝힌 투자 계획은 거시환경, 실제 집행과 투자 실적은 이 항목에 씀
- 확보 경로는 2단계 표를 따르고 확보하지 못한 항목은 미확보로 표시

### 5-Forces 경쟁구조

포터의 다섯 경쟁요인인 신규진입자 위협, 공급자 교섭력, 구매자 교섭력, 대체재 위협, 산업 내 경쟁강도로 시장의 경쟁 구조를 판정한다.

- (분석 단위) 산업 가치사슬 단계별 시장, 산업 전체, 둘의 혼합 중에서 정함. 경쟁 조건이 다른 제품군이나 지역은 별도 단위로 나눔
- (범위 확인과 사용자 지정) 사용자가 단위를 정하지 않으면 제출 자료나 웹 검색으로 산업 정의와 산업 가치사슬을 파악하여 단위 초안을 만들고 지리 범위와 함께 확인받음. 모델 지식만으로 산업 가치사슬을 구성하지 않음. 사용자가 단위나 판정 기준을 지정하면 그대로 따르되 단위 간 중복이나 누락이 보이면 알림
- (국내외 분리) 단위마다 글로벌 분석을 먼저 하고 국내 분석을 따로 하며 각각 독립된 강도를 판정. 표기는 해외 대신 글로벌

| 요인 | 수집 항목 |
|---|---|
| 신규진입자 위협 | 진입 장벽(자본 규모, 기술 난도, 규제와 인허가), 규모의 경제, 기존 기업의 보복 가능성, 최근 진입 사례, 정부의 진입 지원이나 규제 |
| 공급자 교섭력 | 공급자 수, 원자재 대체 가능성, 공급자 전환 비용, 공급자의 전방통합 가능성과 진행 여부 |
| 구매자 교섭력 | 구매자 수와 구매 집중도, 제품 차별화 정도, 구매자 전환 비용, 구매자의 후방통합 가능성과 진행 여부 |
| 대체재 위협 | 대체재 유무, 가격 대비 성능, 전환 비용, 대체재 시장의 성장 추세, 수평적 대체 관계의 범위 |
| 산업 내 경쟁강도 | 경쟁자 수, 시장 성장률, 고정비 구조, 제품 차별화, 퇴출 장벽, 정부 지원이나 규제, 수평통합 진행 여부 |

| 요인 | 상 | 중 | 하 |
|---|---|---|---|
| 신규진입자 위협 | 진입 장벽이 낮고 신규 진입이 활발 | 진입 장벽이 있으나 실제 진입 사례가 확인됨 | 규모의 경제, 자본 집약도, 기술 축적, 규제 등 구조적 장벽이 높음 |
| 공급자 교섭력 | 공급자가 소수이고 대체 원자재가 없으며 전방통합이 실제로 진행 중 | 공급자는 다수이나 일부 핵심 소재는 소수 공급자에 의존 | 공급자가 다수이고 원자재 대체가 실제로 일어나며 전방통합 동인이 없음 |
| 구매자 교섭력 | 구매 집중도가 높고 전환 비용이 낮으며 후방통합이 실제로 진행 중 | 실제 거래 조건에서 교섭력 균형이 확인됨 | 구매자가 분산되어 있고 전환 비용이 높으며 대안 공급원이 없음 |
| 대체재 위협 | 가격 대비 성능이 앞선 대체재가 상용화되어 시장에 침투 중 | 대체재가 상용화되었으나 전환 비용이나 성능 한계로 침투가 제한적 | 상용화된 대체재가 없거나 전환 비용이 과다 |
| 산업 내 경쟁강도 | 경쟁자가 많고 성장률이 낮으며 차별화가 부족하고 퇴출 장벽이 높음 | 경쟁자가 있으나 시장 성장으로 공존이 가능하고 가격 경쟁이 제한적 | 소수 기업 과점이 확인되고 성장률이 높으며 수평통합이 진행 중 |

위 판정표는 참고 기준이며 실제 판정은 단위별로 수집한 근거에 따라 아래 규칙으로 수행한다.

- 현재 강도는 산업 구조의 사실(규모의 경제, 자본 집약도, 학습곡선, 특허 장벽, 네트워크 효과, 인허가, 기존 기업의 누적 투자, 공급 집중도, 전환 비용)로 판정
- 정부 지원, 스타트업의 진입 시도, 국산화 추진, 대체 기술 연구, 구매자의 자체 생산 검토 같은 잠재 변화만으로 구조가 견고한 산업의 현재 강도를 바꾸지 않음. 잠재 변화는 전망 강도에만 보수적으로 반영
- 정부 정책, 산업 성장률, 기술 변화, 보완재는 별도 요인으로 세우지 않고 다섯 요인에 미치는 영향으로 반영
- 경기 순환 같은 일시적 변화를 구조 변화로 판정하지 않음
- 수직통합(공급자의 전방통합, 구매자의 후방통합)은 계획, 추진, 완료 단계에 따라 교섭력 판정에 반영하고 수평통합(같은 단계 안의 인수합병과 제휴)은 경쟁자 수와 집중도 변화로 경쟁강도 판정에 반영
- 개별 기업 사례나 일부 세그먼트의 특성을 단위 전체의 특성으로 넓히지 않음
- 근거에서 판정으로 이어지는 연결을 제3자가 확인할 수 있게 쓰고 시사점 서술과 근거 서술을 섞지 않음
- 같은 단위 안의 다섯 판정이 서로 모순되지 않는지 확인. 예를 들어 신규진입자 위협이 높은데 경쟁강도가 낮다면 둘이 양립하는 근거를 확인
- 산업 가치사슬 단계로 단위를 나눈 경우 앞 단위의 구매자 교섭력과 뒤 단위의 공급자 교섭력은 같은 거래를 반대편에서 본 판정. 앞 단위의 구매자 교섭력이 "하"인데 뒤 단위에서 앞 단위 공급자의 교섭력도 "하"로 나오면 모순이므로 모든 인접 단위를 역방향으로 대조
- 다섯 요인을 같은 비중으로 다루지 않고 수익성에 가장 영향이 큰 요인을 종합 행에서 밝힘

- (작성 형식) 요인 소제목은 `(요인명 : 현재→전망) 현재 상태를 짚고 변화 방향을 붙인 문장` 형식. 전망 시계가 현재이면 `(요인명 : 상, 중, 하 중 하나) 문장` 형식
- 소제목 아래에 (현황)과 (전망)을 나눠 시사점을 먼저 쓰고 근거를 이어 씀. 전망 시계가 현재이면 접두어 없이 씀
- 단위마다 다섯 요인 다음에 시장 현황과 주요 기업을 둠. 판정이 결론이고 시장 자료가 근거이기 때문
- 단위마다 경쟁환경 종합 서술과 경쟁환경 표를 각각 둠. 산업 가치사슬 단계로 단위를 나눈 경우 단위별 표를 생략하고 종합 표만 두지 않으며 단위별 표 다음에 산업 전체 종합 서술과 종합 표를 둠
- 국내외 분리이면 글로벌 단위별, 글로벌 종합, 국내 단위별, 국내 종합, 전체 종합 순서
- 모든 경쟁환경 표는 아래 양식 하나만 쓰고 임의의 비교표를 만들지 않음

| 구분 | 경쟁강도(현재) | 경쟁강도(전망) | 내용 | 근거 | 데이터 |
|---|---|---|---|---|---|
| 신규진입자 위협 | 상, 중, 하 중 하나 | 상, 중, 하 중 하나 | (현황) 시사점, (전망) 시사점 | (현황) 구조적 근거, (전망) 변화 근거 | (현황) 정량 데이터, (전망) 정량 데이터 |
| 공급자 교섭력, 구매자 교섭력, 대체재 위협, 산업 내 경쟁강도 | 같은 방식 | 같은 방식 | 같은 방식 | 같은 방식 | 같은 방식 |
| 종합 | - | - | 다섯 판정을 종합한 경쟁 구조의 특성과 영향이 가장 큰 요인 | 요인 간 상호작용의 구조적 근거 | - |

- 셀은 1-2문장으로 압축하고 상세 분석은 본문에 둠. 셀 안의 (현황)과 (전망)은 `<br>` 태그로 줄을 나눔
- 전망 시계가 현재이면 전망 열 전체를 "-"로 두고 셀 안의 (현황), (전망) 접두어와 줄바꿈 없이 씀
- 전망 강도는 변화 근거가 있을 때만 현재와 다르게 판정
- 데이터 열에는 출처 없는 수치를 쓰지 않고 자료가 없으면 확보 가능한 최선의 정보와 미확보 표시를 적음
- 산업 전체 종합 판정은 산업 구조 전체를 기준으로 수행하고 판정 근거를 따로 적음. 단위별 판정의 단순 평균은 쓰지 않음
- 사용자가 특정 요인만 요청하면 해당 요인만 분석하고 표 없이 본문만 요청하면 표를 생략

## 내부역량 모듈

분석 주체가 가진 자원과 역량을 사실 위주로 정리한다. 강점과 약점을 함께 다루고 개선 방향이나 필요 사항은 쓰지 않는다. 미시환경에서 확인한 산업 요건과 비교되는 항목이 드러나게 쓴다.

### 자산 현황

분석 주체 유형에 따라 아래 항목을 기본 조사 대상으로 삼는다. 자료가 없는 항목은 미확보로 표시한다.

| 주체 유형 | 조사 항목 |
|---|---|
| 지역 | 소재 대기업과 중소기업(주요 기업 표 형식으로 구분 작성), 혁신 주체 간 연계 구조, 앵커 혁신기관, 산업 집적지와 클러스터, 산업 통계, 대학과 관련 학과, 연구기관, 기업지원기관, 공공연구기관 분원, 연구 실증 시설과 장비, 데이터 처리 시설, 지역이 직접 수립한 정책, 수행 중인 사업, 연구책임자급 연구진 |
| 기업과 공공기관 | 연혁과 조직, 인력, 예산과 재무, 사업과 제품, 시설과 장비, 데이터와 지식재산, 수행 중인 사업 |

목록형 자산은 아래 열 구성으로 정리한다.

| 표 | 열 구성 | 작성 기준 |
|---|---|---|
| 시설과 장비 | 보유 기관, 명칭, 종류(실증 시설, 연구 장비, 데이터 처리 시설), 규격, 수량, 용도, 개방 여부와 이용 조건 | 규격과 수량은 보유 기관 공개 자료 기준 |
| 수행 중인 사업 | 구분(외부 재원 연구개발, 자체 재원 연구개발, 비연구개발 지원사업. 외부 재원은 지역이 주체일 때 중앙정부 재원을 받아 지역 기관이 수행하는 사업), 소관 부처나 주관 기관, 수행 기관, 사업명, 사업 기간, 사업 내용, 연도별 예산 | 현재 진행 중인 사업만 기재하고 신청 예정이나 미선정 사업은 제외. 연구개발 사업과 비연구개발 사업을 섞지 않음 |
| 연구진 | 소속 유형(기업, 대학, 연구기관), 성명, 소속, 연구 분야, 대표 공개 논문이나 과제 | 적법한 자료 수집 규칙의 공개 정보 범위로 한정 |

### 역량 진단

내부 진단은 Arthur D. Little이 제시한 SPRO의 네 영역(전략, 프로세스, 자원, 조직)에 문화를 더한 다섯 영역으로 분석 주체의 현재 상태를 점검한다. 문화는 SPRO에 없는 영역이며 공유 가치와 행동 규범을 따로 점검하기 위해 추가한다.

| 영역 | 점검 내용 |
|---|---|
| 전략 | 비전, 목표, 중점 사업, 자원 배분 방향 |
| 프로세스 | 주요 업무 절차(조직 가치사슬의 활동 단위로 나눠 점검 가능), 의사결정 절차, 정보시스템, 성과 관리 방식 |
| 자원 | 인력 규모와 전문성, 재원, 시설과 장비, 데이터, 지식재산, 대외 협력망 |
| 조직 | 조직 구조, 권한과 책임, 부서 간 협업 방식, 거버넌스 |
| 문화 | 공유 가치, 리더십 방식, 구성원 행동 규범 |

VRIO 판정은 주요 자원과 역량별로 네 질문에 예나 아니오로 답하고 아래 표로 결과를 분류한다(Barney, 1995).

- (가치) 기회를 활용하거나 위협을 줄이는 데 기여하는가
- (희소성) 같은 자원을 가진 경쟁 주체가 적은가
- (모방 난도) 이 자원이 없는 주체가 확보하려면 비용상 불리한가
- (조직) 이 자원을 활용할 조직, 절차, 제도가 갖춰져 있는가

| 가치 | 희소성 | 모방 난도 | 조직 | 판정 |
|---|---|---|---|---|
| 아니오 | - | - | - | 경쟁 열위 |
| 예 | 아니오 | - | - | 경쟁 동등 |
| 예 | 예 | 아니오 | - | 일시적 우위 |
| 예 | 예 | 예 | 아니오 | 활용되지 않은 우위 |
| 예 | 예 | 예 | 예 | 지속적 우위 |

- 판정마다 근거 팩트 번호를 적음
- 희소성과 모방 난도는 미시환경이나 벤치마킹의 비교 자료가 있을 때만 판정하고 비교 자료가 없으면 "판단 보류"로 적음
- 한쪽 방향의 사실만 모으지 않고 강점과 약점을 함께 조사

## 벤치마킹 모듈

비교 기준이 되는 다른 주체의 성과와 추진 방식을 조사한다. 성과 비교는 같은 지표로 수준 차이를 재고 추진 방식 비교는 그 성과를 만든 방법과 조건을 조사한다.

- (대상 선정) 분석 주체와 조건(규모, 산업, 발전 단계, 제도 환경)이 비교 가능하고 성과 자료가 공개된 대상을 고르며 선정 사유와 분석 주체와의 차이를 적음
- (대상 범위) 지리 범위에 맞춰 해외 사례, 국내 타 지역 사례, 동종 기관 사례를 고름. 지역이 분석 주체이면 해외 사례와 타 지역 사례를 모두 검토
- (추진 방식 비교) 아래 표로 정리

| 대상 | 국가나 지역 | 추진 주체 | 기간 | 추진 내용 | 성과(정량 근거) | 성공 요인 | 제약과 실패 요인 | 분석 주체와의 차이 |
|---|---|---|---|---|---|---|---|---|

- (성과 비교) 분석 주체와 대상의 수치를 같은 지표, 같은 기준 연도, 같은 단위로 맞춘 뒤 격차를 코드로 계산. 기준을 맞출 수 없으면 비교 수치를 쓰지 않고 기준 차이를 적음
- (격차 정리) 국내와 해외, 분석 주체와 타 지역 사이의 격차를 성과 비교 방식으로 정리
- (균형) 성공 요인과 함께 실패 요인과 제약 조건을 조사
- (연결) 사례의 사실이 내부역량이나 미시환경의 어느 팩트와 비교되는지 팩트 번호로 적음
- 도입 권고나 적용 방안은 쓰지 않음

## 시사점 작성

시사점은 여러 팩트를 묶어 분석 주체에게 주는 의미를 압축한 결론이다. 팩트 확보에 공을 들이고 시사점은 방향을 알 수 있는 수준으로 간결하게 쓴다.

- 형식은 `- (시사점 제목) 시사점 문장 [IM-01, 근거: MA-02, MI-05]`
- 근거 팩트의 모듈 약호로 외부 요인(MA, MI)과 내부 요인(IN)이 구분되게 함. 벤치마킹(BM) 근거 시사점은 외부와 내부 어느 쪽에도 쓸 수 있음
- 모든 팩트가 1개 이상 시사점에 쓰이는지 대조하고 어느 시사점에도 쓰이지 않는 팩트는 주제와 무관하므로 삭제. 목록형 표는 표 앞뒤의 서술 팩트로 대조
- 행동 제안("추진 필요", "확대해야")은 쓰지 않음. 분석과 처방을 나눠 두면 후속 전략 작업에서 근거를 추적하기 쉬움
- 결론의 범위를 근거 팩트의 범위보다 넓히지 않음
- 시사점에서 팩트로, 팩트에서 근거 대장으로 거슬러 올라가 모든 연결이 끊기지 않았는지 확인

## 결과물 작성 규칙

### 보고서 구성

- 전체 분석과 모듈 분석은 문서 제목에 전체 결론을 명제로 쓰고 첫 섹션에 시사점 목록을 둠. 시사점은 이 섹션에만 쓰고 뒤에서 반복하지 않음. 시사점이 없는 항목 분석은 해당 항목 섹션으로 바로 시작
- 이후 순서는 대상 개요, 거시환경, 미시환경, 내부역량, 벤치마킹. 수행하지 않은 모듈은 건너뛰되 순서는 바꾸지 않음
- 연혁, 조직, 예산, 인력 같은 주체 소개는 대상 개요 다음에 둘 수 있고 역량 진단은 환경분석 뒤에 둠
- 각 섹션 첫 문장에 해당 섹션의 결론을 둠
- 헤더는 헤더만 보고 하위 내용을 알 수 있게 작명하고 한 헤더에 한 주제만 담음. "정책 동향 및 기술 동향"처럼 두 주제를 묶지 않음
- 헤더는 키워드형과 문장형 중 하나로 문서 전체를 통일(5-Forces 요인 소제목은 정해진 형식 사용)하고 형제 헤더는 같은 패턴으로 평행하게 작명(예: "해외 정책 동향", "국내 정책 동향"). "개요", "배경", "현황" 같은 일반 라벨의 반복을 피함
- 같은 층의 항목은 3-4개를 권장하고 5개 이상이면 상위 묶음을 만들며 분류 기준은 하나로 통일
- 팩트 번호와 시사점 번호를 결과물에 남김. 사용자가 번호 없는 정리본을 요청하면 번호를 지운 판을 따로 만듦

### 문장과 서식

- 개조식과 명사형 종결로 쓰고 1문장에 1메시지만 담음. 한 문장에 누가, 언제, 어디서, 무엇을, 왜, 어떻게가 각각 한 번씩만 나오게 하고 두 번 나오면 문장을 나눔
- "그리고", "그러나", "-으며" 같은 연결어와 문장을 잇는 쉼표를 쓰지 않음. 같은 종류 항목을 3개 이상 나열할 때는 쉼표를 씀
- 소제목은 "(소제목) 내용" 형식으로 쓰고 콜론이나 하이픈으로 붙이지 않음
- 마크다운은 `#` 문서 제목, `##` 섹션, `###` 필요할 때만 하위 구획, `-` 서술 항목, `>` 출처로 씀. 들여쓴 하위 목록은 쓰지 않고 항목 간 관계는 소제목과 번호로 나타냄
- 출처 블록은 해당 서술 바로 아래에 두고 출처가 여럿이면 빈 줄로 블록을 나눔
- 목록형 자료(정책, 기업, 기관, 시설, 사업, 연구진, 통계)는 표로 쓰고 해석이 담긴 사실은 서술 항목으로 씀. 표 앞뒤에 표가 보여주는 사실을 서술하고 표를 연달아 배치하지 않으며 표를 인용 블록이나 코드 블록 안에 두지 않음
- 핵심 메시지에 쓰는 정량 수치는 3개 이내로 고르고 나머지는 표로 보냄. 시계열은 3-5년 이상을 쓰고 연평균 성장률과 비중을 함께 적음
- 물결표는 하이픈(-)으로 바꾸고 em dash, 한쪽을 부정한 뒤 다른 쪽을 긍정하는 대비 구문, 근거 없는 수량 선언("3대 과제" 등), 과장 수식어를 쓰지 않음
- 결과물이나 작성 과정을 설명하는 문장("본 보고서는", "조사한 결과", "아래 표로 정리하면")을 쓰지 않음
- 작업 용어(모듈, 단계, 근거 대장, 확인 수준, 품질 등급, 분석 단위, 판정)는 결과물에 쓰지 않음. PEST, 5-Forces, VRIO 같은 분석 틀 이름과 다섯 경쟁요인 이름은 섹션 이름으로 쓸 수 있음
- 전문용어와 약어는 첫 등장 시 전체 명칭을 쓰고 필요하면 `> (용어) 한 줄 설명` 블록을 붙임

### 결과물 골격 예시

```markdown
# OO 지역 OO 산업은 해외 수요 확대 속도에 비해 지역 양산 기반 확충이 더딘 상황
## 환경 변화의 시사점
- (국내 공급 기반 정체) 해외 수요 증가에 비해 국내 양산 기업 수 정체 [IM-01, 근거: MA-02, MI-05]
- (지역 실증 인프라 보유) 지역 실증 시설이 외부 기업에 개방되어 시제품 검증 수요 흡수 가능 [IM-02, 근거: IN-04, BM-01]
## OO 산업 개요
- (정의) A를 원료로 B를 생산하여 C에 공급하는 산업
- (제외 범위) D는 대체재로 분류하여 분석 대상에서 제외
- (분석 범위) 국내외 통합, 2021-2025년 동향, 전망 시계 5년
## 해외 정책 동향
- (EU) OO 규정 시행으로 역내 판매 제품의 OO 요건 강화 [MA-01]
> 기관명(연도), 자료명(URL 전체 경로)
## 경쟁구조
### (신규진입자 위협 : 하→중) 높은 설비 투자 장벽이 유지되나 공정 표준화로 진입 여지 확대
- (현황) 시사점 서술 [MI-06]
- (전망) 시사점 서술 [MI-07]
```

## 산출 전 점검

아래 항목을 코드나 원문 대조로 확인하고 하나라도 통과하지 못하면 해당 부분을 고친 뒤 다시 확인한다.

- 수행한 범위가 요청 범위와 일치하고 요청하지 않은 모듈이 없음
- 모든 팩트에 팩트 번호와 출처가 있고 공개 자료 URL이 전체 경로이며 데이터베이스 추출 자료는 추출 조건과 추출일이 근거 대장에 있음
- 본문의 모든 수치가 코드 재계산 값과 일치
- 모든 시사점에 근거 팩트 번호가 있고 모든 팩트가 1개 이상 시사점에 쓰임(번호 대조 코드로 확인)
- 각 팩트의 모듈 배치가 모듈 구분 기준과 일치하고 산업 가치사슬과 조직 가치사슬이 섞이지 않음
- 분석 섹션과 시사점에 처방, 목표 상태, 권고 문장이 없음
- 5-Forces를 수행했으면 단위별 표, 종합 행, 요인 간 대조, 인접 단위 간 대조가 모두 완료됨
- 확인 수준 2, 3이면 승인되지 않은 인용이 본문에 없음
- 제외 등급 출처만을 근거로 한 서술과 비공식 내부 기록만을 근거로 한 수치가 없음
- 개인정보와 기밀 표시 자료가 규칙 범위 안에서만 쓰임
- 금지 표현과 작업 용어가 없음(문자열 검색으로 확인)

마지막으로 비판적인 검토자의 눈으로 결과물을 다시 읽는다. 실제로 확인된 약점만 고치거나 사용자에게 알리고 확인되지 않은 약점을 만들어 내지 않는다.
