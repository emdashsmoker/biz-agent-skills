# 실무 통계

## 용어

| 용어 | 정의 |
|------|------|
| 의사결정 질문 | 조사 결과를 근거로 의사결정 주체, 결정 시한, 결정 사항을 명시한 문장 |
| 이해관계자 | 조사 결과를 보고받거나 활용하는 고객, 발주처, 내부 의사결정자 |
| 분석 계획표 | 자료 수집 전에 작성하는 빈 결과표와 빈 차트의 목록 |
| 확률표본 | 모집단 명부에서 무작위로 추출하여 대상별 선정 확률을 산출할 수 있는 표본 |
| 비확률표본 | 공개 모집, 온라인 패널, 지인 소개처럼 응답자의 자발적 참여나 조사자의 편의 선정으로 구성된 표본 |
| 오차범위 | 확률표본에서 우연 변동만으로 발생하는 추정치의 변동 폭이며 95% 신뢰수준을 기본으로 적용한다 |
| 효과크기 | 집단 간 차이나 변수 간 관계의 크기를 표본 크기와 무관하게 나타낸 지표 |
| 비교 집단 | 결과를 구분하여 보고하는 하위 집단 (지역, 기업 규모, 업종 등) |
| 상위 두 응답 비율 | 5점 척도에서 4점 또는 5점을 선택한 응답의 비율 |
| 가공 기록 | 원자료를 분석용 자료로 변환하는 과정의 판단과 적용 규칙을 기록한 문서 |

산출물에서도 위 용어를 동일한 정의로 사용하고 다른 명칭으로 대체하지 않는다.

## 작동 원칙

- (결정에서 출발) 모든 문항과 분석은 의사결정 질문과 연계한다. 연계되지 않는 문항은 설계에서 삭제한다. 표본 크기와 분석 범위의 결정 기준이 의사결정 질문이기 때문이다.
- (재현 가능한 계산) 비율, 평균, 표본 크기, 검정 결과 등 모든 수치는 코드로 산출한다. 비정형 표의 해석과 정리에 필요한 판단은 모델과 사용자가 담당한다. 판단 내용은 가공 기록에 규칙 문장으로 기록하고 적용은 코드로 수행한다. 동일한 원자료와 가공 기록이 주어지면 제3자도 동일한 결과를 재현할 수 있어야 한다.
- (가장 단순한 설계) 의사결정 질문에 답할 수 있는 방법이 복수이면 문항 수, 표본 크기, 분석 단계가 가장 적은 방법을 선택한다. 결과를 표 1개나 막대그래프 1개로 바로 정리할 수 있는 문항 형식을 우선 적용한다.
- (근거 범위 안의 결론) 결론은 표본이 대표하는 범위 안에서 도출한다. 비확률표본의 결과는 응답자 기준으로 서술한다.

## 조사 유형

| 유형 | 입력 형태 | 분석 단위 |
|------|-----------|-----------|
| 응답형 수요조사 | 필요, 의향, 선호를 조사하는 설문 응답 | 응답자 |
| 과제형 수요조사 | 기술수요조사, 과제수요조사, RFP 형식 수요조사처럼 정해진 양식으로 제출된 과제 후보 제안서 | 제안서 |
| 진단형 설문 | 성숙도 모델처럼 정해진 진단 모델의 문항 응답 | 진단 대상 조직 |
| 2차 자료 | 공식 통계, 행정 자료, 기존 조사 결과 | 원자료의 단위 |

한 과업에 여러 유형이 혼재하면 유형별로 구분하여 설계하고 분석한다. 유형별 기준은 references/survey-types.md를 참조한다.

## 비용 절감

조사 비용은 문항 수, 표본 크기, 비교 집단 수, 가공 시간에 따라 증가한다. 아래 순서로 비용을 절감한다.

- 공식 통계와 행정 자료로 답할 수 있는 질문은 조사 범위에서 제외한다.
- 분석 계획표와 연계되지 않는 문항을 삭제한다.
- 표본 크기는 요구 정밀도와 비교 집단 수를 기준으로 결정한다. 오차범위를 절반으로 축소하려면 표본이 4배 필요하다.
- 비교 집단은 의사결정에 활용하는 구분만 설정한다. 비교 집단마다 최소 표본이 별도로 필요하다.
- 자유 응답 문항은 분석 계획표에 분류 기준이 마련된 문항만 포함한다.

30명 표본의 충분성 판단 기준과 이해관계자 설명 예시는 references/design.md를 참조한다.

## 사용자 확인

아래 경우에만 사용자에게 확인을 요청한다. 그 외의 선택에는 이 스킬의 기본 기준을 적용하고 적용 기준을 결과와 함께 한 줄로 명시한다.

- 요청 문장과 자료로 의사결정 질문을 추론할 수 없는 경우
- 단일 가공 판단이 보고 대상 결론을 변경하는 경우
- 예산과 정밀도 사이에서 선택이 필요한 경우

## 계산 도구

- 기본 도구는 Python과 pandas, NumPy, SciPy, statsmodels, matplotlib이다. 이 스킬이 요구하는 계산은 모두 기본 도구로 처리할 수 있다.
- SPSS, Stata, SAS, R처럼 별도로 설치하는 통계 소프트웨어와 기본 도구 외의 라이브러리는 사용자가 자신의 환경에 직접 설치한 경우에 사용한다. 사용한 도구의 명칭, 버전, 설정은 가공 기록에 명시한다.
- 코드를 실행할 수 없는 환경에서는 계산식과 입력 수치를 제시하고 스프레드시트 수식을 함께 제공한다. 모델이 추정한 수치는 결과로 사용하지 않는다.

## 산출 전 점검

- 모든 문항과 결과표가 의사결정 질문과 연계되어 있는가
- 모든 수치가 코드 실행 결과이며 계산식과 입력 수치가 기록되어 있는가
- 가공 기록만으로 동일한 분석용 자료를 재현할 수 있는가
- 모든 수치에 대상, 표본 수, 시점이 명시되어 있는가
- 비확률표본 결과가 응답자 기준으로 서술되어 있는가
- 차이의 신뢰구간이 0을 포함하는 항목들이 유사한 수준으로 분류되어 있는가
- references/reporting.md의 왜곡 점검을 완료했는가
