# 보고

## 수치 문장

- 모든 수치에 대상, 표본 수, 시점, 조사 방식을 명시한다. 예시 문장은 "OO년 O월 온라인 공개 모집으로 응답한 중소기업 212곳 중 64%가 참여 의향을 밝혔다"이다.
- 비율에는 분모를 명시한다. 문항별 분모가 다르면 각각 명시한다.
- 비율의 차이는 %p로 표기하고 상대 변화는 %로 표기한다. 30%에서 36%로 상승하면 6%p 상승이며 상대 변화로는 20% 증가이다.
- 치우친 수치는 평균과 중앙값을 함께 제시한다.
- 확률표본의 추정치에는 오차범위나 신뢰구간을 명시한다.
- 비확률표본의 결과에는 오차범위 대신 아래 문장을 사용한다. 이 문장은 Baker 외(2013)의 권고에 근거한다.

> 이 조사는 [모집 방식]으로 모집한 응답자 [n]명의 결과이다. 모집단을 대표하도록 추출한 표본이 아니므로 결과는 응답자 기준으로 해석한다.

### 유사 수준 판정

- 두 추정치 차이의 95% 신뢰구간이 0을 포함하면 두 항목을 "유사한 수준"으로 분류하여 보고한다. 차이의 신뢰구간은 references/analysis.md의 비교 방법으로 산출한다.
- 비확률표본에도 같은 계산을 내부 판단 기준으로 적용한다. 이때 산출한 신뢰구간은 보고서에 모집단 오차범위로 표기하지 않는다.
- 순위표에서 유사한 수준으로 분류된 항목은 같은 순위로 표시한다.

## 차트

- 막대그래프의 수치 축은 0에서 시작한다. 선그래프의 축 시작점이 0보다 크면 축 시작점을 표시한다.
- 상호 비교하는 차트는 같은 축 범위를 사용한다.
- 크기는 막대 길이로 표현한다. 그림의 넓이나 부피로 크기를 표현하면 수치 비율과 시각적 비율이 일치하지 않는다.
- 차트마다 표본 수와 해당 문항을 명시한다.
- 차트 1개에는 메시지 1개를 담는다. 분석 계획표의 "분석 질문"이 차트 제목의 출발점이다.

## 왜곡 점검

아래 점검표는 허프(Huff 1954)가 정리한 통계 왜곡 유형에 근거한다.

| 유형 | 점검 질문 | 대응 |
|------|-----------|------|
| 편향된 표본 | 관심, 이해관계, 접근성으로 인해 특정 성향의 응답자가 집중되었는가 | 모집 방식과 응답자 구성을 명시하고 결론을 응답자 기준으로 서술 |
| 선별된 평균 | 평균, 중앙값, 최빈값 중 유리한 수치만 선택했는가 | 사용한 대표값을 명시하고 치우친 수치는 중앙값 병기 |
| 누락된 수치 | 표본 수, 분모, 불확실성, 비교 기준이 누락되었는가 | 수치 문장 규칙 적용 |
| 무의미한 차이 | 신뢰구간이 0을 포함하는 차이를 순위나 변화로 표현했는가 | 유사한 수준으로 분류 |
| 과장된 그래프 | 축을 절단하여 차이를 확대했는가 | 막대 축은 0에서 시작하고 비교 차트는 같은 축 범위 사용 |
| 면적 그림 | 그림의 넓이나 부피로 크기를 표현했는가 | 막대 길이로 표현 |
| 대상이 바뀐 수치 | A를 측정한 수치로 B를 주장했는가 (예 의향 비율로 참여 규모를 주장) | 측정 대상 그대로 서술 |
| 선후 관계의 인과 해석 | 시간 순서나 동반 변동만으로 원인을 주장했는가 | 연관으로 서술 |
| 기준 변경 | 기준 연도, 분모, %와 %p를 유리한 방향으로 변경했는가 | 기준을 고정하고 명시 |

보고서 배포 전에 허프가 제시한 다섯 질문으로 최종 점검을 수행한다.

- (누가 말하는가) 출처와 출처의 이해관계를 명시했는가
- (어떻게 알았는가) 표본과 측정 방법을 명시했는가
- (무엇이 누락되었는가) 분모, 비교 기준, 불확실성을 명시했는가
- (주제가 바뀌지 않았는가) 측정 대상과 주장 대상이 일치하는가
- (상식에 부합하는가) 수치의 크기와 방향이 알려진 사실과 부합하는가

## 이해관계자 설명

- 결과는 자료로 확인한 사항, 이번 자료로 판단할 수 없는 사항, 판단에 필요한 추가 자료로 구분하여 전달한다.
- 관행과 다른 분석 방법을 제안할 때는 교과서와 공식 기관 지침에서 널리 수용된 근거를 제시한다. 설명은 의사결정에 필요한 정밀도를 중심으로 구성한다.
- 결과가 예상과 다르더라도 분석 계획표에서 설정한 비교를 그대로 보고한다.
- 의향을 수요 규모로, 제출 건수를 수요 크기로, 상관을 효과로 환산해 달라는 요청을 받으면 측정 대상 그대로의 문장과 해당 문장의 변경에 필요한 추가 근거를 함께 제시한다.

## 보고 점검

- 모든 수치에 대상, 표본 수, 시점, 조사 방식이 명시되어 있는가
- %와 %p가 구분되어 있는가
- 비확률표본 결과에 응답자 기준 문장이 포함되어 있는가
- 차이의 신뢰구간이 0을 포함하는 항목들이 유사한 수준으로 분류되어 있는가
- 막대그래프 축이 0에서 시작하고 비교 차트의 축 범위가 같은가
- 왜곡 점검표와 다섯 질문을 모두 통과했는가
