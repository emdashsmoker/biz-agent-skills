# 가공과 분석

## 가공

비정형 자료는 과업마다 형태가 달라 하나의 고정 코드로 처리하기 어렵다. 가공은 판단 규칙으로 처리하고 규칙의 적용은 코드로 수행한다.

### 진행 방식

- 원자료는 원본 상태로 보관하고 사본으로 작업한다.
- 모델이 표 구조(병합 셀, 다단 머리글, 단위 행, 합계 행)를 해석하고 정리안을 작성한다.
- 정리안을 상위 일부 행에 먼저 적용하여 결과를 확인한 뒤 전체에 적용한다.
- 적용 전후의 행 수, 열 수, 합계를 비교하여 누락과 중복 여부를 확인한다.

### 가공 기록

모든 판단은 아래 양식으로 기록한다.

| 순번 | 대상 | 판단 | 적용 규칙 | 영향 건수 | 결론 변화 |
|------|------|------|-----------|-----------|-----------|
| 1 | 문항 7 | 기타 응답 중 기존 선택지와 의미가 같은 응답을 해당 선택지로 재분류 | 응답 원문에 선택지 명칭이 포함되면 해당 선택지로 재분류 | 14 | 없음 |

결론 변화 열에는 해당 규칙을 적용하지 않았을 때 주요 결과의 변화 여부를 기재한다. 결과가 달라지면 사용자에게 확인을 요청한다.

### 결측

- 무응답, 해당 없음, 모름을 서로 다른 코드로 구분한다.
- 결측은 빈칸으로 유지한다. 대체가 필요하면 방법과 건수를 기록하고 대체 전 결과를 함께 보고한다.
- 결과표에는 문항별 유효 응답 수를 분모로 명시한다.

### 이상치

- 입력 오류(단위 혼동, 자릿수 오류)와 실제 극단 응답을 구분한다. 입력 오류는 근거가 확인된 경우에 수정하고 수정 내용을 기록한다.
- 실제 극단 응답은 유지하고 중앙값 기준 결과를 함께 검토한다. 극단 응답의 포함 여부에 따라 결론이 달라지면 두 결과를 모두 보고한다.

### 불성실 응답

- 판정 기준은 결과 확인 전에 설정한다.
- 이 스킬의 기본 기준은 행렬형 문항 전체에 같은 번호를 선택한 응답, 소요 시간이 전체 중앙값의 3분의 1 미만인 응답, 상호 모순되는 응답이다.
- 판정된 응답은 원자료에 표시만 한다. 제외 전후 결과를 비교하고 제외 건수를 보고한다.

### 자유 응답 분류

- 분류 기준표에는 코드, 정의, 대표 예시를 기재한다. 1개 응답에 복수 코드를 부여할 수 있다.
- 언어모델로 분류하면 무작위로 선정한 일부 응답을 사람이 재분류하여 일치 여부를 확인한다. 불일치가 반복되는 코드는 정의를 수정한 뒤 다시 분류한다.
- 결과는 코드별 언급 응답자 수와 비율로 보고한다. 분모는 자유 응답 작성자 수이다.

### 단위 통일

- 금액 단위, 통화, 기준 연도, 집계 기간(연간, 월간)을 통일하고 변환식을 가공 기록에 명시한다.

## 분석

분석 방법은 분석 계획표의 질문 유형에 따라 선택한다. 기본 방법으로 질문에 답할 수 있으면 더 복잡한 방법을 추가하지 않는다.

### 분석 선택

| 질문 유형 | 기본 방법 | 보고 수치 | 차트 |
|-----------|-----------|-----------|------|
| 수준 | 비율, 평균, 중앙값 | 비율과 윌슨 신뢰구간, 평균, 중앙값, 사분위범위 | 가로 막대, 히스토그램 |
| 비교 | 아래 비교 방법 | 차이, 신뢰구간, 효과크기 | 가로 막대 |
| 변화 | 같은 대상이면 대응 비교, 다른 대상이면 집단 비교 | 변화량, 신뢰구간 | 세로 막대, 선 |
| 관계 | 스피어만 상관, 교차표 | 상관계수, 행 비율 | 산점도, 누적 막대 |
| 우선순위 | 선택 비율, 중요도-만족도 분석, 보리치 요구도, 계층분석법 | references/survey-types.md 참조 | 막대, 4분면 산점도 |

신뢰구간과 오차범위는 확률표본에서 모집단 추정치로 보고한다. 비확률표본에는 references/reporting.md의 규칙을 적용한다.

### 비교 방법

- (두 집단 비율) 비율 차이와 95% 신뢰구간을 보고한다. 검정은 카이제곱 검정을 사용한다. 기대빈도 5 미만 칸이 있으면 피셔 정확검정을 사용한다.
- (두 집단 평균) 웰치 t검정을 사용한다 (Delacre 외 2017). 등분산 여부와 관계없이 같은 방법을 적용한다. 효과크기는 코헨 d로 보고한다.
- (세 집단 이상 평균) 웰치 분산분석을 사용한다 (Delacre 외 2019). 집단 간 차이가 확인되면 두 집단씩 웰치 t검정을 수행하고 다중비교 보정을 적용한다.
- (치우친 수치) 왜도 절댓값이 1 이상이면 치우친 수치로 판단한다. 이 기준은 이 스킬의 기본 기준이다. 치우친 수치는 중앙값 차이와 부트스트랩 신뢰구간을 함께 보고한다 (Hesterberg 2008). 부트스트랩은 반복 2,000회와 고정 난수 시드를 기본으로 적용한다.
- (리커트 문항) 평균 비교를 사용할 수 있다 (Norman 2010). 상위 두 응답 비율의 차이를 함께 보고한다.
- (같은 응답자의 두 문항) 응답자 단위 대응 부트스트랩으로 차이의 신뢰구간을 산출한다.

### 다중비교

- 비교 횟수가 증가하면 우연에 의한 유의한 결과가 나타날 확률이 증가한다.
- 분석 계획표에 사전 명시한 비교가 복수이면 벤저민-호흐베르크 방법으로 보정한다 (Benjamini & Hochberg 1995).
- 분석 계획표에 없던 비교는 보정 여부와 관계없이 탐색 결과로 표시한다.

### 해석 기준

- p값은 자료가 특정 가정과 어긋나는 정도를 나타낸다. p값은 가설이 참일 확률이나 효과의 크기를 나타내지 않는다 (Wasserstein & Lazar 2016).
- 결론은 효과크기, 신뢰구간, 표본 수를 중심으로 서술하고 p값은 보조 수치로 제시한다.
- 실무적으로 의미 있는 차이의 기준(예 5%p 이상)은 의사결정 질문 단계에서 사전에 설정한다.
- 단일 시점 설문에서 확인된 관계는 연관으로 서술한다. 인과로 서술하려면 시간 순서, 대안적 설명 검토, 작동 경로가 필요하다.
- 합계 결과를 근거로 결정하면 주요 비교 집단 내에서도 같은 방향인지 확인한다. 집단 구성이 다르면 합계와 집단별 결과의 방향이 반대로 나타날 수 있다.
- 점수가 특히 낮거나 높아 선정된 대상의 전후 변화에는 개입 없이도 평균으로 회귀하는 변동이 포함된다 (Barnett 외 2005). 선정되지 않은 대상의 변화와 함께 비교한다.

### 가중치

- 응답자 구성이 알려진 모집단 구성(기업 규모, 지역 등)과 다르면 사후 층화 가중치 적용 결과와 미적용 결과를 함께 산출한다.
- 사후 층화 가중치 = 모집단 내 해당 집단 비율 ÷ 표본 내 해당 집단 비율
- 두 결과의 결론이 같으면 가중치 미적용 결과를 보고하고 가중치 적용 결과는 가공 기록에 명시한다. 결론이 다르면 두 결과를 모두 보고한다.

## 측정 품질

- (크론바흐 알파) α = k ÷ (k − 1) × (1 − Σ문항 분산 ÷ 합계 점수 분산)이며 k는 문항 수이다 (Cronbach 1951).
- (등급 일치 비율) 두 평가자가 같은 등급을 부여한 제안서 수 ÷ 전체 제안서 수
- (급내상관계수) 모든 평가자가 전체 제안서를 평가한 경우 ICC(2,1) = (BMS − EMS) ÷ (BMS + (k − 1) × EMS + k × (JMS − EMS) ÷ n)로 계산한다 (Shrout & Fleiss 1979). BMS는 제안서 간 평균제곱, JMS는 평가자 간 평균제곱, EMS는 잔차 평균제곱, k는 평가자 수, n은 제안서 수이다.
- (계층분석법 일관성 비율) CR = CI ÷ RI이고 CI = (λmax − n) ÷ (n − 1)이다. λmax는 쌍대비교 행렬의 최대 고유값이고 n은 비교 항목 수이다.
- (무작위 지수 RI) n이 3, 4, 5, 6, 7, 8, 9일 때 RI는 각각 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45이다 (Saaty 1980).

## 계산 규칙

- 모든 수치는 코드로 산출하고 코드 파일을 산출물과 함께 보관한다.
- 결과표에는 분모와 결측 수를 함께 출력한다.
- 난수를 사용하는 계산은 시드를 고정한다.
- 사용한 라이브러리의 명칭과 버전을 기록한다.

| 계산 | 함수 |
|------|------|
| 비율 신뢰구간 | `statsmodels.stats.proportion.proportion_confint(method="wilson")` |
| 두 비율 차이의 신뢰구간 | `statsmodels.stats.proportion.confint_proportions_2indep` |
| 카이제곱 검정, 피셔 정확검정 | `scipy.stats.chi2_contingency`, `scipy.stats.fisher_exact` |
| 웰치 t검정 | `scipy.stats.ttest_ind(equal_var=False)` |
| 웰치 분산분석 | `statsmodels.stats.oneway.anova_oneway(use_var="unequal")` |
| 왜도 | `scipy.stats.skew` |
| 부트스트랩 신뢰구간 | `scipy.stats.bootstrap` (같은 응답자 비교는 `paired=True`) |
| 스피어만 상관 | `scipy.stats.spearmanr` |
| 다중비교 보정 | `statsmodels.stats.multitest.multipletests(method="fdr_bh")` |
| 검정력과 표본 크기 | `statsmodels.stats.power` |
