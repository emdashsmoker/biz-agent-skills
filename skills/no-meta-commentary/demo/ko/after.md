# 사내 초거대AI 전사 확대 근거

**6주 시범 운영에서 품질팀의 문서 검색 시간은 76%, 보고서 초안 작성 시간은 61% 줄었고 보안 사고는 한 건도 없었음. 참여자 전원이 계속 사용을 원하고 설계팀과 기획팀도 사용을 요청함.**

## 시범 운영 개요

| 항목 | 내용 |
|---|---|
| 기간 | 2026년 11월 2일(월) ~ 12월 11일(금), 6주 |
| 참여 | 품질팀 3명 |
| 운영 방식 | 사내 서버에 모델을 설치하여 운영 |

## 1. 반복 업무 시간 대폭 단축

| 업무 | 도입 전 (건당) | 도입 후 (건당) | 건당 절감 | 단축률 |
|---|---|---|---|---|
| 과거 품질 문서 검색 | 25분 | 6분 | 19분 | 76% |
| 불량 원인 분석 보고서 초안 작성 | 3시간 | 1시간 10분 | 1시간 50분 | 61% |

- 문서 검색은 같은 시간에 약 4배 많은 건을 처리할 수 있는 수준
- 보고서 초안 1건마다 확보되는 1시간 50분을 내용 검토와 개선 대책 수립에 투입 가능

## 2. 현업의 지속 사용 의향 확인

- 참여자 3명 전원이 계속 사용하겠다고 응답
- 6주 동안 실제 업무에 써 본 사용자의 평가여서 현업 정착 가능성을 보여 주는 근거

## 3. 보안 위험 없는 운영 구조 검증

- 모델을 사내 서버에 설치하여 품질 문서를 외부 서비스로 보내지 않는 구조로 운영
- 6주 운영 기간 중 보안 사고 0건
- 같은 운영 구조를 다른 부서에도 그대로 적용 가능

## 4. 타 부서의 자발적 도입 수요

- 설계팀과 기획팀이 시범 운영 기간 중 사용을 요청
- 현업이 먼저 요청한 수요여서 확대 초기의 사용 정착 부담이 작음
- 문서 검색과 보고서 초안 작성은 설계와 기획 업무에서도 반복되는 작업이어서 품질팀과 같은 시간 단축 효과를 기대할 수 있음
