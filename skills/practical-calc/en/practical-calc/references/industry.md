# Industry Analysis

Input-output coefficients measure how spending spreads through the economy along transactions between industries. The location quotient shows in which regions an industry clusters.

## Economic Ripple Effects

The tool computes how much output, value added and employment rise, directly and indirectly, when spending such as project costs, consumption, investment or exports becomes final demand for product groups. The input-output table that supplies the coefficients sets the geographic scope of the effect.

### Terms

| Term | Definition |
|---|---|
| Output inducement coefficient | Output generated across all industries, directly and indirectly, by one unit of final demand for a product |
| Value-added inducement coefficient | Value added generated across all industries by the same unit of final demand |
| Job inducement coefficient | Workers generated by 1 billion KRW of final demand, including self-employed and unpaid family workers, in persons per 1 billion KRW |
| Employment inducement coefficient | Wage employees generated by 1 billion KRW of final demand, in persons per 1 billion KRW |

Coefficients come from the Bank of Korea input-output tables. Spending on imports does not raise domestic output, so use coefficients on a domestic-product basis. The Bank of Korea publishes benchmark input-output tables and extended tables for the years in between, so use the latest table and state its type and year in the report.

- (National economy) Coefficients from the national input-output table give the effect across the whole domestic economy.
- (Regional economy) Regional coefficients from the Bank of Korea regional input-output tables give the effect inside that region. Effects that spread to other regions are not part of this value.
- (Other countries) Coefficients with the same definitions from another country's input-output tables work the same way. For amounts outside KRW, write the currency unit in `--unit` and enter the amount the employment coefficient refers to in `--emp-base`. With employment coefficients stated per USD 1 million and amounts in USD million, use `--emp-base 1`.

Check that the scope of the analysis matches the scope of the coefficient table, and name the table in the report.

### Formulas

```
induced output = sum over product groups of spending x output inducement coefficient
induced value added = sum over product groups of spending x value-added inducement coefficient
induced employment = sum over product groups of spending (in units of the coefficient base amount) x employment inducement coefficient
```

- Bank of Korea employment coefficients are per 1 billion KRW, so the script converts amounts to units of 1 billion KRW before multiplying. Amounts in 100 million KRW divide by 10, and amounts in million KRW divide by 1,000. The script handles this conversion from the KRW unit given in `--unit`.
- When using job inducement coefficients, run with `--emp-type jobs` so the result reads as induced jobs.
- The output inducement coefficient includes the unit of final demand itself, so it is 1 or more. The value-added inducement coefficient on a domestic-product basis is 1 or less. Coefficients outside these ranges make the script ask the user to check the coefficient type.
- When published employment coefficients use a different classification level from the output coefficients, enter for each row the coefficient of the class that contains the product group, and state the classification level in the report.
- The calculation follows the input-output model's assumptions of fixed input structures and no supply constraints. Results are gross effects of the spending, with no deduction for other spending that the project may displace.

### Input Collection Order

1. Total spending and its unit (default 100 million KRW)
2. Related product groups (Bank of Korea input-output product classification)
3. Allocation of spending across product groups
4. Output, value-added and employment (or job) inducement coefficients for each product group

Coefficients come from values the user checked in the input-output tables or from an input-output table file the user supplies. In an output inducement table in matrix form (the inverse matrix), the column sum for a product group is its output inducement coefficient. The tables have many sectors and several table types, so the risk of misreading a coefficient is high, and the user should enter coefficients directly where possible. When the user writes coefficients in text, such as "Product group A output 1.95, value added 0.62, employment 6.1", convert them into the CSV format below.

### Input Format

```
item,amount,output_coef,va_coef,emp_coef
Product group A,120,1.95,0.62,6.1
Product group B,50,2.10,0.55,4.3
```

With `--total` set to total spending, the script flags any difference from the allocated sum.

### Run Example

```
python scripts/io_impact.py --input examples/impact.csv --unit "100 million KRW" --total 200 --chart impact.png
```

## Location Quotient

The location quotient (LQ) compares a region's share of an industry with the same industry's share nationwide. A value above 1 means the industry clusters in that region more than the national average.

### Formulas

```
LQ = (regional industry value / regional all-industry value) / (national industry value / national all-industry value)
share of national = regional industry value / national industry value
```

- Values are employees or establishments. The employee basis shows where employment concentrates, and the establishment basis shows where businesses concentrate.
- When the data has a national row, name it with `--national-label`. Otherwise the script adds up the regions given to build national values.
- When the data has an all-industry row, name it with `--total-label`. Otherwise the script adds up the industries given. If a total row sits in the data without this option, the total doubles, and the script prints a notice.
- LQ is a ratio of shares, so a small region can show a high LQ. Read it together with the share of national to judge scale.
- Regions at or above `--threshold` (default 1.0) appear in a separate list.

### Data Preparation

For Korean data, the Census on Establishments tables on the Korean Statistical Information Service (KOSIS) work well: "시도·산업·사업체구분별 사업체수, 종사자수" (establishments and employees by province, industry and establishment type) or "시도 · 산업별 사업체수, 종사자수 및 매출액" (establishments, employees and sales by province and industry). Download as CSV and reshape into long format with three columns: region, industry and value. Keep the reshaping code with the input file.

- Tables broken down by establishment type are calculated on the total (계) rows. Check the establishment type column name in the file and pass it as `--filter <column name>=계`.
- Symbols in number cells (such as - or X) have meanings defined in the table notes. Replace them with numbers or remove the rows, and state the treatment in the report. The script stops on leftover symbols and reports the value.

### Input Collection Order

1. File with establishments or employees by region and industry (CSV, XLSX)
2. Target industry name and measure (employees or establishments)
3. After showing the result table, ask whether a chart is needed

### Input Format

```
region,industry,value
Nation,All industries,1000000
Nation,Manufacturing,200000
Region 1,All industries,300000
Region 1,Manufacturing,45000
```

Set other column names with `--region-col`, `--industry-col` and `--value-col`.

### Run Example

```
python scripts/lq.py --input examples/lq.csv --industry Manufacturing --national-label Nation --total-label "All industries" --measure employees --chart lq.png
```

Result tables and charts list regions in descending order of LQ.
