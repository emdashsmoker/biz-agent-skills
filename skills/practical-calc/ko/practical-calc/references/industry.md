# 산업 분석

지출이 산업 간 거래를 따라 경제 전체로 퍼지는 효과는 산업연관 계수로 계산한다. 업종이 어느 지역에 모여 있는지는 입지계수로 확인한다.

## 경제적 파급효과

사업비나 소비, 투자, 수출 같은 지출이 상품군별 최종수요로 쓰일 때 생산, 부가가치, 고용이 직접, 간접으로 얼마나 늘어나는지 계산한다. 효과가 미치는 공간 범위는 계수를 가져온 산업연관표가 정한다.

### 용어

| 용어 | 정의 |
|---|---|
| 생산유발계수 | 어떤 상품의 최종수요가 1단위 생길 때 모든 산업에서 직접, 간접으로 늘어나는 생산액 |
| 부가가치유발계수 | 같은 최종수요 1단위가 모든 산업에서 늘리는 부가가치 |
| 취업유발계수 | 최종수요 10억원이 늘리는 취업자 수(자영업자와 무급가족종사자 포함), 단위 명/10억원 |
| 고용유발계수 | 최종수요 10억원이 늘리는 임금근로자 수, 단위 명/10억원 |

계수는 한국은행 산업연관표에서 받는다. 수입품에 쓰인 지출은 국내 생산을 늘리지 않으므로 국산품 기준 계수를 쓴다. 한국은행은 기준년 산업연관표와 그 사이 연도의 연장표를 공표하므로 가장 최근 표를 쓰고 표의 종류와 연도를 보고서에 적는다.

- (국가 경제 효과) 전국 산업연관표의 계수를 쓰면 국내 경제 전체에서 생기는 효과가 나온다.
- (지역 경제 효과) 한국은행 지역산업연관표의 지역 계수를 쓰면 해당 지역 안에서 생기는 효과가 나온다. 다른 지역으로 퍼지는 효과는 이 값에 포함되지 않는다.
- (다른 나라 경제) 해당 국가 통계기관의 산업연관표에서 같은 정의의 계수를 받으면 같은 방식으로 계산한다. 원화 이외 통화의 금액은 `--unit`에 통화 단위를 적고 `--emp-base`에 고용 계수의 기준 금액을 입력한다. 고용 계수가 100만 달러당 인원이고 금액 단위가 USD million이면 `--emp-base 1`이다.

분석 범위와 계수 표의 범위가 같은지 확인하고 보고서에 계수 표의 이름을 적는다.

### 산식

```
생산유발액 = 상품군별 투입 금액 x 생산유발계수 의 합
부가가치유발액 = 상품군별 투입 금액 x 부가가치유발계수 의 합
고용유발인원 = 상품군별 투입 금액(고용 계수 기준 금액 단위) x 고용유발계수 의 합
```

- 한국은행 고용 계수는 10억원당 인원이므로 금액 단위를 10억원으로 바꾼 뒤 곱한다. 억원 단위 금액은 10으로 나누고 백만원 단위 금액은 1,000으로 나눈다. 스크립트는 `--unit`에 적은 원화 단위로 이 환산을 자동 처리한다.
- 취업유발계수를 쓰면 `--emp-type jobs`로 실행하여 결과 이름을 취업유발인원으로 바꾼다.
- 생산유발계수는 최종수요 1단위 자체를 포함하므로 1 이상이다. 국산품 기준 부가가치유발계수는 1 이하다. 이 범위를 벗어난 계수를 입력하면 스크립트가 계수 종류를 확인하라고 알린다.
- 공표 자료에서 고용 계수의 분류 단위가 생산 계수와 다르면 각 상품군이 속한 분류의 계수를 행마다 입력하고 어느 분류 단위를 썼는지 보고서에 적는다.
- 이 계산은 산업 간 투입 구조가 고정되어 있고 공급 제약이 없다는 산업연관모형의 가정을 따른다. 결과는 사업 지출이 만드는 총효과이며 다른 지출이 줄어드는 효과는 차감하지 않은 값이다.

### 입력 수집 순서

1. 총 투입 금액과 단위(기본 억원)
2. 관련 상품군(한국은행 산업연관표 상품 분류 기준)
3. 상품군별 금액 배분
4. 상품군별 생산유발계수, 부가가치유발계수, 고용유발계수 또는 취업유발계수

계수는 사용자가 산업연관표에서 직접 확인한 값이나 사용자가 제출한 산업연관표 파일에서 받는다. 행렬 형태의 생산유발계수표(역행렬표)를 받으면 상품군 열의 합계가 그 상품군의 생산유발계수다. 산업연관표는 부문 수가 많고 표 종류가 여러 가지라서 계수를 잘못 읽을 위험이 크므로 사용자에게 직접 입력을 먼저 권한다. 사용자가 "상품군 A 생산 1.95, 부가 0.62, 고용 6.1"처럼 글로 주면 아래 CSV 형식으로 옮긴다.

### 입력 형식

```
item,amount,output_coef,va_coef,emp_coef
상품군 A,120,1.95,0.62,6.1
상품군 B,50,2.10,0.55,4.3
```

`--total`에 총 투입 금액을 주면 배분 합계와 다를 때 알린다.

### 실행 예시

```
python scripts/io_impact.py --input examples/impact.csv --unit 억원 --total 200 --chart impact.png
```

## 입지계수

입지계수(LQ)는 한 지역의 특정 업종 비중을 전국의 같은 업종 비중과 비교한 값이다. 1보다 크면 그 지역에 해당 업종이 전국 평균보다 많이 모여 있다는 뜻이다.

### 산식

```
LQ = (지역의 해당 업종 값 / 지역의 전체 산업 값) / (전국의 해당 업종 값 / 전국의 전체 산업 값)
전국 대비 비중 = 지역의 해당 업종 값 / 전국의 해당 업종 값
```

- 값은 종사자수 또는 사업체수를 쓴다. 종사자수 기준은 고용 규모의 집중을, 사업체수 기준은 사업체의 집중을 나타낸다.
- 전국 행이 자료에 있으면 `--national-label`로 그 이름을 지정한다. 지정하지 않으면 입력된 지역을 모두 더해 전국 값을 만든다.
- 전체 산업 행이 자료에 있으면 `--total-label`로 지정한다. 지정하지 않으면 입력된 업종을 모두 더해 전체 산업 값을 만든다. 합계 행이 섞여 있는데 지정하지 않으면 전체 값이 두 배로 잡히므로 스크립트가 알림을 출력한다.
- LQ는 비중의 비율이라서 규모가 작은 지역에서도 크게 나올 수 있다. 전국 대비 비중을 함께 보고 규모를 판단한다.
- `--threshold`(기본값 1.0) 이상인 지역 목록을 따로 출력한다.

### 자료 준비

국가통계포털(KOSIS)의 전국사업체조사 통계표 "시도·산업·사업체구분별 사업체수, 종사자수" 또는 "시도 · 산업별 사업체수, 종사자수 및 매출액"을 권장한다. CSV로 받아 지역, 업종, 값 세 열의 긴 형식으로 바꾼다. 형식 변환에 쓴 코드는 입력 파일과 함께 남긴다.

- 사업체구분이 나뉜 표는 사업체구분 '계' 행을 기준으로 계산한다. 파일에 적힌 사업체구분 열 이름을 확인해 `--filter <열 이름>=계`로 지정한다.
- 숫자 자리에 있는 기호(-, X 등)는 통계표 주석에서 뜻을 확인하고 숫자로 바꾸거나 행을 제외한다. 처리 내용은 보고서에 적는다. 기호가 남아 있으면 스크립트는 계산하지 않고 해당 값을 알린다.

### 입력 수집 순서

1. 지역별, 산업별 사업체수 또는 종사자수 파일(CSV, XLSX)
2. 분석할 업종 이름과 측정 기준(종사자수 또는 사업체수)
3. 결과 표를 보인 뒤 차트가 필요한지 확인

### 입력 형식

```
region,industry,value
전국,전체,1000000
전국,제조업,200000
지역 1,전체,300000
지역 1,제조업,45000
```

열 이름이 다르면 `--region-col`, `--industry-col`, `--value-col`로 지정한다.

### 실행 예시

```
python scripts/lq.py --input examples/lq.csv --industry 제조업 --national-label 전국 --total-label 전체 --measure 종사자수 --chart lq.png
```

결과 표와 차트는 LQ 내림차순으로 정렬한다.
