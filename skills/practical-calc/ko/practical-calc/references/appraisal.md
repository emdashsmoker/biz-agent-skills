# 사업 타당성 분석

사업에 드는 비용과 사업이 만드는 편익을 같은 시점의 가치로 바꾸어 비교한다. 결과 지표는 B/C 비율, NPV, IRR, 회수기간, 민감도 분석이다. 같은 계산을 재무성 분석에도 쓴다. 이때 편익 자리에 현금유입을, 비용 자리에 현금유출을 입력하고 B/C 비율은 수익성지수(PI), NPV는 FNPV로 표시한다.

## 용어

| 용어 | 정의 |
|---|---|
| 할인 기준연도 | 현재가치를 맞추는 연도이며 그 해 말 시점의 가치로 환산한다 |
| t | 연도 - 할인 기준연도 |
| 할인율 | 미래 금액을 현재가치로 바꿀 때 쓰는 연간 비율 |
| 편익, 비용 | 경제성 분석에서 사회 전체가 얻는 가치와 치르는 대가 |
| 현금유입, 현금유출 | 재무성 분석에서 사업 주체가 받고 내는 현금 |
| 사업 종료 연도 | 사업비가 투입되는 마지막 연도 |
| 회임기간 | 사업 종료 연도 다음 해부터 첫 편익이 생기기 전까지 편익이 없는 연수 |
| 편익 지속기간 | 첫 편익 연도부터 편익이 이어지는 연수 |
| 분석기간 | 첫 현금흐름 연도부터 마지막 현금흐름 연도까지이며 `analysis_end_year`를 주면 그 연도까지 |
| 잔존가치 | 분석기간이 끝날 때 남는 자산 가치이며 마지막 연도 비용에서 차감한다 |

## 산식

```
할인계수(t) = 1 / (1 + r)^t
편익 PV = 연도별 편익 x 할인계수의 합
비용 PV = 연도별 비용 x 할인계수의 합
B/C 비율 = 편익 PV / 비용 PV
NPV = 편익 PV - 비용 PV
IRR = 연도별 (편익 - 비용) / (1 + IRR)^t 의 합이 0이 되는 할인율
```

- 첫 편익 연도는 `사업 종료 연도 + 회임기간 + 1`이다. 사업이 2028년에 끝나고 회임기간이 2년이면 첫 편익은 2031년에 생긴다.
- 할인율이 도중에 바뀌면 전환 연도까지는 첫 할인율 r1로, 그 뒤 연도분만 새 할인율 r2로 누적 할인한다. 전환 연도(`after_year`)를 T라고 하면 T 이후 연도의 할인계수는 `(1 + r1)^-(T - 할인 기준연도) x (1 + r2)^-(연도 - T)`이다. 영국 재무부 Green Book의 체감 할인율 할인계수표도 같은 방식으로 계산되어 있다.
- IRR은 -90%에서 1,000% 사이에서 순편익 현재가치가 0이 되는 할인율을 모두 찾는다. 순현금흐름의 부호가 한 번만 바뀌면 IRR이 하나로 정해진다. 부호가 여러 번 바뀌어 IRR 후보가 여럿이면 스크립트가 후보를 모두 보여 주고 IRR 대신 NPV와 B/C 비율로 판단하도록 알린다.
- 할인 회수기간은 할인한 누적 순편익이 처음 0 이상이 되는 시점까지의 연수다. 단순 회수기간은 할인하지 않은 누적 순편익으로 같은 계산을 한다. 연수는 첫 현금흐름 연도의 시작부터 세고 회수가 일어나는 연도 안에서는 순편익이 연중 고르게 생긴다고 보고 직선 보간한다.
- 회수기간은 대안끼리 비교할 때 쓰는 보조 지표다. 사업 하나의 타당성은 B/C 비율, NPV, IRR로 판단한다.

## 판단 기준

| 지표 | 경제성 분석 | 재무성 분석 |
|---|---|---|
| 비율 지표 | B/C 비율 1.0 이상 | PI 1.0 초과 |
| 순현재가치 | NPV 0 이상 | FNPV 0 초과 |
| 내부수익률 | IRR이 사회적 할인율보다 큼 | IRR이 자본비용보다 큼 |

## 예비타당성조사 기준값

국내 예비타당성조사 방식으로 분석할 때 쓰는 값이다. 사회적 할인율은 3년마다 조정 여부를 검토하므로 분석 전에 최신 지침을 확인한다.

| 항목 | 기준 | 조항 |
|---|---|---|
| 사회적 할인율 | 4.5% | 제50조 |
| 철도, 수자원 사업 | 운영 30년까지 4.5%, 그 뒤 3.5% | 제50조 |
| 할인 기준연도 | 조사 착수 전년도 말 | 제49조 |
| 분석기간 | 사업기간 + 운영 30년(도로, 공항, 항만, 의료시설, 기타 대규모 건설), 철도 40년, 수자원 50년, 정보화와 기타 재정사업은 사업별 | 제49조 |
| 경제적 비용 | 부가가치세와 매몰비용 제외, 기회비용 포함 | 제45조 |
| 민감도 분석 변수 | 사업비, 운영비, 수요, 할인율 | 제51조 |
| 재무성 분석 | 실질 재무적 할인율 4.5%, 세금과 이자비용을 비용에 포함 | 제55조 |

철도나 수자원 사업은 `rate_switch`의 `after_year`에 운영 30번째 연도를 입력한다. 운영이 2031년에 시작하면 `after_year`는 2060이다.

## 입력 수집 순서

1. (기본 정보) 할인 기준연도, 사업 시작 연도, 사업기간, 할인율, 회임기간, 편익 지속기간
2. (편익 항목) 연도별 금액 또는 생성 규칙
3. (비용 항목) 연도별 금액 또는 생성 규칙

할인율을 입력하지 않으면 스크립트가 사회적 할인율 4.5%를 적용하고 확인 사항에 그 사실을 적는다. 한 사업 안에서 서로 독립된 성과물이 따로 편익을 내면 편익 항목마다 회임기간과 지속기간을 따로 받는다. 이때 항목별 편익의 합계가 같은 편익을 두 번 세지 않는지 확인한다. 값을 담은 파일(CSV, XLSX, PDF)을 받으면 값을 추출해 JSON 입력 파일로 옮기고 입력 요약 표에 추출한 값을 그대로 보인다.

## 입력 형식

```json
{
  "unit": "억원",
  "mode": "economic",
  "base_year": 2025,
  "discount_rate": 0.045,
  "rate_switch": {"after_year": 2060, "rate": 0.035},
  "cost_rules": [
    {"item": "총사업비", "total": 300, "start_year": 2026, "years": 3},
    {"item": "운영비", "annual": 12, "start_year": 2029, "end_year": 2058}
  ],
  "benefit_rules": [
    {"item": "이용자 시간 절감", "annual": 40, "project_end_year": 2028, "gestation": 0, "duration": 30, "growth": 0.01}
  ],
  "costs": [{"item": "잔존가치", "year": 2058, "amount": -20}],
  "benefits": [],
  "sensitivity": {"rate_delta": 0.01, "cost_changes": [-0.1, 0.1], "benefit_changes": [-0.1, 0.1]}
}
```

| 필드 | 필수 여부 | 내용 |
|---|---|---|
| `unit` | 선택 | 금액 단위 표기 |
| `mode` | 선택 | `economic`(기본값) 또는 `financial` |
| `base_year` | 필수 | 할인 기준연도 |
| `discount_rate` | 선택 | 할인율을 소수로 입력하며 4.5%는 0.045이고 생략하면 0.045 적용 |
| `rate_switch` | 선택 | `after_year` 다음 해부터 `rate` 적용 |
| `analysis_end_year` | 선택 | 분석 마지막 연도이며 그 뒤 현금흐름은 계산에서 제외 |
| `costs`, `benefits` | 선택 | 연도별 금액 목록 `{"item", "year", "amount"}` |
| `cost_rules`, `benefit_rules` | 선택 | 아래 생성 규칙 목록 |
| `sensitivity` | 선택 | 민감도 분석 변동폭이며 기본값은 할인율 ±1%p, 비용 ±10%, 편익 ±10% |

### 생성 규칙

연도별 금액을 일일이 받지 않고 규칙으로 만드는 방법이다.

- (균등 배분) `total`, `start_year`, `years`를 주면 `total / years`를 `start_year`부터 `years`년 동안 배정한다.
- (연간 반복) `annual`과 시작 연도, 종료 연도를 주면 매년 같은 금액을 배정한다. 시작 연도는 `start_year`로 주거나 `project_end_year`와 `gestation`으로 계산한다. 종료 연도는 `end_year`로 주거나 `duration`으로 계산한다.
- (증가율) 연간 반복 규칙에 `growth`를 주면 k번째 해 금액은 `annual x (1 + growth)^k`이며 첫해 k는 0이다.
- (잔존가치) 마지막 연도 비용에 음수 금액으로 입력한다. 스크립트는 음수 비용이 있는 연도를 확인 사항으로 알린다.

## 실행 예시

```
python scripts/appraisal.py --input examples/project.json --out appraisal_result.json --chart cumulative_npv.png
```

## 결과 보고

- (연차별 분석표) 연도, t, 할인계수, 비용, 비용 PV, 편익, 편익 PV, 순편익 PV와 합계
- (경제성 지표) 편익 PV, 비용 PV, B/C 비율, NPV, IRR, 할인 회수기간, 단순 회수기간
- (민감도 분석) 할인율, 비용, 편익을 바꾼 시나리오별 B/C 비율과 NPV
- (재현 정보) 입력 JSON과 실행 명령

민감도 분석의 비용 변동은 모든 비용 항목에 같은 비율로 적용된다. 사업비나 운영비 하나만 바꾸거나 수요를 바꾸려면 해당 값을 고친 입력 파일로 다시 계산한다.
