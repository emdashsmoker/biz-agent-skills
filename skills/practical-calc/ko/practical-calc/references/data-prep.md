# 입력 데이터 준비

사용자가 제출하는 자료는 엑셀 보고서 표, 통계포털에서 내려받은 파일, 회계 시스템 출력물, PDF 표, 대화창에 입력한 숫자처럼 형태가 제각각이다. 스크립트는 정해진 형식만 읽으므로 자료의 값은 그대로 두고 형태만 입력 형식에 맞게 바꾼다.

## 원칙

- 원본 파일은 고치지 않는다. 변환 결과는 새 파일로 저장한다.
- 변환은 pandas 코드로 하고 코드를 `prep_<도구 이름>.py` 같은 파일로 저장한다. 원본 파일과 이 코드가 있으면 제3자가 같은 입력 파일을 다시 만든다.
- 열 이름 변경, 긴 형식 변환처럼 형태만 바꾸는 작업은 코드에 남기면 충분하다. 단위 환산, 기호를 숫자로 바꾸기, 행 제외처럼 값이 달라지는 작업은 결과 보고의 입력 요약에도 적는다.
- 합계가 어느 열에 있는지, 단위가 무엇인지, 기호가 무슨 뜻인지는 표의 머리말과 주석에서 확인한다. 자료만으로 정할 수 없으면 사용자에게 묻고 값을 추정해 채우지 않는다.
- 변환 뒤에는 원본과 결과의 행 수와 주요 합계를 출력해 값이 누락되거나 두 번 세어지지 않았는지 확인한다.

## 작업 순서

1. (구조 파악) 시트 목록, 머리글 행 위치, 병합된 셀, 표 위아래의 단위 표기, 주석, 합계 행과 소계 행을 확인한다.
2. (열 대응) 아래 도구별 입력 규격의 열이나 필드에 원본의 어느 열이 해당하는지 정한다.
3. (형태 변환) 연도나 지역이 열 방향으로 펼쳐진 넓은 형식은 `melt`로 긴 형식으로 바꾼다.
4. (값 정리) 아래 숫자 정리 규칙을 적용한다.
5. (필터와 집계) 필요한 행만 남기고 같은 키가 여러 번 나오면 합산 여부를 정한다. 소계 행과 합계 행이 섞여 있으면 둘 중 하나만 남긴다.
6. (저장과 검산) CSV(UTF-8)나 JSON으로 저장하고 행 수와 합계를 원본과 비교해 출력한다.
7. (계산) 저장한 파일로 스크립트를 실행한다.

## 숫자 정리

| 원본 표기 | 처리 |
|---|---|
| `1,234` | 스크립트가 쉼표를 천 단위 구분 기호로 보고 자동 제거 |
| `(1,234)` | 회계식 음수 표기로 보고 -1,234로 자동 변환 |
| `12.5%` | JSON의 비율 필드(할인율, 시장규모 비율 등)는 소수 0.125로, `hhi.py --shares`의 점유율 열은 12.5로 변환 |
| `-`, `X`, `…` 같은 기호 | 표 주석에서 뜻을 확인한 뒤 0으로 바꾸거나 행을 제외 |
| `1.2억`처럼 단위가 붙은 값 | 숫자와 단위를 분리하고 한 단위로 통일 |
| `2024년`, `2024p` 같은 연도 | 정수 연도로 바꾸고 잠정치 표시는 입력 요약에 기록 |
| `1.234,5` 같은 소수점 쉼표 | 스크립트의 쉼표 규칙과 충돌하므로 전처리에서 소수점 표기로 변환 |

스크립트는 쉼표, 괄호 음수, 앞뒤 공백만 자동 처리한다. 퍼센트 기호나 기호가 남아 있으면 계산을 멈추고 해당 값을 알린다.

## 도구별 입력 규격

열 이름은 대부분 옵션으로 바꿀 수 있다(예: `--year-col`). 자세한 필드는 각 참조 문서의 입력 형식에 있다.

| 스크립트 | 형식 | 필요한 열 또는 필드 |
|---|---|---|
| `cagr.py` | CSV, XLSX 또는 옵션 값 | `year`, `value` |
| `deflate.py` | CSV, XLSX | `year`, `nominal`, `index` |
| `appraisal.py` | JSON | `base_year`와 `costs`, `benefits`, `cost_rules`, `benefit_rules` 중 필요한 항목 |
| `ahp.py` | JSON | `criteria`, `respondents[].matrix` |
| `pl_summary.py` | CSV, XLSX | `item`과 기간별 열 |
| `capex.py` | JSON | `periods` 또는 `assets` |
| `bep.py` | JSON | `fixed_cost`, `products[]` |
| `variance.py mix` | CSV, XLSX | `item`, `budget_qty`, `budget_price`, `actual_qty`, `actual_price` |
| `variance.py accuracy` | CSV, XLSX | `period`, `forecast`, `actual` |
| `io_impact.py` | CSV, XLSX | `item`, `amount`, `output_coef`, `va_coef`, `emp_coef` |
| `lq.py` | CSV, XLSX | `region`, `industry`, `value` |
| `hhi.py` | CSV, XLSX | `firm`, `value` |
| `market_size.py` | JSON | `approaches` |

## 자료 유형별 변환

- (통계포털 표) 내려받은 파일을 열어 머리글 행, 구분 열, 합계 행의 실제 배치를 확인한 뒤 위 작업 순서를 적용한다. 열 이름과 구분 값은 파일에 적힌 그대로 코드에 옮긴다.
- (재무제표) 전자공시나 회계 시스템에서 받은 손익계산서는 계정 이름을 `pl_summary.py`가 인식하는 이름으로 바꾸고 하위 계정은 제외한다. 괄호 음수와 쉼표는 그대로 두어도 된다.
- (산업연관표) 한국은행 계수표에서 분석할 상품군의 계수를 찾아 상품군별 한 행으로 모은다. 역행렬 형태의 생산유발계수표는 상품군 열의 합계를 계수로 쓴다.
- (PDF와 이미지 표) 표를 추출한 뒤 추출한 표를 입력 요약에 그대로 보인다. 글자 인식으로 읽은 숫자는 합계가 원본 표의 합계와 맞는지 확인하고 맞지 않으면 사용자에게 해당 숫자를 묻는다.
- (대화창에 입력한 숫자) 값과 단위를 그대로 옮겨 입력 파일을 만들고 입력 요약에 옮긴 값을 보인다.
