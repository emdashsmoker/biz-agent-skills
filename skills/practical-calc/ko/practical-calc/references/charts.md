# 차트 규칙

차트 하나는 메시지 하나를 전달한다. 먼저 차트가 보여 줄 메시지를 한 문장으로 정하고 그 메시지가 어떤 비교인지 가린 뒤 차트 형태를 고른다. 스크립트의 `--chart` 옵션은 아래 규칙을 적용한 기본 차트를 만든다.

## 차트 선택

| 비교 유형 | 메시지 예 | 차트 형태 |
|---|---|---|
| 구성비 | A가 전체의 40%를 차지한다 | 원형 또는 누적 막대 |
| 항목 비교 | 지역 2의 LQ가 가장 높다 | 가로 막대 |
| 시계열 | 매출이 5년 동안 꾸준히 늘었다 | 세로 막대 또는 선 |
| 상관 | 투자액이 클수록 매출이 크다 | 산점도 |
| 행렬 | 업종별, 지역별 분포가 다르다 | 히트맵 또는 버블 |
| 증감 분해 | 물량 증가가 매출 증가의 대부분이다 | 폭포 |

## 도구별 기본 차트

| 스크립트 | 차트 | 메시지 |
|---|---|---|
| `cagr.py`, `deflate.py` | 세로 막대 | 연도별 값의 변화 |
| `appraisal.py` | 세로 막대 | 누적 순편익 PV가 0을 넘는 시점 |
| `ahp.py` | 가로 막대 | 기준별 가중치 순위 |
| `pl_summary.py` | 폭포 | 영업이익 변동의 요인 |
| `capex.py` | 세로 막대 | 기간별 CAPEX |
| `bep.py` | 선 | 매출액선과 총비용선이 만나는 판매량 |
| `variance.py` | 폭포 | 가격, 구성, 물량 효과의 크기 |
| `io_impact.py` | 가로 막대 | 상품군별 생산유발액 순위 |
| `lq.py` | 가로 막대 | 지역별 LQ 순위와 기준선 1.0 |
| `hhi.py` | 가로 막대 | 기업별 점유율 순위 |
| `market_size.py` | 가로 막대 | TAM, SAM, SOM 규모 |

## 스타일

- (색) 기본 데이터는 파스텔 네이비 #6B8EC2, 강조와 감소는 #F5A962, 합계 막대는 #4F6F9E, 기준에 못 미치는 항목은 #BCC9E2로 칠한다. 여러 계열은 #4F6F9E, #6B8EC2, #93AAD3, #BCC9E2 순서로 쓴다. 색만으로 의미를 전하지 않도록 데이터 레이블과 부호를 함께 표시한다.
- (글꼴) 나눔고딕(NanumGothic) 굵은 글씨 14pt를 쓰고 모든 텍스트를 굵게 한다. 글자색은 #1A1A1A다.
- (배경) 흰색을 쓰고 그림자, 그라데이션, 입체 효과는 쓰지 않는다.
- (제목) 차트 안에는 제목을 표시하지 않는다. 메시지 문장은 보고서 본문의 차트 제목으로 쓴다.
- (축과 선) 격자선, 범례, 차트 테두리를 쓰지 않는다. 가로 막대는 왼쪽 축선만, 세로 막대와 폭포는 아래쪽 축선만, 선과 산점도는 왼쪽과 아래쪽 축선을 남긴다.
- (레이블) 값은 데이터 레이블로 직접 표시한다. 막대가 15개를 넘으면 처음, 끝, 최솟값, 최댓값, 음수에서 양수로 바뀌는 지점만 표시하여 겹침을 막는다.
- (정렬) 항목 비교는 큰 값이 위에 오도록 내림차순으로, 시계열은 시간 순서로 배치한다.
- (범주 수) 구성비 차트는 범주가 6개 이상이면 상위 4-5개와 기타로 묶는다.

## 검수

차트 파일을 만든 뒤 이미지를 열어 아래 항목을 확인하고 문제가 있으면 고쳐 다시 그린다.

- 글자가 잘리거나 영역 밖으로 나가지 않는가
- 레이블과 막대, 레이블끼리 겹치지 않는가
- 한글이 깨지지 않는가
- 가장자리 여백과 요소 간격이 고른가
- 차트의 숫자가 계산 결과 표와 같은가
- 메시지와 관계없는 요소가 남아 있지 않은가

## 기본 차트에 없는 형태

원형, 산점도, 히트맵처럼 스크립트가 만들지 않는 차트는 matplotlib 코드를 새로 작성하되 `scripts/chart.py`의 `PALETTE`, `SERIES_COLORS`, `apply_style()`을 불러와 같은 스타일을 적용한다. 레이블이 겹치면 레이블 수를 줄이거나 adjustText 패키지로 위치를 조정한다.
