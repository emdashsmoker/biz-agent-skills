# 차이 분석

예산이나 전기 실적과 이번 실적의 차이를 가격 효과, 구성 효과, 물량 효과로 나눈다. 예측이 실적과 얼마나 맞았는지도 같은 스크립트로 계산한다.

## 가격, 구성, 물량 효과

### 용어

| 용어 | 정의 |
|---|---|
| 기준값(B) | 비교 기준이 되는 예산 또는 전기 실적 |
| 실적(A) | 이번 기간 실적 |
| 수량(Q), 단가(P) | 항목별 판매량과 단위당 금액 |
| 기준 구성비 | 항목별 기준 수량 / 기준 수량 합계 |
| 가격 효과 | 단가 변화가 만든 차이 |
| 구성 효과 | 전체 수량 안에서 항목 비중이 바뀌어 생긴 차이 |
| 물량 효과 | 전체 수량이 늘거나 줄어 생긴 차이 |

### 산식

항목 i마다 아래 값을 구하고 전 항목을 더한다.

```
가격 효과 = (실적 단가 - 기준 단가) x 실적 수량
구성 효과 = (실적 수량 - 실적 수량 합계 x 기준 구성비) x 기준 단가
물량 효과 = (실적 수량 합계 x 기준 구성비 - 기준 수량) x 기준 단가
총차이 = 실적 단가 x 실적 수량 - 기준 단가 x 기준 수량
```

- 세 효과를 더하면 총차이와 정확히 같다. 스크립트는 항목마다 이 등식을 확인하고 맞지 않으면 멈춘다.
- 구성 효과와 물량 효과를 더한 값은 `(실적 수량 - 기준 수량) x 기준 단가`로 흔히 판매량 차이라고 부른다.
- 항목이 하나면 구성 효과는 0이다.
- `--basis margin`으로 단가 열에 단위당 이익을 입력하면 이익 차이를 같은 방식으로 나눈다. 기본값 `revenue`는 매출 차이를 나눈다.
- 기준 수량이 0이고 기준 단가가 비어 있는 신규 항목은 기준 단가를 실적 단가로 둔다. 신규 항목의 차이는 구성 효과로 잡힌다.
- 실적 수량이 0이고 실적 단가가 비어 있는 중단 항목은 실적 단가를 기준 단가로 둔다.
- 인건비 차이는 직급이나 부서를 항목으로, 인원을 수량으로, 1인당 평균 인건비를 단가로 입력한다. 이때 물량 효과는 인원 효과, 구성 효과는 직급 구성 효과, 가격 효과는 1인당 인건비 효과가 된다.

### 입력 수집 순서

1. 비교 기준(예산 또는 전기)과 분석 대상(매출 또는 이익)
2. 항목별 기준 수량과 기준 단가
3. 항목별 실적 수량과 실적 단가

### 입력 형식

```
item,budget_qty,budget_price,actual_qty,actual_price
제품 A,1000,50,1100,48
제품 B,500,80,450,82
제품 C,0,,120,60
```

열 이름이 다르면 `--item-col`, `--bq-col`, `--bp-col`, `--aq-col`, `--ap-col`로 지정한다.

### 실행 예시

```
python scripts/variance.py mix --input examples/sales_variance.csv --chart variance_bridge.png
```

차트는 기준값에서 세 효과를 거쳐 실적에 이르는 폭포 차트다.

### 차이 설명 작성

차이가 큰 항목마다 아래 내용을 두세 문장으로 적는다.

- 차이의 방향(이익에 유리 또는 불리)과 금액, 비율
- 세 효과 가운데 차이를 만든 요인과 그 금액
- 요인의 원인이 된 사건(가격 인하, 신제품 출시 등)과 일회성 여부
- 필요한 후속 조치(추가 조사, 전망 수정 등)

원인 자리에는 결과 지표와 다른 사건이나 변수를 적는다. 금액이 큰 요인부터 적고 반대 방향으로 상쇄한 요인이 있으면 함께 적는다.

## 예측 정확도

```
정확도(기간) = 1 - |실적 - 예측| / |실적|
MAPE = 기간별 |실적 - 예측| / |실적| 의 평균
```

- 실적이 0인 기간은 비율을 정의할 수 없어 MAPE 계산에서 제외하고 목록을 알린다.
- 입력은 `period`, `forecast`, `actual` 세 열이다.

```
python scripts/variance.py accuracy --input examples/forecast.csv
```
