# AHP 가중치

AHP(계층화 분석법)는 평가 기준을 두 개씩 짝지어 상대적 중요도를 묻고 그 답으로 기준별 가중치를 구하는 방법이다. 응답의 앞뒤가 맞는지는 일관성 비율(CR)로 확인한다. 예비타당성조사의 종합평가도 이 방법으로 경제성, 정책성, 지역균형성장 등의 가중치와 사업 시행 대안의 종합 점수를 구한다.

## 용어

| 용어 | 정의 |
|---|---|
| 쌍대비교 행렬 | i행 j열에 기준 i가 기준 j보다 몇 배 중요한지를 적은 정사각 행렬이며 j행 i열에는 그 역수가 들어간다 |
| 가중치 | 쌍대비교 행렬의 최대 고유값에 대응하는 고유벡터를 합이 1이 되도록 나눈 값 |
| 최대 고유값 | 행렬의 가장 큰 고유값이며 응답이 완전히 일관되면 비교 항목 수 n과 같다 |
| CI | 일관성 지수 = (최대 고유값 - n) / (n - 1) |
| RI | 무작위로 채운 행렬의 평균 CI |
| CR | 일관성 비율 = CI / RI |

## 비교 척도

| 값 | 표현 | 의미 |
|---|---|---|
| 1 | 동등 | 두 기준이 같은 정도로 중요 |
| 3 | 약간 중요 | 경험과 판단이 한쪽을 약간 더 선호 |
| 5 | 중요 | 경험과 판단이 한쪽을 강하게 선호 |
| 7 | 매우 중요 | 한쪽을 훨씬 강하게 선호하며 실제로 우세함이 입증됨 |
| 9 | 극히 중요 | 한쪽을 선호하는 근거가 가능한 가장 높은 수준 |
| 2, 4, 6, 8 | 중간값 | 인접한 두 판단 사이 |

행의 기준이 열의 기준보다 덜 중요하면 역수(예: "1/3")를 적는다.

## 산식

- 응답자별로 가중치, 최대 고유값, CI, CR을 구한다.
- RI는 Saaty의 값을 쓴다. n이 3부터 10까지일 때 RI는 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45, 1.49다. n이 2 이하면 CR은 0이다.
- 비교 항목이 10개를 넘으면 스크립트는 계산하지 않는다. 기준을 상위 기준과 하위 기준으로 나누어 단계별로 입력한다.
- 여러 응답자의 판단은 행렬 원소별 기하평균으로 합쳐 집단 행렬을 만들고 집단 행렬에서 가중치와 CR을 다시 구한다.
- 대안 평가를 입력하면 기준마다 대안 쌍대비교로 대안 우선순위를 구한다. 대안의 종합 점수는 기준 가중치 x 해당 기준의 대안 우선순위를 모든 기준에 걸쳐 더한 값이다.
- 기준이 여러 단계로 나뉘면 단계마다 스크립트를 실행하고 하위 기준의 최종 가중치는 상위 기준 가중치 x 하위 기준 가중치로 구한다.

## 판단 기준

| 항목 | 기준 | 근거 |
|---|---|---|
| 일관성 허용 범위 | CR 0.1 이하 | Saaty(1987) |
| 예비타당성조사 환류 조건 | CR 0.15 초과 시 재설문 등 환류 가능 | 예비타당성조사 수행 총괄지침 제75조 |
| 예비타당성조사 사업 타당성 | 사업 시행 대안의 종합 점수 0.5 이상 | 예비타당성조사 수행 총괄지침 제53조 |

`cr_threshold`의 기본값은 0.1이다. 예비타당성조사 방식을 따르면 0.15를 입력한다. `exclude_inconsistent`를 `true`로 두면 기준을 넘는 응답자를 집단 행렬 계산에서 제외한다. 기본값 `false`에서는 모든 응답자를 합치고 기준을 넘는 응답자 목록만 알린다.

## 입력 수집 순서

1. 평가 기준 목록
2. 응답자별 기준 쌍대비교
3. 대안 평가가 필요하면 대안 목록과 기준별, 응답자별 대안 쌍대비교
4. CR 허용 기준과 비일관 응답 제외 여부

## 입력 형식

행렬의 대각선은 1이고 위쪽 삼각형만 채우면 된다. 아래쪽 삼각형은 `null`로 두면 역수로 자동 채워진다. 아래쪽에 값을 적으면 위쪽 값의 역수인지 확인한다.

```json
{
  "criteria": ["경제성", "정책성", "지역균형"],
  "cr_threshold": 0.1,
  "exclude_inconsistent": false,
  "respondents": [
    {"id": "R1", "matrix": [[1, 2, 3], [null, 1, 2], [null, null, 1]]},
    {"id": "R2", "matrix": [[1, "1/2", 2], [null, 1, 3], [null, null, 1]]}
  ],
  "alternatives": ["사업 시행", "사업 미시행"],
  "alternative_judgments": {
    "경제성": [{"id": "R1", "matrix": [[1, 2], [null, 1]]}, {"id": "R2", "matrix": [[1, 1], [null, 1]]}],
    "정책성": [{"id": "R1", "matrix": [[1, 3], [null, 1]]}, {"id": "R2", "matrix": [[1, 2], [null, 1]]}],
    "지역균형": [{"id": "R1", "matrix": [[1, 2], [null, 1]]}, {"id": "R2", "matrix": [[1, 3], [null, 1]]}]
  }
}
```

## 실행 예시

```
python scripts/ahp.py --input examples/ahp.json --chart ahp_weights.png
```

## 결과 보고

- (응답자별 결과) 최대 고유값, CI, CR, 일관성 충족 여부, 기준별 가중치
- (집단 가중치) 가중치 내림차순 표와 집단 행렬의 CR
- (대안 평가) 기준별 대안 우선순위와 대안별 종합 점수
- (확인 사항) CR 기준을 넘은 응답자 목록
