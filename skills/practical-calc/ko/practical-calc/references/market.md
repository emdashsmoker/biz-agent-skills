# 시장 분석

시장 안에서 판매가 몇몇 기업에 얼마나 몰려 있는지는 HHI와 CRk로 재고 시장이 얼마나 큰지는 TAM, SAM, SOM으로 추정한다. 두 계산 모두 결과가 시장 정의에 따라 달라지므로 계산 전에 제품 범위와 지역 범위를 정하고 보고서에 적는다.

## 시장집중도

### 산식

```
HHI = 기업별 시장점유율(%) 제곱의 합
CRk = 점유율 상위 k개 기업의 점유율 합
결합 후 HHI 증가분 = 2 x 기업 a 점유율 x 기업 b 점유율
```

- HHI는 0에서 10,000 사이 값이다. 한 기업이 시장 전체를 차지하면 10,000이다.
- 매출액을 입력하면 입력 기업 매출 합계를 100%로 보고 점유율을 계산한다. 점유율(%)을 입력할 때는 `--shares`를 붙인다.
- 점유율 합계가 100%에 못 미치면 나머지 기업의 구성을 알 수 없다. 스크립트는 나머지를 아주 작은 기업 여럿으로 볼 때의 값(하한)과 한 기업으로 볼 때의 값(상한)을 범위로 보여 준다.
- `--k`로 CRk의 k를 정한다. 기본값은 1, 3, 4다.
- `--merge "A사,B사"`를 주면 두 기업이 합쳐질 때의 HHI 증가분과 결합 후 HHI를 계산한다.

### 참고 기준

아래 기준은 기업결합 심사에서 쓰는 값이다. 시장 구조를 설명할 때 인용하면 어느 기관의 어떤 기준인지 함께 적는다.

| 기관 | 기준 |
|---|---|
| 공정거래위원회 기업결합 심사기준 | 수평결합에서 HHI 1,200 미만, HHI 1,200 이상 2,500 미만이면서 증가분 250 미만, HHI 2,500 이상이면서 증가분 150 미만이면 경쟁 제한 우려가 낮은 범위로 봄 |
| 공정거래위원회 기업결합 심사기준 | 상위 3개 이하 사업자 점유율 합계 75% 이상 등 추가 조건을 갖추면 경쟁 제한성을 추정 |
| 미국 법무부와 연방거래위원회 2023 기업결합 지침 | HHI 1,800 초과를 고집중 시장으로 보고 증가분 100 초과 결합을 경쟁 제한 추정 대상으로 봄 |

### 입력 수집 순서

1. 시장 정의(제품 범위, 지역 범위, 기준 연도)
2. 기업별 매출액 또는 점유율과 자료 출처
3. 결합을 검토할 기업이 있으면 두 기업 이름

### 입력 형식

```
firm,value
A사,32
B사,25
C사,18
```

### 실행 예시

```
python scripts/hhi.py --input examples/shares.csv --shares --merge "C사,D사" --chart shares.png
```

## 시장규모

### 용어

| 용어 | 정의 |
|---|---|
| TAM | 제품이나 서비스 범주 전체에 대한 연간 수요 금액 |
| SAM | TAM 가운데 사업의 제품, 지역, 판매 경로로 실제 공급할 수 있는 부분 |
| SOM | SAM 가운데 계획 기간 안에 경쟁 상황과 영업 역량을 감안해 확보할 수 있다고 보는 부분 |
| 하향식 추정 | 공표된 전체 시장 규모에서 출발해 비율을 차례로 곱하는 방식 |
| 상향식 추정 | 고객 수, 고객당 지출액 같은 단위 값에서 출발해 곱해 올라가는 방식 |

### 산식

추정 방식마다 단계를 순서대로 적는다. 첫 단계 값이 출발 값이고 그다음 단계부터는 앞 단계까지의 누적 곱에 곱한다. TAM 단계가 끝난 시점의 누적 곱이 TAM, SAM 단계가 끝난 시점의 누적 곱이 SAM, SOM 단계가 끝난 시점의 누적 곱이 SOM이다.

- 단계는 TAM, SAM, SOM 순서로 적고 각 시장 구분에 단계가 하나 이상 있어야 한다.
- 비율은 소수로 적는다. 25%는 0.25다.
- 상향식 추정은 단계를 곱한 결과가 금액이 되도록 단위를 맞춘다. 고객 수(개사) x 고객당 연간 지출(억원)은 억원이 된다.
- 각 단계의 `source`에 자료 출처나 가정의 근거를 적는다. 근거가 없는 비율은 가정으로 표시하고 민감도를 보려면 값을 바꾼 입력 파일로 다시 계산한다.
- 두 가지 추정 방식을 입력하면 시장 구분별 차이를 계산한다. 차이가 크면 차이를 만든 단계를 찾아 가정을 다시 확인한다.
- `projection`을 주면 각 시장 규모에 일정한 연평균 성장률을 적용해 목표 연도 규모를 구한다. 성장률도 출처를 적는다.

### 입력 수집 순서

1. 시장 정의(제품 범주, 지역, 기준 연도)와 금액 단위
2. 하향식 추정의 출발 값과 비율, 각 출처
3. 상향식 추정의 단위 값과 비율, 각 출처
4. 목표 연도 규모가 필요하면 연평균 성장률과 연도

### 입력 형식

```json
{
  "unit": "억원",
  "approaches": {
    "하향식": [
      {"stage": "TAM", "name": "국내 업무용 소프트웨어 시장", "value": 50000, "source": "시장 조사 보고서"},
      {"stage": "SAM", "name": "대상 업종 비중", "value": 0.25},
      {"stage": "SOM", "name": "5년 내 목표 점유율", "value": 0.05}
    ],
    "상향식": [
      {"stage": "TAM", "name": "대상 기업 수(개사)", "value": 80000},
      {"stage": "TAM", "name": "기업당 연간 지출(억원)", "value": 0.6},
      {"stage": "SAM", "name": "영업 가능 지역 비중", "value": 0.55},
      {"stage": "SOM", "name": "연간 도달 고객 비중", "value": 0.06}
    ]
  },
  "projection": {"start_year": 2025, "end_year": 2030, "growth_rate": 0.08}
}
```

### 실행 예시

```
python scripts/market_size.py --input examples/market.json --chart market.png
```
