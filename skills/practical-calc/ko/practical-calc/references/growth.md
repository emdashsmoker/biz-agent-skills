# 성장률과 실질가격 환산

두 도구는 연도별 값을 다룬다. CAGR은 두 시점 사이의 연평균 성장 속도를 구하고 실질가격 환산은 물가 변동분을 걷어 내어 서로 다른 연도의 금액을 같은 가격 수준으로 맞춘다.

## CAGR

CAGR(연평균 성장률)은 시작값이 매년 같은 비율로 커져 종료값에 도달했다고 볼 때의 연간 성장률이다.

```
CAGR = (종료값 / 시작값) ^ (1 / n) - 1
n = 종료 연도 - 시작 연도
```

- n은 두 시점 사이의 연수다. 2020년 값과 2024년 값을 비교하면 관측값은 5개이고 n은 4다.
- 시작값이 0 이하이거나 종료값이 음수이면 CAGR을 정의할 수 없다. 스크립트는 이 경우 계산하지 않고 원인을 알린다.
- 간격이 연 단위가 아니면 `--years`로 기간을 직접 입력한다. 30개월이면 2.5를 입력한다.
- 시계열 파일을 입력하면 가장 이른 연도와 가장 늦은 연도로 CAGR을 구하고 전년 대비 증감률 표를 함께 출력한다.

### 입력 수집 순서

1. 시작값과 종료값
2. 시작 연도와 종료 연도

시계열 전체가 있으면 `year`, `value` 두 열의 CSV나 XLSX로 받는다. 열 이름이 다르면 `--year-col`, `--value-col`로 지정한다.

### 실행 예시

```
python scripts/cagr.py --start-value 1200 --end-value 1820 --start-year 2020 --end-year 2024
python scripts/cagr.py --input examples/series.csv --chart cagr.png
```

### 결과 보고

계산 과정 표를 먼저 보이고 결과값은 백분율로 코드 블록에 따로 적어 바로 복사할 수 있게 한다.

## 실질가격 환산

명목값은 해당 연도 가격으로 잰 금액이고 실질값은 가격 기준연도의 가격으로 다시 잰 금액이다. 물가가 오른 해의 명목값은 실제 물량 변화보다 크게 보이므로 연도 간 비교에는 실질값을 쓴다.

```
실질값(t) = 명목값(t) x 가격지수(가격 기준연도) / 가격지수(t)
```

- 가격지수는 명목값의 성격에 맞춰 고른다. 예비타당성조사 수행 총괄지침 제49조는 비용 보정에 건설투자 GDP 디플레이터를, 편익 보정에 소비자물가지수를 원칙으로 쓰고 다른 지수를 쓰면 근거를 적도록 한다.
- 국내 물가지수와 디플레이터는 한국은행 경제통계시스템(ECOS)에서 받는다.
- 가격 기준연도의 지수가 입력 자료에 없으면 스크립트는 계산하지 않고 알린다.
- 결과에는 명목 CAGR과 실질 CAGR이 함께 나온다. (1 + 명목 CAGR) / (1 + 실질 CAGR) - 1은 같은 기간 가격지수의 연평균 상승률과 같다.

### 입력 형식

`year`, `nominal`, `index` 세 열의 CSV나 XLSX를 쓴다. 열 이름이 다르면 `--year-col`, `--value-col`, `--index-col`로 지정한다.

```
year,nominal,index
2024,121,106.0
2025,130,108.3
```

### 실행 예시

```
python scripts/deflate.py --input examples/nominal.csv --base-year 2025 --chart real.png
```
