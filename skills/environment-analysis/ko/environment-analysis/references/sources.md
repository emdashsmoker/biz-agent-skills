# 자료 경로와 출처 검증

모든 모듈에 공통으로 적용하는 자료 수집, 출처 품질, 검증 강도, 계산 규칙이다. 출처 표기 형식은 references/writing.md에 있다.

## 지식 원천

- 사실은 사용자 제출 자료, 이번 작업에서 직접 조회한 웹 페이지, 연결 시스템에서 조회한 자료에서만 가져온다
- 세 경로에 없는 내용은 모델 자체 지식으로 채우지 않고 확인되지 않았다고 적는다
- 모든 계산은 코드로 하고 출처에 적힌 수치도 코드로 검산한다
- 웹 자료의 출처는 정보가 실린 하위 페이지의 전체 주소로 적는다. 상위 도메인만 적으면 제3자가 해당 정보를 찾을 수 없다

## 자료 경로

| 경로 | 예 | 적용 기준 |
|---|---|---|
| 웹검색과 페이지 조회 | 정부 발표, 공식 통계, 연구 보고서, 학술 논문 | 공개 자료 품질 |
| 사용자 제출 파일 | 보고서, 통계 추출본, 유료 DB 추출본, 사내 문서 | 문서 성격에 따라 공개 자료 품질이나 내부 자료 품질 |
| 연결 시스템 | MCP 커넥터(문서 도구, 메일, 메신저, 일정), 공공 데이터 API, 사내 DB와 데이터 웨어하우스, 지식 그래프 | 내부 자료 품질과 내부 자료 보안, 공개 API는 공개 자료 품질 |

### 검색엔진으로 찾기 어려운 자료

| 자료 | 주로 쓰는 경로 |
|---|---|
| 국가 연구개발 사업과 과제 정보 | 국가 연구개발 정보 시스템의 공개 API, 사용자 추출 파일 |
| 공식 통계 세부표 | 통계 기관 API, 통계 포털 추출 파일 |
| 기업 공시와 재무 | 공시 시스템 API |
| 특허 | 특허청 DB, 공개 특허 검색 서비스, 사용자 추출 파일 |
| 논문 | 학술 DB API, 사용자 추출 파일 |
| 기업 연구개발비 | 연구개발활동 조사 통계, 산업별 실태조사, 기업 공시 |
| 벤처 투자 | 협회와 정부 통계, 유료 투자 DB의 사용자 추출 파일 |
| 내부 역량 자료 | 사내 문서 시스템, 사내 DB, 사용자 제출 파일 |

### 경로 사용 규칙

- 작업을 시작할 때 쓸 수 있는 커넥터, API, DB를 확인한다. 필요한 경로가 없으면 필요한 자료 목록을 정리해 사용자에게 한 번에 요청한다
- 자료원마다 이용 약관을 따른다. 인증키 발급, 호출 제한, 재배포 제한, 출처표시 조건(공공누리 유형 등)이 해당한다. 약관과 요금 체계는 자주 바뀌므로 이용 시점의 공식 안내로 확인한다
- 인증키, 토큰, 비밀번호는 산출물, 로그, 출처 표기에 남기지 않는다
- 자료원이 금지한 방식의 대량 수집은 하지 않는다
- 받지 못한 자료를 다른 경로의 추정으로 채우지 않고 미확인으로 둔다
- DB에서 뽑은 건수와 금액(과제, 특허, 논문, 투자 건 등)은 DB명, 검색 조건, 조회일을 출처 표기에 함께 적는다. 제3자가 같은 조건으로 다시 조회할 수 있어야 한다

### 구조가 복잡한 DB 탐색

국가 연구개발 정보 시스템, 투자 DB, 특허 DB, 통계 포털 세부표, 사내 DB 등 구조가 복잡한 DB는 DB마다 항목 구성, 분류 체계, 검색 방식이 다르고 구조가 개편되기도 한다. 이 스킬의 지침만으로는 DB별 조회 방법을 정할 수 없으므로 사용자와 단계별로 확인하며 탐색한다. 주제와 무관한 자료가 섞였는지, 필요한 자료가 빠졌는지는 주제를 아는 사용자가 가장 정확히 판단한다.

- (조건 제안) DB의 공식 안내, API 문서, 사용자가 준 추출 파일로 항목과 분류 체계를 파악한 뒤 검색어, 기간, 분류, 제외 기준을 사용자에게 제안한다
- (표본 확인) 제안한 조건으로 먼저 소량을 조회해 건수와 대표 결과 몇 건을 보여준다. 결과가 주제와 맞지 않으면 사용자와 조건을 고쳐 다시 조회한다
- (추출) 사용자가 조건에 동의하면 전체를 추출한다. 최종 조건과 조회일은 출처 표기에 적는다
- (사용자 조회) 로그인이나 유료 이용이 필요한 DB는 사용자에게 조회 조건을 안내하고 추출 파일을 받는다. 파일의 항목 의미나 단위가 불분명하면 사용자에게 확인한다

## 검색 요령

- 한국어 웹과 영어 웹을 모두 검색한다
- 여러 단어를 묶은 긴 검색어보다 짧은 핵심어가 더 나은 결과를 주는 경우가 많다
- 재인용 페이지보다 원 발행처 페이지를 찾아 인용한다
- 사내 기밀이나 개인정보는 웹 검색어에 쓰지 않는다

## 공개 자료 품질

공개 자료의 품질은 아래 구조적 기준으로 판단한다. 매체의 정치 성향과 브랜드 인지도는 판단 기준으로 쓰지 않는다.

| 기준 | 고품질 신호 | 저품질 신호 |
|---|---|---|
| 편집과 사실 확인 절차 | 편집진과 검증 절차가 있는 발행 | 편집진과 검증 절차가 없는 자가 발행 |
| 발행 주체 독립성 | 분석 대상과 이해관계가 없는 제3자 발행 | 홍보, 광고, 자기 홍보 목적의 당사자 발행 |
| 자료 유형 | 원자료를 직접 생산한 1차 자료 | 출처가 불분명한 2차 가공이나 재인용 |
| 검증 가능성 | 원문, 방법론, 표본, 산출 근거 추적 가능 | 근거 추적이 불가능하고 단정만 제시 |
| 전문성과 동료평가 | 동료평가나 전문기관의 공식 발간 | 익명 작성, 전문성 미확인 |
| 자동생성 여부 | 사람 저자와 편집 책임이 확인됨 | 언어모델 자동생성으로 추정되는 검증 불가 콘텐츠 |

기준을 많이 충족할수록 고품질이다. 검증이 불가능하거나 자동생성으로 추정되는 자료는 다른 기준을 충족해도 저품질로 본다.

### 등급별 처리

- (고품질) 판별 기준을 대부분 충족한다. 우선 인용한다
- (한계적) 쓰임에 따라 조건부로 쓸 수 있다. 원출처를 추적하거나 교차 확인한 뒤 인용한다
- (저품질) 검증이 불가능하거나 결격 사유가 뚜렷하다. 인용하지 않고 없는 자료로 취급하며 이 자료에만 기대는 주장은 쓰지 않는다

### 고품질 유형

아래 유형 목록은 예시이며 목록에 없다고 저품질은 아니다. 목록에 없는 자료는 판별 기준으로 개별 판단한다.

| 유형 | 예 |
|---|---|
| 정부와 공공기관 | 중앙부처, 지방자치단체와 소속기관의 공식 발간물과 보도자료, 국가승인통계, 법령 정보 |
| 의회와 감사기관 | 국회예산정책처, 국회입법조사처, 국회미래연구원, 감사원 보고서 |
| 국책연구기관과 전문기관 | 한국개발연구원, 대외경제정책연구원, 산업연구원, 과학기술정책연구원, 정보통신정책연구원, 한국과학기술기획평가원, 소프트웨어정책연구소, 한국지능정보사회진흥원, 정보통신기획평가원, 한국전자통신연구원, 한국과학기술정보연구원, 한국산업기술기획평가원 등 |
| 학술 | 동료평가 학술지 논문과 학위논문. 사전공개 논문은 미검증 자료로 보고 제한적으로 활용하며 원문을 학술 검색 서비스에서 직접 확인 |
| 특허와 표준 | 각국 특허청 공보, WIPO 자료, 국내외 표준 기구 문서 |
| 국제기구 | OECD, IMF, World Bank, UN과 산하기구, IEA, WTO, BIS, Eurostat의 보고서와 통계 |
| 국제 지표 | Stanford HAI AI Index, IMD 국가경쟁력 보고서 |
| 금융기관 | 중앙은행, 거래소 등 공신력 있는 금융기관의 공식 통계와 발간물 |
| 컨설팅과 리서치 | McKinsey, BCG, Bain, Deloitte, PwC, KPMG, EY 보고서, Gartner, IDC, Forrester 등 산업 리서치 |
| 기술 문서 | 대형 오픈소스 프로젝트와 표준 라이브러리의 공식 문서와 공식 저장소(기술 주제 한정) |

통계 집계 서비스와 시장 보고서 재판매 서비스는 2차 자료이므로 원출처를 찾아 인용한다.

### 저품질 유형

공통 신호는 편집과 사실 확인 절차의 부재, 발행 주체 미상, 검증 불가, 자동생성이다. 아래 유형은 인용하지 않는다.

- (자동생성 콘텐츠) 저자와 편집진이 없고 자동생성 주소 체계, 원출처 없는 요약, 자체 검증을 권하는 문구가 보이는 대량 발행 사이트와 AI 생성 백과류
- (사용자 생성 콘텐츠) 개방형 위키 본문, 질의응답 서비스, 사용자 리뷰. 위키 본문은 인용하지 않고 본문이 밝힌 원출처를 추적해 원출처를 인용
- (개인 게시물) 개인 블로그, 개인 SNS 게시물
- (익명 공간) 익명 게시판, 포럼, 댓글
- (선정성 위주 매체) 사실 확인 절차 없이 선정성을 앞세우는 매체
- (출처 미표기 모음) 출처를 밝히지 않는 뉴스 모음, 카드뉴스, 스크래핑 서비스, 제휴 링크 위주 리뷰
- (홍보성 콘텐츠) 스폰서 콘텐츠, 광고성 기사, 보도자료를 그대로 옮긴 기사
- (국가 선전매체) 편집 독립성이 없는 국가 통제 선전 매체
- (발행 주체 불명) 발행 주체와 편집 책임을 확인할 수 없는 도메인

### 한계적 자료 처리

- (일반 언론 보도) 보도가 인용한 원출처를 찾아 원출처를 인용한다. 원출처를 찾지 못하면 보도만으로 근거를 삼지 않는다
- (기업 자체 발표) 이해관계가 있으므로 기업 자기 진술 범위로 한정해 인용한다
- (사전공개 논문) 미검증 자료임을 인지하고 제한적으로 인용한다
- (단일 출처 주장) 한 출처만 제기한 주장은 독립 출처로 교차 확인한 뒤 인용한다
- (의견 글) 사설과 칼럼은 사실 보도와 구분해 필자의 견해로 한정해 인용한다
- (협회와 옹호 단체) 특정 입장을 대변하는 단체의 자료는 이해관계를 고려해 인용한다

### 정치 중립

매체를 정치 성향이나 진영 평가로 등급화하지 않는다. 편집 절차, 검증 가능성, 선정성 같은 구조적 속성으로만 판단해 진영이 다른 두 매체가 같은 기준에서 같은 평가를 받게 한다.

### 전부 저품질일 때

모은 출처가 모두 저품질이면 그 출처를 없는 자료로 보고 해당 주장을 쓰지 않는다. 그 지점은 정보 부재로 남기되 거짓이나 부정으로 단정하지 않는다. 고품질 출처가 필요하면 고품질 유형으로 검색 범위를 좁혀 다시 찾는다.

### 비노출과 예외

- 출처 등급, 배제 사실, 판별 과정은 산출물에 쓰지 않는다. 산출물에는 기준을 통과한 출처만 보통의 인용 형식으로 나타난다. 사용자가 평가 결과를 요청하면 공개한다
- 사용자가 특정 출처의 인용을 지시하면 그 출처는 배제하지 않는다
- 분석 대상 자체가 저품질 자료이면(허위정보 확산 사례 분석 등) 분석 목적의 인용을 허용한다
- 당사자의 자기 진술을 인용하는 경우 자기 진술 범위로 허용한다

## 내부 자료 품질

내부 자료는 주체가 자신에 대해 남긴 기록이다. 조직마다 자료 관리 방식이 다르다. 원천 시스템, 사내 DB, 데이터 웨어하우스로 관리하는 조직이 있고 문서 도구, 공유 드라이브, 메신저에 자료를 두고 쓰는 조직도 있다. 내부 자료는 관리 방식이나 저장 위치와 관계없이 아래 점검 항목으로 판단한다. 점검의 기준은 기록이 무엇을 언제 기준으로 적었는지 확인되는지다.

| 점검 항목 | 내용 |
|---|---|
| 기준 시점 | 수치가 가리키는 시점. 문서에 없으면 작성일이나 메시지 날짜를 대신 쓰고 그 사실을 출처 표기에 밝힌다 |
| 최신본 | 같은 내용의 문서가 여러 개면 가장 최근 수정본을 쓴다 |
| 지표 정의 | 수치가 무엇을 어떤 범위와 단위로 세었는지. 조직이 지표 정의서나 데이터 카탈로그를 운영하면 그 정의를 기준으로 한다. 정의가 다른 수치는 하나의 추이로 잇지 않는다 |
| 중복과 누락 | 여러 문서의 수치를 합칠 때 같은 기록을 두 번 세거나 빠뜨린 기간이 없는지 |

- 점검 항목을 확인할 수 없는 수치는 확인 목록에 모은다. 목록에 문서명, 위치, 확인할 내용을 적어 한 번에 사용자에게 보낸다
- 같은 수치가 문서마다 다르면 사용자가 지정한 기준 문서나 원천 시스템 기록(회계, 인사 시스템 등)을 따른다. 둘 다 없으면 가장 최근 문서의 수치를 쓴다. 다른 수치가 있다는 사실은 확인 목록에 적는다
- 사용자가 답하기 전의 수치는 팩트 대장에 확인 필요로 표시하고 시사점의 근거로 쓰지 않는다

## 내부 자료 보안

- 사용자가 허락한 시스템과 범위만 조회한다
- 분석에 필요한 최소 범위만 조회한다
- 개인을 식별할 수 있는 정보(이름과 연결된 인사 정보, 연락처, 평가 결과 등)는 산출물에 쓰지 않고 부서나 조직 단위로 집계한다
- 팩트 대장의 자료 경로 필드에 연결 시스템을 표시해 사용자가 외부 공유 전에 내부 자료를 가려낼 수 있게 한다
- 내부 자료를 웹 검색어로 쓰거나 외부 서비스로 보내지 않는다
- 조직의 보안 등급 표시나 데이터 정책이 있으면 따른다

## 검증 강도

| 단계 | 절차 |
|---|---|
| 1단계 기본 | 지식 원천 규칙, 코드 계산과 검산, 하위 페이지 주소 표기 |
| 2단계 정량 확인 | 1단계에 더해 정량 데이터를 본문에 쓰기 전에 사용자 확인 |
| 3단계 전수 확인 | 1단계에 더해 모든 출처의 증거를 모아 정성 내용과 정량 데이터 전체를 사용자 확인 |

### 선택 기준

사용자가 단계를 지정하면 그 단계를 쓴다. 지정하지 않으면 산출물의 수정 가능성과 정량 데이터 포함 여부로 정한다.

- (수정 가능) 작성자 본인이나 내부 팀만 보며 폐기할 수 있는 산출물. 개인 조사 메모, 초안, 내부 검토용 자료, 정기 현황 브리핑
- (수정 제한) 외부에 전달했거나 전달할 예정이고 정정 기회가 제한된 산출물. 외부 발송 보고서, 입찰 제안서, 감사 증빙, 게재 논문, 공고 문서, 법원 제출 자료, 최종 보고서

| 수정 가능성 | 정량 데이터 없음 | 정량 데이터 있음 |
|---|---|---|
| 수정 가능 | 1단계 | 2단계 |
| 수정 제한 | 3단계 | 3단계 |

외부 전달 산출물은 수치 오류 외에도 허위 사실 서술과 존재하지 않는 출처 인용이 위험하므로 정량 데이터 유무와 관계없이 3단계를 쓴다. 정량 데이터가 없으면 3단계의 정량 확인 부분은 자연히 생략된다.

- 선택한 단계를 한 줄로 알린다. 형식은 `출처 검증 수준: N단계 (판단 근거 한 줄)`이다
- 사용자가 "더 엄격하게"라고 하면 한 단계 올리고 "이 정도면 된다"라고 하면 한 단계 내린다. 단계를 직접 지정하면 즉시 따른다
- 선택 과정을 길게 설명하지 않는다. 알림 없이 단계를 적용하지 않는다. 표를 거치지 않고 단계를 정하지 않는다. 사용자 요청 외의 보정 규칙을 더하지 않는다

### 2단계 정량 확인

정량 데이터는 수치, 통계, 비율, 백분율, 금액, 성장률, 순위, 건수, 규모 등 숫자로 표현한 모든 정보다. 웹, 제출 파일, 연결 시스템 어디서 왔든 적용한다.

1. 정량 데이터와 출처(기관명, 연도, 자료명, 주소)를 기록한다
2. 본문에 쓰기 전에 아래 양식으로 목록을 보여 준다
3. 승인한 데이터만 본문에 쓴다. 수정 요청은 사용자가 준 값으로 바꾼다. 거부한 데이터는 제외한다

```
정량 데이터 확인 요청

| 번호 | 데이터 항목 | 수치 | 출처 |
|---|---|---|---|
| 1 | (항목) | (수치) | 기관명(연도), 자료명 |

- 승인: 전체 승인 또는 번호 지정 승인
- 수정: 번호와 올바른 수치 제시
- 거부: 해당 데이터 미사용
```

- (예외) 사용자가 대화에서 직접 입력한 수치는 확인하지 않는다. 사용자가 "확인 생략"이나 "바로 써도 된다"고 하면 그 턴에 한해 생략하고 다음 턴부터 절차를 되살린다
- (금지) 확인 없이 정량 데이터를 본문에 쓰지 않는다. "약", "대략", "추정" 같은 표현으로 우회해 쓰지 않는다. 확인을 기다리는 수치를 확정된 사실처럼 쓰지 않는다

### 3단계 전수 확인

인용할 모든 출처와 모든 인용 내용(정의, 주장, 사실 진술, 수치, 날짜)이 대상이다. 정량 데이터는 확인에 더해 코드로 검산한다.

| 자료 경로 | 모을 증거 |
|---|---|
| 웹 | 실재성(기관명과 자료명 검색 결과 요약문), 날짜(검색 결과나 페이지에 표시된 발행일), 주소 접근 결과(성공이나 실패, 페이지 제목), 내용(인용할 내용이 담긴 원문 발췌) |
| 제출 파일 | 날짜(문서의 발행일, 작성일, 기준일 표기), 내용(원문 발췌), 정합성(문서 제목, 작성 기관, 기준 연도가 인용하려는 내용과 맞는지) |
| 연결 시스템 | 식별(시스템명, 문서나 테이블 식별자), 조회(조회 조건이나 경로, 조회 시각), 기준 시점, 내용(원문 발췌) |

원문 발췌는 가공하거나 요약하지 않고 그대로 옮기되 인용할 내용을 확인하는 데 필요한 최소 범위(해당 문장 중심)로 한정한다. 저작물 인용은 정당한 범위 안에서 해야 하기 때문이다. 증거를 찾지 못하면 찾지 못했다는 사실을 그대로 적는다.

본문을 쓰기 전에 모든 증거와 인용 예정 내용을 한 번에 보여 준다. 출처 테이블과 정량 데이터 테이블은 나눈다.

```
인용 항목 확인 요청

[출처와 인용 내용]
| 번호 | 자료 경로 | 출처명 | 발행 연도 | 인용 예정 내용 |
|---|---|---|---|---|

[1번 출처 증거]
- (실재성) 검색 결과 요약문 또는 "검색 결과 없음"
- (날짜) 확인된 날짜 또는 "날짜 미확인"
- (주소 접근) 페이지 제목 또는 "접근 실패"
- (내용) 원문 발췌 또는 "해당 내용 미발견"

[정량 데이터]
| 기호 | 출처 번호 | 출처명 | 발행 연도 | 데이터 항목 | 수치 |
|---|---|---|---|---|---|

- 승인: 전체 승인 또는 번호와 기호 지정 승인
- 수정: 번호나 기호와 올바른 내용 제시
- 교체: 해당 출처 대신 다른 출처 탐색 요청
- 거부: 해당 항목 미사용
```

- 승인한 항목만 본문에 쓴다. 수정 요청은 사용자가 준 내용으로 바꾼다. 교체 요청을 받으면 새 출처에 같은 증거 수집을 다시 한다
- (예외) 사용자가 대화에서 직접 입력한 정보는 확인하지 않는다. "확인 생략" 요청은 2단계와 같이 그 턴에 한해 적용한다
- (금지) 증거 없이 출처를 인용하지 않는다. 승인 없이 인용 내용을 본문에 쓰지 않는다. 인용 내용을 확인 테이블에서 빠뜨리지 않는다. 불확실 표현으로 우회하지 않는다. 확인을 기다리는 내용을 사실처럼 쓰지 않는다. 주소를 만들어 내거나 추정하지 않는다. 발행 연도를 추정하지 않고 증거에서 확인한 연도만 쓴다

## 계산 규칙

모든 계산은 코드로 하고 반올림은 계산을 마친 뒤 한다.

| 지표 | 계산식 |
|---|---|
| 연평균 성장률 | (끝값 / 시작값)^(1 / 기간 연수) - 1. 기간 연수는 끝 연도와 시작 연도의 차이 |
| 비중 | 부분 / 전체 |
| 입지계수 | (지역의 해당 산업 값 / 지역 전체 산업 값) / (전국의 해당 산업 값 / 전국 전체 산업 값). 1보다 크면 전국보다 집중 |
| 상위 n개 기업 집중률(CR) | 상위 n개 기업 점유율의 합 |
| 허핀달-허쉬만 지수(HHI) | 모든 기업 점유율(%)의 제곱합. 최댓값 10,000 |

- 입지계수는 미국 노동통계국이 고용 기준으로 정의한 방식이며 사업체 수나 생산액에도 같은 식을 쓸 수 있다. 어떤 값을 썼는지 적는다
- HHI의 집중 구간 기준은 관할 당국마다 다르므로 적용한 기준과 출처를 함께 적는다
- 통화 환산은 적용 환율의 기준일과 출처를 적는다. 물가 조정은 기준 연도를 적는다
- 단위가 섞이면 하나로 환산하고 환산 사실을 적는다
