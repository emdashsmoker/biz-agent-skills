# 개조식 작성 규칙과 산출 양식

환경분석 보고서를 개조식으로 쓰는 규칙이다. 사용자가 다른 문체나 형식을 지정하면 그 지정을 우선한다.

## 보고서 구성

| 순서 | 구성 | 내용 |
|---|---|---|
| 1 | 제목 | 주제와 범위. 사용자가 결론 중심 보고를 원하면 핵심 결론을 명제로 씀 |
| 2 | 요약 | 핵심 팩트와 시사점을 압축해 보고서의 결론을 먼저 읽게 함 |
| 3 | 분석 범위 | 주체, 주제, 공간 범위, 시간 범위, 자료 기준일. 산업이나 기술 주제면 대상 개요 포함 |
| 4 | 기관현황 | 조직 주체의 기관현황. 사용자가 다른 위치를 정하면 그 위치로 옮김 |
| 5 | 분석 절 | 실행한 모듈을 거시환경, 미시환경, 내부현황, 벤치마킹 순으로 배치 |
| 6 | 시사점 | 출처 단계별 시사점 |
| 7 | 부록 | 팩트 대장. 시사점이 있거나 후속 분석에 넘길 때 포함 |

부분 분석은 실행한 모듈에 필요한 구성만 쓴다. 한 범주만 다루는 짧은 보고서는 요약을 생략하고 분석 범위를 한두 줄로 줄일 수 있다.

각 분석 절은 현재 상태를 먼저 쓰고 최근 변화를 뒤에 쓴다. 보고서 끝의 시사점이 두 내용의 의미를 정리한다.

## 절 작성

- (요지 우선) 각 절의 첫 불릿에 그 절의 팩트를 압축한 요지를 둔다. 요지도 팩트의 범위를 넘지 않는다
- (수직 관계) 상위 불릿은 하위 불릿의 결론이고 하위 불릿은 상위 불릿의 근거다. 위에서 아래로 읽으면 "왜 그런가"에, 아래에서 위로 읽으면 "그래서 무엇인가"에 답해야 한다
- (수평 묶음) 같은 층위의 불릿은 같은 종류의 내용으로 묶는다. 한 층위에 3-4개를 권장하고 5개 이상이면 상위 묶음을 새로 만든다
- (교차 서술) 글로벌과 국내를 함께 다루면 범주마다 글로벌을 먼저 쓰고 국내로 옮겨 간다. 지역이 있으면 마지막에 둔다

## 제목과 헤더

- 헤더 하나에는 주제 하나만 담는다. "정책 및 기술 동향"처럼 두 주제를 묶지 않고 "정책 동향", "기술 동향"으로 나눈다
- 헤더만 보고 아래 내용을 알 수 있게 짓는다. 키워드형과 문장형 가운데 하나를 골라 한 보고서 안에서 통일한다
- 분석 절의 제목은 범주와 주제를 담은 키워드로 쓴다. 거시환경, 미시환경 같은 단계 이름이나 개요, 배경, 현황 같은 일반 라벨은 분석 절 제목으로 쓰지 않는다
- 요약, 분석 범위, 시사점, 부록은 기능 표제로 그대로 쓴다. 시사점 절 안의 하위 표제는 후속 분석을 위해 단계 이름을 쓴다
- 형제 헤더는 같은 패턴으로 짓는다. "글로벌 시장 동향" 옆에는 "국내 시장 동향"을 둔다
- 최종 출력 전에 헤더 이름을 다시 점검한다

## 불릿 구조

```
# 제목
## 섹션 제목
- (소제목) 요지 또는 주장
    + 근거 팩트
    + 근거 팩트
> 기관명(연도), 자료명(링크)
```

- `-` 불릿은 들여쓰지 않고 요지나 주장을 쓴다
- `+` 불릿은 한 단계 들여써서 근거 팩트를 쓴다
- 하위 불릿은 대등한 항목이 두 개 이상일 때만 쓴다. 하나뿐이면 상위 불릿 문장에 합치거나 별도 상위 불릿으로 분리한다. 상위 불릿이 고유 명칭이나 프레임워크이고 하위 불릿이 그 정의를 한 줄로 주는 경우는 하나여도 된다
- 하위 불릿은 3-4개를 권장한다
- `>` 블록은 출처와 데이터 설명에만 쓴다

## 문장

- 한 문장에는 메시지 하나만 담는다. 누가, 언제, 어디서, 무엇을, 왜, 어떻게가 한 문장에 두 번 이상 나오면 문장을 나눈다
- 개조식 명사형 종결을 기본으로 한다(예: "증가", "발표", "확인", "전망"). 존댓말은 쓰지 않는다
- 명사형 종결은 자연스럽게 끝낸다. "달성할 필요"는 "달성 필요"로, "낮은 것"은 "저조"처럼 뜻이 드러나는 명사로 끝낸다. "것", "부분", "셈"으로 문장을 봉합하지 않는다
- "그리고", "그러나" 같은 접속어나 "-하며", "-하고" 같은 연결 어미로 여러 사실을 한 문장에 잇지 않고 문장을 나눈다
- 쉼표는 같은 범주의 항목을 3개 이상 나열할 때 쓴다. 대등한 명사 두 개는 "와", "과" 대신 "A 및 B"로 잇는다(예: "예산과 인력 확보"는 "예산 및 인력 확보"). 비교 대상이나 협력 상대를 나타내는 "와", "과"는 그대로 둔다. 나열 쉼표를 생략하고 명사를 띄어쓰기로만 늘어놓지 않는다
- 소제목은 `(소제목) 내용` 형식으로 괄호로 감싼다. 콜론이나 하이픈으로 소제목을 붙이지 않는다
- 소제목은 내용을 드러내게 짓는다. "(설명)", "(근거)", "(주장)"처럼 의미 없는 소제목이나 같은 소제목의 반복은 피한다
- 기관명, 정책명, 사업명, 제품명은 공식 전체 명칭으로 쓴다. 약어는 처음 나올 때 전체 명칭을 함께 쓴다
- 물결표는 마크다운에서 취소선으로 렌더링될 수 있으므로 범위는 하이픈으로 쓴다(예: 2021-2025년)
- 출처가 밝힌 전망은 전망 주체, 발표 연도, 전망 기간과 함께 쓴다

아래 표현은 쓰지 않는다.

| 유형 | 예 |
|---|---|
| 글과 작성 과정에 대한 서술 | "본 보고서는", "살펴보면", "정리하면", "검색 결과", "요청하신" |
| 대비 강조 | "단순한 A가 아닌 B", "A를 넘어 B로" |
| 숫자 선언 | "3대 과제", "4가지 방향" |
| 의미 없는 연결 | "이러한 맥락에서", "시사하는 바가 크다" |
| 과장 수식 | "획기적", "폭발적", "전례 없는" |
| 기호 남용 | 긴 대시(em dash), 극적 효과의 말줄임표, 강조용 볼드 |
| 절차 내부 용어 | 모듈, 검증 강도, 품질 등급, 판정 |

## 정량 데이터

- 모든 수치는 누가, 언제, 무엇을, 어떤 방법으로 측정했는지 답할 수 있게 쓴다. 예: "OO리서치의 2024년 조사에 따르면 국내 시장은 2023년 약 1조 2,000억 원에서 2028년 약 2조 원으로 연평균 약 10.8% 성장 전망(설문 기반 추정, 기준 시나리오)"
- 3-5개년 이상의 시계열을 우선하고 연평균 성장률과 전체 대비 비중을 함께 적는다
- 본문 불릿의 핵심 수치는 절마다 소수로 줄이고 나머지는 테이블로 옮긴다
- 천 단위 구분 쉼표와 단위를 쓴다

## 테이블

- 정책 목록, 기술 동향, 플레이어, 시설과 장비, 사업 목록처럼 같은 속성을 가진 항목의 목록과 비교에 쓴다
- 테이블 앞에는 그 테이블의 요지를 담은 불릿을 둔다. 요지 없이 테이블을 연달아 붙이지 않는다
- 테이블은 `>` 블록이나 코드 블록 밖에 둔다
- 열은 서로 겹치지 않게 구성하고 셀은 짧게 쓴다

## 출처 표기

- 형식은 `> 기관명 또는 저자명(연도), 자료명(링크)`이다
- 출처가 여럿이면 `>` 블록을 나누고 사이에 빈 줄을 둔다
- 정량 데이터의 출처는 그 데이터가 담긴 불릿 묶음 바로 뒤에 둔다. 정성 서술의 출처는 절 끝에 모을 수 있다
- 링크는 정보가 실린 하위 페이지의 전체 주소로 쓴다
- 사내 자료는 `> 시스템명 또는 문서명(기준 시점), 테이블이나 문서 식별자(조회 조건)` 형식으로 쓰고 개인 식별 정보는 포함하지 않는다

```
> 과학기술정보통신부(2025), 자료명(https://...)

> 통계청(2024), 자료명(https://...)
```

## 시사점 절

시사점 절은 단계별 하위 표제 아래에 한 줄 불릿으로 쓴다. 후속 분석이 출처 단계를 바로 알아볼 수 있도록 테이블로 바꾸지 않는다.

```
## 시사점

### 거시환경
- 시사점 문장 (근거 거시-01, 거시-04)

### 미시환경
- 시사점 문장 (근거 미시-02)

### 내부현황
- 시사점 문장 (근거 내부-03, 미시-05)

### 벤치마킹
- 시사점 문장 (근거 벤치-01, 내부-02)
```

실행하지 않은 단계의 하위 표제는 만들지 않는다.

시사점은 보고서 끝에 모으는 방식을 기본으로 한다. 사용자가 원하거나 분석 절이 길면 각 분석 절 끝에 그 절의 시사점을 둘 수 있으며 이때도 근거 ID와 단계 구분 규칙은 같다.

## 전체 보고서 뼈대

```
# [주제] 대내외 환경분석

## 요약
- 핵심 시사점과 핵심 팩트

## 분석 범위
- (대상) 주체와 주제, 대상 개요
- (범위) 공간 범위, 시간 범위, 자료 기준일

## [주제] 정책 동향
- (글로벌) 요지
    + 근거 팩트
    + 근거 팩트
- (국내) 요지
    + 근거 팩트
    + 근거 팩트
> 출처

## [주제] 시장 동향
...

## [주체] 역량 현황
...

## [비교 대상] 사례
...

## 시사점
### 거시환경
...

## 부록
(팩트 대장)
```

## 부분 분석 뼈대

```
# [주제] 정책 동향

## 분석 범위
- (범위) 공간 범위, 시간 범위, 자료 기준일

## 글로벌 [주제] 정책
- 요지
    + 근거 팩트
    + 근거 팩트
(정책 테이블)
> 출처

## 국내 [주제] 정책
...

## 시사점
### 거시환경
- 시사점 문장 (근거 거시-01, 거시-02)
```

## 작성 점검

- 제목이 주제와 범위를 담는가
- 분석 절 제목이 내용 키워드이고 한 헤더에 주제 하나만 담는가
- 각 절의 첫 불릿이 요지이고 하위 불릿이 근거인가
- 한 문장에 메시지 하나만 있는가
- 명사형 종결이 자연스러운가
- 소제목이 괄호 형식이고 내용을 드러내는가
- 모든 수치에 출처, 기준 시점, 측정 방법이 있는가
- 테이블 앞에 요지 불릿이 있는가
- 출처 링크가 하위 페이지 주소인가
- 금지 표현과 절차 내부 용어가 없는가
- 시사점마다 근거 ID가 있는가
