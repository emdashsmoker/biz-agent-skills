# 5-Forces 경쟁구조 분석

Porter의 5-Forces로 산업의 경쟁구조를 분석하는 절차다. 5개 힘은 신규진입자 위협, 공급자 교섭력, 구매자 교섭력, 대체재 위협, 산업 내 경쟁강도다. Porter(2008, The Five Competitive Forces That Shape Strategy)는 정부 정책, 보완재, 산업 성장률, 기술을 여섯 번째 힘으로 보지 않고 5개 힘의 강도를 바꾸는 요인으로 다뤘다. 이 절차도 같은 방식으로 정부 지원이나 규제를 각 힘의 판정 근거 안에서 다룬다.

## 필수 출력 규칙

아래 규칙은 다른 규칙보다 먼저 적용한다.

- 산업 가치사슬을 분해했다면 산업 가치사슬 시장마다 줄글과 경쟁환경 테이블을 따로 출력한다. 시장별 테이블을 생략하고 종합 테이블만 낸 산출은 완성본으로 보지 않는다
- 국내외 분리를 선택했다면 글로벌과 국내 각각에 대해 산업 가치사슬 시장별 줄글과 테이블을 따로 출력한다
- 모든 경쟁환경 테이블은 같은 표준 양식(구분, 경쟁강도, 내용, 근거, 데이터)을 쓴다. 비교 테이블 같은 임의 양식은 쓰지 않는다
- 국내외 분리 시 국외 쪽 명칭은 "글로벌"로 통일한다

## 실행 방식

- (자동 모드) 사용자가 산업명만 주면 범위 설정부터 분석까지 자동으로 수행한다
- (가이드 모드) 사용자가 범위나 분석단위를 미리 정했으면 그 값을 우선 적용한다
- (근거 자료) 사용자 첨부 자료를 1차 근거로 쓰고 부족한 부분은 웹검색으로 보충한다. 출처 없는 정량 데이터는 쓰지 않는다
- (확인 시점) 범위 확인은 SKILL.md 1단계의 범위 확인에 묶어서 한 번에 받는다

## 1단계 범위 설정

| 항목 | 설명 | 예시 |
|---|---|---|
| 산업명 | 분석 대상 산업 | 수소 에너지 산업 |
| 산업 정의 | 분석 대상의 범위와 포함 및 제외 대상 | 수소의 생산, 저장과 유통, 활용까지 포함하고 다른 에너지원은 대체재로 취급 |
| 지리적 범위 | 국내 한정, 국외 한정, 국내외 포괄, 국내외 분리 중 하나 | 국내외 포괄 |
| 시간적 범위 | 경쟁강도 전망의 시계. 현재(전망 미산출), 중기(3년 이내), 중장기(5년 이내), 산업 생애주기(10년 이내), 초장기(30년 이내, 장기 투자 관점), 사용자 지정 기간, 제한 없음 중 하나 | 중장기 |
| 산업 가치사슬 분해 | 해당 산업에서 통용되는 단계 기준의 분해 | 생산, 저장유통, 활용 |
| 분석단위 구성 | 산업 가치사슬 시장별 분석, 산업 포괄 분석, 혼합 중 하나 | 시장별 분석 후 산업 전체 종합 |

### 범위 설정 원칙

- (산업 정의) 포함 대상과 제외 대상을 명확히 정한다. 인접 산업이나 유관 기술이 분석 대상인지 대체재인지 구분해 분석의 경계를 확정한다
- (시간적 범위) 사용자가 정하지 않으면 중장기(5년 이내)를 쓴다. "현재"를 고르면 경쟁강도 전망 열을 출력하지 않는다
- (산업 가치사슬 분해) 해당 산업에서 실제로 쓰는 단계 명칭을 쓴다. "소재, 부품, 장비, 인프라" 같은 범용 명칭은 그 산업에서 폭넓게 쓰일 때만 쓴다. 분석단위끼리 겹치지 않고 모두 합치면 대상 산업 전체가 되게 구성한다
- (포괄 분석) 산업 가치사슬 분해가 필요 없거나 사용자가 포괄 분석을 원하면 산업 전체를 하나의 분석단위로 둔다

### 지리적 범위 옵션

| 옵션 | 처리 |
|---|---|
| 국내 한정 | 국내 산업만 분석 |
| 국외 한정 | 국외 산업만 분석 |
| 국내외 포괄 | 분석단위는 산업 가치사슬 기준으로 두고 국내외 동향을 각 분석단위 안에서 함께 서술 |
| 국내외 분리 | 각 산업 가치사슬 시장에 대해 글로벌 분석을 먼저 하고 국내 분석을 따로 수행. 두 시장의 경쟁강도와 테이블을 각각 도출 |

Porter(2008)는 지역마다 산업 구조가 크게 다르면 각 지역을 별개 산업으로 보라고 했다. 글로벌과 국내의 구조가 다를 가능성이 크면 국내외 분리가 이 기준에 맞는 선택이다.

### 사용자가 정하지 않았을 때의 자동 설정 절차

1. 첨부 자료가 있으면 그 자료에서 산업 정의와 산업 가치사슬 구조를 뽑는다. 첨부 자료가 없으면 웹검색으로 파악한다. 모델 지식만으로 산업 정의나 산업 가치사슬을 구성하지 않는다
2. 파악한 산업 가치사슬 구조로 분석단위 초안을 만든다
3. 지리적 범위를 제안한다. 기본값은 국내외 포괄이다
4. 산업 정의, 산업 가치사슬 분해, 지리적 범위를 사용자에게 확인받아 범위를 확정한다

## 2단계 근거 수집

산업 기초 정보를 먼저 모은 뒤 힘별 정보를 모은다.

### 산업 기초 정보

분석단위별로 아래 항목을 먼저 모은다. 5개 힘을 판정하는 공통 기반 자료다.

| 항목 | 수집 대상 |
|---|---|
| 시장규모 | 분석단위별 금액 기준 규모. 국내외 분리 시 국내와 글로벌 각각 |
| 시장전망 | 연평균 성장률 등 성장 전망. 전망 기간과 출처 필수 |
| 시장 주요지표 | 매출액, 종사자 수, 사업체 수, 입지계수 등 해당 산업에서 통용되는 지표 |
| 주요 플레이어 | 시장점유율, 매출액이나 인원 등 규모, 사업구조와 주력 상품, 주요 고객군, 주요 경쟁자 |

### 힘별 수집 정보

| 힘 | 수집 대상 |
|---|---|
| 신규진입자 위협 | 진입 장벽(자본 규모, 기술 난이도, 규제, 인허가), 규모의 경제, 기존 사업자의 보복 가능성, 최근 진입 사례, 정부의 진입 지원이나 규제 |
| 공급자 교섭력 | 공급자 수, 원자재 대체 가능성, 공급자 전환 비용, 공급자의 전방통합 가능성, 수직통합 진행 여부 |
| 구매자 교섭력 | 구매자 수, 구매 집중도, 제품 차별화 정도, 구매자 전환 비용, 구매자의 후방통합 가능성, 수직통합 진행 여부 |
| 대체재 위협 | 대체재 존재 여부, 가격 대비 성능, 전환 비용, 대체재 시장의 성장 추세, 수평적 대체 관계의 범위 |
| 산업 내 경쟁강도 | 경쟁자 수, 시장 성장률, 고정비 구조, 제품 차별화, 퇴출 장벽, 정부 지원이나 규제, 수평통합 진행 여부 |

수집한 정보는 분석단위별로 정리해 3단계의 입력값으로 쓰고 정량 데이터마다 출처를 적는다.

## 3단계 힘별 분석

산업 가치사슬 시장마다 5개 힘을 차례로 서술한 뒤 시장 현황과 주요 플레이어를 정리한다. 경쟁강도 판정(결론)을 먼저 쓰고 시장 데이터와 플레이어 현황(근거)을 뒤에 둔다.

```
## 수소 생산시장

### (신규진입자 위협 : 중→상) 기술 장벽이 있으나 생산비용 하락으로 신규 진입 가능성 확대

- (현황) 판정 요지 서술
    + 구조적 근거를 정성적으로 서술
    + 구조적 근거를 정량 데이터로 보강
- (전망) 판정 요지 서술
    + 구조적 근거를 정성적으로 서술
    + 구조적 근거를 정량 데이터로 보강
> 출처 표기

### (공급자 교섭력 : 중→중) 핵심 소재의 소수 기업 집중이 지속되나 대체 소재 개발이 변수

(구매자 교섭력, 대체재 위협, 산업 내 경쟁강도도 같은 구조)

### 시장 현황

- 시장규모, 시장전망, 주요지표 서술
> 출처 표기

### 주요 플레이어

(플레이어 테이블)

- 플레이어 사이의 경쟁 구도 서술
```

### 소제목 작성

- 소제목은 `(힘 이름 : 현재→전망) 문장형 제목` 형식이다. 문장형 제목은 현재 상태를 짧게 짚고 변화 방향을 뒤에 붙인다
- 시간적 범위가 "현재"이면 `(힘 이름 : 상/중/하) 문장형 제목` 형식으로 현재 경쟁강도만 적는다
- 소제목 아래에 (현황)과 (전망)을 나눠 각각 판정 요지와 근거를 쓴다. 시간적 범위가 "현재"이면 접두어 없이 판정 요지와 근거를 바로 쓴다

### 시장 현황과 주요 플레이어

- 5개 힘 분석 뒤에 시장 현황과 주요 플레이어를 둔다. 경쟁강도 판정이 결론이고 시장 데이터와 플레이어 현황이 근거다
- 2단계에서 모은 산업 기초 정보로 작성한다
- (시장 현황) 시장규모, 시장전망, 주요지표를 분석단위별로 정리하고 출처를 단다
- (주요 플레이어) references/micro.md의 플레이어 테이블 양식을 쓴다. 기업명, 국가, 규모는 필수 열이고 나머지 열은 자료 범위에 맞춰 추가하거나 제외한다. 테이블 뒤에 경쟁 구도를 짧게 서술한다

### 분석 원칙

- (판정 요지와 근거 분리) 해당 힘이 산업 경쟁에 주는 의미(판정 요지)와 판정 근거를 섞지 않는다. 판정 요지를 먼저 쓰고 근거로 뒷받침한다
- (산업 수준 판정) 개별 기업 사례를 산업 전체로 넓히지 않는다
- (부분의 전체화 방지) 특정 세그먼트의 특성을 산업 전체의 특성으로 단정하지 않고 분석단위 범위 안에서 판정한다
- (논리 연결) 근거에서 판정으로 가는 인과나 함의 관계가 제3자 관점에서 확인 가능해야 한다
- (인과와 상관 구분) 시간 순서를 인과관계로 단정하지 않는다
- (일반화 제한) 소수 사례로 힘 전체를 판정하지 않는다
- (구조적 현실 우선) 규모의 경제, 자본 집약도, 학습곡선, 특허 장벽, 네트워크 효과, 규제 인허가, 기존 사업자의 누적 투자, 공급 집중도, 전환 비용 같은 구조적 현실로 판정한다. 잠재적 변화 요인만으로 구조가 견고한 산업의 경쟁강도를 바꾸지 않는다. 잠재적 변화 요인은 전망 열에 반영하되 이 역시 보수적으로 판단한다
- (수직통합) 공급자나 구매자의 전방통합과 후방통합을 해당 교섭력 판정에 반영한다. 계획, 추진, 완료 단계에 따라 교섭력 강도가 달라진다
- (수평통합) 같은 산업 가치사슬 단계 안의 인수합병과 전략적 제휴를 산업 내 경쟁강도 판정에 반영한다. 경쟁자 수 감소와 시장 집중도 상승을 고려한다
- (힘 사이의 정합성) 같은 분석단위의 5개 힘은 서로 영향을 준다. 신규진입자 위협을 높게 보면서 산업 내 경쟁강도를 낮게 보는 식의 판정은 둘이 함께 성립하는 근거가 있는지 확인한다
- (산업 가치사슬 사이의 정합성) 한 분석단위의 구매자는 다음 분석단위의 공급자다. 소재 시장의 구매자 교섭력을 "하"로 판정했다면 부품 시장에서 소재 공급자의 교섭력까지 "하"로 판정하면 모순이다. 분석단위별 판정을 마치면 인접 분석단위의 구매자와 공급자 연결을 역방향으로 점검한다

### 구조적 현실 우선 규칙의 힘별 적용

아래는 오판 사례이며 예시 밖의 구조적 현실도 식별해 고려한다.

| 힘 | 판정을 바꾸기에 부족한 근거 |
|---|---|
| 신규진입자 위협 | "정부가 지원한다", "스타트업이 진입을 시도한다"만으로 규모의 경제와 자본 장벽이 견고한 산업의 위협을 올리지 않음 |
| 공급자 교섭력 | "대체 공급자가 등장한다", "국산화를 추진한다"만으로 소수 공급자 과점이 확인된 시장의 교섭력을 내리지 않음 |
| 구매자 교섭력 | "구매자가 자체 생산을 검토한다"만으로 전환 비용이 높고 대안이 없는 구조의 교섭력을 올리지 않음 |
| 대체재 위협 | "연구 중인 기술이 있다", "장기적으로 대체 가능성이 있다"만으로 상용화 시점이 불확실한 대체재의 위협을 올리지 않음 |
| 산업 내 경쟁강도 | "신규 기업이 진입한다"만으로 소수 기업 과점이 확인된 시장의 경쟁강도를 올리지 않음 |

### 경쟁강도 판정 기준

| 힘 | 상 | 중 | 하 |
|---|---|---|---|
| 신규진입자 위협 | 진입 장벽이 낮고 신규 진입이 활발 | 진입 장벽이 있으나 실제 신규 진입 사례가 확인됨 | 규모의 경제, 자본 집약도, 기술 축적, 규제 등 구조적 장벽이 높음 |
| 공급자 교섭력 | 공급자가 소수이고 대체 원자재가 없으며 전방통합이 실제 진행 중 | 공급자가 다수이나 일부 핵심 소재에서 소수 공급자 의존이 확인됨 | 공급자가 다수이고 원자재 대체가 실제로 이루어지며 전방통합 동인이 없음 |
| 구매자 교섭력 | 구매자 집중도가 높고 전환 비용이 낮으며 후방통합이 실제 진행 중 | 실제 거래 조건에서 구매자와 공급자의 교섭력 균형이 확인됨 | 구매자가 분산되고 전환 비용이 높으며 대안 공급원이 없음 |
| 대체재 위협 | 가격 대비 성능이 우월한 대체재가 상용화되어 시장에 침투 중 | 대체재가 상용화되었으나 전환 비용이나 성능 한계로 침투가 제한적 | 상용화된 대체재가 없거나 전환 비용이 과다 |
| 산업 내 경쟁강도 | 경쟁자가 많고 성장률이 낮으며 차별화가 부족하고 퇴출 장벽이 높음 | 경쟁자가 있으나 시장 성장으로 공존 가능하고 실제 가격 경쟁이 제한적 | 소수 기업 과점이 확인되고 성장률이 높으며 수평통합이 진행 중 |

이 기준은 참고용이다. 실제 판정은 분석단위별로 모은 근거에 따라 개별로 한다. 경쟁강도는 상, 중, 하 세 단계만 쓴다.

## 4단계 경쟁환경 종합

산업 가치사슬 시장별 분석 결과를 줄글로 종합한 뒤 테이블로 정리한다. 시장끼리 테이블을 합치거나 비교 테이블을 따로 만들지 않는다.

### 출력 순서

```
(산업 가치사슬 분해 시)
## [시장 A] 경쟁환경 → 줄글 → 경쟁환경 테이블
## [시장 B] 경쟁환경 → 줄글 → 경쟁환경 테이블
## [산업명] 경쟁환경 종합 → 줄글 → 산업 전체 종합 테이블

(국내외 분리 시)
## 글로벌 [시장] 경쟁환경 → 줄글 → 테이블
## 국내 [시장] 경쟁환경 → 줄글 → 테이블
## [산업명] 경쟁환경 종합 → 줄글 → 종합 테이블

(국내외 분리와 산업 가치사슬 분해를 함께 적용 시)
## 글로벌 [시장 A], [시장 B] ... 경쟁환경 → 시장마다 줄글과 테이블
## 글로벌 [산업명] 경쟁환경 종합 → 줄글 → 종합 테이블
## 국내 [시장 A], [시장 B] ... 경쟁환경 → 시장마다 줄글과 테이블
## 국내 [산업명] 경쟁환경 종합 → 줄글 → 종합 테이블
## [산업명] 경쟁환경 종합 → 글로벌과 국내를 종합한 줄글 → 종합 테이블
```

각 줄글은 해당 시장의 경쟁구조가 어떤 특성을 갖는지, 힘들이 어떤 상호작용 패턴을 만드는지 서술한다. 테이블은 줄글 뒤에 둔다.

### 테이블 양식

5개 힘 행 뒤에 종합 행을 둔다.

| 구분 | 경쟁강도(현재) | 경쟁강도(전망) | 내용 | 근거 | 데이터 |
|---|---|---|---|---|---|
| 신규진입자 위협 | 상/중/하 | 상/중/하 | - (현황) 판정 요지<br>- (전망) 판정 요지 | - (현황) 근거<br>- (전망) 근거 | - (현황) 정량 데이터<br>- (전망) 정량 데이터 |
| 공급자 교섭력 | 상/중/하 | 상/중/하 | 같은 형식 | 같은 형식 | 같은 형식 |
| 구매자 교섭력 | 상/중/하 | 상/중/하 | 같은 형식 | 같은 형식 | 같은 형식 |
| 대체재 위협 | 상/중/하 | 상/중/하 | 같은 형식 | 같은 형식 | 같은 형식 |
| 산업 내 경쟁강도 | 상/중/하 | 상/중/하 | 같은 형식 | 같은 형식 | 같은 형식 |
| **종합** | - | - | 5개 힘을 종합한 경쟁구조의 특성 | 종합 판단의 구조적 근거 | - |

### 열 정의

| 열 | 작성 기준 |
|---|---|
| 구분 | 5개 힘 고정과 종합 행 |
| 경쟁강도(현재) | 현시점 기준 상, 중, 하 중 하나. 종합 행은 "-" |
| 경쟁강도(전망) | 시간적 범위 기준 상, 중, 하 중 하나. 종합 행은 "-". 시간적 범위가 "현재"이면 열 전체를 "-"로 처리 |
| 내용 | 해당 힘이 산업 경쟁에 주는 의미(판정 요지). (현황)과 (전망)을 `<br>`로 나눔. 시간적 범위가 "현재"이면 접두어와 줄바꿈 없이 서술 |
| 근거 | 경쟁강도의 정성적 근거. (현황)은 현재의 구조적 근거, (전망)은 변화 근거. "현재"이면 접두어 없이 서술 |
| 데이터 | 경쟁강도의 정량적 근거와 출처. "현재"이면 접두어 없이 서술. 데이터가 없으면 수집 노력 뒤 확보 가능한 최선의 정보를 기재 |

### 종합 행과 테이블 작성

- 종합 행의 내용 열은 5개 힘의 판정을 종합해 해당 분석단위의 경쟁구조 특성을 서술한다
- 종합 행의 근거 열은 힘 사이의 상호작용이나 구조적 패턴을 근거로 쓴다
- 5개 힘을 단일 지표로 합치는 기준이 불분명하므로 종합 행의 경쟁강도 열과 데이터 열은 "-"로 둔다
- 각 셀은 1-2문장으로 압축하고 상세 분석은 3단계 본문에 둔다
- 데이터 열에 출처 없는 수치를 쓰지 않는다
- 전망은 현재 대비 변화 방향의 근거가 있을 때만 현재와 다르게 판정한다
- 산업 가치사슬을 분해했다면 분석단위별 테이블 뒤에 산업 전체 종합 테이블을 추가한다. 산업 전체 판정은 분석단위별 판정의 단순 평균으로 내지 않고 산업 구조 전체를 고려해 내리며 그 근거를 따로 서술한다. 산업 전체 종합 테이블에도 종합 행을 둔다

## 산출물 서술

산출물은 외부에 제출할 수 있는 산업 분석 보고서 수준으로 쓴다.

- 객관적 서술체를 유지하고 제목과 소제목에는 해당 산업과 시장의 고유 명칭을 쓴다
- 분석 과정을 설명하는 서술과 구조를 설명하는 문장은 쓰지 않는다
- 절차 내부 용어("분석단위", "판정", "산업 기초 정보", "요약 테이블", "힘별 분석 구조")와 사고 도구 명칭("MECE", "So What", "Why So")을 본문과 제목에 노출하지 않는다
- "경쟁환경 분석", "산업 구조 분석", "5-Forces", 5개 힘의 명칭은 본문과 소제목에 써도 된다
- 사용자가 특정 용어 노출을 요청하면 따른다

## 점검

- 분석단위가 겹치지 않고 합치면 대상 산업 전체를 포괄하는가
- 각 힘에서 판정 요지와 판정 근거가 분리되어 있는가
- 근거에서 판정으로 가는 연결을 제3자가 확인할 수 있는가
- 특정 세그먼트의 특성을 산업 전체로 넓히지 않았는가
- 소수 사례로 힘 전체를 판정하지 않았는가
- 잠재적 변화 요인만으로 구조가 견고한 산업의 경쟁강도를 바꾸지 않았는가
- 수직통합이 교섭력 판정에, 수평통합이 경쟁강도 판정에 반영되었는가
- 같은 분석단위 안의 힘끼리 판정이 모순되지 않는가
- 인접 분석단위의 구매자 교섭력과 공급자 교섭력 판정이 서로 맞는가
- 정량 데이터에 출처가 있는가
- 경쟁강도에 상, 중, 하만 썼는가
- 테이블 셀이 본문 분석과 일치하는가
- 모든 테이블에 종합 행이 있고 종합 행의 경쟁강도 열이 "-"인가
- 산업 가치사슬 분해 시 시장마다 줄글과 테이블이 따로 있는가
- 산업 가치사슬 분해 시 산업 전체 종합 테이블이 있는가
- 본문에 절차 내부 용어나 과정 설명이 노출되지 않았는가

## 예외

- 사용자가 분석단위를 지정하면 그 구성을 우선 적용하되 분석단위 사이에 겹침이나 누락이 보이면 알린다
- 사용자가 경쟁강도 판정 기준을 따로 정하면 그 기준을 적용한다
- 사용자가 특정 힘만 요청하면 그 힘만 분석한다
- 사용자가 테이블 없이 본문만 요청하면 테이블을 생략한다
