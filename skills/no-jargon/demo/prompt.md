## 시범 운영 기술 구성

- 당사 PoC는 오픈 웨이트 LLM을 온프레미스 GPU 클러스터에 배포하고 사내 문서를 임베딩해 벡터 DB에 적재한 뒤 RAG 파이프라인으로 그라운딩하는 아키텍처 채택
- 베이스 모델은 파라미터 70B급 디코더 온리 트랜스포머이며 컨텍스트 윈도우는 128K 토큰
- 도메인 적합성을 높이기 위해 LoRA 기반 PEFT로 파인튜닝하고 할루시네이션은 레퍼런스 인용 강제와 LLM-as-a-judge 평가로 모니터링
- 추론 단계에서는 INT4 양자화와 KV 캐시 최적화로 TTFT와 토큰당 비용 절감
- 가드레일로 PII 마스킹과 프롬프트 인젝션 필터 적용
