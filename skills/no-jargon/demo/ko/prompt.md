온톨로지와 제조AI를 융합하는 스마트공장 과제 계획서의 기술 설명 부분이야. AI를 잘 모르는 임원도 읽을 수 있게 아래 글을 고쳐 줘.

---

본 과제는 ISA-95 계층 모델을 참조해 설비, 공정, 품질 도메인을 OWL 2 DL 온톨로지로 모델링하고 MES와 ERP 데이터를 R2RML 매핑으로 RDF 트리플스토어에 적재해 지식그래프를 구축한다. 설비 단위 데이터는 OPC UA 정보 모델과 AAS 서브모델로 시맨틱 상호운용성을 확보한다. 추론 엔진은 클래스 계층과 속성 체인으로 명시되지 않은 관계를 도출하고 SHACL 셰이프로 데이터 무결성을 검증한다. AI 계층은 지식그래프 임베딩과 GNN 기반 이상 탐지 모델을 결합한 뉴로심볼릭 구조로 설계하며 탐지 결과는 SPARQL 질의로 근본 원인 후보까지 역추적한다. 운영자 질의는 LLM이 GraphRAG로 지식그래프를 탐색해 설명 가능한 답변을 생성하며 온톨로지 스키마 변경은 버전 관리와 역량 질문(CQ) 기반 회귀 검증으로 통제한다.
