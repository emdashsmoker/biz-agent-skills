## 사내 서버에 설치한 공개 인공지능(AI) 모델이 사내 문서를 근거로 답변하는 구조 채택
- (AI 모델) 이번 시범 운영에서는 여러 대를 묶은 사내 GPU(Graphics Processing Unit) 서버에 개발사가 내려받을 수 있게 공개한 AI 모델을 설치
    + 모델 규모는 학습으로 값이 정해지는 내부 수치 700억 개 수준
    + 한 번에 처리할 수 있는 글의 최대 분량은 약 12만 8,000 토큰
    + 당사 업무 분야에 대한 적합도를 높이기 위해 기존 내부 수치는 고정한 상태에서 소량의 보조 수치만 추가 학습

> (GPU) 많은 계산을 동시에 처리하여 AI 모델 구동에 주로 쓰는 반도체

> (토큰) AI 모델이 글을 처리할 때 나누는 단어 또는 단어 일부 크기의 글자 묶음

- (답변 근거) AI 모델은 질문마다 관련 사내 문서를 검색한 결과를 근거로 답변 작성
    + 사내 문서는 질문과 뜻이 비슷한 내용을 찾을 수 있는 숫자 형태로 변환하여 전용 검색 데이터베이스에 저장
    + 출처 문서 표시를 모든 답변에 의무화하여 근거 없는 내용을 사실처럼 제시하는 오류 점검
    + 채점용 AI 모델이 답변을 평가하여 근거 없는 내용의 포함 여부를 상시 확인
- (처리 효율) 답변 생성 단계에서 질문 입력 후 첫 출력까지 걸리는 시간 및 토큰당 처리 비용 절감
    + 모델 내부 수치를 4비트 크기의 정수로 단순화하여 연산에 필요한 서버 자원 축소
    + 이미 처리한 글의 중간 계산 결과를 임시 저장 공간에 효율적으로 보관하여 같은 계산의 반복 감소
- (보안) 개인정보 유출 및 AI 모델 악용을 방지하는 안전장치 적용
    + AI 모델이 다루는 글에 포함된 개인정보 가림 처리
    + 글 속에 지시문을 섞어 AI 모델이 운영자가 정한 규칙을 무시하게 만드는 공격은 필터로 걸러냄
