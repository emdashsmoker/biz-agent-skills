Our PoC adopts an architecture that deploys an open-weight LLM on an on-prem GPU cluster, embeds internal documents into a vector DB and grounds responses through a RAG pipeline. The base model is a 70B-parameter decoder-only transformer with a 128K-token context window. To improve domain fit, we fine-tune it with LoRA-based PEFT and monitor hallucinations through mandatory reference citation and LLM-as-a-judge evaluation. At inference, INT4 quantization and KV cache optimization reduce TTFT and per-token cost. Guardrails include PII masking and a prompt injection filter.
