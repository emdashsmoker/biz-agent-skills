# 5-Forces 경쟁환경 분석

산업 하나를 시장 단위로 나누고, 시장마다 다섯 가지 경쟁 압력의 세기를 근거와 함께 판정한다.

## 출력 필수 규칙

아래 규칙은 다른 모든 지침보다 먼저 적용한다. 시장별 판정이 빠지면 종합 판정의 근거를 추적할 수 없기 때문이다.

- 가치사슬을 나눈 경우 시장마다 줄글과 경쟁환경 표를 따로 출력한다. 시장별 표 없이 종합 표만 낸 산출물은 완성본으로 제출하지 않는다.
- 국내외 분리를 선택한 경우 글로벌과 국내 각각에 대해 시장별 줄글과 표를 따로 출력한다.
- 모든 경쟁환경 표는 같은 표준 양식(구분, 강도(현재), 강도(전망), 내용, 근거, 데이터)을 쓴다. 시장 간 비교표처럼 양식을 새로 만들지 않는다.
- 국외 시장을 가리키는 제목과 표에는 "글로벌"로 표기한다.

## 용어 정의

이 문서의 용어는 아래 뜻으로만 쓴다.

| 용어 | 뜻 |
|------|----|
| Force | 산업 수익성을 압박하는 다섯 가지 경쟁 압력. 신규진입자 위협, 공급자 교섭력, 구매자 교섭력, 대체재 위협, 산업 내 경쟁 |
| 강도 | Force 하나가 산업 참여 기업의 수익을 얼마나 압박하는지를 상, 중, 하로 나타낸 값. 상은 압박이 크다는 뜻 |
| 가치사슬 | 산업의 생산부터 최종 활용까지 이어지는 산업 단계. 기업 내부 활동을 나누는 포터의 기업 가치사슬과 다른 개념 |
| 시장 | 가치사슬을 나눠 얻은 각 단계의 시장. 분석과 판정의 기본 단위이며 스킬 내부에서는 분석단위로 부른다 |
| 국내 | 사용자가 지정한 자국. 지정하지 않았다면 사용자에게 묻는다 |
| 구조적 근거 | 단기간에 바뀌기 어려운 산업 조건. 규모의 경제, 자본 집약도, 학습곡선, 특허, 네트워크 효과, 규제와 인허가, 기존 사업자의 누적 투자, 공급 집중도, 전환 비용 등 |
| 잠재적 변화 요인 | 아직 산업 조건을 바꾸지 않은 움직임. 정부 지원 발표, 신규 기업의 진입 시도, 국산화 추진, 대체 기술 연구, 통합 검토 등 |

## 실행 방식

- (자동 모드) 사용자가 산업명만 제시하면 범위 설정부터 종합까지 스킬이 제안하고 수행한다.
- (가이드 모드) 사용자가 범위나 분석단위를 미리 정하면 그 값을 먼저 적용한다.

근거 자료는 사용자가 첨부한 자료를 먼저 쓰고, 부족한 부분은 웹검색으로 채운다. 웹검색 도구가 없는 환경이면 사용자에게 자료 첨부를 요청한다. 모델이 기억하는 지식만으로 산업 정의, 가치사슬, 수치를 만들지 않는다. 출처 없는 정량 데이터는 쓰지 않는다. 출처는 "기관명 또는 저자명(연도), 자료명(링크)" 형식으로 적는다.

## 1단계. 범위 설정

분석할 산업의 경계를 정한다. 사용자가 정하지 않은 항목은 스킬이 제안하고 사용자 확인을 받는다.

| 항목 | 정할 내용 | 예시 |
|------|----------|------|
| 산업명 | 분석 대상 산업 | 수소 에너지 산업 |
| 산업 정의 | 포함 대상과 제외 대상. 인접 산업이 분석 대상인지 대체재인지 구분 | 수소의 생산, 저장유통, 활용을 포함하고 태양광 등 다른 에너지원은 대체재로 취급 |
| 지리적 범위 | 국내 한정, 국외 한정, 국내외 포괄, 국내외 분리 중 택1 | 국내외 포괄 |
| 시간적 범위 | 강도(전망)의 기준 시점. 아래 선택지 중 택1 | 중장기 |
| 가치사슬 분해 | 해당 산업에서 통용되는 단계 구분 | 생산, 저장유통, 활용 |
| 분석단위 구성 | 시장별 분석, 산업 포괄 분석, 두 방식 혼합 중 택1 | 시장별 분석 후 산업 전체 종합 |

시간적 범위 선택지는 아래와 같다. 사용자가 정하지 않으면 중장기를 쓴다.

- 현재: 전망을 내지 않는다.
- 중기 3년 이내, 중장기 5년 이내, 장기 10년 이내, 초장기 30년 이내(장기 투자 검토용), 사용자 지정 기간 중 하나를 고르면 그 시점을 기준으로 전망한다.
- 제한 없음: 기준 시점을 고정하지 않고, 근거 자료가 제시하는 전망 시점을 Force별로 적는다.

범위 설정 원칙은 아래와 같다.

- 가치사슬 시장은 서로 겹치지 않고, 모든 시장을 합치면 산업 전체가 되도록 나눈다.
- 시장 이름은 해당 산업에서 실제로 쓰는 명칭을 쓴다. "소재", "부품", "장비", "인프라" 같은 범용 명칭은 그 산업에서 널리 쓰일 때만 쓴다.
- 가치사슬을 나눌 필요가 없거나 사용자가 포괄 분석을 원하면 산업 전체를 시장 하나로 둔다.
- 지리적 범위는 네 가지 중 하나를 고른다.

| 선택지 | 처리 방식 |
|--------|----------|
| 국내 한정 | 국내 산업만 분석 |
| 국외 한정 | 국외 산업만 분석 |
| 국내외 포괄 | 시장은 가치사슬로 나누고, 국내외 동향을 각 시장 안에서 함께 서술 |
| 국내외 분리 | 시장마다 글로벌 분석을 먼저 하고 국내 분석을 따로 한다. 같은 시장이라도 지역별 경쟁 구조가 다를 수 있으므로 강도와 표를 각각 낸다 |

사용자가 범위를 정하지 않았다면 아래 순서로 진행한다.

1. 첨부 자료가 있으면 그 자료에서 산업 정의와 가치사슬을 뽑는다. 없으면 웹검색으로 파악한다.
2. 파악한 가치사슬로 분석단위 초안을 만든다.
3. 지리적 범위를 사용자에게 묻는다. 답이 없으면 국내외 포괄을 쓴다.
4. 산업 정의, 가치사슬 분해, 지리적 범위를 사용자에게 확인받고 범위를 확정한다.

## 2단계. 근거 수집

시장마다 산업 기초 정보를 먼저 모으고, 이어서 Force별 요인을 모은다.

| 산업 기초 정보 | 수집 대상 |
|---------------|----------|
| 시장규모 | 금액 기준 시장규모. 국내외 분리 시 글로벌과 국내 각각 |
| 시장전망 | 연평균 성장률 등 성장 전망. 전망 기간과 출처 필수 |
| 주요지표 | 매출액, 종사자 수, 기업체 수, 입지계수 등 해당 산업에서 통용되는 지표 |
| 주요 기업 | 시장점유율, 매출액이나 인원 같은 규모, 사업구조와 주력상품, 주요 고객, 주요 경쟁자 |

> (입지계수) 특정 지역의 산업별 고용 비중을 기준 지역의 같은 비중과 비교한 비율로, 1보다 크면 그 지역에 해당 산업이 몰려 있다는 뜻

Force별 요인은 아래 표로 모은다. 표의 조건이 확인되면 강도를 높이는 근거가 되고, 반대 조건이 확인되면 강도를 낮추는 근거가 된다.

| Force | 강도를 높이는 조건 |
|-------|------------------|
| 신규진입자 위협 | 공급 측 규모의 경제가 작다. 이용자가 늘수록 가치가 커지는 네트워크 효과가 약하다. 필요한 자본이 적다. 기술 난이도와 규제, 인허가 장벽이 낮다. 고객의 전환 비용이 낮다. 유통 채널을 확보하기 쉽다. 기존 사업자의 특허, 원가, 입지 우위가 작다. 기존 사업자의 보복 가능성이 낮다(과거 보복 사례, 여유 설비와 자금, 저성장이 없음). 정부가 진입을 지원한다. 최근 신규 진입 사례가 이어진다 |
| 공급자 교섭력 | 공급자 수가 적고 구매 산업보다 집중되어 있다. 공급자 매출에서 이 산업의 비중이 작다. 공급자를 바꾸는 비용이 크다. 공급 품목이 차별화되어 있다. 공급 품목을 대신할 원자재가 없다. 공급자가 전방통합을 마쳤거나 추진 중이다 |
| 구매자 교섭력 | 구매자 수가 적거나 구매 물량이 크다. 제품이 표준화되어 차별화가 작다. 구매자의 전환 비용이 낮다. 구매자가 후방통합을 마쳤거나 추진 중이다. 구매자가 가격에 민감하다(구매 원가에서 이 제품 비중이 크다, 구매자 수익성이 낮다, 구매자 제품 품질에 미치는 영향이 작다) |
| 대체재 위협 | 가격 대비 성능이 나은 대체재가 상용화되어 있다. 대체재로 바꾸는 비용이 낮다. 대체재 시장이 성장하고 있다. 같은 기능을 제공하는 인접 제품의 범위가 넓다 |
| 산업 내 경쟁 | 경쟁자가 많거나 규모가 비슷하다. 시장 성장률이 낮다. 고정비 비중이 크다. 제품 차별화와 전환 비용이 작다. 설비 증설 단위가 커서 공급 과잉이 생기기 쉽다. 퇴출 장벽이 높다 |

- 정부 정책, 보완재, 시장 성장률, 기술 변화는 여섯 번째 Force로 두지 않는다. 위 표의 해당 조건을 거쳐 반영한다.
- 인수합병과 전략적 제휴 같은 수평통합은 경쟁자 수와 규모 분포를 바꾸므로 산업 내 경쟁의 "경쟁자 수와 규모" 조건에 반영한다.
- 수집한 정보는 시장별로 정리해 3단계의 입력으로 쓰고, 정량 데이터마다 출처를 따로 적는다.

## 3단계. 시장별 5-Forces 분석

시장마다 다섯 Force를 차례로 판정하고 서술한 뒤, 시장 현황과 주요 기업을 정리한다. 강도 판정이 결론이고, 시장 데이터와 기업 현황은 그 결론을 받치는 근거다.

### 강도 판정 방법

Force마다 2단계 표의 조건을 하나씩 확인하고, 근거가 있는 조건을 강화 요인과 약화 요인으로 나눈다. 그다음 아래 기준으로 강도를 정한다.

| 강도 | 판정 기준 |
|------|----------|
| 상 | 구조적 근거로 확인된 강화 요인이 있고, 이를 상쇄하는 구조적 약화 요인이 없다 |
| 하 | 구조적 근거로 확인된 약화 요인이 있고, 이를 상쇄하는 구조적 강화 요인이 없다 |
| 중 | 구조적 강화 요인과 약화 요인이 함께 확인되거나, 근거가 어느 한쪽으로 기울지 않는다 |

아래 표는 강도별로 자주 나타나는 조건 조합이다. 실제 판정은 시장별로 모은 근거에 따라 개별로 한다.

| Force | 상 | 중 | 하 |
|-------|----|----|----|
| 신규진입자 위협 | 진입 장벽이 낮고 신규 진입이 활발하다 | 진입 장벽이 있지만 실제 신규 진입 사례가 확인된다 | 규모의 경제, 자본 집약도, 기술 축적, 규제 같은 구조적 장벽이 높다 |
| 공급자 교섭력 | 공급자가 소수이고 대체 원자재가 없으며 전방통합이 실제로 진행 중이다 | 공급자는 많지만 일부 핵심 품목에서 소수 공급자 의존이 확인된다 | 공급자가 많고 원자재 대체가 실제로 이루어지며 전방통합 동인이 없다 |
| 구매자 교섭력 | 구매자 집중도가 높고 전환 비용이 낮으며 후방통합이 실제로 진행 중이다 | 실제 거래 조건에서 구매자와 공급자의 교섭력이 균형을 이룬다 | 구매자가 분산되어 있고 전환 비용이 높으며 대안 공급원이 없다 |
| 대체재 위협 | 가격 대비 성능이 나은 대체재가 상용화되어 시장에 침투 중이다 | 대체재가 상용화되었지만 전환 비용이나 성능 한계로 침투가 제한적이다 | 상용화된 대체재가 없거나 전환 비용이 과도하다 |
| 산업 내 경쟁 | 경쟁자가 많고 성장률이 낮으며 차별화가 부족하고 퇴출 장벽이 높다 | 경쟁자가 있지만 시장 성장으로 공존이 가능하고 실제 가격 경쟁이 제한적이다 | 소수 기업의 과점이 확인되고 기업 간 규모 격차가 크며 시장 성장률이 높고 수평통합이 진행 중이다 |

과점이라도 기업 규모가 비슷하면 선도 기업 없이 점유율 다툼이 벌어지기 쉽다. 그래서 산업 내 경쟁의 하 조건에는 규모 격차를 함께 확인한다.

### 판정 원칙

- 현재 강도는 구조적 근거로 정한다. 잠재적 변화 요인만으로 구조가 견고한 산업의 현재 강도를 바꾸지 않는다.
- 전망 강도를 현재와 다르게 두려면 변화 요인이 전망 기간 안에 실현된다는 근거(투자 집행, 상용화 일정, 계약 체결, 법령 시행일 등)가 필요하다. 실현 시점 근거가 없는 요인은 전망 서술에만 적고 강도는 유지한다.
- 수직통합은 진행 단계에 따라 반영한다. 완료했거나 투자를 집행하며 추진 중이면 현재 강도에 반영하고, 계획 발표 단계면 전망 서술에 적는다.
- 개별 기업 사례나 특정 세그먼트의 특성을 산업 전체로 넓히지 않는다. 판정은 해당 시장 범위 안에서 한다.
- 소수 사례로 Force 전체를 판정하지 않는다. 시간상 앞뒤 관계를 인과관계로 단정하지 않는다.
- 근거에서 판정으로 가는 연결을 제3자가 확인할 수 있어야 한다.

잠재적 변화 요인을 과대 반영하는 대표 사례는 아래와 같다. 이 사례 밖에서도 같은 원리로 구조적 근거를 먼저 확인한다.

| Force | 강도를 바꾸지 않는 근거 | 구조적 근거 |
|-------|------------------------|------------|
| 신규진입자 위협 | 정부가 지원한다, 스타트업이 진입을 시도한다 | 규모의 경제와 자본 장벽이 견고하다 |
| 공급자 교섭력 | 대체 공급자가 등장한다, 국산화를 추진 중이다 | 소수 공급자의 과점이 확인된다 |
| 구매자 교섭력 | 구매자가 자체 생산을 검토한다 | 전환 비용이 높고 대안이 없다 |
| 대체재 위협 | 연구 중인 기술이 있다, 장기적으로 대체될 수 있다 | 상용화 시점이 불확실하다 |
| 산업 내 경쟁 | 신규 기업이 진입하고 있다 | 소수 기업의 과점이 확인된다 |

### 정합성 점검

- (Force 간) 같은 시장 안의 다섯 Force는 서로 영향을 준다. 판정이 서로 모순되지 않는지 확인한다. 예를 들어 신규진입자 위협은 상인데 산업 내 경쟁은 하라면, 두 판정이 함께 성립하는 근거가 있는지 확인한다.
- (시장 간) 인접한 두 시장에서 상류 시장의 구매자는 하류 시장의 사업자이고, 하류 시장의 공급자는 상류 시장의 사업자다. 하류 시장이 상류 시장의 주요 구매자라면 상류 시장의 구매자 교섭력과 하류 시장의 공급자 교섭력은 반대 방향이어야 한다. 상류 시장 구매자 교섭력이 하인데 하류 시장 공급자 교섭력도 하라면 모순이다. 하류 시장이 상류 시장 매출의 일부만 차지하면 두 판정이 반대 방향이 아닐 수 있으므로, 그 매출 비중을 근거에 적는다.
- 시장별 판정을 마친 뒤 인접 시장 사이의 구매자와 공급자 관계를 반대 방향에서 다시 확인한다.

### 서술 양식

Force 소제목은 `(Force명 : 현재 강도→전망 강도) 문장형 제목` 형식으로 쓴다. 문장형 제목은 현재 상태를 짧게 짚고 변화 방향을 뒤에 붙인다. 시간적 범위가 현재면 `(Force명 : 상/중/하) 문장형 제목`으로 쓰고, 본문에서 (현황)과 (전망) 접두어 없이 시사점과 근거를 바로 쓴다.

각 Force 본문에서는 시사점을 먼저 쓰고 근거를 아래에 붙인다. 시사점은 이 Force가 산업 경쟁에 주는 의미이고, 근거는 판정의 이유다. 둘을 한 문장에 섞지 않는다.

```
## 수소 생산시장

### (신규진입자 위협 : 중→상) 기술 장벽은 남아 있으나 생산비용 하락으로 신규 진입 여지 확대

- (현황) 시사점
    + 구조적 근거를 정성적으로 서술
    + 구조적 근거를 정량 데이터로 보강
- (전망) 시사점
    + 구조적 근거를 정성적으로 서술
    + 구조적 근거를 정량 데이터로 보강
> 출처

### (공급자 교섭력 : 중→중) 핵심 소재의 소수 기업 집중이 이어지며 대체 소재 개발이 변수

(같은 구조로 구매자 교섭력, 대체재 위협, 산업 내 경쟁까지 서술)

### 시장 현황

- 시장규모, 시장전망, 주요지표를 서술
> 출처

### 주요 기업

| 기업명 | 국가 | 시장점유율 | 규모 | 사업구조 및 주력상품 | 주요 고객 | 비고 |
|--------|------|-----------|------|---------------------|----------|------|
| A사 | 미국 | 20% | 매출 00억 원 | ... | ... | ... |

- 기업 간 경쟁 구도를 짧게 서술
```

- 주요 기업 표의 열은 수집된 데이터에 맞게 줄이거나 늘릴 수 있다. 기업명, 국가, 규모 열은 빼지 않는다.
- 국내외 분리를 선택했다면 같은 시장에 대해 글로벌 섹션과 국내 섹션을 따로 쓴다. 섹션 배치 순서는 4단계와 같다.

## 4단계. 경쟁환경 종합

시장별 분석 결과를 시장마다 줄글로 종합하고, 줄글 바로 뒤에 표준 경쟁환경 표를 둔다. 줄글에는 그 시장의 경쟁 구조가 가진 특성과 Force 사이의 상호작용이 만드는 패턴을 쓴다.

### 문서 배치 순서

문서는 3단계 본문 전체를 먼저 두고 4단계 종합을 뒤에 둔다. 4단계 섹션은 아래 순서로 배치한다.

1. 시장별 경쟁환경 섹션을 가치사슬 순서대로 둔다. 제목은 "OO시장 경쟁환경"으로 쓴다.
2. 국내외 분리를 선택했다면 글로벌 시장 섹션 전체를 먼저 두고, 국내 시장 섹션 전체를 뒤에 둔다.
3. 국내외 분리와 가치사슬 분해를 함께 선택했다면 글로벌 시장 섹션 뒤에 "글로벌 OO산업 경쟁환경 종합"을, 국내 시장 섹션 뒤에 "국내 OO산업 경쟁환경 종합"을 둔다.
4. 가치사슬을 나눴거나 국내외 분리를 선택했다면 맨 끝에 "OO산업 경쟁환경 종합"을 둔다. 시장 하나만 분석했다면 이 섹션을 생략한다.

국내외 분리와 가치사슬 분해를 함께 선택한 경우의 배치 예시는 아래와 같다.

```
## 글로벌 수소 생산시장 경쟁환경
## 글로벌 수소 저장유통시장 경쟁환경
## 글로벌 수소 활용시장 경쟁환경
## 글로벌 수소 에너지 산업 경쟁환경 종합
## 국내 수소 생산시장 경쟁환경
## 국내 수소 저장유통시장 경쟁환경
## 국내 수소 활용시장 경쟁환경
## 국내 수소 에너지 산업 경쟁환경 종합
## 수소 에너지 산업 경쟁환경 종합
```

각 섹션은 줄글 다음에 표준 경쟁환경 표를 둔다.

### 표준 경쟁환경 표

다섯 Force 행 뒤에 종합 행을 둔다.

| 구분 | 강도(현재) | 강도(전망) | 내용 | 근거 | 데이터 |
|------|-----------|-----------|------|------|--------|
| 신규진입자 위협 | 상/중/하 | 상/중/하 | - (현황) 시사점<br>- (전망) 시사점 | - (현황) 근거<br>- (전망) 근거 | - (현황) 정량 데이터<br>- (전망) 정량 데이터 |
| 공급자 교섭력 | 상/중/하 | 상/중/하 | (같은 구성) | (같은 구성) | (같은 구성) |
| 구매자 교섭력 | 상/중/하 | 상/중/하 | (같은 구성) | (같은 구성) | (같은 구성) |
| 대체재 위협 | 상/중/하 | 상/중/하 | (같은 구성) | (같은 구성) | (같은 구성) |
| 산업 내 경쟁 | 상/중/하 | 상/중/하 | (같은 구성) | (같은 구성) | (같은 구성) |
| 종합 | - | - | 다섯 Force를 종합한 경쟁 구조의 특성 | Force 간 상호작용과 구조적 패턴 | - |

| 열 | 작성 기준 |
|----|----------|
| 구분 | 다섯 Force와 종합 행으로 고정 |
| 강도(현재) | 현재 시점 강도. 상, 중, 하 중 하나 |
| 강도(전망) | 시간적 범위 시점의 강도. 상, 중, 하 중 하나. 시간적 범위가 현재면 열 전체를 "-"로 채워 양식을 유지 |
| 내용 | 이 Force가 산업 경쟁에 주는 시사점. (현황)과 (전망)을 `<br>`로 나눔 |
| 근거 | 강도의 정성적 근거. (현황)은 현재 강도의 구조적 근거, (전망)은 변화 근거 |
| 데이터 | 강도의 정량적 근거와 출처 |

- 시간적 범위가 현재면 내용, 근거, 데이터 칸은 (현황)과 (전망) 접두어와 줄바꿈 없이 바로 쓴다.
- 종합 행의 강도 두 칸과 데이터 칸은 "-"로 둔다. 다섯 Force를 하나의 강도로 합치는 기준이 없기 때문이다.
- 각 칸은 1-2문장으로 줄이고 상세 분석은 3단계 본문에 둔다. 표의 모든 칸은 본문 분석과 일치해야 한다.
- 데이터 칸에는 출처 없는 수치를 쓰지 않는다. 직접 지표가 없으면 출처가 있는 대리 지표를 쓰고 대리 지표임을 밝힌다. 대리 지표도 없으면 "확인된 자료 없음"으로 적는다.

### 산업 전체 종합 표

가치사슬을 나눴다면 시장별 표 뒤에 산업 전체 종합 표를 추가한다. 양식은 표준 경쟁환경 표와 같고 종합 행도 포함한다.

- 산업 전체 강도는 시장별 강도의 단순 평균으로 정하지 않는다. 산업 수익에서 차지하는 비중이 큰 시장(시장규모 비중 등으로 확인)의 판정을 먼저 반영한다.
- 시장 간 강도가 다르면 그 차이와 반영 이유를 근거 칸에 적는다.

## 산출물 작성 기준

산출물은 객관적 서술체로 쓴다. 제목과 소제목에는 해당 산업과 시장의 실제 명칭을 쓰고, 내용만으로 구조가 드러나게 쓴다.

산출물 표면에 드러나면 안 되는 표현은 아래와 같다.

| 유형 | 예시 |
|------|------|
| 스킬 자기 노출 | "본 스킬의 워크플로우에 따라", "4단계 분석을 수행하였음" |
| 자기 정당화 | "모든 Force를 빠짐없이 분석", "시장을 겹침과 빠짐 없이 설정" |
| 내부 용어 노출 | "분석단위", "판정" |
| 내부 섹션명 노출 | "요약 테이블", "Force별 분석 구조", "산업 기초 정보"를 제목으로 사용 |
| 분석 과정 서술 | "먼저 신규진입자 위협을 분석하고 다음으로 공급자 교섭력을 살펴본다" |

"경쟁환경 분석", "산업 구조 분석", "5-Forces" 같은 프레임워크 일반 명칭과 다섯 Force 명칭은 소제목에 써도 된다. 사용자가 특정 용어 노출을 요청하면 그 요청을 따른다.

## 출력 전 점검

- 시장들이 서로 겹치지 않고, 합치면 산업 전체가 되는가
- 각 Force에서 시사점과 근거가 분리되어 있는가
- 근거에서 판정으로 가는 연결을 제3자가 확인할 수 있는가
- 특정 세그먼트나 소수 사례를 산업 전체로 넓히지 않았는가
- 잠재적 변화 요인만으로 현재 강도를 바꾸지 않았는가
- 전망 강도를 바꾼 곳마다 전망 기간 안의 실현 근거가 있는가
- 수직통합 동향이 공급자와 구매자 교섭력에, 수평통합 동향이 산업 내 경쟁에 반영되었는가
- 같은 시장 안의 다섯 Force 판정이 서로 모순되지 않는가
- 인접 시장 사이에서 구매자 교섭력과 공급자 교섭력 판정이 모순되지 않는가
- 강도가 상, 중, 하 세 단계만 쓰였는가
- 정량 데이터마다 출처가 있는가
- 표의 각 칸이 본문 분석과 일치하는가
- 모든 표에 종합 행이 있고 종합 행의 강도 칸이 "-"인가
- 가치사슬을 나눴다면 시장마다 줄글과 표가 따로 있고 산업 전체 종합 표도 있는가
- 산출물에 내부 용어나 분석 과정 서술이 드러나지 않았는가

## 예외

- 사용자가 분석단위를 미리 정하면 그 구성을 적용한다. 시장 간 겹침이나 빠짐이 보이면 사용자에게 알린다.
- 사용자가 강도 판정 기준을 따로 정하면 그 기준을 적용한다.
- 사용자가 특정 Force만 요청하면 그 Force만 분석한다.
- 사용자가 표 없이 본문 분석만 요청하면 표를 생략한다.
